# 太阳辐射在地球大气中的传输

## 一、太阳常数 (Solar Constant)

### 1. 定义
在日地**平均距离** $d_0$ 处，与日光垂直平面上的太阳积分辐照度，记作 $\overline{S}_0$。

$$
\overline{S}_0 = \int_0^\infty \overline{S}_{\lambda,0} \, d\lambda
$$

### 2. 数值
- 公认值：$\overline{S}_0 = 1367 \, \text{W} \cdot \text{m}^{-2}$
- 变化范围：约 $\pm 3 \, \text{W} \cdot \text{m}^{-2}$（太阳活动周期）
- 常用近似值：$1366 \, \text{W} \cdot \text{m}^{-2}$ 或 $1368 \, \text{W} \cdot \text{m}^{-2}$

### 3. 太阳的基本参数
| 参数 | 数值 |
|------|------|
| 太阳半径 $R_\odot$ | $6.96 \times 10^8 \, \text{m}$ |
| 太阳质量 $M_\odot$ | $1.99 \times 10^{30} \, \text{kg}$ |
| 日地平均距离 $d_0$ | $1.496 \times 10^{11} \, \text{m}$ (1 AU) |
| 太阳表面温度（有效温度） | 约 5778 K |
| 太阳辐射通量（总功率） | $3.9 \times 10^{26} \, \text{W}$ |

## 二、大气上界的太阳辐射（日射）

### 1. 大气上界水平面上的太阳辐照度
$$
S_0' = S_0 \cos \theta = \overline{S}_0 \, d_m^2 \, (\sin \phi \sin \delta + \cos \phi \cos \delta \cos \omega)
$$

其中：
- $d_m = d_0 / d$：日地距离修正因子（$d_0$：平均距离，$d$：实际距离）
- $\theta$：太阳天顶角
- $\phi$：地理纬度
- $\delta$：赤纬角（黄道面与赤道面夹角，-23.5° ~ +23.5°）
- $\omega$：时角（正午 $\omega=0$，每小时 $15^\circ$）

### 2. 太阳天顶角 $\theta$ 与太阳高度角
- 太阳天顶角 $\theta$：太阳光线与天顶方向的夹角
- 太阳高度角 $h = 90^\circ - \theta$：太阳光线与水平面的夹角

关系：
$$
\cos \theta = \sin \phi \sin \delta + \cos \phi \cos \delta \cos \omega
$$

### 3. 太阳方位角 $\alpha$
太阳光线水平投影与正北方向的夹角（有些定义与正南）：
$$
\cos \alpha = \frac{\sin \delta - \sin \phi \cos \theta}{\cos \phi \sin \theta}
$$

### 4. 大气上界日总辐射量
$$
Q_d = \int_{t_1}^{t_2} S_0' \, dt = \frac{T}{\pi} \overline{S}_0 \, d_m^2 \, (\omega_0 \sin \phi \sin \delta + \cos \phi \cos \delta \sin \omega_0)
$$
- $T = 86400 \, \text{s}$（一天）
- $\omega_0$：日出时角（$\cos \omega_0 = -\tan \delta \tan \phi$）
- 单位：$\text{J} \cdot \text{m}^{-2} \cdot \text{d}^{-1}$

## 三、太阳辐射在大气中的衰减

太阳辐射进入大气后，由于气体的**吸收**和粒子的**散射**，直接辐射被削弱。削弱程度由**比尔-布格-朗伯定律**描述。

### 1. 总衰减系数
在地面，与日光垂直平面上的太阳分光直接辐照度为：
$$
S_\lambda = S_{\lambda,0} \, \exp\left( -\int_0^\infty k_\lambda \, dl \right)
$$

总体积衰减系数：
$$
k_\lambda = k_{\lambda,R} + k_{\lambda,P} + k_{\lambda,O} + k_{\lambda,v} + k_{\lambda,a} + \cdots
$$

| 符号 | 含义 |
|------|------|
| $k_{\lambda,R}$ | 瑞利散射（空气分子） |
| $k_{\lambda,P}$ | 气溶胶散射（米散射） |
| $k_{\lambda,O}$ | 臭氧吸收 |
| $k_{\lambda,v}$ | 水汽吸收 |
| $k_{\lambda,a}$ | 其他气体（CO₂、O₂等）吸收 |

### 2. 光学厚度形式
$$
S_\lambda = S_{\lambda,0} \, e^{-(\delta_{\lambda,R} + \delta_{\lambda,P} + \delta_{\lambda,O} + \delta_{\lambda,v} + \delta_{\lambda,a})} = S_{\lambda,0} \, \tau_{\lambda,R} \tau_{\lambda,P} \tau_{\lambda,O} \tau_{\lambda,v} \tau_{\lambda,a}
$$
其中 $\tau_{\lambda,i} = e^{-\delta_{\lambda,i}}$ 为各成分的透过率。

## 四、相对大气质量 $m$

### 1. 定义
相对大气质量 $m$ 是太阳光线斜穿路径与天顶垂直路径的光学厚度之比：
$$
m = \frac{\delta(\theta)}{\delta(0)} = \frac{\int_0^\infty k_\lambda \rho \, dl}{\int_0^\infty k_\lambda \rho \, dz}
$$

### 2. 均质无折射大气近似
假设大气密度均匀、无折射，则 $dl = \sec\theta \, dz$，得：
$$
m = \sec\theta
$$

### 3. 实际大气的修正
考虑大气折射和密度非均匀，更精确的近似公式（Kasten & Young, 1989）：
$$
m = \frac{1}{\cos\theta + 0.50572(96.07995^\circ - \theta)^{-1.6364}}
$$
其中 $\theta$ 以度为单位。当 $\theta < 80^\circ$ 时，$\sec\theta$ 近似足够好。

## 五、地面接收的太阳辐射

### 1. 直接辐射
未经散射直接到达地面的太阳辐射（方向性很强）。

### 2. 散射辐射（天空辐射）
被大气分子和气溶胶散射后到达地面的辐射。散射辐射是漫射的，无特定方向。

### 3. 总辐射（全球辐射）
$$
E_{\text{total}} = E_{\text{direct}} \cos\theta + E_{\text{diffuse}}
$$

### 4. 地面反照率
$$
\alpha_g = \frac{\text{反射的太阳辐射}}{\text{入射的太阳辐射}}
$$

| 地面类型 | 反照率 (%) |
|----------|-----------|
| 水面 | 6~8 |
| 阔叶林 | 13~15 |
| 草地、沼泽 | 10~18 |
| 水稻田 | 12~18 |
| 灌木 | 16~18 |
| 田野 | 15~20 |
| 草原 | 20~25 |
| 沙漠 | 25~35 |
| 冰川、雪被 | >50 |

### 5. 云反照率
| 云的类型 | 反照率 (%) |
|----------|-----------|
| 大而厚的积雨云 | 92 |
| 陆地上的淡积云 | 29 |
| 陆地上的积云和层积云 | 69 |
| 海洋上的厚层云 | 64 |
| 陆上卷云 | 36 |

**规律**：
- 云层越厚、含水量越大 → 反照率越大
- 深对流云反射很强
- 海洋上的云影响大（反照率远高于海面）

### 6. 行星反照率
入射地球的太阳辐射被地球-大气系统反射回宇宙空间的总百分数。全球平均行星反照率约为 **0.3 (30%)**，其中**云的贡献最大**。

## 六、太阳辐射传输的特例：臭氧吸收

臭氧对紫外辐射（< 0.3 μm）有强烈吸收。假设臭氧质量混合比为 $w_{O_3}$，密度分布 $\rho_{O_3}(z) = w_{O_3} \rho_0 e^{-z/H}$，则光学厚度：
$$
\delta_\lambda(z) = w_{O_3} \rho_0 k'_{ab,\lambda} H e^{-z/H}
$$

高度 $z$ 处太阳辐照度：
$$
F_\lambda(z) = F_\lambda(0) e^{-\delta_\lambda(z)}
$$

辐射变化率：
$$
\frac{dF_\lambda}{dz} = F_\lambda(0) \cdot \frac{\delta_\lambda(z) e^{-\delta_\lambda(z)}}{H} \cdot e^{-z/H}
$$

**权重函数** $W(z) = \frac{\delta_\lambda(z) e^{-\delta_\lambda(z)}}{H}$，其峰值在 $\delta_\lambda(z) = 1$ 处。即**光学厚度为1的高度是吸收最强的层次**。

## 七、太阳辐射在大气中的衰减总结

```
大气上界太阳辐射 S₀
         │
         ▼
    ┌────┴────┐
    │  吸收   │ ← O₃ (UV), O₂, H₂O, CO₂
    └────┬────┘
         │
    ┌────┴────┐
    │  散射   │ ← 瑞利散射 (分子), 米散射 (气溶胶)
    └────┬────┘
         │
    ┌────┴────┐
    │  反射   │ ← 云、地面
    └────┬────┘
         │
         ▼
   地面接收辐射
   (直接 + 散射)
```

| 行星反照率 $\approx 0.3$ | 地气系统平均 |

## 九、记忆要点

1. **太阳常数** $S_0 = 1367 \, \text{W/m}^2$（日地平均距离处）。
2. **太阳天顶角**是关键因子：$\cos\theta$ 决定水平面入射能量。
3. **衰减机制**：吸收（O₃、H₂O、CO₂）+ 散射（分子、气溶胶）。
4. **相对大气质量** $m = \sec\theta$（简化），修正后可查表。
5. **总辐射** = 直接辐射（方向性）+ 散射辐射（漫射）。
6. **反照率**：雪>沙漠>草地>森林>水面；云的反照率很高，尤其是深对流云。
7. **行星反照率 ≈ 0.3**，云贡献最大。

## 📌 重点

- 太阳常数 $\overline{S}_0 = 1367$ W/m²：日地平均距离处与日光垂直平面的太阳积分辐照度，是地球能量来源的基本参数
- 太阳天顶角$\theta$是关键几何因子：$\cos\theta = \sin\phi\sin\delta + \cos\phi\cos\delta\cos\omega$，决定水平面接收的太阳能量$S_0' = \overline{S}_0 d_m^2 \cos\theta$
- 衰减机制：吸收（O₃紫外、H₂O近红外、CO₂）+散射（瑞利散射$\propto \lambda^{-4}$、米散射），总衰减$S_\lambda = S_{\lambda,0} e^{-(\delta_R+\delta_P+\delta_O+\delta_v+\delta_a)}$
- 相对大气质量$m = \sec\theta$（简化）：太阳天顶角越大，光线穿过大气路径越长，衰减越强→日出日落红色
- 总辐射=直接辐射（方向性）+散射辐射（漫射/天空辐射）；地面积雪时散射辐射可从地面反射后再散射→增强天空亮度
- 行星反照率约0.3（30%），云贡献最大：云层越厚、含水量越大→反照率越高（Cb可达92%）；雪面>50%，水面仅6-8%
- 臭氧对UV（<0.3 μm）的强吸收是平流层增温的主要热源；权重函数峰值在$\delta=1$处
- 日地距离修正$d_m = d_0/d$：近日点（1月）太阳辐照度比远日点（7月）高约7%

## 🤔 思考题

> **思考题 1**：太阳常数1367 W/m²在一年中约有±3%的变化，主要受什么影响？为什么北半球冬季（近日点）太阳常数最大，但北半球冬季反而比南半球冬季更冷？
> **思考题 2**：在极地夏季，太阳天顶角可以很小吗？用$\cos\theta = \sin\phi\sin\delta + \cos\phi\cos\delta\cos\omega$分析：在北极（$\phi=90°$）极昼期间$\cos\theta = \sin\delta$，为什么极地接收的太阳辐射仍然很少？
> **思考题 3**：为什么日出和日落时（太阳天顶角大）地面接收的太阳辐射中，散射辐射的比例很高？从直接辐射的路径衰减和散射辐射贡献的相对变化分析。
> **思考题 4**：若某地地面反照率为0.2，到达地面的总辐射为800 W/m²，地面吸收的太阳短波辐射是多少？若地面比辐射率为0.95，温度为300 K，地面长波净辐射约为多少？
> **思考题 5**：云的反照率与云光学厚度/云水路径的关系是怎样的？Twomey效应（云反照率随CCN浓度增加而增大）对气候模拟有何意义？
