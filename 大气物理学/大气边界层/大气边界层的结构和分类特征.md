# 大气边界层的结构和分类特征

## 一、大气边界层的基本概念

### 1. 定义
**大气边界层**（Atmospheric Boundary Layer, ABL）是指大气最底层直接受下垫面影响的区域，其厚度从几百米到两三千米不等。在这一层中：
- 湍流输送（动量、热量、水汽、污染物）占主导地位
- 风速、温度、湿度等物理量有明显的**日变化**
- 下垫面的强迫（动力和热力）通过湍流向上传递

### 2. 边界层的主要特征
| 特征 | 描述 |
|------|------|
| 湍流主导 | 动量、热量、水汽的垂直交换主要通过湍流完成，分子扩散可忽略 |
| 日变化显著 | 晴好天气下，边界层结构有明显的日循环 |
| 快速响应 | 对下垫面变化（日出、日落、地表类型变化）响应时间短（分钟至小时） |
| 厚度变化大 | 从几十米（夜间稳定边界层）到 2~3 km（白天对流边界层） |

### 3. 边界层与自由大气的区别
| 特征 | 大气边界层 | 自由大气 |
|------|-----------|----------|
| 湍流 | 强，主导输送 | 弱，可忽略 |
| 摩擦作用 | 重要 | 可忽略 |
| 风场 | 有风切变，风向随高度变化（埃克曼螺线） | 近似地转风 |
| 日变化 | 显著 | 不明显 |
| 厚度 | 几百米~几公里 | 几公里~几十公里 |

## 二、大气边界层的分层结构

根据湍流特性和物理量垂直分布，边界层通常分为三层：

### 1. 近地面层（Surface Layer，常通量层）
- **厚度**：最底部约 10% 的边界层厚度（几十米）
- **特征**：
  - 湍流通量（动量、感热、潜热）随高度变化很小（≈常数）
  - 风廓线服从对数定律（中性）或对数+线性修正（非中性）
  - 莫宁-奥布霍夫相似理论适用
  - 分子粘性可忽略（但紧贴地表有粘性次层）

### 2. 混合层（Mixed Layer）
- **存在条件**：仅存在于**对流边界层**（不稳定层结）
- **厚度**：从近地面层顶部到边界层顶（约占 80~90% 边界层厚度）
- **特征**：
  - 强烈混合，位温、比湿、风速等**垂直均匀**
  - 湍流强，大涡主导
  - 浮力对流为主，上升热泡和补偿下沉运动
  - 动量、热量、水汽垂直输送强

### 3. 夹卷层（Entrainment Zone）
- **位置**：边界层顶部与自由大气之间的过渡层
- **厚度**：几十米到几百米
- **特征**：
  - 暖空气从自由大气向下卷入边界层
  - 存在逆温（对流边界层顶的逆温盖）
  - 夹卷过程使边界层高度增长
  - 云（积云）常在此层顶部形成

> **注意**：在稳定边界层中，没有明显的混合层，取而代之的是**稳定层**（stable layer），湍流弱且间歇。

## 三、大气边界层的分类

根据**热力层结**（稳定度）和**动力机制**，边界层分为三种主要类型：

### 1. 对流边界层（Convective Boundary Layer, CBL）
- **层结**：**不稳定**（地表加热）
- **形成**：白天太阳辐射加热地面，地面感热通量向上
- **特征**：
  - 强烈的上升热泡和补偿下沉
  - 混合层内位温、风、湿度垂直均匀
  - 垂直速度方差大，$\sigma_w \sim 1.2 w_*$（$w_*$ 为对流速度尺度）
  - 顶部有逆温夹卷层
- **厚度**：几百米~2 km（夏季午后可达 2~3 km）
- **湍流能量来源**：浮力（热力）为主，机械切变为辅

### 2. 中性边界层（Neutral Boundary Layer, NBL）
- **层结**：**中性**（位温垂直均匀）
- **形成**：强风、阴天、夜间强风混合
- **特征**：
  - 无浮力作用，纯机械湍流
  - 风廓线呈对数分布
  - 垂直速度方差 $\sigma_w \sim 1.25 u_*$
  - 湍流连续，强度较弱
- **厚度**：几百米~1 km（取决于风速和粗糙度）
- **湍流能量来源**：风切变（机械产生）

### 3. 稳定边界层（Stable Boundary Layer, SBL）
- **层结**：**稳定**（地表冷却）
- **形成**：夜间地面辐射冷却，或暖平流经冷表面
- **特征**：
  - 浮力抑制湍流，湍流弱且**间歇**
  - 风切变是唯一能量来源，但需克服稳定度
  - 当 $Ri > 0.25$ 时，湍流可能完全停止（层流化）
  - 常出现低空急流（Low-Level Jet, LLJ）
- **厚度**：几十米~几百米（通常 < 500 m）
- **湍流能量来源**：风切变（但受稳定度抑制）

## 四、边界层的日变化

在典型晴好天气下，边界层结构呈现明显的日循环：

### 1. 白天（日出后~日落前）
- **不稳定边界层**（CBL）发展
- 地面加热 → 近地面层首先不稳定 → 热泡上升 → 混合层形成
- 边界层高度逐渐增长，午后达到最大
- 夹卷层顶部卷吸自由大气暖空气，使边界层进一步发展

### 2. 傍晚（日落前后）
- 地面辐射冷却开始
- 近地面形成**稳定边界层**（SBL）
- 残余层（Residual Layer）：白天混合层的一部分残留，保持较高位温，但与地面切断联系

### 3. 夜间
- **稳定边界层**（SBL）持续，厚度约 50~300 m
- 残余层（RL）在上方，中性或弱稳定，无湍流
- 清晨出现强逆温（辐射逆温最大）

### 4. 清晨
- 日出后地面加热，稳定边界层被破坏
- 新对流边界层从地面向上发展，通过夹卷吞没残余层
- 边界层高度快速上升

**日变化示意图**（概念）：
```
高度
  ↑
  |     残余层(RL)         自由大气
  |     (中性/弱稳定)       (层流)
  |    ┌────────────┐
  |    │  夜间稳定  │
  |    │  边界层    │
  |    └────┬───────┘
  +────────────────────→ 时间
    日落  午夜  日出  正午
```

## 五、边界层高度的定义与变化

### 1. 边界层高度的定义
不同方法定义边界层高度：
| 方法 | 定义 |
|------|------|
| 位温廓线 | 从地面向上，位温开始明显增长的高度（CBL顶） |
| 湍流动能 | TKE 降到最小值（如 0.05 m²/s²）的高度 |
| 风廓线 | 风速接近地转风的高度 |
| 逆温层底 | 稳定边界层顶部（逆温层开始的高度） |

### 2. 典型厚度变化
- **对流边界层（CBL）**：中午可达 1~2 km（夏季内陆可超 2 km）
- **中性边界层（NBL）**：500 m~1 km
- **稳定边界层（SBL）**：50~300 m

### 3. 影响边界层厚度的因素
- **热力**：地表热通量越大 → CBL 越高
- **动力**：风速越大 → 机械混合越强 → 边界层越高（特别是中性和稳定）
- **天气系统**：高压下沉抑制边界层发展；低压抬升可增加厚度
- **地形**：山地、城市可增加边界层高度

## 六、边界层中的风场特征

### 1. 埃克曼螺线（Ekman Spiral）
在理想中性、定常、水平均匀条件下，湍流粘性使风向随高度向右偏转（北半球），风速随高度增大并趋近地转风。

### 2. 风速廓线
- **近地面层**：对数律（中性）或对数+线性修正（非中性）
- **混合层**：风速垂直变化小（强混合）
- **稳定边界层**：可能出现低空急流（LLJ），风速最大高度在逆温层顶附近

### 3. 边界层风场与自由大气的区别
| 高度 | 风向 | 风速 |
|------|------|------|
| 地面 | 与等压线有一交角（摩擦导致） | 小 |
| 边界层内 | 随高度向右偏转（北半球） | 增加 |
| 边界层顶 | 接近地转风方向 | 接近地转风速 |

---

## 七、边界层在大气科学中的重要性

1. **物质能量交换**：地面与大气之间的动量、热量、水汽、污染物交换的唯一通道
2. **云的形成**：边界层顶的夹卷和抬升触发层云、积云
3. **污染扩散**：决定污染物地面浓度和分布（CBL扩散快，SBL扩散慢）
4. **天气预报**：影响温度、湿度、风的预报；边界层参数化是数值模式的关键
5. **气候系统**：影响地表通量反馈（土壤湿度-降水反馈等）

## 八、不同边界层类型对比总结

| 特征 | 对流边界层（CBL） | 中性边界层（NBL） | 稳定边界层（SBL） |
|------|------------------|------------------|------------------|
| 层结 | 不稳定 | 中性 | 稳定 |
| 发生时间 | 白天（晴） | 阴天/强风/夜间强风 | 夜间（晴/少云） |
| 主要湍流源 | 浮力（热力） | 机械（切变） | 机械（切变，但受抑制） |
| 湍流强度 | 强 | 中等 | 弱/间歇 |
| 位温廓线 | 近地面超绝热，混合层均匀，顶部逆温 | 垂直均匀 | 随高度增加 |
| 厚度 | 0.5~2 km | 0.3~1 km | 50~300 m |
| 垂直速度方差 | 大（$\sigma_w \sim 1.2 w_*$） | 中等（$\sigma_w \sim 1.25 u_*$） | 小 |
| 夹卷 | 强烈 | 弱 | 可忽略 |
| 云 | 积云（云底在夹卷层） | 无或层云 | 雾、层云 |

## 九、记忆要点

1. **边界层三层结构**：近地面层（常通量层）+ 混合层（仅CBL）+ 夹卷层（顶部）。
2. **三种边界层类型**：CBL（不稳定）、中性（中性）、SBL（稳定）。
3. **日变化**：白天CBL + RL → 夜间SBL + RL → 早晨CBL吞并RL。
4. **CBL**：强浮力湍流，混合均匀，顶部逆温，积云常见。
5. **SBL**：弱间歇湍流，逆温强，低空急流，雾常见。
6. **边界层高度**：热力和动力共同控制。
7. **重要性**：地面-大气交换的唯一通道，影响天气、气候、污染。

## 📌 重点

- 边界层三层结构：近地面层（常通量层，~10%厚度）→混合层（仅CBL，位温均匀，大涡混合）→夹卷层（顶部逆温过渡层，卷吸自由大气）
- 三种边界层类型：对流边界层CBL（不稳定，浮力主导，白天，厚度0.5-2 km）、中性边界层NBL（强风/阴天，机械湍流）、稳定边界层SBL（稳定，夜间，厚度50-300 m，湍流间歇）
- CBL位温廓线特征：近地面超绝热层→混合层（$\partial\theta/\partial z \approx 0$）→顶部逆温盖（夹卷层）；湍流能量以浮力为主
- SBL特征：位温随高度增加（逆温），风切变是唯一湍流源但需克服$Ri>0.25$的抑制，常出现低空急流（LLJ）和间歇湍流爆发
- 边界层日循环：白天CBL发展（混合层增长）→傍晚形成SBL+残余层RL→夜间SBL持续+RL在上→清晨CBL从地面重新发展→吞并RL
- 残余层（RL）：白天混合层夜间残留部分，保持中性层结和较高位温，但与地面切断湍流联系
- 边界层是地面-大气动量/热量/水汽/污染物交换的唯一通道，对天气、气候、污染扩散至关重要
- 埃克曼螺线：边界层内风随高度向右偏转（北半球），风速增大趋近地转风；地面风与等压线有摩擦交角
