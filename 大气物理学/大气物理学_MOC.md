## 交叉知识链接

大气物理学与动力气象学的核心交叉点：

| 大气物理学 | 连接点 | 动力气象学 |
|-----------|--------|-----------|
| 静力学方程 | → 气压-高度的静力平衡 ← | 尺度分析的铅直简化 |
| 位温、$N^2$ | → 稳定度判据 ← | 重力内波恢复力 |
| 虚温 | → 状态方程 ← | 基本方程组闭合 |
| Clausius-Clapeyron | → 水汽潜热 ← | CISK理论能量源 |
| 积云微物理 | → 对流参数化 ← | 条件不稳定与积云 |
| 辐射传输 | → 非绝热加热 $\dot{Q}$ ← | 热力学能量方程 |
| 边界层湍流通量 | → Reynolds应力 ← | Ekman层动量方程 |

---

> **学习建议**：先掌握大气成分和状态方程（第1章），然后理解垂直结构（第2章），再深入热力学（第3章），这是后续辐射学（第4章）和云物理学（第5章）的基础。边界层（第6章）相对独立，可与前几章并行学习。公式只是物理图像的数学表达，先理解再记忆。

## 📌 重点

- 大气物理学六大板块：成分与分布→气压场与分层→热力学→辐射学→云和降水物理学→边界层
- 学习路径：状态方程（$p=\rho R_d T$，$T_v$）→静力平衡（$dp/dz=-\rho g$）→热力学（$\gamma_d$，稳定度）→辐射（Planck/$T_e=255$ K/温室效应）→云物理（CCN→凝结→碰并→降水）
- 六大核心方程贯通全课程：状态方程、静力学方程、热力学第一定律、C-C方程、Schwarzchild方程、TKE方程
- 与动力气象的七大交叉点（见交叉知识链接表）：位温$N^2$连接稳定度与重力波，辐射$\dot{Q}$驱动非绝热加热，边界层通量对应Reynolds应力
- 学习策略：先建立物理图像再记忆公式；注重量级估算（$\gamma_d=9.8$ K/km，$R_d=287$，$T_e=255$ K），理解"数量vs质量"竞争在云微物理中的核心地位

## 🤔 思考题

> **思考题 1**：大气物理学的六大板块形成了怎样的知识逻辑链？从"大气由什么组成"出发，到"大气如何运动、如何辐射、如何形成云雨"——画出这个知识逻辑图。
> **思考题 2**：静力平衡$\partial p/\partial z = -\rho g$在大气物理学中反复出现（压高公式、稳定度判据、边界层参数化等），为什么这个简单方程如此重要？它连接了哪些物理量？
> **思考题 3**：C-C方程$de_s/dT = L e_s/(R_v T^2)$是一个纯热力学方程，但它对云物理（贝吉龙过程）、辐射（水汽反馈）和动力气象（CISK）都有深远影响。从大气物理学的视角，为什么这个"小方程"如此重要？
