# 形成大气逆温层的原因

## 一、逆温层的基本概念

### 1. 定义
**逆温层**是指大气中温度随高度**增加**（即 $\frac{dT}{dz} > 0$）或温度递减率小于零（$\Gamma = -\frac{dT}{dz} < 0$）的层次。逆温层是对流层中稳定度很高的气层，对垂直运动有强烈抑制。

### 2. 逆温层的特征
- 温度随高度**升高**，或等温（$\Gamma = 0$）
- 大气**绝对稳定**（$\Gamma < \gamma_d$，且通常 $\Gamma \leq 0$）
- 抑制对流和湍流发展，有利于雾、霾、层云的维持

### 3. 逆温层的气候学意义
- 抑制污染物扩散 → 导致重污染天气（如雾霾）
- 影响云和降水的发展
- 夜间辐射逆温可导致霜冻

---

## 二、逆温层的形成机制

根据成因不同，逆温层分为以下几种类型：

### 1. 辐射逆温（夜间逆温）

**形成条件**：晴朗、微风的夜间，地面因长波辐射冷却而降温，近地面空气随之冷却，上层空气冷却较慢，形成下冷上暖的逆温结构。

**特征**：
- 在**地面**开始，厚度从几十米到几百米（冬季可达数百米）
- 强度取决于地表有效辐射大小（晴朗干燥的夜间最强）
- 日出后随太阳加热地面而逐渐消失
- 冬季和夜间常见

**示意图**：
```
高度 (m)
   ↑
300 ┤   温暖空气
    │
100 ┤  ┌── 逆温层顶
    │  │
  0 ┤──┴── 地面（强冷却）
       0    5    10   温度(°C)
        逆温层内温度随高度增加
```

### 2. 平流逆温

**形成条件**：暖空气平流到冷的下垫面上（如暖流经过冷洋面、暖空气移过雪地），下层空气受冷而下层降温，形成逆温。

**特征**：
- 可发生在**任何时间**（昼夜皆可）
- 厚度较大（可达数百米到上千米）
- 常见于中高纬度沿海地区（暖湿空气平流到冷洋面）
- 平流雾常与此类逆温相伴

### 3. 下沉逆温

**形成条件**：高压区（反气旋）中，气流下沉导致压缩增温，且下层比上层增温更强，形成逆温。

**特征**：
- 通常在**几百米到两三千米**高度出现
- 稳定层结抑制对流，常与晴好天气、霾层有关
- 副热带高压控制区常见
- 下沉逆温顶部常有层云或层积云

**物理机制**：
下沉气流绝热压缩升温。如果下沉气层厚度大，下层压缩更剧烈，温度升高更多；同时气层顶部还可能受辐射冷却，增强逆温。

### 4. 锋面逆温

**形成条件**：冷锋或暖锋锋区附近，暖空气位于冷空气之上，形成逆温。

**特征**：
- 逆温层出现在**锋区**内部（冷暖空气交界面附近）
- 厚度随锋面强度而异
- 伴随锋面云系和降水
- 冷锋逆温通常较低（几百米），暖锋逆温可在较高高度（1-3 km）

### 5. 地形逆温

**形成条件**：在谷地、盆地中，夜间山坡辐射冷却导致冷空气沿山坡下沉，在谷底聚集，将暖空气抬升，形成低层逆温。

**特征**：
- 局地性强（山区、盆地）
- 夜间形成，早晨最强
- 如四川盆地、兰州河谷等
- 常导致严重的空气污染事件

### 6. 对流层顶逆温（平流层底逆温）

**形成条件**：对流层顶附近，由于平流层臭氧吸收紫外线加热，温度随高度增加。

**特征**：
- 出现在**对流层顶**（约10-16 km高度）
- 是大气**永久性**结构，并非局地现象
- 分隔对流层和平流层，是重要的动力学边界

## 三、逆温层的强度与厚度

### 1. 强度
温度随高度增加的速率，单位：°C/100 m 或 K/km。

- 辐射逆温：通常 1-3°C/100 m（强时可达 5-10°C/100 m）
- 下沉逆温：较弱，0.5-2°C/100 m
- 锋面逆温：强度变化大，可强可弱

### 2. 厚度
- 辐射逆温：几十米到几百米（冬季可达 500 m）
- 平流逆温：几百米到上千米
- 下沉逆温：几百米到 2 km
- 对流层顶逆温：约 1-2 km

## 四、逆温层对天气和污染的影响

### 1. 抑制垂直运动
逆温层中 $\Gamma < 0$，绝对稳定，任何垂直运动（对流、湍流）都被抑制。

### 2. 形成雾和低云
- 近地面逆温 → 水汽在冷表面凝结 → 辐射雾
- 平流逆温 → 平流雾
- 逆温层顶附近水汽相对饱和 → 层云或层积云

### 3. 加剧空气污染
逆温层像"盖子"一样阻止污染物向上扩散，导致近地面污染物浓度急剧升高 → 形成霾或光化学烟雾。

**典型案例**：
- 1952 伦敦烟雾事件（辐射逆温 + 燃煤污染）
- 四川盆地、京津冀冬季雾霾（地形逆温 + 静稳天气）

### 4. 影响农业
- 辐射逆温引起的霜冻（晴夜强辐射冷却 → 地面温度降到 0°C 以下）
- 果园常使用大型风扇或加热器扰动逆温层，防止霜冻

## 五、逆温层的探测与识别

### 1. 常规探空
无线电探空仪（探空气球）测量 T、p、RH 垂直廓线，可直接识别逆温层。

### 2. 温度对数压力图（T-log p）识别
- 逆温层：温度随高度增加（曲线向左弯，即随高度升高温度向低温区移动？需注意坐标）
  - 在 T-log p 图上，横坐标为温度，纵坐标为 $-\ln p$（向上递减）。逆温时，温度随高度增加 → 在图上温度廓线随高度增加而向右偏。
- 等温层：温度廓线垂直

### 3. 地面观测
- 雾或霾的持续存在
- 烟囱烟羽扩散呈"平铺"状
- 夜间温度地面低于上层（自动气象站数据）

## 六、逆温层与其他大气过程的联系

### 1. 与稳定度的关系
逆温层属于**绝对稳定**层结。即使在条件性不稳定层结中，如果存在逆温盖层，可抑制对流发展（CIN 很大），直到地面加热足够强才能突破。

### 2. 与大气边界层的关系
- 夜间稳定边界层（SBL）顶部常存在逆温
- 残留层上方的逆温是前一夜辐射逆温残留

### 3. 与平流层-对流层交换的关系
对流层顶逆温是平流层下层臭氧加热的结果，这个逆温层阻碍了对流层和平流层之间的物质交换（除对流层顶折叠等特殊过程）。

## 七、逆温层成因总结表

| 类型 | 形成原因 | 典型高度 | 时间特征 | 天气特征 |
|------|----------|----------|----------|----------|
| 辐射逆温 | 夜间地面辐射冷却 | 近地面（几十~几百米） | 夜间至清晨 | 晴、微风、雾或霜 |
| 平流逆温 | 暖空气平流到冷下垫面 | 几百米~1 km | 昼夜均可 | 平流雾、层云 |
| 下沉逆温 | 高压区下沉压缩增温 | 数百米~2 km | 稳定天气时 | 晴好、霾层 |
| 锋面逆温 | 冷暖气团交界面 | 锋区高度 | 锋面过境前后 | 云雨天气 |
| 地形逆温 | 冷空气在山谷堆积 | 近地面（谷底） | 夜间、冬季 | 局地重污染 |
| 对流层顶逆温 | 臭氧UV加热 | 10-16 km | 永久存在 | 对流层顶 |

## 八、记忆要点

1. **逆温** = 温度随高度增加，$\Gamma < 0$，绝对稳定。
2. **辐射逆温**：晴夜、地面冷却 → 近地面最强逆温。
3. **平流逆温**：暖空气过冷地面 → 厚逆温。
4. **下沉逆温**：高压下沉区 → 中高层逆温，抑制对流。
5. **锋面逆温**：锋区内部冷暖交界面。
6. **地形逆温**：盆地/山谷夜间冷空气堆积。
7. **危害**：抑制扩散 → 雾霾加重；霜冻。
8. **识别**：探空廓线、T-log p 图、地面雾气持续。

## 📌 重点

- 逆温层$\Gamma = -dT/dz < 0$→温度随高度增加→绝对稳定→强抑制垂直运动（对流和湍流均被压制）
- 六种逆温成因：辐射（晴夜地面冷却）、平流（暖空气→冷下垫面）、下沉（高压压缩增温）、锋面（冷暖交界面）、地形（山谷冷空气堆积）、对流层顶（臭氧UV加热）
- 辐射逆温最强在晴空微风夜间（$E_0 = \epsilon_g(\sigma T_g^4 - E_{l,0}^\downarrow)$最大），云和大风减弱逆温
- 逆温层的环境效应：污染物"盖帽"效应→重霾事件→伦敦烟雾型；霜冻→农业灾害
- 下沉逆温在副热带高压区常见（绝热压缩增温），对霾层维持起关键作用
- 对流层顶逆温是臭氧吸收UV辐射加热形成的永久结构→阻碍平流层-对流层交换
- 在条件不稳定层结中，逆温是"CIN盖"→需足够地面加热或抬升才能突破→触发强对流
