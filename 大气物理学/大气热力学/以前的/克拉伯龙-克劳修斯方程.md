# 克拉伯龙-克劳修斯方程的推导方法
## 第一步：相平衡条件
- 当气液两相处于平衡时，两相的吉布斯自由能变化相等，即：
$$\mathrm{d}g_v = \mathrm{d}g_l$$
- **气相**（水汽）的吉布斯自由能变化：
- $$\mathrm{d}g_v = v_v \, \mathrm{d}e - s_v \, \mathrm{d}T$$
- **液相**（液态水）的吉布斯自由能变化：
  $$\mathrm{d}g_l = v_l \, \mathrm{d}e - s_l \, \mathrm{d}T$$
## 第二步：联立方程
- 在相平衡时，$\mathrm{d}g_v = \mathrm{d}g_l$，代入得：
$$
v_v \, \mathrm{d}e - s_v \, \mathrm{d}T = v_l \, \mathrm{d}e - s_l \, \mathrm{d}T
$$
- 整理后得到：
$$
(v_v - v_l) \, \mathrm{d}e = (s_v - s_l) \, \mathrm{d}T
$$
- 进一步化简为：
$$
\frac{\mathrm{d}e}{\mathrm{d}T} = \frac{s_v - s_l}{v_v - v_l}
$$
## 第三步：引入潜热
- 相变潜热 $L$（如蒸发潜热）定义为：
$$
L = T(s_v - s_l)
$$
- 代入上式得：
$$
\frac{\mathrm{d}e}{\mathrm{d}T} = \frac{L}{T(v_v - v_l)}
$$
## 第四步：理想气体近似
- 对气相应用理想气体状态方程：[[牢三样/动力气象/以前的学习/第二章/理想气体#^3477d2]]
$$v_v = \frac{R^*T}{e}$$
- 其中 $R^*$ 为水汽比气体常数（$461.5\ \mathrm{J/kg \cdot K}$）。液态水体积 $v_l$ 远小于气相体积，可忽略（$v_v \gg v_l$），因此：
$$
\frac{\mathrm{d}e}{\mathrm{d}T} = \frac{L e}{R^* T^2}
$$
#### **第六步：积分求解**
- 分离变量后积分：
$$
\int \frac{\mathrm{d}e}{e} = \int \frac{L}{R^* T^2} \, \mathrm{d}T
$$
- 假设 $L$ 为常数，积分结果为：
$$
\ln \frac{e}{e_0} = -\frac{L}{R^*}\left(\frac{1}{T} - \frac{1}{T_0}\right)
$$
- 取指数形式：
$$
e(T) = e_0 \exp\left[\frac{L}{R^*}\left(\frac{1}{T_0} - \frac{1}{T}\right)\right]
$$
#### **最终形式**
- 克拉珀龙-克劳修斯方程的微分形式为：
$$
\frac{\mathrm{d}e}{\mathrm{d}T} = \frac{L e}{R^* T^2}
$$
- 或积分形式：[[湿度参量#^c91d4c]]
$$
e(T) = e_0 \exp\left(-\frac{L}{R^* T}\right)
$$

```python
import numpy as np
import matplotlib.pyplot as plt

# 常量定义
R = 461.5  # 水汽比气体常数，单位：J/(kg·K)
L = 2.5e6  # 汽化潜热，单位：J/kg
T0 = 273.15  # 参考温度，单位：K
e0 = 611.2  # 参考温度下的饱和水汽压，单位：Pa

# 计算饱和水汽压的函数
def calculate_saturation_vapor_pressure(T):
    return e0 * np.exp((L / R) * (1 / T0 - 1 / T))

# 温度范围（-20°C 到 40°C）
T_min = 253.15  # -20°C
T_max = 313.15  # 40°C
T = np.linspace(T_min, T_max, 100)  # 生成100个温度点

# 计算饱和水汽压
e_s = calculate_saturation_vapor_pressure(T)

# 绘制曲线
plt.figure(figsize=(6, 5))
plt.plot(T - 273.15, e_s/100, label="Saturation Vapor Pressure", color="blue")
plt.xlabel("Temperature (°C)")
plt.ylabel("Saturation Vapor Pressure (hPa)")
plt.title("Clausius-Clapeyron Equation")
plt.grid(True)
plt.legend()
plt.show()

```
