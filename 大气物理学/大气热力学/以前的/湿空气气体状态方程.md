
# 湿空气气体状态方程推导

## 1. **干空气状态方程**
干空气满足理想气体状态方程：[[干空气气体状态方程]]
$$
p_d = \rho_d R_d T
$$

水汽分压 $e$ 满足类似形式：
$$
e = \rho_v R_v T
$$
其中：
- $\rho_v$ 为水汽密度  
- $R_v = 461 \, \mathrm{J/(kg \cdot K)}$ 为水汽比气体常数  
---
## 2. **湿空气总压与密度**
根据道尔顿分压定律，湿空气总压为：
$$
p = p_d + e = (\rho_d R_d + \rho_v R_v) T
$$
湿空气总密度为：
$$
\rho = \rho_d + \rho_v
$$
定义比湿$q$为水汽质量与湿空气质量之比：[[湿度参量#^80b0db]]
$$
q = \frac{\rho_v}{\rho_d + \rho_v} \implies \rho_v = \rho q, \quad \rho_d = \rho (1 - q)
$$
将 $R_d$ 和 $R_v$ 按质量加权平均，得到湿空气气体常数：
$$
R_m = (1 - q) R_d + q R_v = R_d \left( 1 + q \left( \frac{R_v}{R_d} - 1 \right) \right)
$$
由于 $\frac{R_v}{R_d} = \frac{461}{287} \approx 1.608$，得：
$$
R_m = R_d (1 + 0.608q)
$$
将混合气体常数代入总压方程：
$$
p = \rho R_m T = \rho R_d (1 + 0.608q) T
$$
定义虚温：
$$
T_v = T (1 + 0.608q)
$$
**湿空气状态方程**最终形式为：
$$
p = \rho R_d T_v
$$
## **虚温物理意义**
虚温 $T_v$ 是干空气在相同压强下具有与湿空气相同密度时所需的温度。  
- 水汽的存在（$q > 0$）使湿空气密度小于干空气密度，等效于虚温升高。  
- 虚温修正使湿空气状态方程形式上与干空气一致，便于实际应用。


```python
def calculate_moist_air_density(p_hPa, t_c, q):
    """
    计算湿空气密度的Python函数
    
    参数：
    p_hPa : float  # 总气压（单位：hPa）
    t_c   : float  # 温度（单位：摄氏度）
    q     : float  # 比湿（无量纲，kg/kg）
    
    返回：
    rho   : float  # 湿空气密度（单位：kg/m³）
    """
    # 物理常数
    R_d = 287.0  # 干空气比气体常数 [J/(kg·K)]
    
    # 单位转换
    T_kelvin = t_c + 273.15       # 摄氏温度转开尔文
    p_pa = p_hPa * 100            # 气压转帕斯卡
    
    # 计算虚温
    T_v = T_kelvin * (1 + 0.608 * q)
    
    # 状态方程计算密度
    rho = p_pa / (R_d * T_v)
    
    return rho

p = 1013.0 # hPa 
temp = 25.0 # °C 
q = 0.012 # 比湿 12 g/kg 
density = calculate_moist_air_density(p, temp, q)

print(density)
```
