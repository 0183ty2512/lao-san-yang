# 大气静力稳定度判据以及条件性不稳定

## 一、大气静力稳定度的基本概念

### 1. 定义
处于静力平衡状态的大气层中，空气块受到动力或热力扰动产生向上或向下的垂直运动后，能否继续发展（远离平衡位置）或返回平衡位置，取决于**大气层结**（温度和湿度的垂直分布）。大气的这种属性称为**大气静力稳定度**（或称层结稳定度）。

### 2. 与动力稳定度的区别
- **静力稳定度**：关注气块受扰动后是否容易发生垂直运动（取决于浮力）
- **动力稳定度**：关注气流本身的动力学不稳定性（如惯性不稳定、对称不稳定等）

### 3. 阿基米德浮力
单位质量气块在垂直方向上的运动方程：
$$
\frac{dw}{dt} = -\frac{1}{\rho}\frac{\partial p}{\partial z} - g
$$

由于气块与环境满足静力平衡近似（准静力条件），且气压连续，环境气压梯度满足 $\frac{\partial p_e}{\partial z} = -\rho_e g$，代入得：
$$
\frac{dw}{dt} = g\frac{\rho_e - \rho}{\rho}
$$

利用状态方程 $\rho \propto 1/T_v$，可得：
$$
\frac{dw}{dt} = g\frac{T_v - T_{ve}}{T_{ve}} \approx g\frac{T - T_e}{T_e}
$$
其中 $T_v$、$T_{ve}$ 分别为气块和环境的虚温，$T$、$T_e$ 为实际温度（近似）。

> **物理意义**：气块受净阿基米德浮力产生的加速度由气块与环境温度差决定。气块比环境暖（$T > T_e$）时向上加速，冷（$T < T_e$）时向下加速。

## 二、静力稳定度判据

### 1. 定义环境温度递减率 $\Gamma$ 和气块温度递减率 $\gamma$
- **环境温度递减率**：$\displaystyle \Gamma = -\frac{dT_e}{dz}$（正值表示温度随高度降低）
- **气块温度递减率**：$\displaystyle \gamma = -\frac{dT}{dz}$（视气块是否饱和，可为干绝热 $\gamma_d$ 或湿绝热 $\gamma_s$）

假设气块从平衡位置 $z_0$ 受扰上升到 $z_0 + dz$，气块初始温度 $T_0 = T_e(z_0)$，上升后：
- 环境温度：$T_e(z) = T_e(z_0) - \Gamma dz$
- 气块温度：$T(z) = T_0 - \gamma dz$

因此温度差：
$$
T(z) - T_e(z) = (T_0 - \Gamma dz) - (T_0 - \gamma dz) = (\gamma - \Gamma) dz
$$

### 2. 加速度表达式
$$
\frac{dw}{dt} = g\frac{T - T_e}{T_e} \approx g\frac{\gamma - \Gamma}{T_e} dz
$$

### 3. 稳定度判据（未饱和湿空气，$\gamma = \gamma_d$）

| 条件 | 符号关系 | 物理意义 | 稳定度 |
|------|----------|----------|--------|
| $\Gamma > \gamma_d$ | $\gamma_d - \Gamma < 0$ | 气块上升后比环境冷 | **绝对不稳定**（加速远离平衡） |
| $\Gamma = \gamma_d$ | $\gamma_d - \Gamma = 0$ | 气块温度始终等于环境 | **中性** |
| $\Gamma < \gamma_d$ | $\gamma_d - \Gamma > 0$ | 气块上升后比环境暖 | **绝对稳定**（返回平衡） |

> **注意**：从加速度公式看，$\frac{dw}{dt} \propto (\gamma - \Gamma) dz$。若 $\gamma - \Gamma > 0$，则 $dz > 0$ 时加速度向上（加速上升），$dz < 0$ 时加速度向下（加速下沉）——即离开平衡位置的加速度与位移同向，是不稳定。判断时要小心符号。

实际上更简洁的判据：
- $\Gamma > \gamma_d$：环境比干绝热线更陡 → 不稳定
- $\Gamma = \gamma_d$：中性
- $\Gamma < \gamma_d$：环境比干绝热线更平缓 → 稳定

## 三、饱和湿空气的稳定度（湿绝热）

### 1. 湿绝热递减率 $\gamma_s$
饱和湿空气绝热上升时，由于凝结潜热释放，减温率小于干绝热：
$$
\gamma_s = \gamma_d - \frac{L_v}{c_p} \frac{dr_s}{dz} \quad (\frac{dr_s}{dz} < 0 \Rightarrow \gamma_s < \gamma_d)
$$

$\gamma_s$ 不是常数，随温度和气压变化（高温下 $\gamma_s$ 小，低温下接近 $\gamma_d$）。

### 2. 判据（饱和湿空气）
| 条件 | 稳定度 |
|------|--------|
| $\Gamma > \gamma_s$ | 不饱和空气按干绝热，饱和空气不稳定 |
| $\Gamma = \gamma_s$ | 中性 |
| $\Gamma < \gamma_s$ | 稳定 |

---

## 四、条件性不稳定

### 1. 定义
当环境温度递减率介于干绝热和湿绝热之间时：
$$
\gamma_s < \Gamma < \gamma_d
$$

- 对**未饱和**气块：$\Gamma < \gamma_d$ → 气块按干绝热上升时比环境冷 → **稳定**
- 对**饱和**气块：$\Gamma > \gamma_s$ → 气块按湿绝热上升时比环境暖 → **不稳定**

因此，这种层结称为**条件性不稳定**（有条件的不稳定：只有当气块达到饱和并继续上升时才出现不稳定）。

### 2. 物理图像
若低层有充足水汽，气块被抬升到凝结高度（LCL）后开始潜热释放，之后气块温度沿湿绝热线下降，可能比环境暖，从而获得正浮力继续上升。若低层干燥，气块难以饱和，则保持稳定。

### 3. 条件性不稳定的常用判据
- 用位温 $\theta$ 和假相当位温 $\theta_{se}$ 判断：
  - 绝对稳定：$\frac{\partial \theta}{\partial z} > 0$ 且 $\frac{\partial \theta_{se}}{\partial z} > 0$
  - 绝对不稳定：$\frac{\partial \theta}{\partial z} < 0$
  - 条件不稳定：$\frac{\partial \theta}{\partial z} > 0$ 但 $\frac{\partial \theta_{se}}{\partial z} < 0$

> 因为干绝热过程 $\theta$ 守恒，湿绝热过程 $\theta_{se}$ 守恒。若 $\theta$ 随高度增加（稳定），但 $\theta_{se}$ 随高度减少，说明饱和气块可能不稳定。

## 五、重力波与浮力频率（Brunt-Väisälä 频率）

### 1. 重力波方程
由 $\displaystyle \frac{dw}{dt} = g\frac{\gamma - \Gamma}{T_e} dz$，令 $w = dz/dt$，得：
$$
\frac{d^2 z}{dt^2} = N^2 dz
$$
其中：
$$
N^2 = \frac{g}{T_e} (\gamma - \Gamma)
$$

### 2. 浮力频率
在**稳定层结**（$\Gamma < \gamma$）时，$N^2 > 0$，方程变为：
$$
\frac{d^2 z}{dt^2} + \omega^2 dz = 0, \quad \omega = \sqrt{\frac{g}{T_e}(\gamma - \Gamma)} = \sqrt{\frac{g}{T_e}(\gamma_d - \Gamma)}
$$
$\omega$ 称为**Brunt-Väisälä 频率**（浮力频率）。

**特点**：
- 稳定大气中，受扰气块以频率 $\omega$ 做简谐振荡
- 典型量级：$\omega \sim 1-2 \times 10^{-2} \, \text{s}^{-1}$，周期 $T = 2\pi/\omega \sim 300-600 \, \text{s}$
- 若风速 $10 \, \text{m/s}$，过山波波长约 $3-6 \, \text{km}$

## 六、不稳定能量与 CAPE / CIN

### 1. 不稳定能量的概念
气块上升过程中，浮力做功转化为动能。单位质量气块从 $z_0$ 上升到 $z$ 的动能增量为：
$$
\Delta E_k = \frac{1}{2}(w^2 - w_0^2) = \int_{z_0}^z g\frac{T_v - T_{ve}}{T_{ve}} dz
$$

在 T-log p 图上，该积分与**状态曲线**（气块上升温度曲线）和**层结曲线**（环境温度曲线）围成的面积成正比。

### 2. 关键高度
- **抬升凝结高度 (LCL)**：气块干绝热上升达饱和的高度
- **自由对流高度 (LFC)**：状态曲线与层结曲线的**第一个交点**，此后气块温度高于环境（正浮力）
- **平衡高度 (EL)**：状态曲线与层结曲线的**第二个交点**，此后气块温度低于环境（负浮力）

### 3. 对流抑制能量 (CIN)
从 LCL 到 LFC，状态曲线位于层结曲线左侧（气块比环境冷），浮力做负功，抑制对流发展：
$$
\text{CIN} = -R_d \int_{p_{\text{LFC}}}^{p_{\text{LCL}}} (T_v - T_{ve}) \, d\ln p > 0
$$
- 物理意义：气块要到达自由对流高度，必须获得的**最小初始动能**（需有足够强的抬升触发）
- 量级：几十到几百 J/kg

### 4. 对流有效势能 (CAPE)
从 LFC 到 EL，状态曲线位于层结曲线右侧（气块比环境暖），浮力做正功，加速上升：
$$
\text{CAPE} = R_d \int_{p_{\text{EL}}}^{p_{\text{LFC}}} (T_v - T_{ve}) \, d\ln p
$$
- 物理意义：气块从 LFC 到 EL 过程中获得的**最大动能**（对应最大上升速度）
- 量级：弱对流 < 1000 J/kg，强对流 1000-3000 J/kg，超级单体 > 3000 J/kg

### 5. 最大上升速度估算
忽略阻力，最大上升速度：
$$
w_{\max} \approx \sqrt{2 \times \text{CAPE}}
$$

### 6. 潜在不稳定型的分类
- **真潜在不稳定**：CAPE > CIN，气块一旦触发就能发展成强对流
- **假潜在不稳定**：CAPE < CIN，即使抬升到 LFC，由于 CAPE 较小，也难以形成强对流

> 低层湿度大 → LCL 低 → CIN 小，更容易满足 CAPE > CIN，出现真潜在不稳定。

## 七、稳定度与位温/假相当位温的垂直分布

### 1. 位温 $\theta$ 与稳定度（干空气）
由 $\displaystyle \frac{\partial \theta}{\partial z} = \frac{\theta}{T} (\gamma_d - \Gamma)$
- $\frac{\partial \theta}{\partial z} > 0$ → $\Gamma < \gamma_d$ → 稳定
- $\frac{\partial \theta}{\partial z} = 0$ → $\Gamma = \gamma_d$ → 中性
- $\frac{\partial \theta}{\partial z} < 0$ → $\Gamma > \gamma_d$ → 不稳定

### 2. 假相当位温 $\theta_{se}$ 与条件性稳定度
对于饱和气层，可以导出：
$$
\frac{\partial \theta_{se}}{\partial z} \approx \frac{\theta_{se}}{T} (\gamma_s - \Gamma)
$$

因此：
- $\frac{\partial \theta_{se}}{\partial z} > 0$ → $\Gamma < \gamma_s$ → 饱和气块稳定
- $\frac{\partial \theta_{se}}{\partial z} = 0$ → $\Gamma = \gamma_s$ → 中性
- $\frac{\partial \theta_{se}}{\partial z} < 0$ → $\Gamma > \gamma_s$ → 饱和气块不稳定

### 3. 常用综合判据
| 条件 | 稳定度 |
|------|--------|
| $\frac{\partial \theta}{\partial z} > 0$ 且 $\frac{\partial \theta_{se}}{\partial z} > 0$ | **绝对稳定** |
| $\frac{\partial \theta}{\partial z} > 0$ 但 $\frac{\partial \theta_{se}}{\partial z} < 0$ | **条件不稳定** |
| $\frac{\partial \theta}{\partial z} < 0$ | **绝对不稳定** |

## 八、热雷暴预报与 CCL

### 1. 对流凝结高度 (CCL)
在 T-log p 图上，从地面露点沿等饱和比湿线上升，与层结曲线的交点称为**对流凝结高度**。这是热力对流产生的积云云底高度。

### 2. 热雷暴的地面触发温度
- 从 CCL 沿干绝热线下降到地面，对应的温度 $T_r$ 即为**形成雷暴至少需要的地面温度**
- 白天太阳加热使地面温度达到 $T_r$ 以上，且低层湿度足够，就可能有热雷暴发生

## 九、稳定度判据总结表

| 判据 | 条件 | 稳定度 |
|------|------|--------|
| $\Gamma$ 与 $\gamma_d$ | $\Gamma > \gamma_d$ | 绝对不稳定 |
| | $\Gamma = \gamma_d$ | 中性 |
| | $\Gamma < \gamma_d$ | 绝对稳定（未饱和） |
| $\Gamma$ 与 $\gamma_s$ | $\Gamma > \gamma_s$ | 饱和气块不稳定 |
| | $\Gamma = \gamma_s$ | 中性 |
| | $\Gamma < \gamma_s$ | 饱和气块稳定 |
| 条件不稳定 | $\gamma_s < \Gamma < \gamma_d$ | 未饱和稳定，饱和不稳定 |
| $\partial \theta / \partial z$ | $>0$ | 未饱和稳定 |
| | $<0$ | 绝对不稳定 |
| $\partial \theta_{se} / \partial z$ | $<0$ | 条件不稳定 |
| CAPE / CIN | CAPE > CIN 且 CIN 可克服 | 真潜在不稳定 |

## 十、记忆要点

1. **浮力加速度**：$dw/dt = g(T-T_e)/T_e$，暖升冷降。
2. **干绝热判据**：$\Gamma$ 与 $\gamma_d$ 比较。
3. **条件不稳定**：$\gamma_s < \Gamma < \gamma_d$，是绝大多数对流天气的层结条件。
4. **重力波**：稳定层结中气块以浮力频率振荡。
5. **CAPE**：正面积，对流潜势；**CIN**：负面积，触发能量。
6. **LCL、LFC、EL**：云底、自由对流开始、平衡高度。
7. **位温与假相当位温**的垂直分布可快速判断稳定度。

## 📌 重点

- 浮力加速度$dw/dt = g(T-T_e)/T_e$：气块比环境暖→向上加速→不稳定；比环境冷→下沉→稳定
- 干绝热判据$\Gamma$ vs $\gamma_d=9.8$ K/km：$\Gamma>\gamma_d$绝对不稳定，$\Gamma=\gamma_d$中性，$\Gamma<\gamma_d$对未饱和气块稳定
- 条件性不稳定$\gamma_s < \Gamma < \gamma_d$是绝大多数对流天气的层结：未饱和时稳定，饱和后不稳定→潜热释放是关键
- 三个关键高度：LCL（云底）、LFC（自由对流开始，克服CIN后首次$T>T_e$）、EL（平衡高度，$T<T_e$结束）
- CAPE = $R_d\int_{p_{EL}}^{p_{LFC}}(T_v-T_{ve})d\ln p$→对流有效势能；$w_{\max} \approx \sqrt{2\times\text{CAPE}}$；CIN→对流抑制，需抬升触发克服
- 位温判别法：$\partial\theta/\partial z < 0$绝对不稳定；$\partial\theta/\partial z>0$但$\partial\theta_{se}/\partial z<0$条件不稳定
- 浮力频率$N^2 = (g/T_e)(\gamma_d-\Gamma)$：在稳定层结（$N^2>0$）中气块以频率$N$振荡→重力波；周期~5-10分钟
- 低层湿度↑→LCL↓→CIN↓→更易触发对流；日间加热可降低CIN使潜在不稳定释放
