露点和水汽压之间的关系可以通过**克拉伯龙-克劳修斯方程**（Clapeyron-Clausius Equation）来描述。

### 为什么使用这个方程？
1. **露点的定义**：露点是指空气在等压冷却过程中达到饱和时的温度。当空气中的水汽压达到饱和水汽压时，水汽开始凝结成水滴，此时的温度即为露点。[[湿度参量#^271ba1]]
2. **水汽压与温度的关系**：饱和水汽压随温度的变化是非线性的，克拉伯龙-克劳修斯方程方程准确地描述了这种关系。通过这个方程，可以计算出不同温度下的饱和水汽压，从而确定露点温度。

### 具体推导
给定温度 $T$ 和水汽压 $e$，可以通过克劳修斯-克拉佩龙方程的积分形式计算露点温度 $T_d$：$$\ln \frac{e_s(T_d)}{e_s(T)} = \frac{L_v}{R_v} \left( \frac{1}{T} - \frac{1}{T_d} \right)$$其中，$e_s(T_d)$ 是露点温度下的饱和水汽压，$e_s(T)$ 是当前温度下的饱和水汽压。以上公式可以变为：
$$\frac{1}{T_d} = \frac{1}{T_0} - \frac{R_v}{L_v} \ln \frac{e}{e_s(T_0)}$$
将公式整理为 $T_d$ 在左边，$e$ 在右边的形式：
$$
T_d = \left( \frac{1}{T_0} - \frac{R_v}{L_v} \ln \frac{e}{e_s(T_0)} \right)^{-1}
$$

```python
import numpy as np
import matplotlib.pyplot as plt

def calculate_dew_point(e_hPa):
    """
    根据水汽压计算露点温度（支持标量或np.array输入）
    参数：
        e_hPa : 水汽压（单位：hPa），可以是标量或numpy数组
    返回：
        露点温度（单位：°C），类型与输入一致
    """
    # 常量定义
    T0 = 273.15      # 参考温度（K）
    Rv = 461.0       # 水汽气体常数（J/(kg·K)）
    Lv = 2.5e6       # 汽化潜热（J/kg）
    es_T0 = 6.11     # T0下的饱和水汽压（hPa）

    # 将输入转换为numpy数组（支持标量、列表、np.array）
    e = np.asarray(e_hPa, dtype=np.float64)
    
    # 计算露点温度（K）
    ln_term = np.log(e / es_T0)
    inv_Td = (1/T0) - (Rv / Lv) * ln_term
    Td_K = 1 / inv_Td
    
    # 转换为摄氏度并返回
    Td_C = Td_K - 273.15
    return np.round(Td_C, 1) if e.ndim == 0 else np.round(Td_C, 1)


# 输入标量
print(calculate_dew_point(20.0))  # 输出：-12.9

# 输入数组
e_array = np.arange(10, 40.1, 0.2)  # 测试边界值
td = calculate_dew_point(e_array)
# 输出：[-273.1   -12.9    25.5]（单位：°C）
plt.plot(e_array, td)
plt.show()

```
