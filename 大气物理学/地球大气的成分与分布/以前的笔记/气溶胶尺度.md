# 气溶胶按照尺度的分类

气溶胶（Aerosol）是悬浮在大气中的固体或液体微粒，根据其**粒径大小**，通常可分为以下几类：

## 1. 气溶胶尺度分类总结

| **模式**                      | **粒径范围**      | **主要来源**        | **大气影响**    |
| --------------------------- | ------------- | --------------- | ----------- |
| **超细模式**（Nucleation Mode）   | <0.01 μm      | 气相核化、燃烧、机动车尾气   | 快速凝并，不易保持   |
| **Aitken 模式**（Aitken Mode）  | 0.01 - 0.1 μm | 燃烧、二次气溶胶        | 可能成长为 CCN   |
| **积聚模式**（Accumulation Mode） | 0.1 - 1 μm    | 燃烧、硫酸盐、硝酸盐、海盐   | 主要影响云、气候    |
| **粗模式**（Coarse Mode）        | >1 μm         | 沙尘、海盐、生物气溶胶、火山灰 | 影响空气质量、局地气候 |

## 2. 不同尺度气溶胶的环境影响
### 超细和 Aitken 颗粒：
   - 由于小粒径，它们对人体健康影响较大，可深入肺部，甚至进入血液。
   - 主要来源于燃烧和二次气溶胶过程。
### 积聚模式颗粒：
   - 对气候变化影响最大，因为它们是**主要的 CCN**，影响云和降水。
   - 可吸收或散射太阳辐射，改变地球的辐射平衡。
### 粗模式颗粒：
   - 主要影响空气质量（PM₁₀），但对 CCN 作用较小。
   - 它们在大气中的寿命较短，因此影响通常是局地性的，而非全球性的。
