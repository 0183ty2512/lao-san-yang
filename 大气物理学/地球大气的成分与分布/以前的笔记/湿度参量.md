### 1. **比湿（$q$）**

^80b0db

- **定义**：湿空气中水汽质量与湿空气总质量的比值。公式是：
  $$q = \frac{m_v}{m_v + m_d}$$
  其中： $m_v$ 是水汽质量，$m_d$ 是干空气质量。单位为$kg/kg$ 或 $g/kg$。
---
### 2. **混合比（$r$）**
- **定义**：湿空气中水汽质量与干空气质量的比值，公式是：
  $$r = \frac{m_v}{m_d}$$
- 单位是$kg/kg$ 或 $g/kg$。
- **与比湿的关系**：$$q = \frac{r}{1 + r}$$
  由于 $r$ 通常很小（$r < 0.04$），因此 $q \approx r$。
---
### 3. **水汽压（$e$）**
- **定义**：湿空气中水汽的分压强。计算公式为：
  $$
  e = X_v \cdot p
  $$
  其中，$X_v$ 是水汽的摩尔分数，$p$ 是湿空气的总压强。**单位**：$hPa$ 或 $Pa$。
---
### 4. **饱和水汽压（$e_s$）**

^c91d4c

- **定义**：在一定温度下，湿空气达到饱和时的水汽压，通过克拉伯龙-克劳修斯方程（C-C 方程）计算：
  $$
  \ln e_s = \ln e_{s0} + \frac{L_v}{R_v} \left( \frac{1}{T_0} - \frac{1}{T} \right)
  $$
  其中$e_{s0}$ 是参考温度 $T_0$ 下的饱和水汽压， $L_v$ 是水的汽化潜热，$R_v$ 是水汽的气体常数，单位是$hPa$ 或 $Pa$。
---
### 5. **相对湿度（$RH$）**

^ab1519

- **定义**：实际水汽压与同温度下饱和水汽压的百分比。计算公式为：  $$RH = \frac{e}{e_s} \times 100\%$$单位$\%$ 或无量纲。
---
### 6. **露点温度（$T_d$）**

^271ba1

- **定义**：湿空气在等压冷却过程中达到饱和时的温度，通过实际水汽压 $e$ 和饱和水汽压公式反推得到。$$T_d=e^{-1}_s(e)$$
- **单位**：$^\circ C$ 或 $K$。
```python
import numpy as np
import matplotlib.pyplot as plt

def calculate_saturation_vapor_pressure(T):
    """
    计算饱和水汽压（Tetens公式）
    参数:
        T: 温度（单位：摄氏度，°C）
    返回:
        e_s: 饱和水汽压（单位：hPa）
    """
    # Tetens公式
    e_s = 6.1078 * np.exp((17.27 * T) / (T + 237.3))
    return e_s

# 生成温度范围（-50°C 到 50°C）
T = np.linspace(-50, 50, 200)

# 计算饱和水汽压
e_s = calculate_saturation_vapor_pressure(T)

# 绘制曲线
plt.figure(figsize=(8, 6))
plt.plot(T, e_s, label="$e_s$", color="blue")
plt.xlabel(u"T (°C)", fontsize=12)
plt.ylabel(r"$e_s$ (hPa)", fontsize=12)
plt.grid(True, linestyle="--", alpha=0.6)
plt.legend()
plt.show()
```

### 7. **水汽密度（$\rho_v$）**
- **定义**：湿空气中水汽的质量与湿空气体积的比值，公式为：
  $$\rho_v = \frac{m_v}{V}$$
- **单位**：$g/m^3$ 或 $kg/m^3$。
---
### 8. **虚温（$T_v$）**
- **定义**：湿空气在相同压强和密度下，等效为干空气时的温度，计算公式是：
  $$
  T_v = T (1 + 0.608 q)
  $$
  其中，$T$ 是实际温度，$q$ 是比湿，单位$K$ 或 $^\circ C$。
