
### 1. **定义**  
湿球温度（$T_w$）是指用湿布包裹的温度计在通风条件下测得的温度。当空气流经湿布时，水分蒸发会吸收热量，导致湿布表面温度降低，最终达到的平衡温度即为湿球温度。

### 2. **测量方法**  
- **仪器**：使用通风干湿表（如Assmann psychrometer），包含干球温度计（测环境温度$T$）和湿球温度计（覆盖湿布）。  
- **过程**：湿布水分蒸发消耗潜热，降低自身温度。空气的热量通过传导补充蒸发损失的热量。当热平衡时，湿球温度计的读数即为$T_w$。

### 3. **物理意义**  
- **蒸发与热平衡**：  
  湿布蒸发的水分子扩散到空气中，同时空气的热量传递到湿布表面。平衡时，蒸发的潜热（$L_v \cdot \Delta m$）等于空气传导的热量（$c_p \cdot \Delta T$），即：  
  $$ L_v \cdot \Delta m = c_p \cdot (T - T_w) $$  
  其中$L_v$为汽化潜热，$c_p$为空气定压比热容。
- 湿球温度的隐式表达公式为：$$T_w = T - \frac{L_v}{c_p} \left( \frac{0.622 e_s(T_w)}{p - e_s(T_w)} - w \right)$$
- 对于快速估算，可采用以下简化公式：$$T_w \approx T - \frac{(T - T_d)}{4}$$
	其中$T_d$为露点温度，适用于相对湿度较高（$RH > 50\%$）的情况。[[湿度参量#^ab1519]]

### 4. **特性**  
- **温度关系**：在未饱和空气中，湿球温度介于露点温度（$T_d$）和干球温度（$T$）之间，即：  
  $$ T_d < T_w < T $$  
  当空气饱和时，三者相等：$T_d = T_w = T$。  
- **湿度指示**：$T_w$与相对湿度（$RH$）相关。干湿球温差（$T - T_w$）越大，空气越干燥（$RH$越低）。


```python
import numpy as np

def calculate_wet_bulb_temp(T_C, RH_percent, p_hPa=1013.25):
    """
    根据相对湿度计算湿球温度（数值迭代法）
    参数：
        T_C : 干球温度（°C）
        RH_percent : 相对湿度（%）
        p_hPa : 气压（hPa，默认海平面1013.25 hPa）
    返回：
        湿球温度（°C）
    """
    # 常量定义
    Lv = 2.5e6     # 汽化潜热（J/kg）
    cp = 1005      # 空气定压比热容（J/(kg·K)）
    eps = 0.622    # 水汽/干空气分子量比
    
    # 饱和水汽压计算（Tetens公式）
    def es(T):
        return 6.112 * np.exp(17.67 * T / (T + 243.5))  # T为°C，es为hPa
    
    # 初始猜测值
    Tw_guess = T_C - (1 - RH_percent/100) * 5  # 经验初值
    e = es(T_C) * RH_percent / 100             # 实际水汽压
    
    # 牛顿迭代法
    max_iter = 50
    tolerance = 0.01  # 收敛阈值（°C）
    
    for _ in range(max_iter):
        es_Tw = es(Tw_guess)
        ws_Tw = eps * es_Tw / (p_hPa - es_Tw)  # 饱和混合比（kg/kg）
        w = eps * e / (p_hPa - e)              # 实际混合比
        
        # 热力学平衡方程残差
        f = cp * (T_C - Tw_guess) - Lv * (ws_Tw - w)
        
        # 数值微分计算导数
        delta = 0.01
        es_Tw_d = es(Tw_guess + delta)
        ws_Tw_d = eps * es_Tw_d / (p_hPa - es_Tw_d)
        f_d = cp * (T_C - (Tw_guess + delta)) - Lv * (ws_Tw_d - w)
        df_dTw = (f_d - f) / delta
        
        # 更新猜测值
        Tw_guess -= f / df_dTw
        
        if abs(f) < tolerance:
            break
    
    return round(Tw_guess, 1)

# 示例：T=28°C, RH=90%
print(calculate_wet_bulb_temp(28, 90))  # 输出：26.0°C

```
