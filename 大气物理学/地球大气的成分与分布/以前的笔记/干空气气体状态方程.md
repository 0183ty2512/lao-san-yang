# 利用道尔顿分压定律推导干空气的气体状态方程

## 1. 道尔顿分压定律的基本概念

道尔顿分压定律表明，**混合气体的总压强等于各组分气体分压强之和**：$$p = p_1 + p_2 + p_3 + \dots$$在大气中，干空气主要由氮气（N₂）、氧气（O₂）、氩气（Ar）等组成，因此：
$$p_{\text{air}} = p_{N_2} + p_{O_2} + p_{Ar} + \dots$$
其中，每种气体的分压（$p_i$）是在相同温度下单独占据相同体积时所具有的压强。

---
## 2. 结合理想气体状态方程
每种气体均可近似看作理想气体，满足 **理想气体状态方程**：[[牢三样/大气物理学/地球大气的成分与分布/以前的笔记/理想气体]]
$$p_i V = n_i R^* T$$
其中：
- $p_i$：第 $i$ 种气体的分压，
- $V$：气体体积
- $n_i$：第 $i$ 种气体的摩尔数
- $R^*$：普适气体常数（8.31 J/(mol·K)）
- $T$：绝对温度（K）

对所有成分求和：
$$\sum p_i V = \sum n_i R^* T$$
根据道尔顿分压定律：
$$pV = \left( \sum n_i \right) R^* T$$
---
## 3. 计算干空气的平均摩尔质量

混合气体的总摩尔数 $n$ 为：
$$n = \sum n_i = \frac{m}{M}$$
其中，$m$为混合气体的总质量
- $M$干空气的 **平均摩尔质量**，计算如下：
$$M_d = \sum \left( x_i M_i \right)$$
干空气的主要成分及其摩尔质量：
- $N_2$（摩尔分数 78.08%，摩尔质量 28.013 g/mol）
- $O_2$（摩尔分数 20.95%，摩尔质量 31.999 g/mol）
- $Ar$（摩尔分数 0.93%，摩尔质量 39.948 g/mol）

计算可得 **干空气的平均摩尔质量**：$M_d \approx 28.96 \text{ g/mol}$

---
## **4. 推导干空气的气体状态方程**
将 $n = m/M_d$ 代入：$$pV = \frac{m}{M_d} R^* T$$得到：$$p = \frac{m}{V} \cdot \frac{R^*}{M_d} T$$
定义 **干空气的比气体常数**：
$$R_d = \frac{R^*}{M_d} = \frac{8.31}{28.96 \times 10^{-3}} \approx 287 \text{ J/(kg·K)}$$
最终得到 **干空气的气体状态方程**：
$$p = \rho_d R_d T$$
或写成：
$$\alpha_d p = R_d T$$
其中：
- $\rho_d = \frac{m}{V}$ 是干空气密度
- $\alpha_d = \frac{1}{\rho_d}$ 是比体积（m³/kg）


```python
def calculate_dry_air_density(temperature_C, pressure_hPa):
    """
    计算干空气密度的Python函数
    
    参数：
    temperature_C : float - 温度（摄氏度）
    pressure_hPa  : float - 气压（百帕，hPa）
    
    返回：
    density : float - 干空气密度（kg/m³）
    
    公式依据：
    干空气状态方程 ρ = p / (R_d * T)
    """
    # 定义干空气比气体常数（已知内容中给出的精确值）
    R_d = 287.05  # 单位：J/(kg·K)
    
    # 将摄氏温度转换为开尔文温度
    T_K = temperature_C + 273.15
    
    # 将气压从hPa转换为Pa（1 hPa = 100 Pa）
    p_Pa = pressure_hPa * 100
    
    # 计算密度
    density = p_Pa / (R_d * T_K)
    
    return density

# 示例用法（对应已知内容中的随堂练习）
if __name__ == "__main__":
    # 示例1：30°C、1000 hPa时的干空气密度
    print(calculate_dry_air_density(20, 1000))  # 输出 ≈1.14 kg/m³
    
    # 示例2：10°C、1000 hPa时的干空气密度
    print(calculate_dry_air_density(10, 1000))  # 输出 ≈1.23 kg/m³


```
