# 标准大气 (Standard Atmosphere)

## 一、定义

根据世界气象组织 (WMO) 的定义：

> **标准大气** 就是能够粗略地反映出周年的、中纬度状况的，得到国际上承认的，假定的大气温度、压力和密度的垂直分布。

标准大气不是实际大气的精确描述，而是一个**理想化、平均化**的参考模型，用于：
- 航空高度测量基准
- 火箭、导弹飞行性能计算
- 大气辐射传输模拟
- 卫星遥感反演背景场
- 气象仪器校准

---

## 二、常用标准大气模式

大气辐射和大气遥感研究中，需要更详细的大气模式。文件中列出了 **6 种常用模式**（部分来自 AFGL，Air Force Geophysics Laboratory）：

### 1. 中纬度冬季大气 (Mid-Latitude Winter)
- 适用于北半球中纬度（约 45°N）冬季平均状况
- 表面温度较低，对流层顶高度约 10-11 km

### 2. 中纬度夏季大气 (Mid-Latitude Summer)
- 适用于北半球中纬度夏季平均状况
- 表面温度较高，对流层顶高度约 11-12 km

### 3. 亚极地冬季大气 (Sub-Arctic Winter)
- 适用于亚极地（约 60°N）冬季
- **表面温度最低**（可低至 -30°C 以下）

### 4. 亚极地夏季大气 (Sub-Arctic Summer)
- 适用于亚极地夏季
- 对流层顶温度**最高**（因夏季极地平流层下部较暖）

### 5. 赤道大气 (Tropical Atmosphere)
- 适用于赤道地区（约 10°N - 10°S）
- 对流层顶**最低**（可达 -80°C 以下），但对流层顶高度最高（约 16-17 km）

### 6. 美国标准大气 (1976 U.S. Standard Atmosphere)
- 中纬度平均的代表，1976 年发布
- **为上述廓线提供有效的中值**
- 广泛应用于航空航天领域

## 三、温度垂直分布的主要特点

根据文件描述和标准大气知识：

| 模式 | 表面温度 | 对流层顶温度 | 平流层顶（约50 km）温度 |
|------|----------|--------------|------------------------|
| 亚极地冬季 | 最低 | 较低 | 最冷 |
| 中纬度冬季 | 次低 | - | - |
| 中纬度夏季 | 较高 | - | - |
| 赤道大气 | 较高 | 最低（约 -80°C） | - |
| 亚极地夏季 | - | 最高 | 最暖（约 280 K） |
| 美国标准大气 | 15°C (288.15 K) | -56.5°C (216.65 K) | 约 270 K |

### 其他共同特征
- 所有模式在 **50 km 附近**（平流层顶/中间层底）都有一个**二次温度峰值**（因为臭氧吸收太阳紫外辐射加热）
- 亚极地夏季在此高度温度最暖，接近中纬度夏季温度
- 亚极地冬季在此高度温度最冷

### 温度廓线形状示意
```
高度 (km)
  100 ─────────────────────
   80 ────────── 中间层顶
   50 ──────┬── 二次峰值（臭氧加热）
   20 ──────┼── 平流层（温度递增）
   10 ──────┴── 对流层顶
    0 ─────────────────────
       低温          高温
```

## 四、标准大气的其他要素

除了温度，标准大气还定义了以下要素随高度的分布：
- **压力**：由静力学方程和温度廓线积分得到
- **密度**：由状态方程 $p = \rho R T$ 计算
- **声速**：$c = \sqrt{\gamma R T}$（$\gamma = 1.4$）
- **平均分子量**：80 km 以下为常数（28.964 g/mol），以上逐渐减小
- **重力加速度**：随高度变化公式

### 1976 美国标准大气的关键数值（海平面）
| 参数 | 数值 |
|------|------|
| 压力 $p_0$ | 1013.25 hPa |
| 温度 $T_0$ | 288.15 K (15°C) |
| 密度 $\rho_0$ | 1.2250 kg/m³ |
| 声速 $c_0$ | 340.294 m/s |
| 重力加速度 $g_0$ | 9.80665 m/s² |

## 五、标准大气的分层（以 1976 US 标准大气为例）

| 层名 | 高度范围 (km) | 温度直减率 $\gamma$ (K/km) | 温度变化 |
|------|--------------|---------------------------|----------|
| 对流层 | 0 ~ 11 | 6.5 | 递减 |
| 对流层顶 | 11 ~ 20 | 0 | 等温 |
| 平流层下层 | 20 ~ 32 | -1.0 | 等温或微增 |
| 平流层上层 | 32 ~ 47 | 2.8 | 递增（臭氧加热） |
| 平流层顶 | 47 ~ 51 | 0 | 等温 |
| 中间层下层 | 51 ~ 71 | -2.8 | 递减 |
| 中间层上层 | 71 ~ 84.85 | -2.0 | 递减 |
| 中间层顶 | 84.85 ~ 86 | 0 | 等温 |
| 热层 | 86 以上 | 复杂 | 递增 |

> 注：不同标准大气模式的分层高度和直减率略有差异。

## 六、标准大气的应用

1. **气压高度表校准**：飞机气压高度表按标准大气刻度，非标准温度下需修正。
2. **飞行性能计算**：起飞、爬升、巡航性能基于标准大气条件。
3. **火箭、导弹设计**：大气密度、压力剖面影响气动载荷和轨道。
4. **辐射传输模拟**：如 MODTRAN、6S 等辐射传输模型需要标准大气输入。
5. **卫星遥感反演**：作为初猜廓线（first guess）或背景场。
6. **气象仪器检验**：探空仪、气压计等的实验室校准。

## 七、与"大气压力与高度关系"的联系

标准大气本质上是一个**多元大气**的分段组合：每一层内温度直减率 $\gamma$ 为常数，可应用多元大气的压高公式逐层计算压力。

对于第 $i$ 层（高度 $z_i$ 到 $z_{i+1}$，温度 $T_i$ 到 $T_{i+1}$，$\gamma_i = \frac{T_i - T_{i+1}}{z_{i+1} - z_i}$）：

$$
\frac{p_{i+1}}{p_i} = \left( \frac{T_{i+1}}{T_i} \right)^{\frac{g}{R_d \gamma_i}}
$$

对于等温层（$\gamma_i = 0$）：
$$
p_{i+1} = p_i \exp\left( -\frac{g(z_{i+1} - z_i)}{R_d T_i} \right)
$$

## 八、记忆要点

1. **标准大气是理想化的平均模型**，不是实际大气。
2. **6 种主要模式**：中纬度冬/夏、亚极地冬/夏、赤道、美国标准。
3. **表面温度**：亚极地冬季最低，赤道和中纬度夏季最高。
4. **对流层顶温度**：赤道大气最低，亚极地夏季最高。
5. **50 km 二次温度峰值**：臭氧吸收紫外辐射加热，亚极地夏季最暖。
6. **1976 美国标准大气**：提供中值参考，广泛应用。
7. **应用**：航空、航天、遥感、辐射传输。

---

## 九、补充：中国标准大气

中国也有自己的标准大气（GB/T 1920-2020），主要参考 1976 美国标准大气，但根据中国中纬度地区（如北京）的气象观测数据做了适当调整，用于国内航空航天和气象业务。

主要差异：
- 对流层顶高度略低（约 10.5 km）
- 冬季低温修正更严格

## 📌 重点

- 标准大气是WMO定义的中纬度周年平均理想化大气模型，用于航空、航天、遥感的基准参考
- 6种常用模式：中纬度冬/夏、亚极地冬/夏、赤道、美国标准（提供中值）
- 1976 US标准大气海平面：$p_0=1013.25$ hPa, $T_0=288.15$ K, $\rho_0=1.225$ kg/m³, $g_0=9.80665$ m/s²
- 标准大气是多元大气的分段组合：每层$\gamma$常数→$p_{i+1}/p_i = (T_{i+1}/T_i)^{g/(R_d\gamma_i)}$；等温层用指数形式
- 50 km附近二次温度峰值由臭氧吸收UV辐射加热产生，亚极地夏季最暖
- 对流层顶高度与温度的纬向对比：赤道最高（~16-17 km）、最冷（~-80°C）；亚极地夏季对流层顶最暖
- 气压高度表校准依据标准大气——实际$T_v$偏离标准值时产生高度误差（冷区读数偏高，暖区读数偏低）
- 分层结构：对流层（$\gamma=6.5$ K/km）→平流层（臭氧加热增温）→中间层（递减）→热层（递增）

> **思考题 1**：赤道对流层顶温度最低（~-80°C）但高度最高（~16-17 km），而极地对流层顶温度较高但高度较低。从对流层顶的定义（温度递减率由负转正）和热带深对流（Cb穿透到极高高度）的机制解释这一反直觉现象。
> **思考题 2**：飞机气压高度表在冬季高纬度飞行时，若实际大气温度比标准大气低30°C，高度表读数相比实际高度偏高还是偏低？从$h = R_d T_v/(pg)$定量估算误差量级。
