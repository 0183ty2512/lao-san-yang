# 层状云降水的形成机理

## 一、层状云的基本特征

### 1. 定义
**层状云**（stratiform cloud）是指水平范围广阔（数百公里）、垂直厚度相对均匀、无明显对流活动的云系。典型层状云包括**层云**（St）、**高层云**（As）、**雨层云**（Ns）以及锋面系统中的卷层云（Cs）等。

### 2. 层状云降水的主要特征
| 特征 | 描述 |
|------|------|
| 降水强度 | 中等或弱，持续性（小时到数小时） |
| 降水范围 | 广阔（几十到几百公里） |
| 云中上升气流 | 弱（几 cm/s 到几十 cm/s） |
| 云顶温度 | 常低于 0°C，冷云过程主导 |
| 降水机制 | 以**冰晶过程**（贝吉龙过程、淞附、聚合）为主，暖云碰并次要 |

> 纯层状云（如 As、Ns）降水常称为**连续性降水**（continuous precipitation），与积云的阵性降水不同。

---

## 二、层状云降水的宏观条件

### 1. 大尺度抬升机制
- **锋面抬升**：暖锋或冷锋锋区大范围缓慢抬升
- **地形抬升**：湿空气沿山坡迎风坡爬升
- **辐合抬升**：气旋或低压槽区的大尺度辐合
- **高空槽前/急流出口区**：大尺度上升运动区

上升速度一般为 **1-10 cm/s**（远小于积云的 m/s 量级），但持续时间长，可形成较厚的云层（2-6 km）。

### 2. 水汽条件
- 深厚湿层：从近地面到云顶相对湿度高（> 80%）
- 水汽水平输送：暖湿平流持续供应水汽

### 3. 温度垂直结构
- 云顶温度常低于 -10°C（甚至 -30°C），冷云过程充分
- 云内存在**冰晶层**（上层）、**混合层**（中层）、**暖层**（下层，若有融化层）

---

## 三、层状云降水的物理过程

层状云降水的形成主要依赖**冷云过程**，基本序列为：**冰晶活化 → 凝华增长 → 淞附/聚合 → 下落融化**。

### 1. 冰晶活化（Ice nucleation）
- 在云顶附近（温度 -10°C 至 -30°C），**冰核**（IN）通过凝华核化、接触冻结核化或浸润冻结核化产生初始冰晶。
- 冰晶浓度通常很低（0.01-1 L⁻¹），远低于云滴浓度（10²-10³ cm⁻³）。

### 2. 凝华增长（冰晶）
- 冰晶表面饱和水汽压 $e_{si}(T)$ 低于水滴的 $e_{sw}(T)$，因此水汽优先在冰晶上凝华。
- 由于冰晶数量少，每个冰晶可获得充足水汽，快速生长到 **100-200 μm**。

**增长率**：
$$
\frac{dm}{dt} = 4\pi C \, D_v \, \rho_v \, (S_i - 1) \quad (\text{对扩散生长})
$$
其中 $C$ 为冰晶电容（与形状有关），$S_i = e/e_{si}$ 为冰面过饱和度。

### 3. 淞附（Riming）和聚合（Aggregation）
- 当冰晶下落经过**过冷水层**（0°C 至 -10°C）时，与过冷水滴碰撞，水滴冻结在冰晶表面 → 形成**霰**（graupel）或**雪晶**。
- 雪晶之间也可**聚合**（aggregation）形成更大的雪花（尤其在温度接近 0°C 时）。
- 霰和雪花的密度低，下落速度慢（0.5-2 m/s），有充足时间在云中增长。

### 4. 融化层（Bright band）
- 当降水粒子下落到 0°C 层以下时，雪花或霰融化形成**雨滴**。
- 融化导致雷达反射率突然增大（**亮带**，bright band），是层状云降水的典型雷达特征。
- 雨滴继续下落，可能通过碰并收集云滴增长，但通常已形成可测降水。

### 5. 暖云碰并（次要）
- 在云底附近（0°C 以上），少量雨滴可通过碰并收集云滴，使雨滴进一步增大，但贡献通常小于冷云过程。

---

## 四、层状云降水的典型垂直结构

从上到下，层状云降水系统分为几个特征层：

| 层次 | 温度范围 | 主要过程 | 水成物 |
|------|----------|----------|--------|
| 冰晶层（顶部） | < -20°C | 冰晶活化、凝华增长 | 冰晶、雪晶 |
| 混合层（中部） | -20°C ~ 0°C | 淞附、聚合 | 霰、雪花、过冷水滴 |
| 融化层 | 0°C 左右 | 融化 | 雨滴、部分未融化雪花 |
| 暖雨层 | > 0°C | 碰并收集（较弱） | 雨滴 |

> 观测上，雷达亮带位于融化层，是层状云降水的显著标志。

## 五、层状云降水与积云降水的对比

| 特征 | 层状云降水 | 积云降水 |
|------|------------|----------|
| 垂直速度 | 弱（cm/s） | 强（m/s，可达 10-30 m/s） |
| 云厚 | 2-6 km，较均匀 | 几 km 到十几 km |
| 水平范围 | 数百公里 | 几到几十公里 |
| 降水强度 | 持续性，中到大雨？实际为中雨以下 | 阵性，强，可达暴雨 |
| 冰晶浓度 | 低（0.01-1 L⁻¹） | 高（10-100 L⁻¹，对流区） |
| 主要增长机制 | 凝华 + 淞附 + 聚合 | 凇附 + 碰并 + 循环增长 |
| 雷达特征 | 亮带（融化层） | 回波柱、有界弱回波区（BWER） |
| 降水效率 | 较高（30-60%） | 可变（10-40%） |
| 人工影响 | 可增雨（播撒冰核） | 增雨、防雹 |

## 六、影响层状云降水效率的因素

| 因素 | 影响 |
|------|------|
| **冰核浓度** | 过低则冰晶少，贝吉龙过程弱，降水少；过高则冰晶多但小，可能不融化或蒸发 |
| **云顶温度** | 越低（如 -30°C），冰晶活化越易，凝华增长更充分 |
| **过冷水含量** | 混合层过冷水丰富 → 凇附强 → 霰/雪增长快 |
| **融化层厚度** | 厚则雪花完全融化，降水强；薄可能部分雪花落地（湿雪） |
| **大尺度上升** | 维持云体，补充水汽，延长降水时间 |

---

## 七、层状云降水的雷达与卫星特征

- **雷达反射率**：呈均匀层状结构，有明显的**亮带**（0°C 层融化导致反射率增强）
- **垂直剖面**：反射率随高度先增加（冰晶增长），至融化层达峰值（亮带），以下降低（无亮带时为雨滴）
- **卫星红外**：云顶均匀，纹理平滑，云顶温度低

---

## 八、层状云降水的数值模拟要点

- **微物理方案**：需要详细冰相过程（凝华、凇附、聚合、融化）
- **关键参数**：
  - 冰晶凝华率（依赖于冰面过饱和度、冰晶数浓度）
  - 淞附率（与过冷水含量、霰质量浓度有关）
  - 聚合率（温度依赖）
- **与大尺度模式耦合**：层状云降水通常由大尺度强迫（如锋面抬升）驱动，需要准确的垂直速度场和水汽平流

---

## 九、人工影响层状云降水

- **冷云增雨**：向过冷水层播撒 AgI（或干冰），增加冰晶浓度，促进贝吉龙过程，提高降水效率。
- **时机**：云顶温度 -10°C 至 -20°C 且过冷水丰富时效果较好。
- **效果**：相对增雨 10-30%，但需严格科学评估。

---

## 十、记忆要点

1. **层状云降水**：持续性、大范围、弱上升，以冷云过程（冰晶→凝华→淞附→聚合→融化）为主。
2. **冰晶层**：冰晶活化、凝华生长（贝吉龙过程）。
3. **混合层**：淞附形成霰，聚合形成雪花。
4. **融化层**：雪花/霰融化形成雨滴，雷达亮带。
5. **与积云降水对比**：层状云弱上升、高降水效率、亮带特征。
6. **人工增雨**：播撒冰核可提高层状云降水效率。

## 📌 重点

- 层状云降水以冷云过程为主导：冰晶活化（云顶-10°C至-30°C）→凝华增长（贝吉龙过程，$e_{si} < e_{sw}$）→淞附/聚合→融化（0°C层亮带）
- 垂直四层结构：冰晶层（<-20°C，核化+凝华）→混合层（-20~0°C，淞附+聚合）→融化层（0°C）→暖雨层（>0°C，碰并）
- 冰晶凝华增长率$\frac{dm}{dt} = 4\pi C D_v \rho_v (S_i - 1)$，冰晶电容$C$与形状有关；冰晶数少（0.01-1 L⁻¹）→每个获充足水汽→快速长大
- 雷达亮带是层状云标志特征：雪花/霰在0°C层融化→外层水膜→介电常数突变→反射率增大
- 大尺度缓慢抬升（锋面/地形/辐合，1-10 cm/s）驱动，降水效率高（30-60%），持续时间长
- 与积云降水对比：层状云弱上升、凝华+聚合为主、亮带特征；积云强上升、凇附+碰并+循环增长
- 冰核浓度有最优范围：过低→贝吉龙过程弱→降水少；过高→冰晶过多过小→蒸发不落地
- 人工增雨：向过冷水层（-10~-20°C）播撒AgI→增强贝吉龙过程→提高降水效率10-30%
