# 斜压地转适应与垂直模态

难度：★★★★☆（4/5）｜考试相关度：★★★★☆（4/5）。评级是复习建议，不是命题概率。

直接真题：[[牢三样/往年试题分析/2010|2010 一-4]]。知识专题没有以该问法展开的说明，历年解析已有概要；本页补垂直模态、尺度比较和算例。

## 1．为什么不能照搬一个浅水层

斜压大气的温度和风随高度变化。不平衡扰动会同时涉及风场、质量场、温度场，并激发不同垂直结构的惯性重力波。适当线性条件下可把扰动展开为垂直模态的和，每个模态具有等效波速 $c_n$ 和形变半径
$$L_{Dn}=c_n/|f|.$$
外模态一般较快；内模态通常较慢、形变半径较小。不能把外模态几千公里的尺度直接用于所有内模态。

## 2．各模态的风压调整

对每一模态，类浅水关系为 $\hat\omega_n^2=f^2+c_n^2K_h^2$。比较水平尺度 $L$ 与 $L_{Dn}$：

- $L\gg L_{Dn}$：典型初值调整中，风场较多地向质量场所要求的地转风调整。
- $L\ll L_{Dn}$：质量场较多调整以适应风场。
- 两者相当：两场都有明显调整。

这是尺度倾向，具体幅度仍取决于初始风压扰动。波可以把不平衡能量辐射离开局部区域；封闭无耗散有限区域中的快波也可能反射、持续振荡，不能把调整理解成所有快波必然消失。

## 3．最终平衡需同时满足三类约束

地转关系给出水平风压联系；静力关系联系温度与质量场；两者组合成热成风关系，限制垂直风切变。初始位涡、质量和边界条件共同决定保留的平衡部分。因此“最终没有垂直切变”不是斜压地转适应的结论。

## 4．算例

取均匀稳定层结、刚性上下边界的一种简单内模模型，$m_1=\pi/H$，静力长波近似下 $c_1=N/m_1=NH/\pi$。令 $N=0.01\ \mathrm{s^{-1}},H=10^4$ m、$f=10^{-4}\ \mathrm{s^{-1}}$，得到
$$c_1=31.8\ \mathrm{m/s},\qquad L_{D1}=318\ \mathrm{km}.$$
对 $L=1000$ km，$L/L_{D1}\simeq3.14$，该内模态偏向风场调整。若外模态 $c_0=300$ m/s，则 $L_{D0}=3000$ km，同一水平扰动相对外模态反而为小尺度。系数 $\pi$ 来自此例边界，不应无条件加到所有形变半径公式上。
