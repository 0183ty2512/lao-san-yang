## 温带和东亚气旋与反气旋

### 从全球到东亚的落地视角

前面几节讲的是气旋/反气旋的"通用物理"，这一节把镜头拉到自己家门口——**中国及周边地区**的气旋和反气旋长什么样、从哪里来、到哪里去。

---

## 一、温带气旋

### 1. 定义与基本特征

- **温带气旋** = 锋面气旋，发生在中高纬度，带锋面（冷锋 + 暖锋 + 暖区）
- 水平尺度：一般 1000 ~ 2000 km，大的可到 3000 km（跟中国东西宽度差不多）
- 垂直结构：**斜压性强**——低层冷中心，高空有暖脊，温度场落后于高度场
- 生命史：约 3~5 天（初生 $\to$ 青年 $\to$ 锢囚 $\to$ 消亡）

> **比喻**：如果把台风比作"火焰"（纯热量驱动），温带气旋就是"水流摩擦生电"（冷暖气团摩擦释放能量）。一个是热机，一个是斜压波动。

### 2. 形成模式

| 模式 | 比例 | 条件 |
|------|------|------|
| 静止锋上波动 | >70% | 高空槽前正涡度平流叠加准静止锋 |
| 冷锋进入热倒槽 | ~19% | 冷锋进入暖性低压，暖锋锋生 |
| 锢囚点上新生 | ~5% | 锢囚锋附近新生 |

### 3. 发展机制回顾

- **涡度因子**：高空槽前正涡度平流 → 高层辐散 → 地面减压
- **热力因子**：暖平流/冷平流 → 厚度变化 → 槽脊变频
- **潜热反馈**：上升 → 凝结 → 放热 → 加强上升（爆发性发展）

> **提示**：涡度因子是点火器，热力因子是燃料，潜热反馈是涡轮增压器。三者齐全的气旋发展最猛。

### 4. 典型天气

- 暖锋前：连续性降水（层状云，范围大）
- 冷锋后：阵性降水、大风、降温
- 锢囚阶段：云雨区最广，天气最复杂

### 5. 移动规律

- 沿高空引导气流方向，一般**西南 → 东北**
- 移速约 30~50 km/h

> **思考题**：为什么温带气旋通常向东北方向移动？
>
> **解答**：中纬度对流层盛行西风（偏西风），高空引导气流总体偏西→偏东；同时气旋东南侧暖平流 → 减压区在气旋前方（东北侧），地面系统有向减压区移动的趋势。两者合力 → 西南→东北路径是主流。

## 二、温带反气旋

### 1. 定义与特征

- 中高纬度地面高压，通常**冷性**（冷高压），中心气压高，水平尺度大（常 2000~4000 km）
- 结构：低层冷中心，近地面常有逆温层；高空往往对应脊或脊前西北气流
- 可维持数天至数周

### 2. 来源

- **大陆冷高压**：冬季大陆辐射冷却形成（西伯利亚高压是"巨无霸"）
- **移动性高压**：高空脊后西北气流引导冷高压南下
- **入海变性**：冷高压入海后增温增湿 → 可变为暖性高压

### 3. 天气

- 中心附近：晴好、静风（冬季低温，夏季高温）
- 前缘：常带冷锋，天气剧烈
- 后部：偏南风回暖

> **思考题**：冷高压入海后为什么会"变性"？变性后的高压性质有何不同？
>
> **解答**：冷高压入海后，底层空气接触温暖海水 → 感热从海面输入 → 气团底部增温 → 原来的"冷高压"底部变暖 → 大气层结变为上冷下暖（不稳定）→ 触发对流 → 降水出现。同时高压的冷性减弱，变得像暖性高压，从"晴冷"变为"有阵雨的海上高压"。

## 三、东亚气旋

东亚是全球温带气旋最活跃的区域之一。

### 主要类型一览

| 类型 | 源地 | 多发季节 | 特点 |
|------|------|----------|------|
| **蒙古气旋** | 蒙古高原 | 春、秋 | 强烈，伴随沙尘暴，影响北方 |
| **黄河气旋** | 黄河下游 | 春、夏 | 降水强，可发展为东北气旋 |
| **江淮气旋** | 江淮流域 | 春、夏 | 与梅雨锋相关，暴雨频繁 |
| **西南涡** | 四川盆地 | 春、夏 | 东移后发展为江淮气旋，暴雨重要来源 |
| **东北气旋** | 东北地区 | 春、秋、冬 | 常与蒙古气旋合并 |
| **东海气旋** | 东海 | 冬、春 | 出海气旋，常爆发性发展 |

> **比喻**：东亚气旋就像"接力赛"——西南涡生成于四川盆地 → 东移后变为江淮气旋 → 出海成为东海气旋 → 在日本以东爆发性发展。一个气旋可以在不同阶段被命名为不同类型。

### 移动路径

- **北路**：蒙古 → 内蒙古 → 东北 → 日本海（影响北方、东北亚）
- **中路**：蒙古/河套 → 华北 → 渤海 → 朝鲜半岛（影响华北、东北）
- **南路**：江淮/长江流域 → 东海 → 日本以南（影响华东、日本）

> **重点**：中国东部沿海的"南路"气旋出海后常在日本以东迅速加深为爆发性气旋（气象炸弹），因为那里正好是黑潮暖流所在。

## 四、东亚反气旋

### 1. 西伯利亚高压——冬天的主角

- 冬季大陆最强冷高压，中心气压可达 **1040~1070 hPa**（极端超过 1080 hPa）
- 活动规律：9 月建立 → 10 月加强 → 12~1 月最强 → 4~5 月减弱消失
- 路径：西北路（中路）、东路、西路
- 天气：寒潮、大风、强降温、霜冻

> **比喻**：西伯利亚高压就像冬天里一坨巨大的"冷气团大冰块"，每次都趁着西风带波动"掉"下来一股冷空气（寒潮），让中国大部体验"速冻"。

### 2. 西太平洋副热带高压——夏天的主角

- 副高控制区：高温干旱
- 副高边缘：雷阵雨（水汽输送 + 不稳定）
- 副高位置直接影响中国夏季雨带位置

> **重点**：冬季看西伯利亚高压（冷）、夏季看西太副高（暖），两者一动，中国天气就变天。

### 3. 反气旋天气小结

| 类型 | 季节 | 天气 |
|------|------|------|
| 西伯利亚冷高压 | 冬季 | 晴冷、辐射降温、逆温、雾霾 |
| 副高内部控制 | 夏季 | 晴热、高温、干旱 |
| 副高边缘 | 夏季 | 雷阵雨、暴雨 |
| 入海变性高压 | 过渡季 | 阵雨、不稳定天气 |

## 五、对比总结

| 特征 | 温带气旋 | 温带反气旋 |
|------|----------|------------|
| 气压 | 低压中心 | 高压中心 |
| 北半球环流 | 逆时针 | 顺时针 |
| 有无锋面 | 有（冷锋+暖锋） | 无（冷高压前缘例外） |
| 垂直运动 | 上升（云雨） | 下沉（晴好） |
| 天气 | 阴雨、大风 | 晴好干燥/晴热 |
| 典型东亚系统 | 蒙古气旋、江淮气旋、东海气旋 | 西伯利亚高压、西太副高 |

> **思考题**：中国的"冬冷夏热"气候特征与东亚特有的气旋/反气旋系统有什么关系？
>
> **解答**：冬季西伯利亚高压盘踞蒙古和西伯利亚，不断输送冷空气南下，中国东部盛行偏北风，寒冷干燥；夏季西太副高西伸北抬，其西侧偏南气流将暖湿空气输送到中国东部，同时副高边缘的不稳定触动暴雨。季风环流本质上是大陆冷高压（冬）和海洋副热带高压（夏）季节性交替的结果。而蒙古气旋、江淮气旋等活动系统则在二者交接过程中触发剧烈天气。
