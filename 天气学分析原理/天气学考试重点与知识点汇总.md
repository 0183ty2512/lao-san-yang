### 第九章 天气学分析原理（★★★★★ 最高频）

> 天气学分析原理涵盖气象要素场的定量描述、物理量诊断计算、热力学图解分析及天气图分析方法，是连接动力气象理论与实际天气预报的桥梁。以下知识点均来自1989-2026年试题中对分析方法的直接考查。

#### 9.1 基本物理量诊断计算

| 考点 | 出现频次 | 最近出现 |
|------|----------|----------|
| 涡度（表达式/计算） | 5次 | 2005 |
| 散度（表达式/计算） | 4次 | 2005 |
| 温度平流（表达式与定性判断） | 5次 | 2026 |
| 垂直速度（计算方法与量级） | 2次 | 2003 |
| 水汽通量与水汽通量散度 | 1次 | 2023 |
| 连续方程（表达式与物理意义） | 2次 | 2001 |
| 流函数与势函数 | 2次 | 2018 |

**核心公式**：
- 涡度：$\zeta = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}$，绝对涡度 $\zeta_a = \zeta + f$
- 散度：$D = \nabla \cdot \vec{V} = \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}$
- 温度平流：$-\vec{V} \cdot \nabla T = -(u\frac{\partial T}{\partial x} + v\frac{\partial T}{\partial y})$
- 流函数/势函数：$\vec{V} = \vec{k} \times \nabla \psi + \nabla \chi$，涡度 $\zeta = \nabla^2\psi$，散度 $D = \nabla^2\chi$
- 垂直速度量级：天气尺度 **1~10 cm/s**（几hPa/h），中尺度对流系统 **1~10 m/s**（几十hPa/h）
- 散度量级：行星尺度 $10^{-6}$ s⁻¹，对流系统 $10^{-3}$ s⁻¹
- 水汽通量：$\frac{1}{g}q\vec{V}$；水汽通量散度：$\nabla \cdot (\frac{1}{g}q\vec{V})$

#### 9.2 热力学变量与图解分析

| 考点 | 出现频次 | 最近出现 |
|------|----------|----------|
| 位温 $\theta$（定义/表达式/推导） | 6次 | 2022 |
| 假相当位温 $\theta_{se}$ | 3次 | 2000 |
| 假绝热（湿绝热）过程 | 1次 | 2023 |

**知识关联链**：
```
位温θ（干绝热守恒量）
  → 假相当位温θse（湿绝热守恒量，含潜热）
    → 夏季剖面分析用θse（考虑水汽凝结潜热释放）
      → θse随高度减小 → 对流不稳定
```

**核心理解**：
- **位温** $\theta = T(\frac{p_0}{p})^{R/c_p}$：未饱和空气块干绝热移到1000hPa时的温度，干绝热过程中守恒
- **假相当位温** $\theta_{se}$：包含水汽全部凝结释放潜热后的位温，湿绝热过程中守恒
- 夏季分析中用 $\theta_{se}$ 代替 $\theta$ 的原因：夏季水汽充沛，凝结潜热不可忽略，$\theta_{se}$ 能同时反映温度和湿度的影响，是更全面的热力学守恒量
- **假绝热过程**：水汽凝结后立即脱离气块（与外界无水汽交换），过程不可逆

#### 9.3 大气稳定度分析

| 考点 | 出现频次 | 最近出现 |
|------|----------|----------|
| 位势稳定度（定义与判据） | 2次 | 1999 |
| 对流不稳定（位势不稳定） | 2次 | 2004 |
| 条件不稳定 | 1次 | 2005 |
| 稳定度综合概念 | 1次 | 2004 |

**稳定度判别**：
```
静力稳定度（气块法）
  ├── 绝对不稳定：γ > γd（层结递减率 > 干绝热递减率）
  ├── 条件不稳定：γm < γ < γd
  └── 绝对稳定：γ < γm

对流（位势）不稳定：
  ∂θse/∂z < 0 → 对流不稳定（整层抬升后不稳定能量释放）
  ∂θse/∂z > 0 → 对流稳定
```

#### 9.4 天气图分析基础

| 考点 | 出现频次 | 最近出现 |
|------|----------|----------|
| 地转风表达式及分析应用 | 3次 | 2002 |
| P坐标系/等压面图分析原理 | 2次 | 1999 |
| 位势/位势高度/压高公式 | 3次 | 2024 |
| 静力方程（表达式与物理意义） | 3次 | 2024 |
| 气压系统基本形式与变化原因 | 1次 | 2004 |
| 剖面分析 | 1次 | 1989 |
| 流线与轨迹 | 1次 | 1994 |

**知识关联链**：
```
坐标变换（Z→P）
  → 静力平衡 → 压高公式（气压与高度对应关系）
    → 等压面图（位势高度场代替等高面，简化方程）
      → 地转风原则（风沿等高线/等位势高度线吹）
        → 天气图分析（等压面图+地面图+辅助图）
```

**核心理解**：
- **P坐标系优越性**：①等压面上密度为常数，方程简化；②实际观测以气压为基准；③静力方程直接给出压高关系
- **用等压面代替等高面**的原因：等压面上空气密度均匀，消除了密度水平变化的影响，运动方程简洁
- **位势** $\Phi = \int_0^z g\,dz$（单位：位势米 gpm），位势高度 $H = \Phi/g_0$（$g_0 = 9.8$ m/s²）
- **压高公式**：$z_2 - z_1 = \frac{R\bar{T}}{g}\ln\frac{p_1}{p_2}$（静力平衡+状态方程导出，2024年推导题）
- **气压系统基本形式**：低压、高压、槽、脊、鞍形场——由等压线（等位势高度线）形态确定
- **剖面分析**：空间垂直剖面和时间剖面，夏季用 $\theta_{se}$ 代替 $\theta$ 分析大气层结

#### 9.5 动力学诊断方程

| 考点 | 出现频次 | 最近出现 |
|------|----------|----------|
| 涡度平流定性判断 | 4次 | 2017 |
| ω方程各项意义 | 5次 | 2017 |
| 位势倾向方程 | 4次 | 2017 |
| 位涡守恒及应用 | 5次 | 2021 |
| 涡度方程各项意义 | 2次 | 2017 |
| 地转偏差表达式 | 1次 | 2010 |

**知识关联链**：
```
涡度方程（六大因子）
  → 准地转涡度方程（简化）
    → 位势倾向方程（诊断高度场变化）
      → ω方程（诊断垂直运动）
        → 位涡守恒（绝热无摩擦下PV守恒）
          → 应用：气流过山背风坡低压槽形成机制
```

**核心理解**：
- **ω方程**：$\sigma\nabla^2\omega + f_0^2\frac{\partial^2\omega}{\partial p^2} = -\frac{R}{p}\nabla^2(-\vec{V}_g\cdot\nabla T) + f_0\frac{\partial}{\partial p}[-\vec{V}_g\cdot\nabla(\zeta_g+f)]$
  - 右第一项：**温度平流拉普拉斯**（暖平流→上升，冷平流→下沉）
  - 右第二项：**涡度平流随高度变化**（正涡度平流随高度增加→上升）
- **位涡**：$PV = \frac{\zeta+f}{\rho}\frac{\partial\theta}{\partial p}$，绝热无摩擦守恒 $d(PV)/dt = 0$
- 气流过山背风坡低压槽：山脉背风坡气柱拉伸→$\zeta$ 增大→气旋性弯曲→低压槽
- **地转偏差** $\vec{V}' = \vec{V} - \vec{V}_g = \frac{1}{f}\vec{k}\times\frac{d\vec{V}_g}{dt}$，是大气运动的演变机制

## 四、高频推导题型总结

### 1. 罗斯贝波频散关系推导（最常考）
**步骤**：
1. 线性化正压无辐散涡度方程
2. 引入扰动流函数 $\psi = \psi_0 e^{i(kx+ly-\omega t)}$
3. 代入得频散关系：$\omega = k\bar{u} - \frac{\beta k}{k^2+l^2}$
4. 波速：$c = \frac{\omega}{k} = \bar{u} - \frac{\beta}{k^2+l^2} = \bar{u} - \beta(\frac{L}{2\pi})^2$
5. 群速：$c_g = \frac{\partial\omega}{\partial k} = \bar{u} + \beta\frac{k^2-l^2}{(k^2+l^2)^2}$

### 2. 重力惯性外波推导
**步骤**：
1. 浅水方程组
2. 线性化（$u = \bar{u}+u'$，$h = H_0+h'$）
3. 设扰动与y无关，设波动解 $e^{i(kx-\omega t)}$
4. 得频率方程：$(\omega - k\bar{u})^2 = f_0^2 + gH_0k^2$
5. 相速：$c = \bar{u} \pm \sqrt{f_0^2/k^2 + gH_0}$
6. 群速：$c_g = \bar{u} \pm \frac{gH_0k}{\sqrt{f_0^2 + gH_0k^2}}$

### 3. 位涡方程推导
**步骤**：
1. 从水平运动方程+连续方程出发
2. 取涡度方程
3. 利用位温守恒
4. 组合得 $\frac{d}{dt}(\frac{\zeta+f}{\rho}\frac{\partial\theta}{\partial p}) = 0$

### 4. 位温表达式推导（2022年考）
**步骤**：
1. 从热力学能量方程出发：$c_v\frac{dT}{dt} + p\frac{d\alpha}{dt} = \dot{Q}$
2. 利用 $c_p = c_v + R$ 和 $p\alpha = RT$，推出 $c_p\frac{dT}{dt} - \alpha\frac{dp}{dt} = \dot{Q}$
3. 干绝热过程 $\dot{Q}=0$，得 $c_p\,dT = \alpha\,dp$
4. 代入状态方程 $\alpha = RT/p$，得 $c_p\frac{dT}{T} = R\frac{dp}{p}$
5. 积分得 $Tp^{-R/c_p} = const$
6. 引入 $p_0 = 1000$hPa，得 $\theta = T(\frac{p_0}{p})^{R/c_p}$

### 5. 压高公式推导（2024年考）
**步骤**：
1. 从静力平衡方程出发：$\frac{\partial p}{\partial z} = -\rho g$
2. 代入状态方程 $p = \rho RT$ → $\rho = p/(RT)$
3. 得 $\frac{dp}{p} = -\frac{g}{RT}dz$
4. 积分：$\int_{p_1}^{p_2}\frac{dp}{p} = -\frac{g}{R}\int_{z_1}^{z_2}\frac{dz}{T}$
5. 引入气层平均温度 $\bar{T}$，得压高公式：$z_2 - z_1 = \frac{R\bar{T}}{g}\ln\frac{p_1}{p_2}$
6. 物理意义：两层等压面之间的厚度与气层平均温度成正比（暖层厚、冷层薄）
