假相当位温随高度减小时大气处于对流不稳定状态，东北低压对应的高空急流为极锋急流。

解析来源（对应题目行） · 原始年度题干

审校状态：尚未逐题学科审校。

相关高频考点复习摘要（须按本题设问取舍，不替代完整解答）：

位势不稳定： 位势不稳定针对整层抬升，常以 $\partial\theta_e/\partial z<0$ 或教材的假相当位温梯度判断。整层抬升饱和后可转为不稳定。它不同于单气块条件不稳定 $\Gamma_m<\Gamma<\Gamma_d$，两者不能简单当同义词。

高空急流： 高空急流是对流层上部狭长强风带，横向和垂直切变强。极锋急流与斜压锋区相关，副热带急流还受低纬角动量输送影响；冬强偏南、夏弱偏北。急流加减速与曲率引起非地转次级环流，可影响下方上升和气旋发展。

以上摘要用于回忆答题主线，不是官方评分标准；推导、计算和多小问仍须完成下方步骤。

原记录填空值： 对流不稳定；极锋急流。下文核对其物理含义；出现修改意见时，以修改后的说明为准。

  1. 干大气 $N^2=(g/\theta)d\theta/dz$。位温随高度增大为干静力稳定，等位温为中性，随高度减小为不稳定。这是对单个小气块竖直位移的判据。

  2. 饱和上升时潜热释放使湿绝热直减率 $\Gamma_m<\Gamma_d$。若环境直减率满足 $\Gamma_m<\Gamma<\Gamma_d$，未饱和气块稳定而饱和气块不稳定，称条件不稳定。

  3. 位势（对流）不稳定针对整层抬升：$d\theta_e/dz<0$（按教材也用假相当位温 $\theta_{se}$）时，抬升至饱和后低层更暖湿、释放更多潜热，整层可转为不稳定；位势稳定度可写成 $\partial\theta_e/\partial z$，在 $p$ 坐标符号相反。

  4. 条件不稳定与位势不稳定并非同义，原题若写“条件（位势）不稳定”应分别说明。常见应用是雷暴：先由抬升克服抑制，气块达到自由对流高度后释放不稳定能量，并非有不稳定层结就必然立刻降雨。

  5. 急流是狭长的强风带，横向和竖直风切变显著，急流轴是局地最大风速的位置。高空西风急流位于对流层上部，冬季更强、更偏南；夏季整体偏北、减弱。东亚日本附近冬季急流可很强，题中 70—80 m/s 是典型量级而非上限。

  6. 极锋急流与中纬度锋区斜压性相联系；副热带急流还与低纬向极运动的角动量输送和热成风共同有关。强南北温度梯度通过热成风使西风随高度增强；不能只归因于地面风向上复制。

  7. 急流入口、出口的加减速和曲率导致非地转次级环流，局部辐散有利于下方上升和气旋发展；简单直急流象限规则只在相应理想条件下适用。

2024-三-3 · 完整解答

长波辐射的传播特征，并用来解释温室效应

修改意见（2026-10-05，第三批）：

补吸收与发射并存的传输方程及积分解，用顶层收支解释温室效应。

核对依据： 地球－大气系统的长波辐射。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列物理条件、方程推导和所列外部依据判断。

复核后详细解答：

  1. 波段及物质。 地表与大气温度约为数百K，主要发出热红外长波。水汽、二氧化碳、臭氧等在不同谱带吸收并发射；云也有显著作用。大气窗口相对透明，但受水汽和云影响，并非任何天气下都完全透明。
  2. 单条光路传输。 沿辐射传播方向$s$，局地热力学平衡且忽略长波散射时，$dI_\nu/ds=-\beta_{a,\nu}I_\nu+\beta_{a,\nu}B_\nu(T)$。第一项移除原光束，第二项是当地介质热发射；同一吸收系数出现在两项体现Kirchhoff关系。设沿程$d\tau_\nu=\beta_{a,\nu}ds$，则$dI_\nu/d\tau_\nu+I_\nu=B_\nu(T)$。
  3. 逐步求解。 两边乘积分因子$e^{\tau}$，得$d(Ie^\tau)/d\tau=B(T)e^\tau$。从0到$\tau$积分：$I(\tau)e^\tau-I(0)=\int_0^\tau B[T(t)]e^t dt$，所以 $$I(\tau)=I(0)e^{-\tau}+\int_0^\tau B[T(t)]e^{-(\tau-t)}dt.$$ 结果明确分为原有辐射透过和沿程各层发射。不能只写$I=I_0e^{-\tau}$而漏掉温暖大气自身的长波发射。
  4. 地表和大气之间。 地面长波一部分经窗口到太空，一部分被大气和云吸收；大气向上和向下均发射。向下长波使地面净长波损失小于其单独向上发射量，但辐射净能量仍可由较暖地表流向较冷环境，不违反热力学第二定律。
  5. 温室效应的顶层解释。 取太阳吸收暂不变，增加红外吸收能力后，在对流层温度通常随高度下降的情况下，许多波段向太空的有效辐射高度升高，来自更冷的层，固定温度廓线时向外长波减小。输入大于输出形成能量积累，地表和对流层随后增温，直到大气顶出射重新与吸收太阳辐射相平衡。
  6. 简单模型核对。 仅为解释机制，设全球均匀地表为黑体，大气一层对短波透明、对长波全吸收，且忽略对流。记吸收太阳通量为$F$。大气收地表$\sigma T_s^4$，向上下各发$\sigma T_a^4$，故$\sigma T_s^4=2\sigma T_a^4$；大气顶平衡要求$\sigma T_a^4=F$，因此$T_s=(2F/\sigma)^{1/4}$，比无大气时$T_e=(F/\sigma)^{1/4}$高。真实大气部分吸收、多层、存在对流与云，不能把该模型温度当成地球实测值。
  7. 限定。 温室效应不是辐射被永远困住，也不是温室气体只吸收不发射。云、冰粒等情形可能需要长波散射；本题的传输式是在明确近似下说明主过程。

地转偏差对大气运动的演变作用

核对依据： 平衡流场的基本特征与性质。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列方程推导与量纲检查作出判断。

复核后详细解答：

  1. 定义。 水平实际风与同一质量场对应的地转风之差为$\mathbf V_a=\mathbf V-\mathbf V_g$。采用气压坐标，$f\mathbf k\times\mathbf V_g=-\nabla_p\Phi$。
  2. 由动量方程求偏差。 实际运动满足$D\mathbf V/Dt+f\mathbf k\times\mathbf V=-\nabla_p\Phi+\mathbf F$，其中$\mathbf F$为摩擦加速度。减去地转关系得$D\mathbf V/Dt+f\mathbf k\times\mathbf V_a=\mathbf F$。左乘$\mathbf k\times$，利用水平向量恒等式$\mathbf k\times(\mathbf k\times\mathbf V_a)=-\mathbf V_a$： $$\boxed{\mathbf V_a=\frac1f\mathbf k\times\left(\frac{D\mathbf V}{Dt}-\mathbf F\right)}.$$ 无摩擦时偏差风在加速度左侧（北半球）；定常无惯性时为$-\mathbf k\times\mathbf F/f$，在摩擦力右侧。参考笔记的摩擦公式若写正号，应按其力定义核对；按“作用于空气的摩擦力”约定须为上述负号。
  3. 质量与垂直运动。 常数$f$下$u_g=-\Phi_y/f,v_g=\Phi_x/f$，混合偏导相消，$\nabla_p\cdot\mathbf V_g=0$。于是实际散度来自偏差风，连续方程$\nabla_p\cdot\mathbf V+\omega_p=0$把它与垂直运动联系。给定边界及整层散度后才能确定$\omega$，不能只凭一个层次的辐散断定全柱上升。
  4. 热力与系统演变。 垂直运动改变绝热冷却增温及水汽凝结，反过来调整温度和位势场；急流加减速、曲率和摩擦可产生次级环流，因此近地转的大尺度系统仍能发展。
  5. 能量联系。 水平气压梯度功率为$-\mathbf V\cdot\nabla_p\Phi$。地转风与$\nabla_p\Phi$垂直，其贡献为零；故压力功由$-\mathbf V_a\cdot\nabla_p\Phi$承担，非地转分量联系质量场与动能转换。
  6. 适用限制。 在β平面，$\nabla_p\cdot\mathbf V_g=-\beta v_g/f$一般不为零；“地转风无散度”须注明$f$平面或相应近似阶次。近赤道$f$趋零时，不可直接套用含$1/f$的中纬度近似。

准地转运动

修改意见（2026-10-07，第四批）：

给出准地转运动的展开条件和非地转次级环流作用，避免等同严格地转或零垂直运动。

核对依据： 尺度分析和基本方程组的简化；平衡流场的基本特征与性质。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列物理条件、方程推导和所列外部依据判断。

复核后详细解答：

  1. 水平动量式为$D\mathbf V_h/Dt+f\mathbf k\times\mathbf V_h=-\nabla_hp/\rho$（等高面形式，暂忽略摩擦）。惯性项与科氏项比值分别是$Ro=U/(|f_0|L)$、$Ro_t=1/(|f_0|T)$。
  2. 当两者均小，并采用一致的稳定层结、弱β变化等准地转尺度安排时，最低阶水平动量为$f_0\mathbf k\times\mathbf V_g=-\nabla_hp/\rho$；垂直方向近似静力平衡。风写为$\mathbf V_h=\mathbf V_g+\mathbf V_a$，其中$|\mathbf V_a|/U=O(Ro)$。
  3. 常$f_0$等压面地转风$\mathbf V_g=\mathbf k\times\nabla_p\Phi/f_0$满足$\nabla_p\cdot\mathbf V_g=0$；非地转风的散度与$\partial_p\omega$通过连续式相联系，产生次级环流。因此近地转不等于实际散度和垂直速度严格为零。
  4. 准地转运动的时间演变由涡度、热力学及连续关系共同约束；小非地转项虽然不主导瞬时水平力平衡，却不能从全部预报方程中删掉。
  5. 赤道附近$f_0\to0$、强摩擦边界层、快速调整或强对流等不满足上述条件，不能普遍使用同一准地转近似。

锋生

修改意见（2026-10-07，第四批）：

保留锋生函数但增加简单收缩流的逐步检验，强调水平温度梯度增强。

核对依据： 锋生和锋消过程。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列物理条件、方程推导和所列外部依据判断。

复核后详细解答：

  1. 锋生指已有锋区加强或由较弱水平热力梯度逐渐形成锋区。以位温定义$\mathbf G=\nabla_h\theta$，锋生函数$F=D|\mathbf G|/Dt$；$F>0$为锋生，$F<0$为锋消。某地气温下降并不自动说明锋生，关键是相邻气团之间的梯度是否增强。
  2. 由$D\theta/Dt=\dot\theta$对水平坐标$x_i$求导，注意导数与随体导数不交换：$DG_i/Dt=\partial_i\dot\theta-(\partial_iu_j)G_j-(\partial_iw)\theta_z$，其中$i,j=x,y$且重复$j$求和。
  3. 利用$D|\mathbf G|/Dt=G_i(DG_i/Dt)/|\mathbf G|$，得 $$F=\frac{\mathbf G\cdot\nabla_h\dot\theta-G_i(\partial_iu_j)G_j-\theta_z\mathbf G\cdot\nabla_hw}{|\mathbf G|}.$$ 三部分为差异非绝热加热、水平变形/辐合、竖直倾斜作用，符号由具体场决定。
  4. 取二维收缩—伸长流$u=-ax,v=ay,a>0$，水平总散度为0，但若温度梯度沿$x$，且绝热、无倾斜，$F=-|G|u_x=a|G|>0$。说明即使总散度为零，变形压缩跨锋距离也能锋生。
  5. 因此不能把“锋生”只定义为辐合，也不能认为气旋性旋转本身就一定增强温度梯度。名词解释可写第1点及三类机制，推导用于理解与防错。

辐射差额

修改意见（2026-10-05，第三批）：

明确采用地表向下为正的净辐射约定，与有效辐射和地表总能量收支分开。

核对依据： 太阳辐射在地球大气中的传输；地球－大气系统的长波辐射。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列物理条件、方程推导和所列外部依据判断。

复核后详细解答：

  1. 地表辐射差额是地表吸收的总辐射通量与向外辐射通量之差，即地表净辐射，单位$\mathrm{W/m^2}$。本解统一取使地表获得能量为正。
  2. 分开短波与长波：入射短波$S_\downarrow$减反射短波$S_\uparrow$，再加大气向下长波$L_\downarrow$减地表向上长波$L_\uparrow$，故 $$R_n=S_\downarrow-S_\uparrow+L_\downarrow-L_\uparrow.$$
  3. 定义地表短波反照率$\alpha=S_\uparrow/S_\downarrow$，以及有效长波辐射$L_{\rm eff}=L_\uparrow-L_\downarrow$，便有$R_n=(1-\alpha)S_\downarrow-L_{\rm eff}$。所以有效辐射只对应长波净损失，不等于全部辐射差额。
  4. 白天短波吸收常使$R_n>0$；夜间$S_\downarrow\approx0$，通常净长波损失使$R_n<0$，但这些是常见情形而非定义的一部分。
  5. 净辐射可用于感热、潜热、地中热通量和储能变化。它本身不包含这些非辐射项；不能把完整地表能量收支等同于辐射差额。若题目改为大气顶收支，须重设边界与各项。
