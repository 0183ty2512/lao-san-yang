2015-二-3 · ★★★（同考点5年）

暴雨形成的条件。

解析来源（对应题目行） · 原始年度题干

原资料审校标记（未由本站重新逐题验证）：尚未逐题学科审校。

相关高频考点复习摘要（须按本题设问取舍，不替代完整解答）：

暴雨形成条件： 暴雨需充足并持续的水汽供应、有效抬升、较高降水效率和足够持续时间。锋面、切变、低涡、地形及冷池可触发；不稳定与风切变可组织强对流，训练效应增加累积雨量。并非所有暴雨都要求强条件不稳定。

以上摘要用于回忆答题主线，不是官方评分标准；推导、计算和多小问仍须完成下方步骤。

  1. 暴雨需要持续的水汽供应、有效抬升和较高降水效率，并常有不稳定能量与中尺度组织配合。水汽只是原料；没有辐合和抬升，湿空气未必产生暴雨。

  2. 水汽由低空急流等输送至锋区或切变线，辐合后被迫抬升。锋面、低涡、切变线、地形及雷暴冷池出流均可触发上升；暖湿气块达到自由对流高度后释放不稳定能量。

  3. 风切变使对流组织化，冷池和环境风配合可反复触发新单体；系统移动缓慢或单体沿相似路径连续经过同一区域，形成训练效应，增加累计雨量。层状降水也可产生暴雨，不能把强条件不稳定列为每场暴雨的绝对必要条件。

  1. 环境条件。 低层暖湿、具有可释放的不稳定能量，锋面/辐合线/地形等提供抬升；适宜的垂直风切变使上升和下沉气流分离，支持较长寿命。强切变有助组织化，但不能取代水汽和浮力。

  2. 组织类型。 多单体风暴由不同生命阶段单体组成，冷池边界不断触发新单体，整体比单个单体活得久；超级单体的识别核心是深厚、持续旋转的上升气流（中气旋），不是单纯雨量最大。NWS 超级单体说明

  3. 飑线是沿线状排列并组织成系统的强对流，前缘辐合与冷池推进触发新生对流，可有后部层状降水。过站时常风向突变、阵风增强、温度骤降、气压骤升，伴雷雨、冰雹等；地面升压主要与冷池密度增加及动力作用有关。

2016-三-2 · ★★★★（同考点10年）

什么是 CISK？扰动来源是什么，用台风的发生发展为例论述。

解析来源（对应题目行） · 原始年度题干

原资料审校标记（未由本站重新逐题验证）：尚未逐题学科审校。

相关高频考点复习摘要（须按本题设问取舍，不替代完整解答）：

第二类条件不稳定（CISK）： CISK是对流和大尺度环流的正反馈：初始旋转扰动→摩擦辐合和水汽输送→凝结潜热加热→暖心、质量场及高层外流调整→低压和辐合增强。能量依海气焓供应与湿对流转化，不能把凝结视作凭空产能。

以上摘要用于回忆答题主线，不是官方评分标准；推导、计算和多小问仍须完成下方步骤。

  1. 初始扰动。 季风槽、热带辐合带扰动、东风波、赤道罗斯贝波等可提供涡度、辐合和持续对流。多数初始扰动不会发展，环境与内部组织过程都重要。

  2. CISK 链条。 初始低压旋转 → 边界层摩擦造成向中心的水汽辐合 → 对流凝结释放潜热 → 暖心及质量场调整、高层外流加强 → 低压和低层旋转增强 → 更强辐合。对流和大尺度环流相互反馈而非单独气块条件不稳定，因此称第二类条件不稳定。它是理想化解释，现代海气通量反馈等机制不可省略。

  3. 能量。 水汽主要由暖海蒸发补给，海面潜热和显热通量提供焓；凝结将潜热释放，暖升冷沉及压力功转化为动能，摩擦耗散动能。不能把凝结说成凭空制造能量。

2018-三-1 · ★★★★（同考点7年）

什么是台风？以及台风发生发展的有利条件

解析来源（对应题目行） · 原始年度题干

原资料审校标记（未由本站重新逐题验证）：尚未逐题学科审校。

相关高频考点复习摘要（须按本题设问取舍，不替代完整解答）：

热带气旋概念： 热带气旋是在热带或副热带海洋形成、具闭合低层气旋环流和有组织对流的非锋面暖心系统。台风是西北太平洋等区域达到规定强度的名称；低层入流、中层眼墙上升、高层外流是其典型结构。

热带气旋生成条件： 热带气旋生成需暖海焓供应、暖湿且有对流潜能的环境、较弱垂直风切变、可用科氏作用、初始低层旋转扰动和高层外流。季风槽、东风波等可提供初始扰动；有利条件不等于保证生成。

以上摘要用于回忆答题主线，不是官方评分标准；推导、计算和多小问仍须完成下方步骤。

  1. 定义。 热带气旋是在热带或副热带海洋形成、具有闭合低层气旋环流和有组织深对流的非锋面暖心系统；台风是西北太平洋等区域达到规定强度的热带气旋称谓，不能把所有热带低压直接叫台风。

  2. 结构与分层。 低层摩擦入流、气旋旋转和辐合；中层眼墙强上升、强风和强降水，外围有螺旋雨带；高层向外辐散，常带反气旋性外流。中心气压低、温度暖，最大风通常在眼墙附近而不在眼中心。眼区下沉增温、相对湿度低、风较弱，可有低云，不能绝对说完全无云。

  3. 生成条件。 较深的暖海水供给焓，低层暖湿、对流潜能和中层湿度较充足，垂直风切变较弱，有初始低层旋转扰动及高层有效外流；离赤道要足够远以有可用科氏作用。常用约 26.5℃ 是经验参考，并非脱离海洋热含量和大气状态的绝对门槛。

  4. 初始扰动。 季风槽、热带辐合带扰动、东风波、赤道罗斯贝波等可提供涡度、辐合和持续对流。多数初始扰动不会发展，环境与内部组织过程都重要。

  5. CISK 链条。 初始低压旋转 → 边界层摩擦造成向中心的水汽辐合 → 对流凝结释放潜热 → 暖心及质量场调整、高层外流加强 → 低压和低层旋转增强 → 更强辐合。对流和大尺度环流相互反馈而非单独气块条件不稳定，因此称第二类条件不稳定。它是理想化解释，现代海气通量反馈等机制不可省略。

  6. 能量。 水汽主要由暖海蒸发补给，海面潜热和显热通量提供焓；凝结将潜热释放，暖升冷沉及压力功转化为动能，摩擦耗散动能。不能把凝结说成凭空制造能量。

复核后详细解答：

发生发展的有利环境及原因：

  1. 暖海及持续焓供应。 海面蒸发与显热交换补给空气能量，较深暖水层有助于抵抗风暴搅拌造成的海面冷却。常用约26.5℃是经验参考，不能脱离整层海洋热含量和大气热力状态当绝对阈值。
  2. 适于深对流的热力状态和湿度。 低层暖湿、一定的对流潜能及较湿中层，使凝结加热能持续组织；干空气卷入可导致蒸发冷却并削弱对流组织。
  3. 低层初始旋转与辐合。 已有扰动提供气旋性涡度和低层汇流，使分散对流更容易集中为涡旋。不能仅凭海水暖就凭空生成闭合气旋。
  4. 可用的地球旋转作用。 通常离赤道有一定距离，科氏作用有利于组织环流；“约5°以外”是常见经验，而不是数学上的绝对禁区，仍须看实际绝对涡度及扰动。
  5. 较弱的深层垂直风切变。 有利于低层中心、深对流及暖心在垂直方向保持耦合；过强切变容易使涡旋倾斜并把加热区移离中心。具体影响还依切变方向、结构和涡旋强度。
  6. 与对流相配合的高层外流。 上升空气能在上层向外输送，配合整柱质量调整和持续深对流；外流既是环流响应也可受环境促进，不能孤立地当作一个永远预先存在的开关。

这些条件是传统“必要条件”问法下应说明的环境因素，满足若干条不保证形成或增强。关于海温经验值与暖水层作用，可交叉参阅NOAA海洋条件说明；不把统计经验改写成无例外定律。

CISK反馈（第二问）： 初始弱低压旋转→摩擦使低层气流向中心汇入→水汽辐合与抬升组织积云→凝结加热及暖心发展→上层外流、整柱质量和压力场调整→低压及环流增强→再次加强汇流。需要反馈超过耗散；加热本身并非地面必降压的充分条件。水汽能量先由海气焓交换补给，再经热力过程及压力功转为动能。

初始扰动类型（第三问）：

  1. 热带东风波中的气旋性扰动，可提供低层涡度、辐合及对流组织。
  2. 季风槽、热带辐合带内的低压涡旋或有组织云团，具有气流汇聚及旋转背景。
  3. 赤道罗斯贝波等热带波动的气旋性部分，以及多尺度相互作用形成的旋转扰动，可提供或增强胚胎涡旋。
  4. 这些类别可能重叠：一个云团可同时处在季风槽及东风波环境内。不是所有热带波动都能直接演变成台风，不填写缺乏样本依据的各类生成百分比。

热带扰动发生发展的 CISK 机制

修改意见（2026-10-04）：

原反馈主线正确；补质量收支环节，避免把“加热”直接等同“地面降压”，并区分能量供应和能量转换。

核对依据： 台风发展的第二类条件不稳定（CISK）理论。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列方程推导与量纲检查作出判断。

复核后详细解答：

  1. 概念。 第二类条件不稳定强调有组织的大尺度环流与积云对流之间的反馈，区别于仅讨论单气块在环境中浮力增长的第一类条件不稳定。
  2. 初始旋转扰动。 环境中先有弱低压或气旋性扰动；边界层摩擦削弱切向风，使空气产生向低压的入流，组织水汽辐合与抬升。初始扰动可由东风波、季风槽等提供，但并非任一扰动都会发展。
  3. 积云响应。 暖湿空气抬升到饱和，对流凝结释放潜热，增加气柱热力能并形成有组织的加热；加热的位置、湿度和垂直风切变影响其是否能有效作用于涡旋。
  4. 环流反馈。 加热促使厚度和压力场调整、暖心及上层外流发展。在整柱质量净流出等条件下，地面气压降低，低层压力梯度与气旋环流增强，进一步加强摩擦入流。地面气压取决于柱质量；单凭“气柱变暖”不能无条件推出地面降压。
  5. 闭合反馈链。 弱扰动→低层辐合及水汽供应→对流加热→暖心、外流及质量场调整→扰动增强→辐合增强。只有反馈增长能克服耗散和不利环境作用时，才会发展。
  6. 能量来源与局限。 暖海通过蒸发潜热及显热通量补给空气焓，对流把水汽所携能量释放为热力能，适当热力—环流配置再将部分能量转为动能。CISK是理想化反馈框架，不能以它替代所有热带气旋发展机制，也不能把经验海温或切变数值当成无例外的充分条件。

什么是第二类条件性不稳定（CISK）？能量来源是什么？

复核后详细解答：

  1. 定义。 第二类条件不稳定是大尺度环流与积云对流相互促进的理想化机制；第一类条件不稳定主要讨论单气块的浮力，而CISK强调环流组织与对流反馈。
  2. 环流促进对流。 初始低压和旋转扰动产生边界层入流、摩擦辐合，集中水汽并提供抬升，使对流能持续地组织在扰动附近。
  3. 对流反馈环流。 凝结加热促使暖心和上层外流发展，经过压力及整柱质量调整，低压环流可以加强，进一步增强低层汇流。加热不能单独保证地面降压，尚需质量收支配合。
  4. 能量来源。 水汽所携能量主要由暖海蒸发等海气交换提供；凝结把这部分潜热转成热力能，适当的暖升冷沉及压力功把其中一部分转为动能，动能又有摩擦耗散。完整回答应写“海面供应→潜热释放→热力与压力功转换→动能”，不只写“能量来自凝结”。
  5. 条件和局限。 湿度、风切变、初始涡旋及对流位置决定反馈能否胜过耗散。CISK不是全部台风发展过程的唯一解释，也不等于每次对流都会增强台风。
