大气臭氧的形成及消散机制

修改意见（2026-10-05，第三批）：

补全Chapman反应及催化损耗的净反应，并区分对流层臭氧生成。

核对依据： 臭氧与大气散射。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列物理条件、方程推导和所列外部依据判断。

复核后详细解答：

  1. 生成第一步：氧分子光解。 能量足够的短波紫外使，为后续提供氧原子。短波紫外随向下传播被吸收，故生成受高度影响。
  2. 生成第二步：三体结合。 氧原子与氧分子结合：。一般为空气中的第三体，带走多余能量以稳定产物，本身没有被净消耗。空气过稀时三体碰撞机会减少。
  3. 直接光解与回收。 臭氧吸收适当波长辐射后。生成的氧原子可能再结合为臭氧，所以一次臭氧光解并不总意味着活性氧族永久损失；它同时参与平流层辐射加热和光化学平衡。
  4. 终止反应。 使氧原子和臭氧都转为普通氧分子。生成、光解和此反应构成经典Chapman机制的基本反应组，但单靠它不能准确描述全部实际臭氧量。

运用大气物理知识解释气溶胶在云雾降水及大气辐射中的作用？

修改意见（2026-10-05，第三批）：

核对依据： 大气气溶胶的概念、谱分布、来源及在大气过程中的作用。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列物理条件、方程推导和所列外部依据判断。

复核后详细解答：

  1. 定义。 大气气溶胶是悬浮于空气中的固态或液态微粒及其与气体构成的分散体系。常见来源包括海盐、沙尘、燃烧颗粒以及气态前体物生成的二次颗粒；云滴、雨滴通常在云物理中另归为水成物。
  2. 云雾凝结。 部分可吸湿颗粒可充当云凝结核。空气冷却使相对湿度升高后，合适的粒子先吸水，达到相应临界过饱和度便可活化成云滴。曲率效应使小纯水滴较难稳定，溶质效应降低平衡水汽压，两者共同决定活化；因此不是任何粒子在任何湿度下都能成为云滴。
  3. 冰相成核。 某些颗粒在适宜低温与湿度下可充当冰核，参与浸没冻结、接触冻结等过程，影响冰晶数目和混合相云演变。冰核与云凝结核的有效性不同，不能把所有颗粒等同为冰核。
  4. 降水过程。 气溶胶改变初始云滴数目、大小和谱宽，进而改变碰并、冰相增长和降水。若液态水总量相同而活化云滴更多，平均云滴偏小，暖雨碰并可能延迟；巨型凝结核也可能形成较大水滴、促进碰并。冰核多少会影响冰晶竞争水汽及混合相过程。最终降水响应还依赖水汽、云动力和云寿命，不能写“气溶胶越多降水一定越多/越少”。
  5. 直接辐射作用。 颗粒对太阳短波散射，使一部分辐射返回太空、减少到达地面的短波；吸收性颗粒还可吸收辐射、加热所在空气层。净效应依赖成分、粒径、地表反照率和垂直位置，不能把所有气溶胶都归为单纯冷却。
  6. 通过云的辐射作用。 在液水路径相同的比较条件下，较多较小云滴通常使云光学厚度和反照率增大；粒子也能改变降水效率、云量与云寿命。吸收性颗粒引起的层结变化还会改变云。这些响应带有环境依赖，不能由第一项效应直接推断全部净气候作用。
  7. 综合关系。 成核改变微物理，微物理影响降水与云光学性质，辐射加热又反馈云动力。答题按“云雾—冰相与降水—直接辐射—云介导辐射”的顺序展开即可。

简述臭氧在大气中的空间分布特征。

修改意见（2026-10-05，第三批）：

按垂直、纬向及季节分布回答；区分臭氧数密度、混合比和柱总量。

本段与上文相同，可回看前面的解析，不再重复展开。

复核后详细解答：

  1. 先规定描述量。 臭氧数密度表示单位体积的臭氧分子数，混合比表示臭氧相对于空气的比例，柱总量是从地面到高空的垂直积分。空气密度随高度减小，所以三者不能共用一个“峰值高度”。
  2. 垂直分布。 大气臭氧约九成位于平流层，臭氧层是富集区而非一道实心薄层。臭氧数密度通常在约20—25 km附近达到较大值，但高度随纬度和季节变化；按体积混合比描述的峰值可更高。对流层臭氧份额较小，却对近地面空气质量与辐射具有意义。
  3. 为什么存在垂直峰值。 较高处紫外辐射较强，却因空气和氧分子稀少不利于大量三体结合；较低处氧分子多，但能分解氧分子的短波紫外已被上层吸收。生成、损耗和输送的共同平衡，使臭氧富集在平流层某一高度范围。
  4. 纬向分布。 热带受强日照、光化学生成活跃，但平流层环流将臭氧输送至中高纬，故柱总量通常并非热带最大。不能只按太阳辐射强弱由赤道到极地单调推断臭氧总量。
  5. 时间与特殊区域。 中高纬柱总量常有明显季节变化，受环流和化学过程共同控制；南极春季在冷极涡、极地平流层云和日照恢复条件下可发生显著化学损耗，形成臭氧洞。该异常不能代表全年、所有高纬地区均缺臭氧。
  6. 近地面补充。 对流层臭氧既受平流层交换影响，也可由前体物光化学反应生成，所以污染地区近地面高臭氧不能解释为“臭氧层整体下沉”。

分布与描述量另参照NOAA/WMO臭氧问答，Q1与Q3。上述高度为概括范围，不能替代原教材某一纬度的指定曲线。
