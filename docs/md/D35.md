### 2011-一-6 · ★★（同考点3年）

地转适应过程

[解析来源（对应题目行）](https://github.com/0183ty2512/lao-san-yang/blob/main/%E5%8A%A8%E5%8A%9B%E6%B0%94%E8%B1%A1%E8%AF%BE%E5%90%8E%E4%B9%A0%E9%A2%98/%E8%AF%95%E9%A2%98%E8%A7%A3%E7%AD%94/%E5%BE%80%E5%B9%B4%E8%AF%95%E9%A2%98%E8%A7%A3%E6%9E%90/2011.md#L196) · [原始年度题干](https://github.com/0183ty2512/lao-san-yang/blob/main/%E5%BE%80%E5%B9%B4%E8%AF%95%E9%A2%98%E5%88%86%E6%9E%90/2011.md)

**审校状态：尚未逐题学科审校。**

**相关高频考点复习摘要（须按本题设问取舍，不替代完整解答）：**

**地转适应：** 地转适应是风压不平衡激发惯性重力波，传播带走不平衡部分，剩余趋向平衡的过程。以变形半径 $L_D=c/|f|$ 比较尺度；斜压大气不同竖直模态各有自己的 $c$ 与 $L_D$，需同时满足位涡及边界约束。

> 以上摘要用于回忆答题主线，不是官方评分标准；推导、计算和多小问仍须完成下方步骤。

1. 地转偏差（非地转风）为 $\mathbf V_a=\mathbf V-\mathbf V_g$。水平动量方程写为 $D\mathbf V/Dt+f\mathbf k\times\mathbf V=-\nabla_p\Phi+\mathbf F$。
2. 减去地转平衡后 $D\mathbf V/Dt+f\mathbf k\times\mathbf V_a=\mathbf F$。左乘 $\mathbf k\times$，利用水平向量恒等式 $\mathbf k\times(\mathbf k\times\mathbf V_a)=-\mathbf V_a$，得到 $\mathbf V_a=\mathbf k\times(D\mathbf V/Dt-\mathbf F)/f$。
3. 地转风在 $f$ 平面无辐散，非地转风虽小却控制辐合辐散，由连续方程驱动垂直运动，从而改变质量场和温度场。这使天气系统能够发展，不能把地转近似理解为整个运动绝对静止。
4. 地转适应是初始风压不平衡激发惯性重力波，快速传播带走不平衡部分，剩余流趋近地转平衡的过程。比较水平尺度 $L$ 与变形半径 $L_D=c/|f|$：$L\gg L_D$ 时较偏向风适应压力，$L\ll L_D$ 时较偏向压力适应风。
5. 斜压适应需分解不同竖直模态，每个模态具有自己的等效波速和变形半径；内模态通常较慢。结果受位涡、总质量、边界及初始条件共同限制，并非摩擦把所有风消耗为零。

**核对依据：** [平衡流场的基本特征与性质](https://github.com/0183ty2512/lao-san-yang/blob/main/%E5%8A%A8%E5%8A%9B%E6%B0%94%E8%B1%A1/%E8%87%AA%E7%94%B1%E5%A4%A7%E6%B0%94%E4%B8%AD%E7%9A%84%E5%B9%B3%E8%A1%A1%E6%B5%81%E5%9C%BA%E3%80%81%E7%8E%AF%E6%B5%81%E5%AE%9A%E7%90%86%E5%92%8C%E6%B6%A1%E5%BA%A6%E6%96%B9%E7%A8%8B/%E5%B9%B3%E8%A1%A1%E6%B5%81%E5%9C%BA%E7%9A%84%E5%9F%BA%E6%9C%AC%E7%89%B9%E5%BE%81%E4%B8%8E%E6%80%A7%E8%B4%A8.md)。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列方程推导与量纲检查作出判断。

**复核后详细解答：**

1. **定义。** 水平实际风与同一质量场对应的地转风之差为$\mathbf V_a=\mathbf V-\mathbf V_g$。采用气压坐标，$f\mathbf k\times\mathbf V_g=-\nabla_p\Phi$。
2. **由动量方程求偏差。** 实际运动满足$D\mathbf V/Dt+f\mathbf k\times\mathbf V=-\nabla_p\Phi+\mathbf F$，其中$\mathbf F$为摩擦加速度。减去地转关系得$D\mathbf V/Dt+f\mathbf k\times\mathbf V_a=\mathbf F$。左乘$\mathbf k\times$，利用水平向量恒等式$\mathbf k\times(\mathbf k\times\mathbf V_a)=-\mathbf V_a$：
$$\boxed{\mathbf V_a=\frac1f\mathbf k\times\left(\frac{D\mathbf V}{Dt}-\mathbf F\right)}.$$
无摩擦时偏差风在加速度左侧（北半球）；定常无惯性时为$-\mathbf k\times\mathbf F/f$，在摩擦力右侧。参考笔记的摩擦公式若写正号，应按其力定义核对；按“作用于空气的摩擦力”约定须为上述负号。
3. **质量与垂直运动。** 常数$f$下$u_g=-\frac{\partial \Phi}{\partial y}/f,v_g=\frac{\partial \Phi}{\partial x}/f$，混合偏导相消，$\nabla_p\cdot\mathbf V_g=0$。于是实际散度来自偏差风，连续方程$\nabla_p\cdot\mathbf V+\omega_p=0$把它与垂直运动联系。给定边界及整层散度后才能确定$\omega$，不能只凭一个层次的辐散断定全柱上升。
4. **热力与系统演变。** 垂直运动改变绝热冷却增温及水汽凝结，反过来调整温度和位势场；急流加减速、曲率和摩擦可产生次级环流，因此近地转的大尺度系统仍能发展。
5. **能量联系。** 水平气压梯度功率为$-\mathbf V\cdot\nabla_p\Phi$。地转风与$\nabla_p\Phi$垂直，其贡献为零；故压力功由$-\mathbf V_a\cdot\nabla_p\Phi$承担，非地转分量联系质量场与动能转换。
6. **适用限制。** 在β平面，$\nabla_p\cdot\mathbf V_g=-\beta v_g/f$一般不为零；“地转风无散度”须注明$f$平面或相应近似阶次。近赤道$f$趋零时，不可直接套用含$1/f$的中纬度近似。

焚风：

**修改意见（2026-10-05，第三批）：**

用完整迎风/背风热力路径解释焚风，限定经典降水模型并说明不必每次都迎风降雨。

**核对依据：** [大气中的干绝热过程](https://github.com/0183ty2512/lao-san-yang/blob/main/%E5%A4%A7%E6%B0%94%E7%89%A9%E7%90%86%E5%AD%A6/%E5%A4%A7%E6%B0%94%E7%83%AD%E5%8A%9B%E5%AD%A6/%E5%A4%A7%E6%B0%94%E4%B8%AD%E7%9A%84%E5%B9%B2%E7%BB%9D%E7%83%AD%E8%BF%87%E7%A8%8B.md)。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列物理条件、方程推导和所列外部依据判断。

**复核后详细解答：**

1. 焚风是越山或山地相关下沉气流在背风坡造成的暖而干的风。下降时气压增加，气块受压缩增温；不是主要靠空气摩擦山坡发热。
2. **经典迎风段。** 设同一比较高度为0，山顶高度$H$，迎风LCL高度$z_L<H$。未饱和气块从0升到$z_L$按$\Gamma_d$降温；从$z_L$升到$H$按平均湿绝热递减率$\Gamma_m$降温，并有凝结降水移走水分，故山顶温度$T_H=T_0-\Gamma_d z_L-\Gamma_m(H-z_L)$。
3. **背风段。** 假设凝结物已移除，气块背风下降基本未饱和，回到相同高度时按干绝热增温$\Gamma_dH$，得到$T_b=T_H+\Gamma_dH$。
4. **逐项相减。** 代入山顶温度：$T_b-T_0=-\Gamma_dz_L-\Gamma_m(H-z_L)+\Gamma_dH=(\Gamma_d-\Gamma_m)(H-z_L)>0$。这说明饱和上升段降温较慢，而下降增温较快，造成同高度暖差。若全程未饱和、可逆地升降同一气块，$\Gamma_m$段不存在，就不能由此模型推出同高度净增温。
5. **为什么干。** 迎风降水减少气块水汽，背风增温又提高饱和水汽压，二者使相对湿度减小。即使绝对水汽变化小，仅增温也能降低相对湿度。
6. **模型边界。** 实际焚风还可能由较高位温空气下沉、等熵抽降及混合等形成，并不必每次都出现明显迎风降水。上式是经典失水模型的解释，不是所有焚风的唯一成因或精确预报式。

**核对依据：** [作用于气块的力](https://github.com/0183ty2512/lao-san-yang/blob/main/%E5%8A%A8%E5%8A%9B%E6%B0%94%E8%B1%A1/%E4%BB%A5%E5%89%8D%E7%9A%84%E5%AD%A6%E4%B9%A0/%E7%AC%AC%E4%BA%8C%E7%AB%A0/%E4%BD%9C%E7%94%A8%E4%BA%8E%E6%B0%94%E5%9D%97%E7%9A%84%E5%8A%9B.md)；[平衡流场的基本特征与性质](https://github.com/0183ty2512/lao-san-yang/blob/main/%E5%8A%A8%E5%8A%9B%E6%B0%94%E8%B1%A1/%E8%87%AA%E7%94%B1%E5%A4%A7%E6%B0%94%E4%B8%AD%E7%9A%84%E5%B9%B3%E8%A1%A1%E6%B5%81%E5%9C%BA%E3%80%81%E7%8E%AF%E6%B5%81%E5%AE%9A%E7%90%86%E5%92%8C%E6%B6%A1%E5%BA%A6%E6%96%B9%E7%A8%8B/%E5%B9%B3%E8%A1%A1%E6%B5%81%E5%9C%BA%E7%9A%84%E5%9F%BA%E6%9C%AC%E7%89%B9%E5%BE%81%E4%B8%8E%E6%80%A7%E8%B4%A8.md)。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列物理条件、方程推导和所列外部依据判断。

**复核后详细解答：**

1. 气压梯度力来自气块相对表面受到的压力不同，合力指向气压降低方向。气象运动方程通常写单位质量的力，即加速度$\mathbf F_p=-\nabla p/\rho$。
2. 取$x$向厚度$dx$、截面积$dS$的小气块。左面向右的压力为$p(x)dS$，右面向左的压力为$p(x+dx)dS$；合力为$[p(x)-p(x+dx)]dS\approx-p_xdx\,dS$。除质量$\rho dx\,dS$，得到$F_{px}=-p_x/\rho$，其他方向同理。
3. 梯度$\nabla p$指向压力增长最快方向，负号使力垂直等压面而指向低压；相同压强梯度下密度越小，单位质量力越大。单位检验：$(\mathrm{Pa/m})/(\mathrm{kg/m^3})=\mathrm{m/s^2}$。
4. 等高面水平形式为$-\nabla_zp/\rho$。静力条件下，等压面上$0=dp=p_x|_z dx+p_z dz$、$p_z=-\rho g$，于是$g\partial_xz|_p=(1/\rho)\partial_xp|_z$，故同一水平压力作用可写$-\nabla_p\Phi$。它不是因为等压面$p$恒定就“没有水平压力作用”。
