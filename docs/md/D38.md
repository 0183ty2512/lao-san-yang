暴雨形成的条件。

**相关高频考点复习摘要（须按本题设问取舍，不替代完整解答）：**

**暴雨形成条件：** 暴雨需充足并持续的水汽供应、有效抬升、较高降水效率和足够持续时间。锋面、切变、低涡、地形及冷池可触发；不稳定与风切变可组织强对流，训练效应增加累积雨量。并非所有暴雨都要求强条件不稳定。

> 以上摘要用于回忆答题主线，不是官方评分标准；推导、计算和多小问仍须完成下方步骤。

1. 暴雨需要持续的水汽供应、有效抬升和较高降水效率，并常有不稳定能量与中尺度组织配合。水汽只是原料；没有辐合和抬升，湿空气未必产生暴雨。

2. 水汽由低空急流等输送至锋区或切变线，辐合后被迫抬升。锋面、低涡、切变线、地形及雷暴冷池出流均可触发上升；暖湿气块达到自由对流高度后释放不稳定能量。

3. 风切变使对流组织化，冷池和环境风配合可反复触发新单体；系统移动缓慢或单体沿相似路径连续经过同一区域，形成训练效应，增加累计雨量。层状降水也可产生暴雨，不能把强条件不稳定列为每场暴雨的绝对必要条件。

### 1994-一-3 · ★★（同考点2年）

**本次复核提示（2026-10-31）：** 飑线、雷暴为对流系统；冰雹是降水现象、龙卷是小尺度涡旋，不能将三者全部当同一尺度系统类别。

与强对流活动有关的中尺度天气有**飑线**、**雷暴**、**冰雹/龙卷**等。

[解析来源（对应题目行）](https://github.com/0183ty2512/lao-san-yang/blob/main/%E5%8A%A8%E5%8A%9B%E6%B0%94%E8%B1%A1%E8%AF%BE%E5%90%8E%E4%B9%A0%E9%A2%98/%E8%AF%95%E9%A2%98%E8%A7%A3%E7%AD%94/%E5%BE%80%E5%B9%B4%E8%AF%95%E9%A2%98%E8%A7%A3%E6%9E%90/1994.md#L104) · [原始年度题干](https://github.com/0183ty2512/lao-san-yang/blob/main/%E5%BE%80%E5%B9%B4%E8%AF%95%E9%A2%98%E5%88%86%E6%9E%90/1994.md)

**审校状态：尚未逐题学科审校。**

> 以上摘要用于回忆答题主线，不是官方评分标准；推导、计算和多小问仍须完成下方步骤。

**原记录填空值：** 飑线；雷暴；冰雹/龙卷。下文核对其物理含义；出现修改意见时，以修改后的说明为准。

1. **环境条件。** 低层暖湿、具有可释放的不稳定能量，锋面/辐合线/地形等提供抬升；适宜的垂直风切变使上升和下沉气流分离，支持较长寿命。强切变有助组织化，但不能取代水汽和浮力。

2. **组织类型。** 多单体风暴由不同生命阶段单体组成，冷池边界不断触发新单体，整体比单个单体活得久；超级单体的识别核心是深厚、持续旋转的上升气流（中气旋），不是单纯雨量最大。[NWS 超级单体说明](https://www.weather.gov/ama/supercell)

3. 飑线是沿线状排列并组织成系统的强对流，前缘辐合与冷池推进触发新生对流，可有后部层状降水。过站时常风向突变、阵风增强、温度骤降、气压骤升，伴雷雨、冰雹等；地面升压主要与冷池密度增加及动力作用有关。

### 2016-三-2 · ★★★★（同考点10年）

什么是 CISK？扰动来源是什么，用台风的发生发展为例论述。

**相关高频考点复习摘要（须按本题设问取舍，不替代完整解答）：**

**第二类条件不稳定（CISK）：** CISK是对流和大尺度环流的正反馈：初始旋转扰动→摩擦辐合和水汽输送→凝结潜热加热→暖心、质量场及高层外流调整→低压和辐合增强。能量依海气焓供应与湿对流转化，不能把凝结视作凭空产能。

> 以上摘要用于回忆答题主线，不是官方评分标准；推导、计算和多小问仍须完成下方步骤。

1. **初始扰动。** 季风槽、热带辐合带扰动、东风波、赤道罗斯贝波等可提供涡度、辐合和持续对流。多数初始扰动不会发展，环境与内部组织过程都重要。

2. **CISK 链条。** 初始低压旋转 → 边界层摩擦造成向中心的水汽辐合 → 对流凝结释放潜热 → 暖心及质量场调整、高层外流加强 → 低压和低层旋转增强 → 更强辐合。对流和大尺度环流相互反馈而非单独气块条件不稳定，因此称第二类条件不稳定。它是理想化解释，现代海气通量反馈等机制不可省略。

3. **能量。** 水汽主要由暖海蒸发补给，海面潜热和显热通量提供焓；凝结将潜热释放，暖升冷沉及压力功转化为动能，摩擦耗散动能。不能把凝结说成凭空制造能量。

### 2018-三-1 · ★★★★（同考点7年）

什么是台风？以及台风发生发展的有利条件

**相关高频考点复习摘要（须按本题设问取舍，不替代完整解答）：**

**热带气旋概念：** 热带气旋是在热带或副热带海洋形成、具闭合低层气旋环流和有组织对流的非锋面暖心系统。台风是西北太平洋等区域达到规定强度的名称；低层入流、中层眼墙上升、高层外流是其典型结构。

**热带气旋生成条件：** 热带气旋生成需暖海焓供应、暖湿且有对流潜能的环境、较弱垂直风切变、可用科氏作用、初始低层旋转扰动和高层外流。季风槽、东风波等可提供初始扰动；有利条件不等于保证生成。

> 以上摘要用于回忆答题主线，不是官方评分标准；推导、计算和多小问仍须完成下方步骤。

1. **定义。** 热带气旋是在热带或副热带海洋形成、具有闭合低层气旋环流和有组织深对流的非锋面暖心系统；台风是西北太平洋等区域达到规定强度的热带气旋称谓，不能把所有热带低压直接叫台风。

2. **结构与分层。** 低层摩擦入流、气旋旋转和辐合；中层眼墙强上升、强风和强降水，外围有螺旋雨带；高层向外辐散，常带反气旋性外流。中心气压低、温度暖，最大风通常在眼墙附近而不在眼中心。眼区下沉增温、相对湿度低、风较弱，可有低云，不能绝对说完全无云。

1. **生成条件。** 较深的暖海水供给焓，低层暖湿、对流潜能和中层湿度较充足，垂直风切变较弱，有初始低层旋转扰动及高层有效外流；离赤道要足够远以有可用科氏作用。常用约 26.5℃ 是经验参考，并非脱离海洋热含量和大气状态的绝对门槛。

2. **初始扰动。** 季风槽、热带辐合带扰动、东风波、赤道罗斯贝波等可提供涡度、辐合和持续对流。多数初始扰动不会发展，环境与内部组织过程都重要。

3. **CISK 链条。** 初始低压旋转 → 边界层摩擦造成向中心的水汽辐合 → 对流凝结释放潜热 → 暖心及质量场调整、高层外流加强 → 低压和低层旋转增强 → 更强辐合。对流和大尺度环流相互反馈而非单独气块条件不稳定，因此称第二类条件不稳定。它是理想化解释，现代海气通量反馈等机制不可省略。

4. **能量。** 水汽主要由暖海蒸发补给，海面潜热和显热通量提供焓；凝结将潜热释放，暖升冷沉及压力功转化为动能，摩擦耗散动能。不能把凝结说成凭空制造能量。

### 2022-二-2 · 完整解答

什么是第二类条件性不稳定（CISK）？能量来源是什么？

**修改意见（2026-10-04，第二批）：**

原答案基本正确，但定义未在开头，且能量来源写得过短；补从海面供应到压力功的能量链和质量调整条件。

本段与上文相同，可回看前面的解析，不再重复展开。

**复核后详细解答：**

1. **定义。** 第二类条件不稳定是大尺度环流与积云对流相互促进的理想化机制；第一类条件不稳定主要讨论单气块的浮力，而CISK强调环流组织与对流反馈。
2. **环流促进对流。** 初始低压和旋转扰动产生边界层入流、摩擦辐合，集中水汽并提供抬升，使对流能持续地组织在扰动附近。
3. **对流反馈环流。** 凝结加热促使暖心和上层外流发展，经过压力及整柱质量调整，低压环流可以加强，进一步增强低层汇流。加热不能单独保证地面降压，尚需质量收支配合。
4. **能量来源。** 水汽所携能量主要由暖海蒸发等海气交换提供；凝结把这部分潜热转成热力能，适当的暖升冷沉及压力功把其中一部分转为动能，动能又有摩擦耗散。完整回答应写“海面供应→潜热释放→热力与压力功转换→动能”，不只写“能量来自凝结”。
5. **条件和局限。** 湿度、风切变、初始涡旋及对流位置决定反馈能否胜过耗散。CISK不是全部台风发展过程的唯一解释，也不等于每次对流都会增强台风。
