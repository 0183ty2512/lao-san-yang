**我国雨带季节活动：** 我国雨带一般由华南前汛期，推进到江淮梅雨，再到华北、东北盛夏雨季，秋季南撤。副高脊线20—25°N、25—30°N、30—35°N是常用阶段性经验范围，应结合西伸东退、冷空气和年份差异，不能当作硬界线。

> 以上摘要用于回忆答题主线，不是官方评分标准；推导、计算和多小问仍须完成下方步骤。

**原记录填空值：** 雨季/多雨；伏旱/高温少雨；高温/热带气旋影响。下文核对其物理含义；出现修改意见时，以修改后的说明为准。

1. 西太平洋副热带高压是副热带地区深厚、暖性的反气旋系统。中层常用 500 hPa 高度场描述，其内部下沉、对流受抑制，西北侧及北侧暖湿气流与中纬度系统相遇，是重要雨带区。
2. 形成与副热带下沉、行星波、海陆热力差异及热带加热有关，不能单说成“海面冷所以形成冷高压”。暖性结构使高压在较高层更明显，但不同层中心、脊线并不完全重合。
3. 春季至初夏副高偏南，华南锋面和季风雨活跃；6 月前后第一次北跳后，长江中下游进入梅雨，传统脊线经验约为 20°—25°N。
4. 进一步北抬至约 25°—30°N，雨带向江淮、淮河流域推进；7 月下旬至 8 月上旬前后脊线可在 30°—35°N，雨带到华北、东北，长江中下游较易受高压控制出现伏旱。秋季副高南撤，雨带随之南退。
5. 除南北移动，还要考虑西伸东退、强度和滞留时间。副高西伸使水汽输送路径和落区改变，长期稳定可造成一侧持续暴雨、另一侧持续高温。上述纬度和日期是复习用经验，不是每年的硬界线。
6. 原题若把 25°—30°N 直接与华北盛夏雨季对应，应另起行纠正：通常华北盛夏雨季对应更北的 30°—35°N 阶段。

5. **中层（约500 hPa）。** 西太平洋副热带高压西伸北抬到适当位置，其西北侧引导暖湿气流；中高纬阻塞脊及其间或下游冷槽不断输送较冷空气。槽脊、副高位置相对稳定时，冷暖交汇与雨带可较长时间维持。双阻型是常见配置之一，不是每年梅雨的必要条件。
6. **低层（常看850—700 hPa）和地面。** 西南低空急流及偏南暖湿气流提供持续水汽与能量；在梅雨锋、切变线、低涡或急流出口附近形成有利辐合，触发并组织降水。850 hPa在高原可位于地下，应按地形选层。
7. **高中低层相互配合。** 中层稳定形势使抬升带少动，低层暖湿输送不断供给，高层质量外流配合上升；反复发展的中尺度雨团把大尺度持续条件转化为强降水。梅雨结束常随副高和主要雨带进一步北移、局地环流条件变化，不能仅归因于某个单独系统突然消失。

锋生

**修改意见（2026-10-07，第四批）：**

保留锋生函数但增加简单收缩流的逐步检验，强调水平温度梯度增强。

**核对依据：** [锋生和锋消过程](https://github.com/0183ty2512/lao-san-yang/blob/main/%E5%A4%A9%E6%B0%94%E5%AD%A6%E5%88%86%E6%9E%90%E5%8E%9F%E7%90%86/%E6%B0%94%E5%9B%A2%E4%B8%8E%E9%94%8B/%E9%94%8B%E7%94%9F%E5%92%8C%E9%94%8B%E6%B6%88%E8%BF%87%E7%A8%8B.md)。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列物理条件、方程推导和所列外部依据判断。

**复核后详细解答：**

1. 锋生指已有锋区加强或由较弱水平热力梯度逐渐形成锋区。以位温定义$\mathbf G=\nabla_h\theta$，锋生函数$F=D|\mathbf G|/Dt$；$F>0$为锋生，$F<0$为锋消。某地气温下降并不自动说明锋生，关键是相邻气团之间的梯度是否增强。
2. 由$D\theta/Dt=\dot\theta$对水平坐标$x_i$求导，注意导数与随体导数不交换：$DG_i/Dt=\partial_i\dot\theta-(\partial_iu_j)G_j-(\partial_iw)\theta_z$，其中$i,j=x,y$且重复$j$求和。
3. 利用$D|\mathbf G|/Dt=G_i(DG_i/Dt)/|\mathbf G|$，得
$$F=\frac{\mathbf G\cdot\nabla_h\dot\theta-G_i(\partial_iu_j)G_j-\theta_z\mathbf G\cdot\nabla_hw}{|\mathbf G|}.$$
三部分为差异非绝热加热、水平变形/辐合、竖直倾斜作用，符号由具体场决定。
4. 取二维收缩—伸长流$u=-ax,v=ay,a>0$，水平总散度为0，但若温度梯度沿$x$，且绝热、无倾斜，$F=-|G|\frac{\partial u}{\partial x}=a|G|>0$。说明即使总散度为零，变形压缩跨锋距离也能锋生。
5. 因此不能把“锋生”只定义为辐合，也不能认为气旋性旋转本身就一定增强温度梯度。名词解释可写第1点及三类机制，推导用于理解与防错。

**复核后详细解答：**

1. **背景准备。** 江淮地区冷暖气流交汇形成锋区或切变带，低层偏南、西南暖湿输送提供水汽，水平温度梯度提供可供斜压转换的能量。
2. **初始波动。** 西风带高空槽或短波东移到有利位置，低层锋区出现波动和气旋性环流；暖空气在低压前侧向北伸展，冷空气在后侧南下，冷暖锋结构逐渐建立。
3. **加深机制。** 成长时地面低压常在高空槽前，高低层相位差支持热输送和上升。若整柱质量净流出，地面气压下降；低层辐合本身带入质量，并不单独造成降压。涡度平流、温度平流及其垂直结构共同参与动力诊断，不能仅由某层正涡度平流直接判定加深。
4. **潜热反馈。** 持续水汽输送与抬升使降水释放潜热，进一步调整温度、位涡及环流，可增强气旋。但增长仍取决于加热位置、背景斜压性及耗散。
5. **移动和天气。** 在偏西引导气流及发展区配置下，系统常向东或东北移；暖锋附近可有连续降水，冷锋或暖区在不稳定条件下可有强对流，气压梯度增强可带来大风。
6. **后期。** 高低层趋于垂直重叠、有效位能供应减少或移入不利环境时，系统可能锢囚、填塞；出海后也可能再发展。西南涡移出可参与江淮气旋生成，但不是每个江淮气旋都必须经历这一来源。

温带气旋发展的四个阶段及其特征。

**修改意见（2026-10-04，第二批）：**

**核对依据：** [锋面气旋和爆发性气旋](https://github.com/0183ty2512/lao-san-yang/blob/main/%E5%A4%A9%E6%B0%94%E5%AD%A6%E5%88%86%E6%9E%90%E5%8E%9F%E7%90%86/%E6%B0%94%E6%97%8B%E4%B8%8E%E5%8F%8D%E6%B0%94%E6%97%8B/%E9%94%8B%E9%9D%A2%E6%B0%94%E6%97%8B%E5%92%8C%E7%88%86%E5%8F%91%E6%80%A7%E6%B0%94%E6%97%8B.md)。本地资料为学习笔记，不视作官方标准答案；冲突处依据下列方程推导与量纲检查作出判断。

**复核后详细解答：**

1. **波动初生阶段。** 锋区出现波动，暖空气一侧向冷侧推进，冷空气另一侧向暖侧推进，形成暖锋、冷锋雏形及弱低压环流。高空扰动与低层锋区的配合有利生成，但不能把一项单层指标当充分条件。
2. **发展或青年阶段。** 低压加深、环流加强，冷暖锋与暖区逐渐清楚；高低层有利相位与暖升冷沉支持有效位能向动能转换。暖锋附近可有较广连续降水，冷锋和暖区在不稳定条件下可有对流。暖区不必在整个发展阶段持续扩大。
3. **成熟、锢囚阶段。** 在经典挪威气旋模式中，冷锋赶上暖锋，近中心暖空气被抬离地面，暖区逐渐收窄，形成锢囚锋，系统范围及云雨结构可很复杂。最深气压或最强风出现的时刻因个例而异，锢囚初期仍可能继续加深。
4. **衰亡阶段。** 当可利用斜压能量减少、高低层趋于重叠且耗散占优时，气旋填塞，锋区及云雨逐渐减弱。存在再发展或锢囚点新生等情形，不能把“锢囚”直接等同“生命结束”。
5. **模型范围。** 此四阶段用于经典温带锋面气旋生命史；实际气旋可能中途消散，或遵循不同结构演变。答题不必加入与本问无关的反气旋路径。
