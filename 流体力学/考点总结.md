# 流体力学I 考点总结

> 基于《流体力学I》学习资料提炼，涵盖核心概念、公式、定理与典型模型，适合考前回顾。

## 一、流体运动学

### 1. 连续介质假设
- 适用条件：特征尺度 ≫ 分子平均自由程
- 失效场景：稀薄气体、微纳流动、毛细血管流动

### 2. 两种描述方法
- **拉格朗日法**：随体，$$f=f(a,b,c,t)$$ → 迹线
- **欧拉法**：空间，$$F=F(x,y,z,t)$$ → 流线
- 联系：[[实质导数]] $$\frac{D}{Dt} = \frac{\partial}{\partial t} + (\mathbf{u}\cdot\nabla)$$

### 3. 流线与迹线
- 流线：$$\frac{dx}{u}=\frac{dy}{v}=\frac{dz}{w}$$，$$t$$ 固定
- 迹线：$$\frac{dx}{u}=\frac{dy}{v}=\frac{dz}{w}=dt$$，$$t$$ 为自变量
- 重合条件：**定常流动**

### 4. 连续方程
- 欧拉形式：$$\frac{\partial\rho}{\partial t} + \nabla\cdot(\rho\mathbf{u}) = 0$$
- 拉格朗日形式：$$\frac{D\rho}{Dt} + \rho\nabla\cdot\mathbf{u} = 0$$
- 不可压缩：$$\nabla\cdot\mathbf{u}=0$$；定常：$$\frac{\partial\rho}{\partial t}=0$$

### 5. 亥姆霍兹速度分解定理
- $$\mathbf{u}(M) = \underbrace{\mathbf{u}(M_0)}_{\text{平移}} + \underbrace{\boldsymbol{\omega}\times\delta\mathbf{r}}_{\text{旋转}} + \underbrace{\mathbf{E}\cdot\delta\mathbf{r}}_{\text{变形}}$$
- 应变率张量 $$\mathbf{E}$$：对称部分，含线应变与角变形
- 旋转张量：反对称部分，对应涡量 $$\boldsymbol{\omega} = \frac{1}{2}\nabla\times\mathbf{u}$$

### 6. 有旋运动与涡量
- 涡量 $$\boldsymbol{\Omega} = \nabla\times\mathbf{u}$$，旋转角速度 $$\boldsymbol{\omega} = \frac{1}{2}\boldsymbol{\Omega}$$
- 涡线、涡管、涡通量
- [[斯托克斯公式]]：$$\Gamma = \oint \mathbf{u}\cdot d\mathbf{l} = \iint \boldsymbol{\omega}\cdot d\mathbf{S}$$
- 运动学涡管强度守恒（亥姆霍兹第一定理）

### 7. 无旋运动与速度势
- 无旋 $$\Rightarrow$$ 存在速度势 $$\phi$$，$$\mathbf{u} = \nabla\phi$$
- 不可压缩无旋 $$\Rightarrow$$ 拉普拉斯方程 $$\nabla^2\phi = 0$$

## 二、流体运动的基本方程

### 1. 应力张量
- 二阶对称张量，6个独立分量
- 静止流体：只有法向应力 $$p_{ij} = -p\delta_{ij}$$

### 2. 本构方程（牛顿流体）
- 三条假设：线性、各向同性、静止退化为 $$-pI$$
- $$P = -pI + 2\mu\mathbf{E} - \frac{2}{3}\mu(\nabla\cdot\mathbf{u})I$$
- 不可压缩：$$P = -pI + 2\mu\mathbf{E}$$

### 3. N-S 方程
- 可压缩：$$\rho\frac{D\mathbf{u}}{Dt} = \rho\mathbf{F} - \nabla p + \mu\nabla^2\mathbf{u} + \frac{\mu}{3}\nabla(\nabla\cdot\mathbf{u})$$
- 不可压缩：$$\rho\frac{D\mathbf{u}}{Dt} = \rho\mathbf{F} - \nabla p + \mu\nabla^2\mathbf{u}$$
- 理想流体（$$\mu=0$$）→ 欧拉方程

### 4. 能量方程与耗散函数
- 耗散函数 $$\Phi \ge 0$$，表示粘性导致的机械能损失

### 5. 边界条件
- 运动学：法向速度连续，$$\frac{DF}{Dt}=0$$
- 动力学：应力连续（有表面张力时法向应力不连续）

### 6. 环流定理与涡度方程
- [[开尔文环流定理]]：理想、正压、体积力有势 → $$\frac{D\Gamma}{Dt}=0$$
- 涡度方程：
  \[$$
  \frac{D\boldsymbol{\omega}}{Dt} = (\boldsymbol{\omega}\cdot\nabla)\mathbf{u} - (\nabla\cdot\mathbf{u})\boldsymbol{\omega} + \frac{\nabla\rho\times\nabla p}{\rho^2} + \nu\nabla^2\boldsymbol{\omega}
  $$\]
  四项依次：拉伸扭转、散度、斜压、粘性扩散

## 三、理想流体动力学

### 1. 欧拉方程与兰姆方程
- 兰姆方程：$$\frac{\partial\mathbf{u}}{\partial t} + \nabla\left(\frac{u^2}{2}+\Pi+P\right) = -\boldsymbol{\omega}\times\mathbf{u}$$

### 2. 伯努利方程
- 适用条件：理想、正压、体积力有势、定常、沿流线
- 重力场不可压：$$\frac{p}{\rho} + \frac{u^2}{2} + gz = \text{const}$$（沿流线）
- 无旋定常：全流场常数相同

### 3. 拉格朗日积分（柯西积分）
- 无旋流动，非定常亦可：$$\frac{\partial\phi}{\partial t} + \frac{u^2}{2} + \frac{p}{\rho} + gz = F(t)$$

### 4. 雷诺输运定理
- $$\frac{D}{Dt}\int_{\tau}\Phi d\tau = \int_{C.V.}\frac{\partial\Phi}{\partial t}d\tau + \int_{C.S.}\Phi\mathbf{u}\cdot\mathbf{n}dA$$
- 应用：质量、动量、能量守恒的积分形式

### 5. 动量定理与动量矩定理
- 定常控制体形式，用于求解力和力矩

## 四、理想不可压流体的平面无旋定常流动

### 1. 流函数
- 二维不可压缩：$$u=\frac{\partial\psi}{\partial y}, v=-\frac{\partial\psi}{\partial x}$$
- 流线 $$\psi=const$$，流量 $$=$$ 两点流函数差
- 无旋条件：$$\nabla^2\psi=0$$

### 2. 复位势
- $$W(z) = \phi + i\psi$$，解析函数
- 复速度：$$\frac{dW}{dz} = u - iv$$
- 环量与流量：$$\oint \frac{dW}{dz}dz = \Gamma + iQ$$

### 3. 基本势流
- 均匀流：$$W = V_\infty z$$
- 点源/汇：$$W = \frac{Q}{2\pi}\ln z$$
- 点涡：$$W = \frac{i\Gamma}{2\pi}\ln z$$
- 偶极子：$$W = \frac{\mu}{z}$$

### 4. 布拉修斯定理
- 合力：$$F_x - iF_y = \frac{i\rho}{2}\oint (\frac{dW}{dz})^2 dz$$
- 力矩：$$M = -\frac{\rho}{2}\text{Re}\oint z(\frac{dW}{dz})^2 dz$$

### 5. 儒可夫斯基升力定理
- $$L = \rho V_\infty \Gamma$$，方向：来流方向逆环流转90°

### 6. 圆柱绕流
- 无环量：$$W = V_\infty(z + \frac{a^2}{z})$$，压力对称 → 零阻力（达朗贝尔佯谬）
- 有环量：叠加点涡产生升力（马格努斯效应）

### 7. 镜像法
- 平面边界：$$W(z) = f(z) + \overline{f}(z)$$
- 圆边界：$$W(z) = f(z) + \overline{f}(\frac{a^2}{z})$$

## 五、均质粘性不可压流体运动

### 1. 库埃特流
- 上板运动，无压差：$$u = \frac{U}{b}y$$，线性分布

### 2. 泊肃叶流
- 两固定平板，压差驱动：$$u = \frac{G}{2\mu}y(b-y)$$，抛物线分布

### 3. 量纲分析与相似律
- $$\pi$$ 定理：$$n$$ 个量，$$r$$ 个基本量纲 → $$n-r$$ 个无量纲数
- 主要相似准则：
  - $$Re = \frac{\rho UL}{\mu}$$（惯性/粘性）
  - $$Fr = \frac{U^2}{gL}$$（惯性/重力）
  - $$Eu = \frac{p_0}{\rho U^2}$$（压力/惯性）
  - $$St = \frac{L}{UT}$$（非定常性）
- 流动相似：几何、运动、动力相似，且所有独立无量纲数相等

- 速度势 vs 流函数
- 流线 vs 迹线
- 拉格朗日描述 vs 欧拉描述
- 系统 vs 控制体
- 单值速度势 vs 多值速度势
- 有旋运动 vs 无旋运动
- 兰金组合涡的速度与压力特征
