## 1. 流体力学基础概念与基本方程

### 1.1 基本假设

大气作为流体的三个基本假设：

1. **连续性假设**：大气是连续流体，表征大气运动状态和热力状态的各种基本物理量都是时间和空间的连续函数。
2. **理想气体假设**：将大气视为理想气体，满足理想气体状态方程 $p = \rho R_d T$。
3. **薄层近似**：地球大气的有效厚度远小于地球半径 $r$，故 $r \approx a$（地球半径），$dr/dz \approx 1$。

### 1.2 拉格朗日观点与欧拉观点

- **拉格朗日观点**：研究某一个质点的运动轨迹，其状态函数是与流体质点的起始位置和时间有关的函数。
- **欧拉观点**：研究某一个固定空间位置，其状态函数与流体的位置和时间有关。

全导数（物质导数）：
$$\frac{d}{dt} = \frac{\partial}{\partial t} + \mathbf{V} \cdot \nabla$$

### 1.3 作用于气块的力

**真实力**：
- 气压梯度力：$-\frac{1}{\rho}\nabla p$
- 地球引力
- 摩擦力（分子粘性力 + 湍流粘性力）

**虚拟力（视示力）**：
- 科里奥利力：$-2\boldsymbol{\Omega} \times \boldsymbol{V}$，北半球指向速度的右侧
- 惯性离心力

**重力** = 万有引力 + 惯性离心力的合力

### 1.4 大气运动基本方程组（五大方程）

五个方程构成闭合方程组，可求解 $u, v, w, \rho, T, q$ 六个未知量：

| 方程名称 | 物理本质 | 数学表达 |
| :--- | :--- | :--- |
| 运动方程 | 牛顿第二定律（动量守恒） | $\frac{d\mathbf{V}}{dt} = -\frac{1}{\rho}\nabla p - 2\boldsymbol{\Omega}\times\mathbf{V} + \mathbf{g} + \mathbf{F}$ |
| 连续方程 | 质量守恒 | $\frac{\partial\rho}{\partial t} + \nabla\cdot(\rho\mathbf{V}) = 0$ |
| 热力学能量方程 | 热力学第一定律 | $c_p\frac{dT}{dt} - \alpha\frac{dp}{dt} = \dot{Q}$ |
| 水汽方程 | 水汽质量守恒 | $\frac{dq}{dt} = S/\rho$ |
| 状态方程 | 理想气体状态关系 | $p = \rho R_d T_v$（$T_v = (1+0.608q)T$ 为虚温） |

### 1.5 连续方程（质量守恒）详解

**向量形式**：
$$\frac{\partial \rho}{\partial t} + \nabla \cdot (\rho \mathbf{V}) = 0$$

或拉格朗日形式：
$$\frac{d\rho}{dt} + \rho \nabla \cdot \mathbf{V} = 0$$

**速度散度的物理意义**：
$$\nabla \cdot \mathbf{V} = \frac{1}{\delta\tau}\frac{d(\delta\tau)}{dt}$$

即速度散度等于单位体积流体的相对膨胀率。辐散时流体膨胀、密度减小；辐合时流体收缩、密度增大。

**$p$ 坐标系连续方程**（最重要形式）：
$$\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial \omega}{\partial p} = 0$$

其中 $\omega = dp/dt$ 为 $p$ 坐标系"垂直速度"。此式无时间导数，是**诊断方程**。

**达因补偿原理**：整层大气积分水平散度为零：
$$\int_0^\infty \rho\left(\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}\right)dz = 0$$

即低层辐合必伴有高层辐散（或反之），是天气系统三维环流结构的约束。

**不可压缩近似**：$\frac{d\rho}{dt}=0 \Rightarrow \nabla\cdot\mathbf{V}=0$，适用于中小尺度运动，但对大尺度不成立（密度层结效应不可忽略）。

**球坐标连续方程**：
$$\frac{\partial \rho}{\partial t} + \frac{1}{r\cos\phi}\frac{\partial(\rho u)}{\partial\lambda} + \frac{1}{r\cos\phi}\frac{\partial(\rho v\cos\phi)}{\partial\phi} + \frac{1}{r^2}\frac{\partial(\rho w r^2)}{\partial r} = 0$$

### 1.6 状态方程

$$p = \rho R_d T_v, \quad T_v = (1+0.608q)T, \quad R_d = 287\,\text{J}\cdot\text{kg}^{-1}\cdot\text{K}^{-1}$$

状态方程是标量方程，在所有坐标系中形式一致。

### 1.7 热力学能量方程

$$c_p \frac{dT}{dt} - \alpha \frac{dp}{dt} = \dot{Q}, \quad \alpha = 1/\rho$$

大尺度运动中温度变化由温度平流和垂直运动主导。静力平衡下 $\frac{dp}{dt} \approx -\rho g w$。

### 1.8 球坐标系与局地直角坐标系对比

| 特性 | 球坐标系 | 局地直角坐标系 |
| :--- | :--- | :--- |
| 适用范围 | 全球、大尺度、任意纬度 | 中纬度、有限区域（$L \ll a$） |
| 曲率项 | 完整保留 | 忽略 |
| 科氏力项 | 含 $u,v,w$ 引起的分量（含 $\tan\phi$ 项） | 简化为 $-fv$ 和 $fu$ |
| 重力 | 径向引力+离心力合成 $g(r,\phi)$ | 常数 $g$，仅在 $z$ 方向 |

## 2. 尺度分析与无量纲数

### 2.1 尺度分析的基本方法

将大气运动按水平尺度分类：

| 尺度   | 水平尺度            | 实例       | 主导平衡    |
| :--- | :-------------- | :------- | :------ |
| 行星尺度 | $10^7$ m        | 超长波、大气环流 | 地转平衡    |
| 天气尺度 | $10^6$ m        | 气旋、反气旋   | 地转平衡+偏差 |
| 中尺度  | $10^5$ m        | 对流系统     | 梯度风/非地转 |
| 小尺度  | $10^3$-$10^4$ m | 雷暴、龙卷    | 旋衡/强非地转 |

### 2.2 罗斯贝数（Rossby Number）

$$Ro = \frac{U}{f_0 L}$$

物理意义：惯性力与科氏力的比值。

- $Ro \ll 1$：地转流（大尺度运动，科氏力主导）
- $Ro \sim 1$：梯度流（惯性力与科氏力量级相当）
- $Ro \gg 1$：旋衡流（惯性力主导，科氏力可忽略，如龙卷）

### 2.3 弗劳德常数（Froude Number）

弗劳德数是惯性力与重力之比，在流体力学中衡量流动的相对重要性。

### 2.4 基别尔数（Kibel Number）

$$\varepsilon = \frac{1}{f_0 T}$$

衡量局地加速度与科氏力之比。对于天气尺度运动 $\varepsilon \sim 0.1$（准定常）。

### 2.5 五个"准"

尺度分析导出的五个近似关系：
- **准静力**：垂直加速度可忽略 → 静力平衡
- **准水平**：$w \ll u, v$
- **准地转**：实际风近似地转风
- **准无辐散**：$\nabla_h \cdot \mathbf{V}_h \approx 0$
- **准定常**：$\partial/\partial t$ 项小

## 3. 平衡流场（地转风、梯度风、热成风、地转偏差）

### 3.1 平衡流场概述

**平衡流场**指在自由大气（忽略摩擦）中，水平气压梯度力、科里奥利力和惯性离心力三者达到平衡时的风场。

### 3.2 地转风（Geostrophic Wind）

水平气压梯度力与科里奥利力平衡时的水平风场，是大气运动的零级近似。

$$\mathbf{V}_g = \frac{1}{f\rho}\mathbf{k}\times\nabla_h p$$

$p$ 坐标系形式：
$$u_g = -\frac{1}{f}\frac{\partial\Phi}{\partial y}, \quad v_g = \frac{1}{f}\frac{\partial\Phi}{\partial x}$$

- **白贝罗定律**（北半球）：背风而立，高压在右，低压在左。
- **地转风散度**：$p$ 坐标系下 $\nabla_p\cdot\mathbf{V}_g=0$（水平无辐散）。
- $Ro \ll 1$ 时适用，赤道 ($f \to 0$) 不适用。

### 3.3 惯性运动（Inertial Motion）

水平气压梯度力为零时，科氏力单独提供向心加速度：
$$\frac{V_i^2}{R_T} + fV_i = 0 \Rightarrow R_T = -\frac{V_i}{f}$$

- 反气旋式弯曲，周期 $T = 2\pi/f$（惯性周期）
- 实际大气中纯惯性运动罕见

### 3.4 旋衡运动（Cyclostrophic Motion）

$Ro \gg 1$，科氏力可忽略，气压梯度力与离心力平衡：
$$V_c = \sqrt{-\frac{R_T}{\rho}\frac{\partial p}{\partial n}}$$

适用于龙卷、尘卷风等小尺度强涡旋系统。

### 3.5 梯度风（Gradient Wind）

气压梯度力+科氏力+离心力三者平衡：
$$\frac{V_G^2}{R_T} + fV_G + \frac{1}{\rho}\frac{\partial p}{\partial n} = 0$$

$$V_G = -\frac{fR_T}{2} + \sqrt{\left(\frac{fR_T}{2}\right)^2 - \frac{R_T}{\rho}\frac{\partial p}{\partial n}}$$

- 气旋式（$R_T>0$）：地转风偏大，风速无上限
- 反气旋式（$R_T<0$）：地转风偏小，风速有物理上限 $V_{G,\max} = -fR_T/2$

### 3.6 热成风（Thermal Wind）

地转风随高度的变化量，反映大气斜压性：

$$\mathbf{V}_T = \mathbf{V}_g(p_1) - \mathbf{V}_g(p_0) = \frac{R}{f}\mathbf{k}\times\nabla_p\overline{T}$$

- 北半球背热成风而立，低温在左，高温在右
- 正压大气（无水平温度梯度）中热成风为零
- **冷平流**：风随高度逆转；**暖平流**：风随高度顺转
- 深厚系统（冷低压、暖高压）vs 浅薄系统（冷高压、暖低压）

### 3.7 地转偏差（Ageostrophic Wind）

$$\mathbf{V}' = \mathbf{V} - \mathbf{V}_g$$

**边界层地转偏差**（有摩擦）：$\mathbf{V}' = \frac{1}{f}\mathbf{k}\times\mathbf{F}$，指向摩擦力右侧，使风穿越等压线。

**自由大气地转偏差**（无摩擦）：$\mathbf{V}' = \frac{1}{f}\mathbf{k}\times\frac{d\mathbf{V}}{dt}$，指向加速度左侧。

地转偏差虽小，但直接联系水平辐合辐散与垂直运动——高空槽前辐散上升、槽后辐合下沉。

| 平衡流类型 | 平衡力 | 适用条件 | 关键性质 |
| :--- | :--- | :--- | :--- |
| 地转风 | PGF = Cor | $Ro\ll1$，平直等压线 | 水平无辐散 |
| 惯性运动 | Cor = 离心力 | 无PGF | 反气旋式圆，周期 $2\pi/f$ |
| 旋衡运动 | PGF = 离心力 | $Ro\gg1$，小尺度强涡旋 | 风速可极大 |
| 梯度风 | PGF+Cor+离心力 | 弯曲等压线 | 反气旋有风速上限 |
| 热成风 | 地转风随高度变化 | 斜压大气 | 反映温度平流 |
| 地转偏差 | 非平衡剩余 | 有加速度/摩擦 | 驱动辐合辐散 |

## 4. 环流定理与涡度方程

### 4.1 速度环流

$$C = \oint_L \mathbf{V}\cdot d\mathbf{r}$$

由斯托克斯定理与涡通量等价：$C = \int_A \boldsymbol{\omega}\cdot d\mathbf{A}$

### 4.2 绝对环流定理（Kelvin 定理）

$$\frac{d_a C_a}{dt} = -\oint_L \alpha\,dp$$

- **力管项** $-\oint_L \alpha\,dp$：反映流体斜压性对环流变化的影响
- 正压流体（$\alpha=\alpha(p)$）：力管项为零，绝对环流守恒
- 斜压流体：等压面与等比容面相交形成力管，环流可变化
- 力管数 $N = -\oint_L \alpha\,dp$：正力管产生气旋性环流加强

### 4.3 相对环流定理

$$\frac{dC}{dt} = -\oint_L \alpha\,dp - 2\Omega\frac{dA'}{dt}$$

- 力管项（斜压性）+ 惯性项（地球旋转效应）
- 惯性项反映环线面积变化和南北位移对相对环流的影响

### 4.4 应用：海陆风环流

白天陆地升温快 → 等压面/等比容面倾斜 → 形成力管 → 驱动海风环流（低层海→陆，上层反之）。

### 4.5 涡度的定义

$$\boldsymbol{\omega} = \nabla\times\mathbf{V}$$

垂直分量（气象学最关注）：
$$\zeta = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}$$

- 正涡度：气旋式旋转（北半球逆时针）
- 负涡度：反气旋式旋转

**绝对涡度**：$\zeta_a = \zeta + f$（相对涡度 + 地转涡度）

### 4.6 自然坐标系中的涡度

$$\zeta = \frac{V}{R_s} - \frac{\partial V}{\partial n}$$

- **曲率涡度** $\frac{V}{R_s}$：流线弯曲引起
- **切变涡度** $-\frac{\partial V}{\partial n}$：风速水平切变引起

### 4.7 涡度方程（直角坐标系）

$$\frac{d(\zeta+f)}{dt} = -(f+\zeta)\nabla_h\cdot\mathbf{V}_h - \underbrace{\left(\frac{\partial w}{\partial x}\frac{\partial v}{\partial z} - \frac{\partial w}{\partial y}\frac{\partial u}{\partial z}\right)}_{\text{扭曲项}} + \underbrace{\frac{1}{\rho^2}\left(\frac{\partial\rho}{\partial x}\frac{\partial p}{\partial y} - \frac{\partial\rho}{\partial y}\frac{\partial p}{\partial x}\right)}_{\text{力管项}}$$

各项物理意义：

| 项 | 物理意义 |
| :--- | :--- |
| 平流项 | 涡度被气流输送 |
| 散度项 $-(f+\zeta)\nabla_h\cdot\mathbf{V}_h$ | 水平辐合拉伸气柱使涡度增大（最重要项） |
| $\beta$ 项 $-\beta v$ | 南北运动引起地转涡度变化 |
| 扭曲项 | 垂直风切变与水平涡管倾斜的相互作用 |
| 力管项 | 斜压性产生的涡度 |

### 4.8 $p$ 坐标涡度方程

无显式力管项，斜压性通过扭曲项间接影响涡度。

### 4.9 大尺度简化涡度方程

$$\frac{d_h(\zeta+f)}{dt} = -f\nabla_h\cdot\mathbf{V}_h$$

- 准地转理论核心
- 进一步取无辐散 → 正压涡度方程 $\frac{d_h(\zeta+f)}{dt}=0$ → 罗斯贝波理论基础

### 4.10 涡度方程与散度方程耦合

$$\frac{d_h(\zeta+f)}{dt} = f\frac{\partial\omega}{\partial p}$$

将涡度变化与垂直速度的垂直切变联系起来。

## 5. 位势涡度守恒

### 5.1 定义

$$q = \frac{\boldsymbol{\omega}_a \cdot \nabla\theta}{\rho}$$

位势涡度（PV）同时编码了涡旋强度、静力稳定度和热力结构三重信息。

### 5.2 守恒定律

在绝热、无摩擦条件下，位势涡度严格守恒：
$$\frac{dq}{dt} = 0$$

### 5.3 大尺度近似

$$q \approx \frac{\zeta+f}{\rho}\frac{\partial\theta}{\partial z} \approx \frac{\zeta+f}{g}N^2$$

其中 $N^2 = \frac{g}{\theta}\frac{\partial\theta}{\partial z}$ 为浮力频率平方。

**物理解释**：气柱拉伸（厚度增大）→ $\zeta+f$ 增大（气旋趋势）；气柱压缩 → $\zeta+f$ 减小（反气旋趋势）。

### 5.4 等熵面解释

两个相邻等熵面之间的气柱，在绝热运动中质量和位温间隔守恒，因此绝对涡度与厚度之比守恒。

### 5.5 PVU 单位

$$1\,\text{PVU} = 10^{-6}\,\text{m}^2\cdot\text{s}^{-1}\cdot\text{K}\cdot\text{kg}^{-1}$$

$1.5\sim2.0$ PVU 等值面定义为**动力对流层顶**。平流层为高 PV 储库，对流层为低 PV 区域。

### 5.6 应用

1. **$\beta$ 效应与厚度变化**：冷空气南下，$f$ 减小 → 气柱变薄
2. **地形槽（背风槽）**：西风越山 → 气柱先压缩（反气旋涡度）→ 过顶后拉伸（气旋涡度）→ 背风槽
3. **对流层顶折叠与气旋生成**：高 PV 异常下传 → 诱发地面气旋发展
4. **非绝热加热**：潜热释放产生 PV 偶极子

### 5.7 准地转位涡（QGPV）

$$q_{QG} = f_0 + \beta y + \nabla^2\psi + \frac{f_0^2}{\rho_0}\frac{\partial}{\partial z}\left(\frac{\rho_0}{N^2}\frac{\partial\psi}{\partial z}\right)$$

## 6. 大气行星边界层与湍流

### 6.1 雷诺分解与雷诺方程

将瞬时场分解为平均场+脉动场：$\phi = \overline{\phi} + \phi'$

非线性平流项的雷诺平均产生**雷诺应力**：
$$\tau_{ij} = -\rho\overline{u_i'u_j'}$$

### 6.2 平均动量方程（雷诺方程）

$$\frac{\partial\overline{u}}{\partial t} + \overline{u}\frac{\partial\overline{u}}{\partial x} + \overline{v}\frac{\partial\overline{u}}{\partial y} + \overline{w}\frac{\partial\overline{u}}{\partial z} = -\frac{1}{\rho}\frac{\partial\overline{p}}{\partial x} + f\overline{v} - \left(\frac{\partial\overline{u'^2}}{\partial x} + \frac{\partial\overline{u'v'}}{\partial y} + \frac{\partial\overline{u'w'}}{\partial z}\right)$$

### 6.3 湍流交换系数（闭合假设）

$$\overline{u'w'} = -K_m\frac{\partial\overline{u}}{\partial z}$$

$K_m$ 不是流体属性，而是湍流的属性。近地面层 $K_m \sim 0.1\,\text{m}^2/\text{s}$，埃克曼层 $K_m \sim 1\text{-}10\,\text{m}^2/\text{s}$。

### 6.4 埃克曼层（Ekman Layer）

**控制方程**（定常、水平均匀、$K_m$常数、正压边界层）：

$$0 = f_0(v-v_g) + K_m\frac{d^2 u}{dz^2}$$
$$0 = -f_0(u-u_g) + K_m\frac{d^2 v}{dz^2}$$

引入复变量 $W = (u-u_g)+i(v-v_g)$：
$$K_m\frac{d^2W}{dz^2} - if_0W = 0$$

**埃克曼螺线解**（$v_g=0$）：
$$u = u_g\left[1 - e^{-\gamma z}\cos(\gamma z)\right], \quad v = u_g e^{-\gamma z}\sin(\gamma z)$$

其中 $\gamma = \sqrt{f_0/(2K_m)}$。

**关键参数**：

| 参数 | 表达式 | 物理意义 |
| :--- | :--- | :--- |
| 埃克曼标高 $H_E$ | $\sqrt{2K_m/f_0}$ | 湍流粘性力与科氏力量级相当的高度 |
| 埃克曼厚度 $D_E$ | $\pi H_E$ | 风向首次与地转风重合的高度 |
| 地面风偏角 | $45^\circ$（常数$K_m$） | 实际 $10^\circ\text{-}30^\circ$ |

**埃克曼螺线特征**（北半球）：
- $z=0$：风速为零，风向与地转风夹角 $45^\circ$
- 随高度增加，风向顺时针旋转（向右转）
- $z=D_E$：风速略大于地转风（约 $1.043u_g$）
- $z\to\infty$：趋近地转风

### 6.5 埃克曼抽吸（Ekman Pumping）

边界层顶垂直速度：
$$w_E = \frac{1}{2}H_E\zeta_g$$

- 气旋区（$\zeta_g>0$）：$w_E>0$，上升运动
- 反气旋区（$\zeta_g<0$）：$w_E<0$，下沉运动

### 6.6 旋转减弱（Spin-down）

$$\zeta_g(t) = \zeta_g(0)e^{-t/\tau_E}, \quad \tau_E \approx 5\,\text{天}$$

埃克曼抽吸是天气系统衰减的主要机械耗散机制。旋转减弱时间尺度约 5 天，与中纬度气旋自然消亡时间一致。

### 6.7 混合长理论

混合长 $l$ 类比分子运动自由程，湍流交换系数：
$$K_m = l^2\left|\frac{\partial\overline{u}}{\partial z}\right|$$

### 6.8 理查森数（Richardson Number）

$$Ri = \frac{N^2}{(\partial\overline{u}/\partial z)^2}$$

- $Ri < 0.25$：湍流发展（KH不稳定临界值）
- $Ri > 1$：湍流被抑制
- 是层流-湍流转换的重要判据

## 7. 大气中的基本波动

### 7.1 波动基本概念

| 参数 | 定义 | 关系 |
| :--- | :--- | :--- |
| 波数 $k$ | $2\pi$ 距离内波长数 | $k = 2\pi/L$ |
| 圆频率 $\omega$ | 单位时间位相变化 | $\omega = 2\pi/T$ |
| 相速度 $c$ | 等位相面移动速度 | $c = \omega/k$ |
| 群速度 $c_g$ | 波包（能量）传播速度 | $c_g = d\omega/dk$ |

- **频散波**：$c_g \neq c$，相速度依赖于波长
- **非频散波**：$c_g = c$，波形不扩散

**小扰动法**：将变量分解为基本量+扰动量，线性化。
**标准波形法**：设解为 $e^{i(kx+ly+mz-\omega t)}$，导出频散关系。

### 7.2 大气波动分类

| 波动类型 | 恢复机制 | 典型频率 | 滤波条件 |
| :--- | :--- | :--- | :--- |
| 声波 | 可压缩性 | $\omega\sim c_sk$ | 不可压、静力平衡 |
| 重力外波 | 重力+自由面 | $\omega=\sqrt{gH_0}k$ | 固定上下边界 |
| 重力内波 | 浮力（稳定层结） | $\omega\le N$ | 中性层结 |
| 惯性波 | 科氏力 | $\omega=f$ | 无科氏力 |
| 惯性重力波 | 科氏力+浮力 | $\omega>\max(N,f)$ | 无层结/无旋转 |
| 罗斯贝波 | $\beta$效应 | $\omega=-\frac{\beta k}{k^2+l^2}$ | 无$\beta$效应 |

### 7.3 重力外波

浅水系统中由重力和自由面恢复的快波。

频散关系（静力平衡浅水近似）：
$$\omega^2 = gH_0 K^2, \quad c = \sqrt{gH_0} \approx 313\,\text{m/s}$$

非频散波，$c_g = c$。

**非静力平衡修正**：$c = \pm\sqrt{\frac{g}{K}\tanh(KH_0)}$
- 短波（深水波）：频散，$c\approx\sqrt{g/K}$
- 长波（浅水波）：非频散，$c\approx\sqrt{gH_0}$

### 7.4 重力惯性外波

重力外波+科氏力耦合：

$$\omega^2 = f_0^2 + gH_0 K^2$$

- 科氏力使外波变为频散波
- 低频截止频率为 $f_0$
- **罗斯贝变形半径** $L_0 = \sqrt{gH_0}/f_0$ 是判别重力与科氏力相对重要性的关键尺度
- $L \ll L_0$：重力主导（近纯重力外波）
- $L \gg L_0$：科氏力主导（近惯性振荡）
- 地转适应方向：$L > L_0$ 风场适应气压场，$L < L_0$ 气压场适应风场

### 7.5 重力内波

稳定层结流体内部，浮力为恢复力。

频散关系（Boussinesq近似）：
$$\omega^2 = \frac{N^2 k^2}{k^2+m^2}, \quad N^2 = \frac{g}{\overline{\theta}}\frac{d\overline{\theta}}{dz}$$

- 频率限制：$0 < \omega \le N$，最大频率 $N$（Brunt-Väisälä 频率）
- 中纬度典型 $N \approx 1.2\times10^{-2}\,\text{s}^{-1}$，周期约 9 分钟
- **核心特征**：$\mathbf{c}\cdot\mathbf{c}_g=0$（相速度与群速度垂直）
- 垂直方向上能量传播方向与位相传播方向相反：$c_{gz} = -c_z$
- 地形激发的山地波是大气中最重要重力内波源

### 7.6 惯性内波

中性层结（$N^2=0$），科氏力为恢复力：
$$\omega^2 = f_0^2\frac{K_h^2}{K^2}$$

- $\mathbf{c}\cdot\mathbf{c}_g=0$（与重力内波同）
- 垂直方向 $c_{gz}$ 与 $c_z$ 同号（与重力内波相反）

### 7.7 重力惯性内波（混合波）

$$\omega^2 = \frac{N^2 K_h^2 + f_0^2 m^2}{K^2}$$

- 频率介于 $\min(N,f_0)$ 和 $\max(N,f_0)$ 之间
- 中纬度 $N \gg f_0$，以重力内波特征为主
- 在大尺度动力学中被视为"噪音"（通过准地转近似滤除）

### 7.8 罗斯贝波（大气长波/行星波）

恢复力为 $\beta$ 效应（$df/dy = \beta$）。

物理机制：绝对涡度守恒 $\frac{d}{dt}(\zeta+f)=0$ → 质点南北运动引起 $f$ 变化 → 相对涡度相应变化 → 槽脊向西发展。

**频散关系**（正压无辐散）：
$$\omega = \overline{u}k - \frac{\beta k}{k^2+l^2}$$

- 相对于基本气流总是向西传播：$c_{px} - \overline{u} = -\beta/(k^2+l^2) < 0$
- 频散波

**静止波长**：$L_s = 2\pi\sqrt{\overline{u}/\beta}$
- $L < L_s$：波动东进
- $L > L_s$：波动西退
- $L = L_s$：准静止

**群速度**：
$$c_{gx} = \overline{u} + \beta\frac{k^2-l^2}{(k^2+l^2)^2}$$

- $k^2 > l^2$ 时 $c_{gx} > c_{px}$，能量先于位相到达下游 → **上游效应**
- 上游效应是中长期天气预报上下游效应理论的基础

**斜压罗斯贝波垂直传播条件**：
$$m^2 = \frac{N^2}{f_0^2}\left(\frac{\beta}{c-\overline{u}} - k^2 - l^2\right) > 0$$

观测特征：冬季 500hPa 常有 3-5 个长波绕纬圈分布；阻塞高压和切断低压是罗斯贝波强烈非线性发展的产物。

## 8. 不稳定理论

### 8.1 惯性不稳定

**判据**（北半球）：绝对涡度 $\zeta_a = f + \frac{\partial\overline{u}}{\partial y} < 0$

- 反气旋式切变强度足以抵消地转涡度的正贡献
- 能量来源于基本气流动能
- 典型发生区：高空急流反气旋侧、低纬度、锋区
- 天气意义：与晴空湍流（CAT）、对称不稳定、锋面雨带相关
- $\zeta_a > 0$ 时为惯性振荡（稳定），$\zeta_a < 0$ 时指数增长（不稳定）

### 8.2 正压不稳定

能量来源于基本气流水平动能（水平切变 $\partial\overline{u}/\partial y \neq 0$）。

**必要条件（Rayleigh 定理）**：基本位涡梯度 $\frac{d\overline{q}}{dy} = \beta - \overline{u}''$ 必须在流场内变号。

**Fjørtoft 定理**（更强条件）：存在纬度 $y_s$ 使 $\frac{d\overline{q}}{dy}(\overline{u}-\overline{u}_s) < 0$。

能量转换：扰动雷诺应力 $\overline{u'v'}$ 与基本流切变 $\partial\overline{u}/\partial y$ 相互作用。

### 8.3 斜压不稳定

能量来源于基本气流有效位能（水平温度梯度）。

**必要条件（Charney–Stern 定理）**：准地转位涡梯度 $\frac{\partial\overline{q}}{\partial y}$ 在内部变号，或地面位温梯度满足适当条件。

**经典模型**：
- **Eady 模型**：刚盖顶、$f$ 常数，最不稳定波长约 4700 km，与实际气旋尺度一致
- **Charney 模型**：辐射顶、含 $\beta$，短波被稳定

**能量转换**：暖空气上升、冷空气下沉，$\overline{v'T'}$ 使有效位能转换为扰动动能。槽线随高度向西倾斜利于有效位能释放。

### 8.4 对比

| 特征 | 正压不稳定 | 斜压不稳定 |
| :--- | :--- | :--- |
| 能量来源 | 水平动能（水平切变） | 有效位能（水平温度梯度） |
| 必要条件 | $\beta-\overline{u}''$ 变号 | $\partial\overline{q}/\partial y$ 变号 |
| 典型波长 | 几百-几千 km | 约 4700 km |
| 典型增长率 | 几天 | 2-3 天 |
| 典型现象 | 急流扰动、热带气旋初始 | 温带气旋生成、锋面波动 |

### 8.5 中尺度对称不稳定

斜压不稳定+惯性不稳定的混合体，发生在等绝对角动量面与等位温面相交的区域，是锋面附近中尺度雨带的重要触发机制。

## 9. 大气能量学

### 9.1 基本能量形式

| 能量形式 | 表达式 | 说明 |
| :--- | :--- | :--- |
| 动能 $K$ | $\frac{1}{2}(u^2+v^2+w^2)$ | 大气运动的动能 |
| 位能 $\Phi$ | $gz$ | 重力位能 |
| 内能 $I$ | $c_v T$ | 分子热运动能量 |
| 潜热能 $LH$ | $L q$ | 水汽相变释放的能量 |
| 全位能 | $I + \Phi$ | 内能+位能 |

### 9.2 有效位能（APE）

Lorenz 定义：大气实际状态与参考状态（水平均匀层结）的全位能之差，即理论上可转换为动能的最大能量。

$$A^* = \frac{1}{2}\int\frac{\overline{T}}{\gamma_d-\gamma}\left(\frac{T'}{\overline{T}}\right)^2\frac{dp}{g}$$

- 大气中可转换为动能的能量仅占全位能的约 0.5%
- 斜压不稳定将有效位能转换为扰动动能

### 9.3 大气能量循环

有效位能 → 扰动动能 → 纬向动能 →（摩擦耗散）→ 内能
基本过程：经向温度梯度存储有效位能 → 扰动释放（斜压不稳定）→ 能量从天气尺度向行星尺度串级

## 10. 云与降水中的流体力学

### 10.1 水成物粒子的下落末速度

云滴/雨滴在重力与阻力平衡后达到的终端速度。

**斯托克斯阻力**（小雷诺数，适用于云滴 $r < 30\mu m$）：
$$F_D = 6\pi\eta r v$$

下落末速度：
$$v_t = \frac{2}{9}\frac{\rho_w g}{\eta}r^2$$

其中 $\eta$ 为空气动力粘性系数，$\rho_w$ 为水滴密度。

- 云滴（$r\sim10\mu m$）：$v_t\sim1$ cm/s，几乎悬浮
- 雨滴（$r\sim1$ mm）：$v_t\sim6.5$ m/s

**大雷诺数修正**：需考虑绕流阻力系数的变化（层流→湍流过渡）。

### 10.2 云滴的凝结增长（扩散增长）

水汽分子向液滴表面的扩散过程，由菲克定律描述：
$$\frac{dr}{dt} = \frac{D_v}{\rho_w r}\left(\rho_v(\infty) - \rho_v(r)\right)$$

其中 $D_v$ 为水汽分子扩散系数。小滴增长快，但随后因曲率效应和溶液效应受限。

### 10.3 粒子的碰并效率

两个水成物粒子相对运动时的碰撞概率，由碰撞核 $K(r_1, r_2)$ 描述：
$$K(r_1, r_2) = \pi(r_1+r_2)^2|v_t(r_1)-v_t(r_2)|E(r_1,r_2)$$

$E(r_1,r_2)$ 为碰并效率，受水动力学效应（绕流）和静电效应影响。大小粒子速度差大 → 碰撞概率高。

### 10.4 云滴和雨滴的碰并增长

碰并增长方程（随机碰并/连续碰并模型）：
$$\frac{dM}{dt} = \int_0^\infty K(r,r')n(r')m(r')dr'$$

- 碰并增长是雨滴形成的主要机制（暖云降水）
- 重力碰并（大小滴下落速度差）是最重要的碰并方式
- 湍流碰并增强：湍流增加粒子相对速度，提高碰并率
- 初始"幸运大滴"通过碰并快速增长 → 雨胚形成

## 11. 补充内容

### 11.1 薄层近似

大气有效厚度远小于地球半径（$\sim 10\text{km} \ll 6370\text{km}$），故：
- $r \approx a$（地球半径）
- $dr/dz \approx 1$
- 球坐标中可忽略 $1/r^2$ 项与 $1/r$ 项的差异

### 11.2 线性振动

气块受扰后的简谐振动 → 联系到浮力振荡（$N$）和惯性振荡（$f$），是理解大气波动的物理基础。

### 11.3 绝对环流加速度

环流定理在斜压大气中的应用，力管项 $-\oint_L \alpha dp$ 驱动环流加速。

### 11.4 大气能量守恒与能量转换

大气能量收支：太阳辐射 → 感热+潜热 → 全位能 → 有效位能 → 动能 → 摩擦耗散热。
