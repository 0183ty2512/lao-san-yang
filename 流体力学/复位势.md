# 流体力学I 核心概念笔记

## 1. 流体运动学

### 1.1 描述方法
- **拉格朗日法**：跟随质点，$$f = f(a,b,c,t)$$ → 迹线
- **欧拉法**：固定空间点，$$f = F(x,y,z,t)$$ → 流线
- 联系桥梁：[[实质导数（随体导数）]] $$\frac{D}{Dt} = \frac{\partial}{\partial t} + (\mathbf{u} \cdot \nabla)$$
- **定常流动**中，流线与迹线重合。

### 1.2 连续方程（质量守恒）
- **拉格朗日形式**：$$\frac{d\rho}{dt} + \rho \nabla \cdot \mathbf{u} = 0$$
- **欧拉形式**：$$\frac{\partial \rho}{\partial t} + \nabla \cdot (\rho \mathbf{u}) = 0$$
- **不可压缩流体**：$$\nabla \cdot \mathbf{u} = 0$$

### 1.3 亥姆霍兹速度分解定理
- 将 $$\nabla \mathbf{u}$$ 分解为**对称张量**（变形）与**反对称张量**（旋转）
- [[涡量]] $$\boldsymbol{\omega} = \nabla \times \mathbf{u} = 2 \boldsymbol{\Omega}$$

### 1.4 涡量与环量
- **斯托克斯公式**：$$\Gamma = \oint \mathbf{u} \cdot d\mathbf{l} = \iint \boldsymbol{\omega} \cdot d\mathbf{S}$$
- [[涡量守恒定理]]：理想、正压、有势外力 → 涡管强度随体守恒。

## 2. 理想流体动力学

### 2.1 控制方程
- **欧拉方程**：$$\rho \frac{d\mathbf{u}}{dt} = \rho \mathbf{F} - \nabla p$$
- **伯努利方程**：理想、正压、定常、有势外力 → 沿流线 $$\frac{u^2}{2} + P + \Pi = const$$

### 2.2 速度势与无旋流
- **无旋条件** $$\nabla \times \mathbf{u} = 0$$ → 存在 [[速度势]] $$\phi$$，满足 $$\mathbf{u} = \nabla \phi$$
- **单连通区域**：速度势单值，任意闭合回路环量为零
- **多连通区域**：存在孔洞时，速度势多值，绕孔洞环量可不为零，这是产生升力的关键。

## 3. 平面势流（复位势）

### 3.1 复位势与复速度
- **复位势**：$$W(z) = \phi + i\psi$$，解析函数
- **复速度**：$$\frac{dW}{dz} = u - iv$$
- **流线**：$$\psi = const$$；**等势线**：$$\phi = const$$，二者正交。

### 3.2 基本解
- **均匀流**：$$W = V_\infty z$$
- **点源/汇**：$$W = \frac{Q}{2\pi}\ln z$$
- **点涡**：$$W = \frac{i\Gamma}{2\pi}\ln z$$
- **偶极子**：$$W = \frac{\mu}{z}$$

### 3.3 典型应用
- **无环量圆柱绕流**：$$W = V_\infty(z + a^2/z)$$
- **有环量圆柱绕流**：叠加点涡，产生升力，$$L = \rho V_\infty \Gamma$$（[[儒可夫斯基升力定理]]）
- **布拉修斯定理**：利用留数计算力和力矩。

### 3.4 镜像法
- **平面边界**：$$W(z) = f(z) + \overline{f}(z)$$
- **圆边界**：$$W(z) = f(z) + \overline{f}(a^2/z)$$

## 4. 均质粘性不可压流体

### 4.1 控制方程
- **纳维-斯托克斯方程（N-S方程）**：
  $$\rho\frac{d\mathbf{u}}{dt} = \rho\mathbf{F} - \nabla p + \mu\nabla^2\mathbf{u}$$

### 4.2 经典层流解
- **库埃特流**：上板运动，无压差 → 线性速度分布
- **泊肃叶流**：固定平板，有压差 → 抛物线速度分布

### 4.3 量纲分析与相似律
- **$$\pi$$ 定理**：$$n$$ 个物理量，$$r$$ 个基本量纲 → $$n-r$$ 个无量纲数
- **核心准则**：
  - 雷诺数 $$Re$$（惯性/粘性）
  - 弗劳德数 $$Fr$$（惯性/重力）
  - 欧拉数 $$Eu$$（压力/惯性）
  - 斯特劳哈尔数 $$St$$（非定常性）
