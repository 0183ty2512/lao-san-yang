# 第四章 理想流体平面势流与复位势

> 本章介绍平面不可压缩无旋流动的理论，包括流函数、速度势、复位势、基本势流的叠加，以及圆柱绕流、镜像法和儒可夫斯基升力定理。

---

## 4.1 速度势与流函数

### 速度势 $$\phi$$
无旋流动（$$\nabla\times\mathbf{u}=0$$）→ 存在标量函数 $$\phi$$，使得：
$$\mathbf{u} = \nabla\phi$$

不可压缩无旋流动 → $$\phi$$ 满足**拉普拉斯方程**：
$$\nabla^2\phi = 0$$

### 流函数 $$\psi$$
二维不可压缩流动（$$\frac{\partial u}{\partial x}+\frac{\partial v}{\partial y}=0$$）→ 存在流函数 $$\psi$$，使得：
$$u = \frac{\partial\psi}{\partial y},\quad v = -\frac{\partial\psi}{\partial x}$$

### 等势线与流线
- 等势线 $$\phi = \text{const}$$，梯度 $$\nabla\phi$$（=速度）⊥ 等势线
- 流线 $$\psi = \text{const}$$，切线方向 = 速度方向
- $$\phi$$ 与 $$\psi$$ 的等值线族**处处正交**（速度势梯度 ⟂ 流函数梯度）

### 流量计算
过连接点A到B的任意曲线，单位宽度的体积流量 $$Q = \psi_B - \psi_A$$。

---

## 4.2 复位势与复速度

### 复位势
$$W(z) = \phi(x,y) + i\psi(x,y),\quad z = x + iy$$

$$W(z)$$ 是解析函数（满足柯西-黎曼条件）。

### 复速度
$$\frac{dW}{dz} = u - iv$$

复速度的大小 $$|u-iv| = \sqrt{u^2+v^2}$$ 即为合速度。

### 环量与流量的复积分
$$\oint_C \frac{dW}{dz}dz = \Gamma + iQ$$
- 实部 = 速度环量 $$\Gamma$$
- 虚部 = 通过闭合曲线的体积流量 $$Q$$

---

## 4.3 基本势流

| 势流类型 | 复位势 $$W(z)$$ | 复速度 $$dW/dz$$ | 说明 |
|:---|:---|:---|:---|
| 均匀流（沿x） | $$V_\infty z$$ | $$V_\infty$$ | $$V_\infty$$ 为来流速度 |
| 点源 | $$\frac{Q}{2\pi}\ln z$$ | $$\frac{Q}{2\pi z}$$ | $$Q>0$$ 为源（流出），$$Q<0$$ 为汇 |
| 点涡 | $$\frac{i\Gamma}{2\pi}\ln z$$ | $$\frac{i\Gamma}{2\pi z}$$ | $$\Gamma>0$$ 为逆时针 |
| 偶极子 | $$\frac{\mu}{z}$$ | $$-\frac{\mu}{z^2}$$ | $$\mu$$ 为偶极子强度 |

### 基本解的线性叠加
基本解的线性组合（叠加原理）可构造复杂流场：
$$W(z) = W_1(z) + W_2(z) + \cdots$$

---

## 4.4 圆柱绕流

### 无环量圆柱绕流
复位势：
$$W(z) = V_\infty\left(z + \frac{a^2}{z}\right)$$
其中 $$a$$ 为圆柱半径。

- 压力分布前后对称 → 合力（阻力）为零
- 这是**达朗贝尔佯谬**的理想流体表现

### 有环量圆柱绕流（马格努斯效应）
$$W(z) = V_\infty\left(z + \frac{a^2}{z}\right) + \frac{i\Gamma}{2\pi}\ln z$$
叠加了环量为 $$\Gamma$$ 的点涡，产生升力。

---

## 4.5 布拉修斯定理

作用在绕流物体上的合力和力矩可通过复速度的回路积分计算：

合力：
$$F_x - iF_y = \frac{i\rho}{2}\oint\left(\frac{dW}{dz}\right)^2 dz$$

力矩（对原点）：
$$M = -\frac{\rho}{2}\text{Re}\oint z\left(\frac{dW}{dz}\right)^2 dz$$

利用**留数定理**可方便地计算这些积分。

---

## 4.6 儒可夫斯基升力定理

$$L = \rho V_\infty \Gamma$$

升力 $$L$$ 与来流速度 $$V_\infty$$、流体密度 $$\rho$$、绕物体的速度环量 $$\Gamma$$ 成正比。

- 升力方向：来流方向逆环量方向转 90°
- 环量 $$\Gamma$$ 的唯一值由**库塔条件**确定（后驻点在后缘）

---

## 4.7 镜像法

### 基本思想
为满足壁面上的边界条件，在壁面对称位置放置适当强度的虚设奇点（源汇、偶极子等），使真实奇点与虚设奇点叠加后的流场自动满足壁面法向速度为零的条件。

### 平面壁面镜像
真实奇点 $$f(z)$$ 位于壁面一侧 → 在对称点放置共轭镜像 $$\overline{f}(z)$$：
$$W(z) = f(z) + \overline{f}(z)$$

### 圆柱面镜像（圆定理）
$$W(z) = f(z) + \overline{f}\left(\frac{a^2}{z}\right)$$
其中 $$a$$ 为圆柱半径，$$f(z)$$ 为圆柱外真实奇点的复位势。

---

## 8.8 达朗贝尔佯谬

### 内容
理想不可压缩流体定常无旋绕流任意形状物体时，物体所受的合力（阻力）恒为零。

### 产生原因
无粘性 → 无摩擦阻力；无旋无分离 → 物体前后压力分布完全对称 → 压差阻力为零。

### 实际流动
真实流体有粘性 → 物面形成**边界层** → 逆压梯度下发生**边界层分离** → 尾涡区 → 前后压力不对称 → 显著的**压差阻力**（形状阻力）。

## 例题与解答

**例题1**：已知流动由一沿 $$x$$ 方向的均匀流（速度 $$V_\infty$$）和一位于原点的点汇（强度 $$Q$$，$$Q<0$$）叠加而成。
(1) 求过 $$(1,1)$$ 的流线方程；
(2) 简述镜像法的基本思想。

**解答**：
(1) 复位势 $$W(z) = V_\infty z + \frac{Q}{2\pi}\ln z$$。流函数（虚部）：
$$\psi = V_\infty y + \frac{Q}{2\pi}\theta$$
过 $$(1,1)$$ 的点：$$y=1$$，$$\theta = \arctan(1/1) = \pi/4$$。代入该点：
$$\psi_{(1,1)} = V_\infty \cdot 1 + \frac{Q}{2\pi}\cdot\frac{\pi}{4} = V_\infty + \frac{Q}{8}$$
流线方程 $$\psi = V_\infty + \frac{Q}{8}$$，即 $$V_\infty y + \frac{Q}{2\pi}\theta = V_\infty + \frac{Q}{8}$$。

(2) **镜像法基本思想**：为满足壁面（平面或圆柱面）上的边界条件，在壁面对称位置放置适当强度的虚设奇点，使真实奇点与虚设奇点叠加后的流场自动满足壁面法向速度为零。本质是用基本解的叠加构造满足复杂边界的流动。

---

**例题2**：某流动的复势为：
$$W(z) = (1+i)\ln(z^2+4) + (3-4i)\ln(z^2-9) + 5z + \frac{20}{z}$$

(1) 指出各基本势流及其位置；
(2) 求 $$|z|=4$$ 所围区域的速度环量 $$\Gamma$$ 及通过的流量 $$Q$$。

**解答**：
(1) 各基本势流：
- $$(1+i)\ln(z^2+4) = (1+i)[\ln(z-2i) + \ln(z+2i)]$$：位于 $$\pm 2i$$、强度 $$1+i$$ 的奇点组合（源/汇+点涡）
- $$(3-4i)\ln(z^2-9) = (3-4i)[\ln(z-3) + \ln(z+3)]$$：位于 $$\pm 3$$、强度 $$3-4i$$ 的奇点组合
- $$5z$$：速度 $$5$$ 沿 $$x$$ 方向的均匀流
- $$\frac{20}{z}$$：位于原点的偶极子

(2) $$\oint_{|z|=4} \frac{dW}{dz}dz = \Gamma + iQ$$：
$$\frac{dW}{dz} = \frac{2z(1+i)}{z^2+4} + \frac{2z(3-4i)}{z^2-9} + 5 - \frac{20}{z^2}$$

在 $$|z|=4$$ 内的奇点：$$z = \pm 2i, \pm 3$$（4个一阶极点）。

留数：$$\text{Res}(2i) = \text{Res}(-2i) = 1+i$$，$$\text{Res}(3) = \text{Res}(-3) = 3-4i$$

总和 $$\sum\text{Res} = 2(1+i) + 2(3-4i) = 8 - 6i$$

$$\oint = 2\pi i \cdot (8-6i) = 16\pi + 12\pi i$$

因此：$$\Gamma = 12\pi$$（实部），$$Q = 16\pi$$（虚部）。

## 思考题与解答

**思考题1**：什么是复位势？它的基本性质有哪些？
**答**：复位势 $$W(z) = \phi + i\psi$$ 是以复坐标 $$z=x+iy$$ 为自变量的解析函数，实部为速度势 $$\phi$$，虚部为流函数 $$\psi$$。性质：（1）解析性（满足柯西-黎曼条件）；（2）$$dW/dz = u-iv$$（复速度）；（3）线性可叠加；（4）$$\oint dW/dz \; dz = \Gamma + iQ$$；（5）等势线与流线正交。

**思考题2**：什么是流函数？流函数的物理意义是什么？
**答**：对于二维不可压缩流动（$$\nabla\cdot\mathbf{u}=0$$），可引入 $$\psi$$ 使得 $$u = \frac{\partial\psi}{\partial y}, v = -\frac{\partial\psi}{\partial x}$$，自动满足连续方程。等 $$\psi$$ 线 = 流线；两点 $$\psi$$ 值之差 = 单位宽度流过的体积流量。

**思考题3**：什么是达朗贝尔佯谬？产生的原因是什么？实际流动情况如何？
**答**：理想流体定常无旋绕流物体时，物体所受合力（阻力）为零——与实验矛盾。原因：无粘 → 无摩擦阻力 + 无边界层分离 → 前后压力对称 → 压差阻力为零。实际有粘流体：物体表面形成边界层 → 逆压梯度下分离 → 尾涡区 → 前后压力不对称 → 显著的压差阻力（形状阻力）。

**思考题4**：儒可夫斯基升力定理的内容是什么？升力取决于哪些因素？
**答**：$$L = \rho V_\infty \Gamma$$。升力与来流速度 $$V_\infty$$、流体密度 $$\rho$$、绕物体环量 $$\Gamma$$ 成正比。环量由物体形状和攻角决定（库塔条件确定其唯一值）。升力方向为来流逆环量转90°。

**思考题5**：镜像法的基本思想是什么？平面边界和圆边界的镜像分别如何构造？
**答**：为满足壁面边界条件，在对称位置放置适当强度的虚设奇点，使实虚奇点叠加后自动满足壁面法向速度为零。平面边界：$$W(z) = f(z) + \overline{f}(z)$$；圆边界（圆定理）：$$W(z) = f(z) + \overline{f}(a^2/z)$$（$$a$$ 为圆柱半径）。
