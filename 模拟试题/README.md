## 使用建议

1. **顺序练习**：按一→十顺序完成，每套限时150分钟
2. **对照答案**：每套做完后仔细对比参考答案，注意名词解释需同时给出定义+表达式+物理意义
3. **重点突破**：根据个人弱项选择对应专题的试卷重点练习（如波动弱→试卷六，辐射弱→试卷七）
4. **推导题训练**：10套试卷覆盖7种不同推导题型，建议每种推导至少独立完成2遍
5. **跨卷对比**：试卷四、九都有台风vs温带气旋对比，试卷六、八都有正压/斜压不稳定——跨卷对比可以加深理解
