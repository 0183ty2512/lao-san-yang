# 模拟试题六 — 波动与不稳定专题

> 侧重点：各类动力不稳定机制 | 热带波动 | 频散与波包 | 相速与群速

---

## 一、名词解释（每题3分，共30分）

1. 正压不稳定
2. 斜压不稳定
3. 惯性不稳定
4. 中尺度对称不稳定
5. 开尔文波
6. 频散波
7. 波包
8. 相速度和群速度
9. 罗斯贝-重力混合波（Yanai波）
10. 上下游效应

## 二、简答题（每题10分，共60分）

1. 简述正压不稳定和斜压不稳定的主要区别（能量来源、发生条件、特征波长、适用区域）
2. 试述赤道地区开尔文波与罗斯贝-重力混合波的主要性质
3. 如何区分频散波和非频散波？能量频散的根本原因是什么？
4. 写出惯性运动的力平衡方程，说明惯性运动的物理图像
5. 简述上下游效应的物理机制，并举例说明
6. 举例说明大气波动演变中有哪些动力不稳定机制

## 三、论述题（每题15分，共45分）

1. 论述斜压不稳定波动的空间结构特征：包括温度槽与气压槽的相位关系、垂直倾斜结构、垂直运动分布、能量转换过程
2. 对比分析热带扰动发生发展的正压不稳定与第二类条件不稳定（CISK）的物理机制差异
3. 罗斯贝数的表达式是什么？如何用罗斯贝数区分大气大尺度运动过程的两个阶段（地转适应过程和准地转演变过程）？

## 四、推导题（15分）

已知线性化正压无辐散涡度方程：
$$\left(\frac{\partial}{\partial t} + \bar{u}\frac{\partial}{\partial x}\right)\nabla^2\psi' + \beta\frac{\partial\psi'}{\partial x} = 0$$

(1) 设波动解 $\psi' = \Psi e^{i(kx+ly-\omega t)}$，推导罗斯贝波的频散关系
(2) 求出相速度 $c_p$ 和群速度 $c_g$ 的表达式
(3) 论证罗斯贝波是频散波，并说明能量频散的方向特点
(4) 求出静止波长 $L_s$，并讨论其物理意义

# 参考答案

## 一、名词解释

**1. 正压不稳定**：基本气流的水平切变能量向扰动转换的动力不稳定。必要条件：$\beta - d^2\bar{u}/dy^2$ 必须在某处为零（郭晓岚条件）。能量来源于基本气流的动能（水平切变），主要出现在热带东风气流中，是热带扰动初始发展的重要机制。

**2. 斜压不稳定**：基本气流的垂直切变能量（即有效位能）向扰动动能转换的动力不稳定。条件：垂直风切变足够强以克服静力稳定度的抑制作用。是中纬度气旋生成的主要机制，特征波长约3000-5000km，增长速率依赖于垂直风切变和静力稳定度之比。

**3. 惯性不稳定**：水平位移的气块在科氏力作用下偏离平衡位置后不能恢复原位的状态。条件：$\partial M/\partial y < 0$（绝对角动量随纬度减小）。多出现在急流轴南侧反气旋切变区（负绝对涡度区）。

**4. 中尺度对称不稳定**：大气在满足静力稳定和惯性稳定的条件下，倾斜对流（沿等熵面的倾斜位移）仍可不稳定发展。条件：$Ri < f/(\zeta+f)$。与中尺度雨带和带状降水的形成密切相关。

**5. 开尔文波**：赤道俘获的向东传播的重力波，无经向速度分量（$v=0$），其经向结构为高斯分布，在赤道振幅最大。是非频散波（相速=群速）。热带平流层准两年振荡（QBO）和MJO的部分特征与开尔文波有关。

**6. 频散波**：群速度不等于相速度的波动（$c_g \neq c_p$）。不同波长的波以不同速度传播，导致波包在传播过程中弥散。罗斯贝波是典型的频散波——在静止介质中能量向东传播的速度可远大于波速。

**7. 波包**：由多个频率和波数相近的波叠加形成的局域化的波动结构。波包的包络以群速度传播（能量传播速度），而载波以相速度传播。在大气中，天气尺度的波动常以波包形式向下游频散能量。

**8. 相速度和群速度**：$c_p = \omega/k$（单色波相位传播速度）；$c_g = d\omega/dk$（波包能量传播速度）。对于频散波二者不相等。罗斯贝波中，$c_g$在静止介质中总为正（向东），而$c_p$可正可负。

**9. 罗斯贝-重力混合波（Yanai波）**：热带大气中兼具重力波和Rossby波特性的赤道俘获波动。向西传播，经向结构为抛物线柱函数的高阶解，是频散波。对热带对流活动有调制作用。

**10. 上下游效应**：上游环流系统（如阻塞高压）的变化通过能量频散向下游传播，导致下游天气系统发生变化的连锁反应。西风带中能量以群速度向下游传播，下游系统的变化可以先于上游波的到达。

## 二、简答题

**1. 正压不稳定 vs 斜压不稳定**：

| 特征 | 正压不稳定 | 斜压不稳定 |
|------|-----------|-----------|
| 能量来源 | 基本气流水平切变的动能 | 基本气流垂直切变的有效位能 |
| 必要条件 | β-d²ū/dy²在某处为零 | 垂直切变 > 临界值 |
| 特征波长 | 较短（约1000-2000km） | 较长（约3000-5000km） |
| 主要区域 | 热带东风气流 | 中纬度西风带 |
| 体现系统 | 东风波、热带扰动 | 温带气旋、锋面波 |

**2. 开尔文波与罗斯贝-重力混合波性质**：
- 开尔文波：①$v=0$（无经向风）；②向东传播；③赤道俘获（e指数衰减）；④非频散（$c_g = c_p$）；⑤重力波性质
- Yanai波：①有经向风分量；②向西传播；③赤道俘获（抛物线柱函数结构）；④频散波；⑤兼具Rossby波和重力波特征

**3. 频散波 vs 非频散波**：
- 频散波：$\omega$与$k$为非线性关系，$d\omega/dk \neq \omega/k$，能量和波形以不同速度传播
- 非频散波：$\omega$与$k$为线性关系，$c_g=c_p$
- 能量频散的根本原因：不同波数的波分量以不同相速度传播→波包的形状随时间变化→能量在空间中扩散

**4. 惯性运动**：
力平衡：科氏力 ↔ 惯性离心力（无气压梯度力）
$$fV = \frac{V^2}{R}$$
气块做惯性圆周运动，周期为半摆日（$T = 2\pi/f$），半径$R = V/f$。在大气中常表现为低纬度或小尺度系统的旋转特征。

**5. 上下游效应**：
上游阻塞高压建立→能量以群速度向下游频散→下游长波槽发展加深→冷空气南下。典型实例：乌拉尔山阻高建立→东亚大槽加深→我国寒潮爆发。

**6. 动力不稳定机制举例**：
(1) 正压不稳定→东风波发展
(2) 斜压不稳定→温带气旋发展
(3) CISK→台风发展
(4) 对称不稳定→中尺度雨带
(5) 惯性不稳定→急流南侧扰动

## 三、论述题

**1. 斜压不稳定波动空间结构**：

**垂直结构**：
- 扰动振幅在对流层顶附近最大
- 槽线随高度向西倾斜（西倾结构）→这是有效位能向扰动动能转换的标志
- 温度槽落后于气压槽（向西滞后约π/2相位）

**水平结构**：
- 槽前为暖平流区（南风+温度北增→暖平流）→上升运动
- 槽后为冷平流区（北风+温度南减→冷平流）→下沉运动
- 暖空气在槽前上升、冷空气在槽后下沉→质量中心降低→有效位能转换为扰动动能

**能量转换**：
有效位能→扰动有效位能→扰动动能。暖平流使低层减压、冷平流使低层升压，维持系统发展。

**2. 正压不稳定 vs CISK**：

| 对比维度 | 正压不稳定 | CISK |
|----------|-----------|------|
| 能量来源 | 基本气流水平切变 | 积云凝结潜热释放 |
| 适用尺度 | 天气-行星尺度 | 中-天气尺度（台风） |
| 必要条件 | β-d²ū/dy²=0 | SST≥26.5°C + 水汽辐合 |
| 物理机制 | 水平切变动能→扰动动能 | 积云→潜热→低层辐合↑→积云↑ |
| 热力作用 | 无直接热力作用 | 积云加热是核心驱动 |
| 区域 | 热带东风带 | 热带海洋 |

两者可协同作用：正压不稳定提供初始扰动→CISK机制放大→台风生成。

**3. 罗斯贝数区分两个阶段**：
$$Ro = \frac{U}{fL}$$

- $Ro \ll 1$（大尺度）：运动分两个阶段
  - **地转适应阶段**：初始流场和气压场不平衡→通过重力惯性波的频散快速调整→达到地转平衡（时间尺度~1/f）
  - **准地转演变阶段**：系统在地转平衡约束下缓慢演变→由涡度平流和温度平流驱动（时间尺度~L/U）
- $Ro \sim 1$（小尺度或低纬度）：两阶段不能分离，始终是非地转运动

## 四、推导题

(1) 设 $\psi' = \Psi e^{i(kx+ly-\omega t)}$，则 $\nabla^2\psi' = -(k^2+l^2)\psi'$

代入线性化方程：
$$(-i\omega + \bar{u}ik)[-(k^2+l^2)]\psi' + \beta ik\psi' = 0$$

$$i(k^2+l^2)(\omega - k\bar{u}) + i\beta k = 0$$

$$\boxed{\omega = k\bar{u} - \frac{\beta k}{k^2+l^2}}$$

(2) **相速度**：
$$c_p = \frac{\omega}{k} = \bar{u} - \frac{\beta}{k^2+l^2} = \bar{u} - \beta\left(\frac{L}{2\pi}\right)^2$$

**群速度**：
$$c_{gx} = \frac{\partial\omega}{\partial k} = \bar{u} - \beta\frac{l^2-k^2}{(k^2+l^2)^2}$$
$$c_{gy} = \frac{\partial\omega}{\partial l} = \frac{2\beta kl}{(k^2+l^2)^2}$$

(3) 从频散关系看，$\omega(k)$不是线性函数，故$c_g \neq c_p$，罗斯贝波是**频散波**。

能量频散方向：$\bar{u}=0$时，$c_{gx} = \beta(k^2-l^2)/(k^2+l^2)^2$。当$k>l$（纬向波数大于经向波数），$c_{gx}>0$（能量向东）；当$k<l$，$c_{gx}<0$。说明长波能量可以向东西两个方向频散，但实际大气中$\bar{u}>0$，$c_{gx}$通常为正。

(4) 令$c_p=0$得静止波长：$L_s = 2\pi\sqrt{\bar{u}/\beta}$

当$L<L_s$时$c_p>0$（波向东移动）；$L>L_s$时$c_p<0$（向西移动，即后退波）；$L=L_s$时波静止。中纬度$\bar{u}\approx15$m/s，$\beta\approx1.6\times10^{-11}$，$L_s\approx6000$km——超长波常为后退波。
