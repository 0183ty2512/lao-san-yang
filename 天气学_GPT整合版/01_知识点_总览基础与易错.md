#### 核心公式速查

| 公式 | 名称 | 含义 |
|------|------|------|
| $\vec{V}_g = \frac{1}{f}\vec{k}\times\nabla\Phi$ | 地转风 | 气压梯度力与科氏力平衡 |
| $\frac{V_f^2}{R_T} + fV_f + \frac{1}{\rho}\frac{\partial p}{\partial n} = 0$ | 梯度风 | 三力平衡 |
| $\frac{\partial \vec{V}_g}{\partial p} = \frac{R}{fp}(\vec{k}\times\nabla_p T)$ | 热成风 | 地转风随高度变化 |
| $c = \overline{u} - \beta(\frac{L}{2\pi})^2$ | 罗斯贝波速 | 长波移动 |
| $F = \frac{d}{dt}(\frac{\partial T}{\partial n})$ | 锋生函数 | 锋的加强/减弱 |
| $\frac{d\theta}{dt} = \frac{\theta}{c_p T}\dot{Q}$ | 位温方程 | 干绝热守恒 |

##### 第一章 大气运动基本特征（★★★★★ 最高频）

| 考点 | 出现频次 | 最近出现 |
|------|----------|----------|
| 气压梯度力 | 5次 | 2026 |

| 正压大气与斜压大气 | 6次 | 2026 |

**知识关联链**：
```
基本力（气压梯度力+科氏力+重力+摩擦力）
  → 地转风（二力平衡）
    → 热成风（地转风随高度的变化，由温度梯度决定）
      → 地转偏差（实际风偏离地转风的原因）
        → 变压风（地转偏差中的变压风分量）
```

**核心理解**：
- 地转风与等高线平行，北半球背风而立高压在右
- 热成风与等温线平行，南暖北冷→西风热成风
- 南暖北冷的大背景导致中纬度高层西风急流

**知识关联链**：
```
气团分类 → 锋面结构（密度不连续） → 马古列斯坡度公式
  → 锋面要素场（温度/气压/风/变压）
    → 锋面天气（第一型/第二型冷锋天气差异）
      → 锋生锋消（动力学机制）
```

**核心理解**：
- 马古列斯公式：$\tan\alpha = \frac{f}{g}\frac{\rho_2V_2 - \rho_1V_1}{\rho_2 - \rho_1}$
- 锋面坡度与密度差成反比、与风速差和纬度成正比
- 第一型冷锋→层状云降水；第二型冷锋→积状云强对流

| 副热带高压 | 8次 | 2024 |

**知识关联链**：
```
气旋/反气旋分类（热力结构分类）
  → 涡度方程（涡度变化的六大因子）
    → 位势倾向方程（高度场变化诊断）
      → ω方程（垂直运动诊断）
        → 斜压系统发展（涡度因子+热力因子）
          → 温带气旋四阶段（波动→发展→锢囚→消亡）
            → 锋面气旋/爆发性气旋

**核心理解**：
- **涡度方程**中六大因子：涡度平流、散度项、β项、力管项、倾斜项、摩擦项
- **阻塞高压**是寒潮预报最关键的天气系统
- 气旋发展的两大因子：涡度因子（动力，涡度平流随高度增加）和热力因子（暖平流上升）

**知识关联链**：
```

  → 三圈环流（Hadley+Ferrel+极地）

#### 四、高频推导题型总结

##### 1. 罗斯贝波频散关系推导（最常考）
**步骤**：
1. 线性化正压无辐散涡度方程
2. 引入扰动流函数 $\psi = \psi_0 e^{i(kx+ly-\omega t)}$
3. 代入得频散关系：$\omega = k\bar{u} - \frac{\beta k}{k^2+l^2}$
4. 波速：$c = \frac{\omega}{k} = \bar{u} - \frac{\beta}{k^2+l^2} = \bar{u} - \beta(\frac{L}{2\pi})^2$
5. 群速：$c_g = \frac{\partial\omega}{\partial k} = \bar{u} + \beta\frac{k^2-l^2}{(k^2+l^2)^2}$

##### 2. 重力惯性外波推导
**步骤**：
1. 浅水方程组
2. 线性化（$u = \bar{u}+u'$，$h = H_0+h'$）
3. 设扰动与y无关，设波动解 $e^{i(kx-\omega t)}$
4. 得频率方程：$(\omega - k\bar{u})^2 = f_0^2 + gH_0k^2$
5. 相速：$c = \bar{u} \pm \sqrt{f_0^2/k^2 + gH_0}$
6. 群速：$c_g = \bar{u} \pm \frac{gH_0k}{\sqrt{f_0^2 + gH_0k^2}}$

##### 3. 位涡方程推导
**步骤**：
1. 从水平运动方程+连续方程出发
2. 取涡度方程
3. 利用位温守恒
4. 组合得 $\frac{d}{dt}(\frac{\zeta+f}{\rho}\frac{\partial\theta}{\partial p}) = 0$

##### 4. 位温表达式推导（2022年考）
**步骤**：
1. 从热力学能量方程出发：$c_v\frac{dT}{dt} + p\frac{d\alpha}{dt} = \dot{Q}$
2. 利用 $c_p = c_v + R$ 和 $p\alpha = RT$，推出 $c_p\frac{dT}{dt} - \alpha\frac{dp}{dt} = \dot{Q}$
3. 干绝热过程 $\dot{Q}=0$，得 $c_p\,dT = \alpha\,dp$
4. 代入状态方程 $\alpha = RT/p$，得 $c_p\frac{dT}{T} = R\frac{dp}{p}$
5. 积分得 $Tp^{-R/c_p} = const$
6. 引入 $p_0 = 1000$hPa，得 $\theta = T(\frac{p_0}{p})^{R/c_p}$

##### 5. 压高公式推导（2024年考）
**步骤**：
1. 从静力平衡方程出发：$\frac{\partial p}{\partial z} = -\rho g$
2. 代入状态方程 $p = \rho RT$ → $\rho = p/(RT)$
3. 得 $\frac{dp}{p} = -\frac{g}{RT}dz$
4. 积分：$\int_{p_1}^{p_2}\frac{dp}{p} = -\frac{g}{R}\int_{z_1}^{z_2}\frac{dz}{T}$
5. 引入气层平均温度 $\bar{T}$，得压高公式：$z_2 - z_1 = \frac{R\bar{T}}{g}\ln\frac{p_1}{p_2}$
6. 物理意义：两层等压面之间的厚度与气层平均温度成正比（暖层厚、冷层薄）

### 2 对于对称槽脊而言,相对涡度平流使得槽线上变高()零,脊线变高()零,槽脊()   D
A.大于,小于,移动  
B.等于,等于,发展  
C.小于,大于,移动  
D.等于,等于,移动

这道题的正确答案是 **D**。

**解析如下：**

对于对称槽脊（即等温线与等高线重合，无温度平流），其发展完全由相对涡度平流决定。根据准地转位势倾向方程：
$$
\nabla^2 \frac{\partial \Phi}{\partial t} \propto -\vec{V}_g \cdot \nabla (\zeta_g + f)$$

- **在槽线上**：槽线是涡度极大值点，其涡度梯度为零（\(\nabla \zeta_g = 0\)）。因此，槽线上没有相对涡度平流，局地变高为零。
- **在脊线上**：脊线是涡度极小值点，其涡度梯度也为零（\(\nabla \zeta_g = 0\)）。因此，脊线上也没有相对涡度平流，局地变高为零。
- **系统的变化**：虽然槽线脊线本身强度不变（变高为零），但在槽前有正涡度平流（导致降压），槽后有负涡度平流（导致升压），这会使槽脊系统**向前移动**，而不是发展加深。

**结论**：变高均为零，系统移动但不发展。故选D。


### 3 梯度风沿着等压线流动   ✓
这句话在经典**梯度风理论**的意义上是正确的，原因是：**梯度风是在理想化、定常的圆形气压场中，达到三力平衡时的一种风，此时流线与等压线完全重合，所以风沿着等压线流动。**

具体解释如下：

1. **理论假设**  
   梯度风模型假设气压场是**轴对称**的（如圆形的高压或低压），等压线是一系列同心圆。在这种理想条件下，沿等压线方向没有气压变化（即没有切向气压梯度力），风速大小恒定，空气微团作匀速圆周运动。

2. **力的平衡**  
   在自然坐标系下，垂直于气流方向（法向）满足三力平衡：
   \[
   0 = -\frac{1}{\rho}\frac{\partial p}{\partial n} - fV - \frac{V^2}{R_T}
   \]
   其中 \(R_T\) 是曲率半径。这个平衡只在法向上存在，沿气流方向（切向）没有任何净力，因此不会出现穿越等压线的运动。

3. **流线与等压线的关系**  
   因为切向没有加速度，风不会穿进或穿出等压线，而是严格按照圆形等压线的切线方向运动。因此，**在梯度风模型中，风矢始终平行于等压线，即“沿着等压线流动”。**

4. **与真实大气的区别**  
   之前讨论中提到的“梯度风有微小偏角、不严格沿等压线”，是针对**实际大气**。在实际天气图上，等压线并非完美圆形，还常有切向气压梯度、摩擦和非定常效应，导致实际风会略微穿越等压线。但作为理论近似，梯度风的定义本身就是沿等压线的。

**总结**  
“梯度风沿着等压线流动”是对梯度风**理想化平衡状态**的正确描述，它是地转风在弯曲流场中的推广，只是前提是气压场轴对称且定常。在实际应用中，通常认为梯度风近似沿等压线，只有在讨论非地转偏差时才会强调其穿越等压线的分量。


3 温度南高北低时,产生的是西风的热成风  错

##### 问题：温度南边高、北边低，产生的是什么热成风？

**正确答案是：在南边高、北边低的温度场中，热成风的方向是西风。但热成风不是实际的风，它是地转风随高度的变化量。**

###### 严谨解释：

1.  **核心公式**：热成风 \($$\vec{V}_T = \frac{R}{f} \ln\frac{p_0}{p} \left( \vec{k} \times \nabla T \right)$$)。

2.  **方向推导**：
    -   南暖北冷，所以水平温度梯度 \(\nabla T\) 由南指向北。
    -   根据叉乘规则，\(\vec{k} \times \nabla T\)（指向北）的结果是指向东。
    -   因此，热成风 \(\vec{V}_T\) 指向东，即**西风热成风**。

3.  **物理意义（关键修正）**：
    -   这个“西风热成风”的含义是：**从低层到高层，地转风的变化量是一个向西风方向的分量**。
    -   如果低层是静风，高层就会是西风。如果低层已经是西风，那么高层的西风会更强。
    -   它完美地解释了为什么中纬度地区（南暖北冷的大背景）的对流层高层会存在强大的**西风急流**。

**暖式锢囚锋 = 冷锋后冷空气"不够冷"，爬到了暖锋前更冷的空气之上。** 所以暖锋前的冷空气比冷锋后的冷空气**更冷**。

### 2 北半球高空西风急流轴的南侧,有()涡度

B. 负  
C. 零  
D. 不确定

##### 详细解释
用自然坐标系中的涡度公式来分析：

$$
\zeta = \frac{V}{R_s} - \frac{\partial V}{\partial n}$$

-   **切变涡度项 (\(-\frac{\partial V}{\partial n}\))**：
    急流轴是风速最大的地方。从轴向南，风速减小。取 \(n\) 方向指向北（即背风而立，左侧为北）。风速向南减小，意味着向北（正 \(n\) 方向）风速递增，即 \(\frac{\partial V}{\partial n} > 0\)。因此，**切变涡度 \(-\frac{\partial V}{\partial n} < 0\)（负涡度）**，贡献反气旋式旋转。

-   **曲率涡度项 (\(\frac{V}{R_s}\))**：
    虽然急流轴南侧通常对应高压脊或反气旋式弯曲的流场，即使气流平直（\(R_s \to \infty\)），此项为零。

综合来看，切变涡度项的负贡献往往占主导，因此急流轴南侧主要表现为**反气旋式涡度**。

##### 为什么是D？正确的物理逻辑应该是这样的

地转适应过程的关键在于**“谁主动改变，去适应谁”**。涡度因子（动力因子）指的就是**初始的流场（涡度场）扰动**。

###### 1. 高层的适应：气压场适应流场

- **初始扰动**：高层首先出现了一个**流场的涡度扰动**。比如，槽前有正涡度平流输入，导致高层产生了**气旋式流场**（流场先变）。
- **适应过程**：这个气旋式流场必然伴随着**辐散**。由于高层空气质量本就稀薄，辐散会迅速抽走空气，导致该处质量亏损。
- **最终结果**：质量亏损使得**气压场被动地发生改变**，即等压面高度降低，形成一个高空低压槽。所以，高层的**气压场变化**是为了平衡和适应初始的**流场变化**。

###### 2. 低层的适应：流场适应气压场

- **初始扰动**：低层初始往往是一个**气压场的质量扰动**。例如，近地面因为强烈加热或地形作用，首先形成了一个**热低压**，即地面**气压场先发生了改变**。
- **适应过程**：地面出现低压中心后，周围气压相对较高，于是产生了指向低压中心的**气压梯度力**，驱动空气向中心辐合。
- **最终结果**：辐合的气流在地转偏向力作用下，逐渐调整成一个**气旋式环流（流场）**。所以，低层的**流场（风场）**是被动地调整，以适应已经变化了的**气压场**。

---

##### 总结对比

| 层次 | 主动改变方 | 被动适应方 | 完整表述 |
| :--- | :--- | :--- | :--- |
| **高层** | **流场**（涡度扰动） | **气压场**（质量场） | 高层**气压场**改变以适应**流场**改变 |
| **低层** | **气压场**（质量扰动） | **流场**（风场） | 低层**流场**改变来适应**气压场**改变 |

这个“上适应下”的差异，是地转适应动力学里非常核心的结论。高层由于惯性大、质量少，流场变，质量场来补；低层摩擦强、质量多，质量场变，流场来调。

### 影响大气运动的力

> 大气运动的基本方程组建立在牛顿第二定律基础上，理解作用于气块的各种力是学习天气学原理的起点。

#### 1. 气压梯度力（Pressure Gradient Force, PGF）

- **定义**：作用于单位质量气块上的净压力，由气压分布不均匀产生。
- **表达式**：

$$
\vec{G} = -\frac{\nabla p}{\rho}
$$

- **推导思路**（以 $x$ 方向为例）：
  - 气块在 $x$ 方向受到的压力差为：
    $$
    p\delta s - (p + \delta p)\delta s = -\delta p \delta s = -\frac{\partial p}{\partial x} \delta x \delta y \delta z
    $$
  - 同理得 $y$、$z$ 方向净力，总净力为 $-\nabla p \cdot \delta\tau$，单位质量力为 $-\frac{\nabla p}{\rho}$。

- **性质**：
  1. 大小与气压梯度成正比，与空气密度成反比
  2. 方向垂直于等压线，由高压指向低压（即 $-\nabla p$ 方向）
  3. 水平分量远小于垂直分量（因垂直气压变化远大于水平变化）

---

#### 2. 地转偏向力（Coriolis Force）

- **定义**：气块相对地球运动时，使运动方向发生改变的惯性力。
- **表达式**（单位质量）：

$$
\vec{A} = -2\vec{\Omega} \times \vec{V}
$$

- **分量形式**（设 $u>0, v>0, w>0$）：
  - 水平方向：
    $$
    \frac{du}{dt} = fv - \hat{f}w,\quad \frac{dv}{dt} = -fu
    $$
  - 垂直方向：
    $$
    \frac{dw}{dt} = \hat{f}u
    $$
  其中 $f = 2\Omega \sin \phi$（地转参数），$\hat{f} = 2\Omega \cos \phi$。

- **性质**：
  1. 与 $\vec{\Omega}$ 垂直，位于纬圈平面内
  2. 与风速 $\vec{V}$ 垂直，不做功，只改变方向
  3. 垂直分量通常较小，主要考虑水平分量
  4. 相对速度为零时，地转偏向力为零

---

#### 3. 重力（Gravity）

- **定义**：地心引力与惯性离心力的合力。
- **特点**：
  - 不指向地心（因地球自转离心力）
  - 地球为椭球体，重力垂直于地球椭球面
  - 赤道最小，极地最大；随高度增加而减小
  - 在水平面上运动时，重力不做功

---

#### 4. 大气的动量守恒方程组

- **矢量形式**：

$$
\frac{d\vec{V}}{dt} = \vec{G} + \vec{F} + \vec{g} - 2\vec{\Omega} \times \vec{V} + \vec{\Omega}^2 \vec{R}
$$

其中：
- $\vec{G}$：气压梯度力
- $\vec{F}$：摩擦力
- $\vec{g}$：重力
- $-2\vec{\Omega} \times \vec{V}$：地转偏向力
- $\vec{\Omega}^2 \vec{R}$：惯性离心力（通常归入重力）

---

#### 思考题与解答

##### 思考题1：气压梯度力为什么垂直于等压线并由高压指向低压？请从公式和物理含义两方面解释。

> **解答**：从公式看，气压梯度力 $\vec{G} = -\frac{\nabla p}{\rho}$，其中 $\nabla p$ 方向垂直于等压线并指向气压升高的方向（即由低压指向高压），前面的负号使方向反转，因此 $\vec{G}$ 垂直于等压线并由高压指向低压。从物理含义看，气块两侧受到的压力大小不等，高压侧压力大于低压侧，净力自然是从高压推向低压。这类似于斜坡上的球，坡度越大（气压梯度越大），滚得越快——气压梯度力的方向永远指向"气压坡"的下坡方向。

##### 思考题2：地转偏向力做功吗？为什么它对大气运动的能量转换没有直接贡献？

> **解答**：地转偏向力不做功，因为 $\vec{A} = -2\vec{\Omega} \times \vec{V}$ 始终与速度 $\vec{V}$ 垂直（叉乘特性）。功的定义为 $W = \vec{F} \cdot \vec{V}$，当力与速度垂直时，点积为零，因此地转偏向力只改变运动方向而不改变速率（动能不变）。这使得大气中的能量转换主要通过气压梯度力（做正功驱动运动）、重力（垂直运动做功）和摩擦力（消耗动能）来实现，地转偏向力在其中起的只是"转向器"的角色——它把气压梯度力驱动的运动偏转成准地转平衡，但不参与能量收支。

### 连续方程（质量守恒定律）

> 连续方程是**质量守恒定律**在流体力学中的表达形式。对于大气，它描述了空气密度和风场之间的相互制约关系。

#### 1. 物理本质

在固定空间中，净流入质量 = 内部质量增加量。这是大气运动最基本的约束条件之一。

#### 2. 推导思路（欧拉观点）

在固定空间中取一个微元六面体 $\delta x \delta y \delta z$，分析净流入质量和内部质量变化。

- **$x$ 方向净流入量**：
  $$
  \rho u \delta y \delta z \delta t - \left( \rho u + \frac{\partial \rho u}{\partial x} \delta x \right) \delta y \delta z \delta t = -\frac{\partial \rho u}{\partial x} \delta x \delta y \delta z \delta t
  $$

- **三个方向总净流入量**：
  $$
  -\left( \frac{\partial \rho u}{\partial x} + \frac{\partial \rho v}{\partial y} + \frac{\partial \rho w}{\partial z} \right) \delta x \delta y \delta z \delta t
  $$

- **六面体内质量变化**：
  $$
  \frac{\partial \rho}{\partial t} \delta x \delta y \delta z \delta t
  $$

由质量守恒（净流入量 = 质量增加量）得：

$$
\frac{\partial \rho}{\partial t} = -\left( \frac{\partial \rho u}{\partial x} + \frac{\partial \rho v}{\partial y} + \frac{\partial \rho w}{\partial z} \right)
$$

#### 3. 欧拉型连续方程

$$
\frac{\partial \rho}{\partial t} + \nabla \cdot (\rho \vec{V}) = 0
$$

其中 $\nabla \cdot (\rho \vec{V})$ 称为**质量散度**，表示单位体积内质量的净流出率。

#### 4. 拉格朗日型连续方程

将欧拉型展开：

$$
\frac{\partial \rho}{\partial t} + u \frac{\partial \rho}{\partial x} + v \frac{\partial \rho}{\partial y} + w \frac{\partial \rho}{\partial z} + \rho \left( \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial w}{\partial z} \right) = 0
$$

即：

$$
\frac{d\rho}{dt} + \rho \nabla \cdot \vec{V} = 0
$$

#### 5. 速度散度的物理意义

由比容 $\alpha = 1/\rho$，得：

$$
\nabla \cdot \vec{V} = \frac{1}{\alpha} \frac{d\alpha}{dt}
$$

- **速度散度**表示流体微团单位时间的**体积相对膨胀率**
- 若 $\nabla \cdot \vec{V} > 0$，体积膨胀（**辐散**）；$< 0$ 则收缩（**辐合**）

#### 6. 不可压缩流体

若流体不可压（密度为常数），则 $\frac{d\rho}{dt} = 0$，代入得：

$$
\nabla \cdot \vec{V} = \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial w}{\partial z} = 0
$$

- **水平散度** $\nabla_h \cdot \vec{V}_h = \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}$ 与垂直运动相联系：
  $$
  \frac{\partial w}{\partial z} = -\nabla_h \cdot \vec{V}_h
  $$
  因此可通过水平风场推断垂直运动（因垂直速度难以直接观测）。

#### 7. p 坐标系中的连续方程

在等压面分析中常用 p 坐标系：

$$
\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial \omega}{\partial p} = 0
$$

其中 $\omega = dp/dt$ 为 p 坐标垂直速度。这是[[天气诊断分析的主要方法|散度与垂直速度诊断]]的基础。

#### 8. 注意区分两种"密度不变"

| 条件 | 含义 | 物理意义 |
|------|------|----------|
| $\frac{\partial \rho}{\partial t} = 0$ | 定常流 | 固定空间点密度不随时间变，但流体质点密度可变化 |
| $\frac{d\rho}{dt} = 0$ | 不可压缩流 | 流体质点密度在运动中保持不变 |

#### 思考题与解答

##### 思考题1：速度散度 $\nabla \cdot \vec{V}$ 的物理意义是什么？为什么辐散和辐合对天气系统的发生发展至关重要？

> **解答**：由 $\nabla \cdot \vec{V} = \frac{1}{\alpha}\frac{d\alpha}{dt}$ 可知，速度散度表示流体微团单位时间的**体积相对膨胀率**。$\nabla \cdot \vec{V} > 0$（辐散）意味着体积膨胀，密度减小；$\nabla \cdot \vec{V} < 0$（辐合）意味着体积收缩，密度增大。辐散和辐合对天气系统至关重要，因为：（1）根据连续方程，水平辐合必然伴随上升运动（质量守恒要求），上升冷却导致水汽凝结，产生云雨天气；（2）水平辐散则对应下沉增温，天气转晴。大气中的垂直运动通常量级很小（cm/s量级），难以直接测量，但通过诊断水平散度就可以推断垂直运动，这是天气分析的常用手段。

##### 思考题2：在不可压缩流体假设下，如何利用水平风场诊断垂直运动？这个方法的局限性是什么？

> **解答**：对于不可压缩流体（$\nabla \cdot \vec{V} = 0$），有 $\frac{\partial w}{\partial z} = -\left(\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}\right)$，即水平散度与垂直运动的垂直变化相平衡。若低层为辐合（水平散度<0），则 $\frac{\partial w}{\partial z} > 0$，意味着垂直速度随高度增大，在中层达到最大上升运动。在实际业务中，常计算各层的水平散度，然后从地面（$w \approx 0$）向上积分得到垂直速度廓线。局限性包括：（1）实际大气是可压缩的，尤其是在深层对流中密度变化不可忽略；（2）p坐标连续方程 $\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial \omega}{\partial p} = 0$ 在形式上等同于不可压缩形式，但变量为 $\omega$ 而非 $w$，需注意转换；（3）风场观测误差在散度计算中会被放大，尤其是小尺度系统。

### 地转风 (Geostrophic Wind)

> 在中高纬自由大气中，水平气压梯度力与科里奥利力平衡时形成的水平匀速直线运动。地转风是天气学中最基本的平衡风场概念。

#### 1. 平衡方程

$$
-\frac{1}{\rho} \frac{\partial p}{\partial n} - f V_g = 0
$$

其中：
- $n$ 指向低压侧（气压梯度方向）
- $f = 2\Omega \sin \phi$ 为地转参数
- $V_g$ 为地转风速（正值）

#### 2. 地转风公式

##### 2.1 等压面形式

$$
\vec{V}_g = \frac{1}{f}\vec{k}\times\nabla\Phi
$$

大小：

$$
V_g = \frac{1}{f}\left|\nabla\Phi\right| = \frac{1}{2\Omega\sin\phi}\left(\frac{\partial\Phi}{\partial n}\right)_p
$$

##### 2.2 p 坐标形式

用地转位势 $\Phi = gz$ 表示：

$$
u_g = -\frac{1}{f} \frac{\partial \Phi}{\partial y},\quad v_g = \frac{1}{f} \frac{\partial \Phi}{\partial x}
$$

或用地势高度 $H$（位势十米）表示：

$$
V_g = -\frac{9.8}{f} \frac{\partial H}{\partial n}
$$

##### 2.3 用气压梯度表示

$$
V_g = -\frac{1}{f\rho}\frac{\partial p}{\partial n} = -\frac{1}{2\Omega\sin\phi\cdot\rho}\frac{\partial p}{\partial n}
$$

- $f = 2\Omega\sin\phi$：科里奥利参数
- $\Phi = gz$：位势高度
- 方向：垂直于气压梯度力，北半球向右偏（背风而立，高压在右，低压在左）

---

#### 3. 地转风的特点

1. **适用范围**：中高纬自由大气，大尺度运动（水平尺度 $> 1000$ km）
2. **赤道附近不适用**：$\phi \to 0$ 时 $f \to 0$，地转偏向力太小，无法平衡气压梯度力。一般 $|\phi| > 5^\circ$ 才可近似使用
3. **风速大小**：
   - 与水平气压梯度成正比（等压线越密，风越大）
   - 与纬度成反比（相同气压梯度下，低纬度地转风更大）
4. **白贝罗定律（Buys Ballot's Law）**：
   - **北半球**：背风而立，**高压在右，低压在左**
   - **南半球**：背风而立，**高压在左，低压在右**

---

#### 4. 地转风的散度

在 **p 坐标系**中，地转风的水平散度为零：

$$
\nabla_p \cdot \vec{V}_g = 0
$$

证明（用地势高度 $z$ 为例）：

$$
\nabla_p \cdot \vec{V}_g = -\frac{g}{f} \frac{\partial^2 z}{\partial x \partial y} + \frac{g}{f} \frac{\partial^2 z}{\partial x \partial y} = 0
$$

- 这意味着：**纯地转风不会引起水平辐合辐散**，垂直运动必须由[[地转偏差]]（非地转分量）或地形等强迫产生。

---

#### 5. 地转风随纬度的变化

##### 5.1 基本关系

**核心推论**：在相同气压梯度（或位势梯度）下，地转风大小与 $\sin\phi$ 成反比。

- 纬度越低，$f$ 越小，地转风越强
- 纬度越高，$f$ 越大，地转风越弱
- 赤道 $\phi=0$，$f=0$，地转平衡不成立

##### 5.2 理想情形

若全球气压梯度均匀，地转风从低纬向高纬迅速减小。例如：
- 20°N：$\sin20°\approx0.342$
- 60°N：$\sin60°\approx0.866$

相同梯度下，60°N 的地转风仅为 20°N 的约 39%。

##### 5.3 实际大气：中纬度风速最大

实际风速分布：赤道弱 → 中纬度强（急流）→ 极地弱

**原因**：
- 最大水平温度梯度出现在中纬度锋区（极锋）
- 热成风关系：
  $$
  \frac{\partial V_g}{\partial p} = \frac{R}{fp}\frac{\partial T}{\partial n}
  $$
- 虽然中纬度 $f$ 较大（抑制地转风），但该区域温度梯度极强，综合结果形成中纬度西风急流。

---

#### 6. 地转风随纬度变化的动力后果：Rossby 波

地转风随纬度的非均匀性来自 $f$ 的变化：

$$
\beta = \frac{df}{dy} = \frac{2\Omega\cos\phi}{R_\oplus}
$$

绝对涡度守恒要求气块南北移动时相对涡度发生补偿变化，形成 Rossby 波。其波速公式为：

$$
c = \overline{u} - \frac{\beta}{k^2}
$$

这是西风带槽脊移动和天气系统发展的理论基础。详见 [[西风带长波（长波分类、移动公式、长波调整)|西风带长波]]。

---

#### 7. 地转风的局限性

- 不适用于赤道附近、低纬度、小尺度系统（如锋面、飑线、龙卷）
- 不适用于有强加速的区域（如急流入口/出口区、强烈发展的气旋）
- 实际风与地转风之差称为[[地转偏差]]，它才是造成天气系统发展和垂直运动的关键

---

#### 思考题与解答

##### 思考题1：为什么地转风公式在赤道附近失效？试从力的平衡角度说明。

> **解答**：地转风是气压梯度力与科里奥利力（地转偏向力）平衡的结果。地转风公式 $V_g = -\frac{1}{f\rho}\frac{\partial p}{\partial n}$ 中，分母含有地转参数 $f = 2\Omega\sin\phi$。在赤道附近（$\phi \to 0$），$f \to 0$，科里奥利力趋于零，此时即使气压梯度力很小，也无法被科里奥利力平衡，公式给出的地转风将趋于无穷大——这在物理上是荒谬的。实际上，在赤道附近，气压梯度力主要由加速度项 $\frac{d\vec{V}}{dt}$ 来平衡，而不是科里奥利力。因此赤道地区的大气运动需要用完全的运动方程来描述，地转近似不再成立。通常认为 $|\phi| > 5^\circ \sim 10^\circ$ 才可近似使用地转风公式。

##### 思考题2：地转风随纬度的变化如何导致Rossby波的形成？请从绝对涡度守恒的角度解释。

> **解答**：地转参数 $f$ 随纬度变化，用 $\beta = \frac{df}{dy} = \frac{2\Omega\cos\phi}{R_\oplus}$ 度量（行星涡度梯度）。在正压无辐散大气中，绝对涡度 $\zeta_a = \zeta + f$ 守恒。当气块向北移动时，进入 $f$ 更大的区域，为保持绝对涡度守恒，相对涡度 $\zeta$ 必须减小（获得反气旋式曲率），气块的路径将向反气旋方向弯曲，最终折返向南。向南移动时间理，$\zeta$ 增大，路径弯回向北。这种 $f$ 的经向变化使气块在南北方向来回振荡，叠加在基本西风气流上，形成大尺度的波动——这就是Rossby波的形成机制。其波速公式 $c = \overline{u} - \beta/k^2$ 表明波长越长（$k$ 越小），波向西退行越快，长波甚至可以静止或退行。

### 梯度风 (Gradient Wind)

> 当大气运动**不考虑摩擦力**，且**流线与等压线重合**时，水平方向的三力平衡：**气压梯度力 + 地转偏向力 + 惯性离心力 = 0**，此时的风称为**梯度风**。

- 梯度风比地转风更接近实际大气，尤其在有显著曲率的流场中（如气旋、反气旋）
- 梯度风风速记为 $V_f$

#### 1. 自然坐标系下的三力投影

| 力 | 切向（$s$ 方向） | 法向（$n$ 方向） |
|----|----------------|----------------|
| 气压梯度力 | $-\frac{1}{\rho} \frac{\partial p}{\partial s}$ | $-\frac{1}{\rho} \frac{\partial p}{\partial n}$ |
| 地转偏向力 | 0 | $-fV$ |
| 惯性离心力 | 0 | $+\frac{V^2}{R_T}$ |

- 假设等压线与流线重合，则 $\frac{\partial p}{\partial s} = 0$，切向加速度为零（$\frac{dV}{dt} = 0$）
- 法向平衡方程为：

$$
\frac{V^2}{R_T} - fV - \frac{1}{\rho} \frac{\partial p}{\partial n} = 0
$$

#### 2. 梯度风平衡方程

整理得：

$$
\frac{V_f^2}{R_T} + fV_f - \frac{1}{\rho} \frac{\partial p}{\partial n} = 0
$$

其中：
- $R_T$：流线曲率半径（气旋式 $R_T > 0$，反气旋式 $R_T < 0$）
- $n$ 指向低压（故 $\frac{\partial p}{\partial n} < 0$）

#### 3. 梯度风公式的求解

将上述方程视为关于 $V_f$ 的一元二次方程：

$$
\frac{1}{R_T} V_f^2 + f V_f - \frac{1}{\rho} \frac{\partial p}{\partial n} = 0
$$

解得：

$$
V_f = -\frac{R_T f}{2} \pm \frac{R_T}{2} \sqrt{ f^2 - \frac{4}{R_T \rho} \frac{\partial p}{\partial n} }
$$

符号选择需满足 $V_f > 0$ 和物理合理性。

##### 3.1 气旋式环流（$R_T > 0$）

- 若取"-"号，则 $V_f < 0$，不成立
- 故只能取"+"号：

$$
V_f = -\frac{R_T f}{2} + \frac{R_T}{2} \sqrt{ f^2 - \frac{4}{R_T \rho} \frac{\partial p}{\partial n} }
$$

- 当气压梯度 $\left|\frac{\partial p}{\partial n}\right|$ 增大时，$V_f$ 增大，**无上限**
- 越向气旋中心，等压线越密，风越大

##### 3.2 反气旋式环流（$R_T < 0$）

- 要求根号内非负：
  $$
  f^2 - \frac{4}{R_T \rho} \frac{\partial p}{\partial n} > 0
  $$
  因 $R_T < 0$ 且 $\frac{\partial p}{\partial n} < 0$，乘积为正，故需：
  $$
  \left|\frac{\partial p}{\partial n}\right| \leq \frac{\rho f^2 |R_T|}{4}
  $$
- 最大梯度风速为：
  $$
  (V_f)_{\max} = -\frac{R_T}{2} f \quad (>0)
  $$
- **反气旋中气压梯度和风速有上限**：高压中心等压线稀疏，边缘等压线可较密

---

#### 4. 梯度风与地转风的比较

- 地转风公式：$V_g = -\frac{1}{f\rho} \frac{\partial p}{\partial n}$
- 梯度风与地转风的关系：

  - **气旋中**（$R_T > 0$）：$V_g > V_f$，地转风大于梯度风
  - **反气旋中**（$R_T < 0$）：$V_g < V_f$，梯度风大于地转风
  - 最大梯度风与地转风的关系：$(V_f)_{\max} = 2 V_g$

---

#### 5. 梯度风高度

- 近地面受摩擦影响，风随高度增大，到某一高度后不再受地表摩擦影响，达到梯度风风速
- 这个高度称为**梯度风高度**，通常为 **300 ~ 500 m** 以上
- 地面越粗糙，梯度风高度越高；越平坦，高度越低

---

#### 6. 小结

| 环流类型 | 曲率半径符号 | 梯度风与地转风比较 | 气压梯度有无上限 |
|----------|-------------|-------------------|------------------|
| 气旋 | $R_T > 0$ | $V_f < V_g$（小于地转风） | 无上限 |
| 反气旋 | $R_T < 0$ | $V_f > V_g$（大于地转风） | 有上限 |

#### 思考题与解答

##### 思考题1：为什么反气旋式环流中气压梯度有上限，而气旋式环流中没有？试从梯度风公式的数学解出发解释。

> **解答**：梯度风平衡方程为 $\frac{V_f^2}{R_T} + fV_f - \frac{1}{\rho}\frac{\partial p}{\partial n} = 0$，这是关于 $V_f$ 的一元二次方程 $aV_f^2 + bV_f + c = 0$（其中 $a=1/R_T$，$b=f$，$c=-\frac{1}{\rho}\frac{\partial p}{\partial n} > 0$）。
>
> 对于反气旋式环流（$R_T < 0$），$a < 0$，判别式 $\Delta = f^2 - \frac{4}{R_T\rho}\frac{\partial p}{\partial n}$。由于 $R_T < 0$ 且 $\frac{\partial p}{\partial n} < 0$，乘积 $\frac{4}{R_T\rho}\frac{\partial p}{\partial n} > 0$，因此需要 $f^2 \geq \frac{4}{|R_T|\rho}\left|\frac{\partial p}{\partial n}\right|$ 才能保证有实数解。这意味着 $\left|\frac{\partial p}{\partial n}\right| \leq \frac{\rho f^2 |R_T|}{4}$——气压梯度有上限。
>
> 物理上，反气旋中惯性离心力指向外（离开中心），与气压梯度力同方向，两者共同被科里奥利力平衡。如果气压梯度太大，合力超过科里奥利力所能提供的最大平衡值，无法维持梯度风平衡。
>
> 对于气旋式环流（$R_T > 0$），$a > 0$，判别式恒正（因为 $\frac{4}{R_T\rho}\frac{\partial p}{\partial n} < 0$），方程总有正实数解，气压梯度无理论上限——气压梯度多大都可以通过增大的梯度风速来平衡。

##### 思考题2：在气旋和反气旋中，梯度风与地转风的大小关系为何不同？这种差异对实际天气分析有什么启示？

> **解答**：从梯度风方程改写为 $V_f = V_g - \frac{V_f^2}{fR_T}$ 可以看出，$V_f$ 与 $V_g$ 的关系取决于曲率半径 $R_T$ 的符号。在**气旋**（$R_T > 0$）中，$V_f = V_g - \frac{V_f^2}{fR_T} < V_g$，即梯度风小于地转风——惯性离心力指向外，部分抵消了科里奥利力，只需较小的风速就能维持平衡。在**反气旋**（$R_T < 0$）中，$V_f = V_g + \frac{V_f^2}{f|R_T|} > V_g$，即梯度风大于地转风——惯性离心力指向内，与气压梯度力叠加，需要更大的科里奥利力（即更大风速）来平衡。
>
> 对天气分析的启示：（1）在气旋中用地转风近似会高估实际风速，在反气旋中用地转风近似会低估实际风速；（2）最大梯度风与地转风的关系为 $(V_f)_{\max} = 2V_g$，这意味着反气旋中心附近的风速可能达到地转风估计的两倍；（3）梯度风高度以上，实际风更接近梯度风而非地转风，因此在曲率显著的系统中（如热带气旋、切断低压），梯度风是更好的参考。

### 热成风 (Thermal Wind)

> 热成风不是真正的"风"，而是**地转风随高度的变化量**，由水平温度梯度唯一决定。它连接了风场和温度场，是理解斜压大气结构和系统发展的核心概念。

#### 1. 定义与公式

等压面上，地转风随气压的变化（即随高度的变化）称为**热成风**。

设两层等压面 $p_0$（下）和 $p_1$（上，$p_1 < p_0$），两层地转风之差就是热成风 $\vec{V}_T$：

$$
\boxed{\vec{V}_T \equiv \vec{V}_g(p_1) - \vec{V}_g(p_0)}
$$

微分形式：

$$
\frac{\partial \vec{V}_g}{\partial p} = \frac{R}{fp} \left( \vec{k} \times \nabla_p T \right)
$$

常用等厚度层形式（取厚度平均温度 $\overline{T}$）：

$$
\boxed{\vec{V}_T = \frac{R}{f} \ln\frac{p_0}{p_1} \left( \vec{k} \times \nabla \overline{T} \right)}
$$

热成风与等压面厚度的关系：

$$
\vec{V}_T = \frac{g}{f} \vec{k} \times \nabla h
$$

其中 $h = \frac{R \overline{T}}{g} \ln \frac{p_1}{p_2}$ 为两等压面之间的厚度。

> **热成风与等厚度线平行**，大小与厚度梯度成正比，与纬度成反比。

---

#### 2. 推导过程

##### 2.1 出发方程：p 坐标地转风
$$
\vec{V}_g = \frac{1}{f} \vec{k} \times \nabla \Phi
$$

##### 2.2 对气压求偏导
$$
\frac{\partial \vec{V}_g}{\partial p} = \frac{1}{f} \vec{k} \times \nabla \left( \frac{\partial \Phi}{\partial p} \right)
$$

##### 2.3 引入静力方程
p 坐标静力方程：
$$
\frac{\partial \Phi}{\partial p} = -\frac{RT}{p}
$$

代入，在等压面上 $\nabla p = 0$：

$$
\boxed{\frac{\partial \vec{V}_g}{\partial p} = \frac{R}{fp} \left( \vec{k} \times \nabla_p T \right)}
$$

##### 2.4 积分得到热成风

从 $p_0$ 到 $p$ 积分：

$$
\vec{V}_g(p) - \vec{V}_g(p_0) = \frac{R}{f} \int_{p}^{p_0} (\vec{k} \times \nabla T) \, d(-\ln p)
$$

定义厚度层平均温度 $\overline{T}$，得最常用形式：

$$
\boxed{\vec{V}_T = \frac{R}{f} \ln\frac{p_0}{p} \left( \vec{k} \times \nabla \overline{T} \right)}
$$

---

#### 3. 方向规则：判断冷暖平流

- **热成风方向平行于等平均温度线**（或等厚度线），在北半球，**背热成风而立，高温在右，低温在左**（与地转风规则一致）
- 实际应用：画单站高空风分析图（风矢随高度变化的连线）：
  - 风矢随高度**顺时针转动**（veering，顺转）→ 有**暖平流**
  - 风矢随高度**逆时针转动**（backing，逆转）→ 有**冷平流**

原理：热成风从下层指向上层，它的方向代表**该层平均温度梯度的方向**。若风随高度顺转，即热成风方向偏于下层风的右侧，表明平均温度场是"高温在右"，站点的风正把暖空气吹来。

| 风随高度变化 | 热成风方向 | 平流类型 |
|-------------|-----------|---------|
| 逆时针旋转（逆转，backing） | 有北风分量 | **冷平流** |
| 顺时针旋转（顺转，veering） | 有南风分量 | **暖平流** |

---

#### 4. 正压大气与斜压大气

| 类型 | 定义 | 特征 |
|------|------|------|
| **正压大气** | 地转风不随高度变化，$\vec{V}_T = 0$ | 温度分布均匀，等压面与等密度面平行 |
| **斜压大气** | 地转风随高度变化，$\vec{V}_T \neq 0$ | 温度分布不均匀，等压面与等密度面相交 |

- 实际大气**总是斜压的**，尤其在锋区、急流区等温线密集区域，热成风显著。

---

#### 5. 应用

##### 5.1 西风急流的成因

极地冷，赤道暖 → 水平温度梯度指向北 → $\vec{k} \times \nabla T$ 指向东（西风热成风）。从地面到高空，西风分量不断累积，形成中纬度高空的西风急流。急流中心位于温度梯度最大处的上方（极锋区上空）。详见 [[行星锋区与急流]]。

##### 5.2 判断大气斜压性及系统发展

- **正压大气**：等温线与等压线平行，地转风不随高度变化
- **斜压大气**：等温线与等压线有交角，存在热成风。水平温度梯度越大，热成风越强，斜压性越强。温带气旋和锋面系统的发展本质上依赖于斜压能量

##### 5.3 诊断高空槽脊的移动与发展

- 暖平流区 → 等压面升高（负变高趋势），产生上升运动
- 冷平流区 → 等压面降低，产生下沉运动

##### 5.4 厚度分析与降水落区

- $500-1000\ \text{hPa}$ 厚度**本质上就是热成风势函数**
- 厚度脊对应暖区，厚度槽对应冷区
- 厚度线密集区 = 锋区位置 = 强热成风区

##### 5.5 热带气旋强度变化诊断

热带气旋暖心结构造成高层反气旋流出。当环境垂直风切变（环境热成风）较小时，暖心得以维持，有利于气旋加强。

##### 5.6 热成风判断大气稳定度

若热成风**先顺转后逆转**：
- 下层：暖平流（顺转）→ 下层变暖
- 上层：冷平流（逆转）→ 上层变冷
- 结果：**层结趋于不稳定**，有利于对流发展

---

#### 6. 易错提醒

- 热成风是**两层地转风之差**，本身不能直接测量
- 热成风公式中的 $\nabla T$ 是等压面上的水平温度梯度，不是垂直递减率
- 赤道上 $f \to 0$，热成风公式失效
- 热成风指向与地转风指向规则一致：北半球，背热成风而立，高温在右，低温在左

#### 思考题与解答

##### 思考题1：如何利用单站高空风分析图中风随高度的旋转方向判断冷暖平流？请结合热成风原理说明。

> **解答**：热成风 $\vec{V}_T = \vec{V}_g(p_1) - \vec{V}_g(p_0)$ 的方向平行于等平均温度线，在北半球背热成风而立，高温在右、低温在左。在单站高空风分析图中，从低层到高层的风矢连线反映了热成风的方向：若风随高度**顺转**（veering，顺时针转），热成风指向下层风的右侧（偏南方向），根据"背热成风而立，高温在右"的规则，暖空气在右侧，即本站东侧（或下游）为暖区——该层平均温度梯度指向东，站点正被南风分量把暖空气输送过来，因此为**暖平流**。反之，风随高度**逆转**（backing，逆时针转），热成风指向下层风的左侧（偏北方向），表明站点正被北风分量把冷空气吹来，为**冷平流**。这一方法在实际业务中是快速判断温度平流的最常用手段，无需绘制厚度图。

##### 思考题2：请用热成风原理解释中纬度西风急流的形成——为什么急流出现在对流层上部的中纬度地区而不是近地面或极地？

> **解答**：热成风公式 $\vec{V}_T = \frac{R}{f}\ln\frac{p_0}{p_1}(\vec{k} \times \nabla\overline{T})$ 表明：地转风随高度的变化（即热成风）由水平温度梯度唯一决定，方向垂直于温度梯度（在北半球指向温度梯度方向的右侧）。由于地球的经向温度分布为"极地冷、赤道暖"，水平温度梯度始终指向北（从赤道指向极地），因此 $\vec{k} \times \nabla\overline{T}$ 指向东——热成风为西风分量。这意味着：从地面到高空，西风分量随高度不断累积，每增加一个厚度层就叠加一份与层内温度梯度成正比的热成风。
>
> 急流出现在对流层上部中纬度而非其他位置的原因：（1）**近地面**——西风累积不够，风速尚小；（2）**极地**——虽然整层温度梯度存在，但极端寒冷的空气柱太"薄"，厚度层数有限；（3）**低纬度**——$f$ 太小，热成风公式中 $1/f$ 放大效应导致低层地转风就很大（参见地转风随纬度变化），热成风叠加反而有限，再加上哈得莱环流的限制。只有在**中纬度锋区**（极锋附近），水平温度梯度最强（锋区两侧温差可达数十度），且大气柱足够深厚，西风从地面到对流层顶不断累加热成风，最终在200-300 hPa附近达到最大值，形成中纬度西风急流。急流中心恰好位于温度梯度最大处（极锋区）的上方。

### 地转偏差 (Geostrophic Departure)

> **地转偏差**（又称偏差风）是指**实际风与地转风之差**。地转偏差虽然量级小（通常为地转风的10%~20%），但它是造成水平辐合辐散和垂直运动的关键。

#### 1. 定义

$$
\vec{D} = \vec{V} - \vec{V}_g
$$

- 地转风是理想化的平衡风场，实际大气中由于摩擦、加速度等影响，风总是偏离地转风
- **地转偏差的散度 = 实际风的散度**（因地转风散度为零）：
  $$
  \nabla \cdot \vec{V} = \nabla \cdot \vec{D}
  $$

---

#### 2. 边界层中的地转偏差（有摩擦）

在边界层（近地面约1~1.5 km）中，三力平衡：**气压梯度力 + 地转偏向力 + 摩擦力 = 0**。

平衡方程为：

$$
0 = -\frac{1}{\rho} \nabla_h p - f \vec{k} \times \vec{V} + \vec{F}
$$

利用地转风定义 $\vec{V}_g = \frac{1}{f\rho} \vec{k} \times \nabla_h p$，可导出：

$$
\vec{D} = \vec{V} - \vec{V}_g = -\frac{1}{f} \vec{k} \times \vec{F}
$$

**结论**：
- 地转偏差的方向与摩擦力垂直，**指向摩擦力的右侧**（北半球）
- 摩擦力使风速减小，风向偏向低压侧，从而产生指向低压的分量，引起水平辐合

---

#### 3. 自由大气中的地转偏差（无摩擦）

在自由大气中（忽略摩擦），水平运动方程为：

$$
\frac{d\vec{V}}{dt} = -f \vec{k} \times (\vec{V} - \vec{V}_g)
$$

由此解得：

$$
\vec{D} = \vec{V} - \vec{V}_g = \frac{1}{f} \vec{k} \times \frac{d\vec{V}}{dt}
$$

**结论**：
- 地转偏差与加速度垂直，**指向加速度方向的左侧**（北半球）
- 有加速度的地方就有地转偏差，从而产生辐合辐散

---

#### 4. 地转偏差的分解（自然坐标系）

将加速度展开为局地变化、平流变化、对流变化，得：

$$
\vec{D} = \frac{1}{f} \vec{k} \times \left( \frac{\partial \vec{V}}{\partial t} + V \frac{\partial \vec{V}}{\partial s} + w \frac{\partial \vec{V}}{\partial p} \right) = \vec{D}_1 + \vec{D}_2 + \vec{D}_3
$$

##### 4.1 变压风（$\vec{D}_1$）

$$
\vec{D}_1 = \frac{1}{f} \vec{k} \times \frac{\partial \vec{V}}{\partial t}
$$

- 由**气压梯度力的局地变化**引起，与**变压梯度**（或变高梯度）成正比
- 方向：由变压高值区指向低值区（北半球）
- **应用**：在地面天气图上，常用**3小时变压线**定性分析变压风。负变压中心对应辐合，正变压中心对应辐散

> 详见 [[变压风]]

##### 4.2 横向（法向）地转偏差（$\vec{D}_{2n}$）

$$
\vec{D}_{2n} = \frac{1}{f} V \frac{\partial V}{\partial s} \vec{n}_0
$$

- 由**沿流线的风速变化**（辐合/辐散）引起
- 当等高线**汇合**（风速沿流向增大）时，偏差指向低压侧；**疏散**时指向高压侧
- 导致水平辐合或辐散，进而影响垂直运动

##### 4.3 切向（纵向）地转偏差（$\vec{D}_{2s}$）

$$
\vec{D}_{2s} = -\frac{1}{f} \frac{V^2}{R_s} \vec{s}_0
$$

- 由**流线曲率**引起，与惯性离心力不平衡有关
- 气旋式曲率（$R_s > 0$）时，$\vec{D}_{2s}$ 与流向相反（减速）
- 反气旋式曲率（$R_s < 0$）时，与流向相同（加速）

##### 4.4 对流项（$\vec{D}_3$）

$$
\vec{D}_3 = \frac{w}{f} \vec{k} \times \frac{\partial \vec{V}}{\partial p}
$$

- 由**垂直运动引起的水平风垂直切变**产生
- 在强对流或锋区附近较显著

---

#### 5. 地转偏差的垂直分布特征

| 层次 | 主导偏差 | 主要作用 |
|------|----------|----------|
| 高层（对流层中上部） | $\vec{D}_{2n}, \vec{D}_{2s}$ | 与急流、槽脊曲率和疏散汇合有关 |
| 中层（500 hPa附近） | 变压风、曲率项 | 与高空槽脊发展和垂直运动关联 |
| 低层（边界层） | 摩擦引起的偏差 | 导致低空辐合辐散，触发垂直运动 |
| 近地面 | 变压风（$\vec{D}_1$） | 由3小时变压场决定，与锋面活动密切相关 |

---

#### 6. 地转偏差与垂直运动的关系

- **高空槽前**：偏差风辐散 → 上升运动 → 云雨天气
- **高空槽后**：偏差风辐合 → 下沉运动 → 晴朗天气（冬季易出现雾霾）

---

#### 7. 小结：地转偏差的三种主要分量

| 分量 | 名称 | 判断依据 | 作用 |
|------|------|----------|------|
| $\vec{D}_1$ | 变压风 | 3小时变压场 | 低层辐合辐散 |
| $\vec{D}_{2n}$ | 法向偏差 | 等高线辐合/辐散 | 产生横向辐合辐散 |
| $\vec{D}_{2s}$ | 切向偏差 | 等高线曲率 | 改变风速，影响散度 |

---

#### 思考题与解答

##### 思考题1：地转偏差在量级上仅为地转风的10%~20%，为什么说它是天气系统发生发展的关键？

> **解答**：虽然地转偏差量级小，但它承担了地转风无法完成的"实际工作"：（1）**散度**——纯地转风的水平散度为零（$\nabla_p \cdot \vec{V}_g = 0$），无法产生水平辐合辐散。实际大气的散度完全由地转偏差贡献（$\nabla \cdot \vec{V} = \nabla \cdot \vec{D}$），而辐合辐散是驱动垂直运动和天气变化的直接原因。（2）**能量转换**——地转风与等压线平行，气压梯度力不做功；而地转偏差跨越等压线，使气压梯度力能做功（$\vec{G} \cdot \vec{D} \neq 0$），实现位能向动能的转换。（3）**系统发展**——高空槽前的偏差辐散"抽气"导致地面减压和气旋发展，这一过程完全依赖地转偏差。可以类比：地转风是大气运动的"背景旋律"，地转偏差则是推动变化的"指挥棒"——前者量大但保守，后者量小但决定性。

##### 思考题2：边界层摩擦地转偏差和自由大气加速度地转偏差在方向和成因上有何本质不同？为什么边界层偏差总指向低压侧？

> **解答**：边界层中，地转偏差 $\vec{D} = -\frac{1}{f}\vec{k} \times \vec{F}$，方向为**摩擦力的右侧**（北半球）。摩擦力 $\vec{F}$ 与风向相反，指向下游方向的后方，其右侧恰好指向低压侧，因此边界层地转偏差总是具有指向低压的分量——这意味着实际风穿越等压线吹向低压（低压辐合、高压辐散），这是边界层Ekman抽吸的动力学基础。自由大气中（无摩擦），地转偏差 $\vec{D} = \frac{1}{f}\vec{k} \times \frac{d\vec{V}}{dt}$，方向为**加速度方向的左侧**。当气块加速时（$\frac{d\vec{V}}{dt}$ 沿流向），偏差指向低压侧；当气块减速时，偏差指向高压侧；当气流弯曲时（法向加速度），偏差方向取决于曲率。两者的本质区别在于：（1）边界层偏差由摩擦力产生，方向固定（指向低压），大小与摩擦系数相关；（2）自由大气偏差由加速度产生，方向随加速方向变化，在大尺度运动中主要与流线曲率（切向偏差）和风速变化（法向偏差）有关。

### 变压风 (Isallobaric Wind)

> 变压风是**地转偏差**的重要组成部分，由气压倾向（变高/变压）的空间不均匀分布引起。它直接反映了气压场快速调整过程中的非地转运动，是诊断垂直运动和天气系统发展的实用工具。

#### 1. 定义与公式

##### 1.1 定义

变压风是由**地面或等压面高度的局地变化率（变压/变高）的梯度**所产生的非地转风分量。它是实际风与地转风之差 $\vec{D}$ 的一部分，属于**自由大气中的地转偏差**。

##### 1.2 公式推导

地转风为：
$$
\vec{V}_g = \frac{1}{f} \vec{k} \times \nabla \Phi
$$

实际风的水平动量方程（忽略摩擦）：
$$
\frac{d\vec{V}}{dt} = -f\vec{k} \times (\vec{V} - \vec{V}_g)
$$

由此得到地转偏差 $\vec{D} = \vec{V} - \vec{V}_g$：
$$
\vec{D} = -\frac{1}{f} \vec{k} \times \frac{d\vec{V}}{dt}
$$

在实际分析中，常将 $\frac{d\vec{V}}{dt}$ 近似用 $\frac{\partial \vec{V}_g}{\partial t}$ 代替（略去平流变化和垂直变化），得到**变压风**的表达式：

$$
\boxed{\vec{D}_1 = -\frac{1}{f} \vec{k} \times \frac{\partial \vec{V}_g}{\partial t} = \frac{1}{f^2} \nabla \left( \frac{\partial \Phi}{\partial t} \right)}
$$

其中 $\frac{\partial \Phi}{\partial t}$ 是**位势高度倾向**。在地面天气图中，常直接使用**气压倾向** $\frac{\partial p}{\partial t}$，地面变压风写作：

$$
\vec{V}_{\text{isall}} = -\frac{1}{\rho f^2} \nabla \left( \frac{\partial p}{\partial t} \right)
$$

##### 1.3 方向规则（北半球）

- 变压风垂直于**等变高线（或等变压线）**，指向**变压梯度的方向**
- 对于**负变压中心（气压下降区）**：变压风**向中心辐合**
- 对于**正变压中心（气压上升区）**：变压风**由中心向外辐散**

> 记忆方法：变高下降（负变高）的地方，等压面在降低，空气必须流入填补，所以风指向变高下降中心；反之亦然。

---

#### 2. 物理意义

- 变压风是**质量场调整过程中的非地转运动**。当气压场迅速变化时（如气旋爆发加深），地转平衡来不及建立，实际风必须偏离地转风以响应质量场的变化
- 它是地转偏差三项分解（变压风 $D_1$、法向偏差 $D_{2n}$、切向偏差 $D_{2s}$）中**直接与局地变化相关**的一项
- 在天气尺度运动中，变压风的量级通常较小，但在系统快速发展区（如气象炸弹、强对流触发前），变压风可显著增强

---

#### 3. 天气学应用

##### 3.1 诊断垂直运动

- **地面负变压中心（减压区）**：变压风辐合 → 强迫上升 → 有利于降水和气旋发展
- **地面正变压中心（加压区）**：变压风辐散 → 强迫下沉 → 有利于天气转晴

在锋面气旋分析中，**暖锋前负变压、冷锋后正变压**的变压场配置，可直接用变压风定性判断垂直环流和降水带。

##### 3.2 系统发展与移动预报

- 若地面气旋中心存在强负变压，且变压风辐合持续，气旋将继续加深
- 当变压风辐合中心与气旋环流中心重合时，气旋达最强；两者逐渐分离则预示气旋将填塞
- **变压梯度的大小**还能帮助判断锋面移速和强度变化

##### 3.3 诊断强对流触发

- 雷暴高压前方的**负变压中心** → 变压风辐合 → 可能触发新的对流单体
- 飑锋过境时，气压骤升、风向突变，可由变压风部分解释

##### 3.4 与达因补偿原理的配合

达因补偿原理要求高低层散度相补偿。当高空有强烈辐散时，地面必须响应而产生负变压中心，从而驱动指向中心的变压风辐合。因此，**变压风是达因补偿原理在地面风场上的具体体现**：高空"抽气" → 地面减压 → 变压风指向减压中心 → 低层辐合上升。

##### 3.5 实际业务中的简单判据

在天气图分析中，预报员常通过勾画**三小时变压场**（或变高场），直接定性判断：
- 等变压器线密集区 → 强变压风 → 强非地转运动 → 可能伴随恶劣天气
- 负变压中心移向 → 未来气旋或低压槽的移动方向
- 变压零线 → 变压风转换带，常对应锋面或切变线

---

#### 4. 限制与提醒

- 变压风是地转偏差的**一阶近似**，忽略了平流变化和摩擦作用
- 在低纬地区 $f$ 很小，公式分母趋近零，变压风公式不再适用
- 在地面图上用气压倾向代替位势倾向时，需注意 $\rho$ 的差异（冷区密度大，同样气压倾向下的变压风较小）

---

#### 思考题与解答

##### 思考题1：如何利用地面3小时变压场定性诊断垂直运动？请结合变压风的方向规则说明。

> **解答**：变压风的方向规则为：负变压中心（气压下降区）→ 变压风向中心辐合；正变压中心（气压上升区）→ 变压风由中心向外辐散。根据连续方程和质量守恒，低层水平辐合必然伴随上升运动，水平辐散伴随下沉运动。因此，在3小时变压场分析中：（1）**负变压中心（负变高区）**对应变压风辐合 → 强迫上升 → 有利于云雨发展、气旋加深；（2）**正变压中心（正变高区）**对应变压风辐散 → 强迫下沉 → 有利于天气转晴。在实际业务操作中，预报员可快速勾画3小时等变压器线，密集的变压线梯度区意味着强变压风和强非地转运动，往往是恶劣天气即将发生或正在发生的区域。例如，暖锋前方常见负变压中心（锋面气旋逼近），冷锋后方常见正变压中心（冷高压推进），这些变压风场配置是定性判断降水和垂直环流的重要依据。

##### 思考题2：当高空有强烈辐散时，地面为什么会出现负变压中心并产生变压风辐合？这反映了一个什么重要的动力学原理？

> **解答**：这反映的是**达因补偿原理**（Dines compensation principle）在地面风场上的具体表现。达因补偿原理指出：在大气柱中，高低层的散度符号相反并相互补偿——高层辐散必然伴随低层辐合，以维持整层质量平衡。当高空（如急流出口区、槽前）出现强烈辐散时，空气被"抽走"，整层气柱质量减少，地面气压开始下降，形成负变压中心。而地面负变压中心一旦出现，就驱动了指向该中心的变压风辐合——这正是达因补偿原理所要求的低层补偿性辐合。因此，**变压风是连接高空强迫（辐散）和低空响应（辐合）的动力学桥梁**：高空"抽气" → 地面减压（负变压）→ 变压风指向减压中心 → 低层辐合上升 → 气旋发展、降水形成。从这个角度看，变压风不是孤立现象，而是整层垂直环流在地面风场上的非地转表现，是预报系统发展的关键信号。

### 大气热力学能量方程

> 描述空气微团在运动过程中温度（或位温）变化与非绝热加热、压缩做功之间的关系。是理解大气垂直运动、稳定度和能量转换的基础。

#### 1. 基本形式（热力学第一定律）

对于一个**单位质量**的空气微团，热力学第一定律可写为：

$$
dQ = c_v \, dT + p \, d\alpha \quad \text{或} \quad dQ = c_p \, dT - \alpha \, dp
$$

- $dQ$：单位质量空气吸收的热量（非绝热加热率）
- $c_v, c_p$：定容比热、定压比热
- $\alpha = 1/\rho$：比容
- $p$：气压
- $T$：温度

##### 推导起点

热力学第一定律普遍形式：
$$
dU = \delta Q - p \, dV
$$

单位质量：内能 $u$，体积 $\alpha$，则 $du = dQ - p \, d\alpha$。理想气体内能只与温度有关 $du = c_v \, dT$，代入即得第一种形式。

引入焓 $h = u + p\alpha$，则 $dh = du + p\,d\alpha + \alpha\,dp$，代入第一定律可得：
$$
dQ = dh - \alpha \, dp
$$

理想气体 $dh = c_p \, dT$，于是得到第二种形式 $dQ = c_p \, dT - \alpha \, dp$。

---

#### 2. 温度方程（用 $T$ 表示的能量方程）

将 $dQ = c_p \, dT - \alpha \, dp$ 两边对时间求全导数：

$$
\frac{dQ}{dt} = c_p \frac{dT}{dt} - \alpha \frac{dp}{dt}
$$

定义**非绝热加热率** $\dot{Q} \equiv \frac{dQ}{dt}$：

$$
c_p \frac{dT}{dt} = \dot{Q} + \alpha \frac{dp}{dt}
$$

或用 $\alpha = RT/p$ 写成：

$$
\boxed{\frac{dT}{dt} = \frac{\dot{Q}}{c_p} + \frac{RT}{c_p p} \omega}
$$

> 其中 $\omega \equiv dp/dt$ 为 $p$ 坐标垂直速度，**$\omega < 0$ 为上升运动，$\omega > 0$ 为下沉运动**。

- 绝热情况下（$\dot{Q}=0$），上升（$\omega<0$）导致降温，下沉（$\omega>0$）导致增温
- 非绝热加热（辐射、潜热释放等）直接改变温度

---

#### 3. 位温方程（保守形式）

**位温** $\theta$ 定义为气块干绝热地移到标准气压 $p_0 = 1000\ \mathrm{hPa}$ 时所具有的温度：

$$
\theta = T \left( \frac{p_0}{p} \right)^{R/c_p}
$$

取对数微分：
$$
\ln\theta = \ln T + \frac{R}{c_p}(\ln p_0 - \ln p)
$$

$$
\frac{d\ln\theta}{dt} = \frac{1}{T}\frac{dT}{dt} - \frac{R}{c_p}\frac{1}{p}\frac{dp}{dt}
$$

代入温度方程，得到：

$$
\boxed{\frac{d\theta}{dt} = \frac{\theta}{c_p T} \dot{Q}}
$$

或展开形式：

$$
\frac{\partial \theta}{\partial t} + \vec{V} \cdot \nabla \theta + \omega \frac{\partial \theta}{\partial p} = \frac{\theta}{c_p T} \dot{Q}
$$

**特例**：当过程为干绝热（$\dot{Q}=0$）时，$\frac{d\theta}{dt}=0$，**位温守恒**。这也是判断气块稳定度和追踪气团的依据。

---

#### 4. 用位温简化热流量方程（等压坐标常用）

常常忽略 $\dot{Q}$ 项，并用位温垂直变化代替温度变化。将热流量方程写为：

$$
\frac{\partial T}{\partial t} + \vec{V} \cdot \nabla T - S_p \omega = \frac{\dot{Q}}{c_p}
$$

其中**静力稳定度参数** $S_p$ 为：

$$
S_p = -\frac{T}{\theta}\frac{\partial \theta}{\partial p} = \frac{RT}{c_p p} - \frac{\partial T}{\partial p}
$$

- $S_p > 0$ 表示层结稳定
- 推导：从位温定义出发，$\frac{\partial \theta}{\partial p}$ 与 $\frac{\partial T}{\partial p}$ 的关系

---

#### 5. 内能和焓形式的能量方程

##### 内能方程

由 $c_v \frac{dT}{dt} = \dot{Q} - p \frac{d\alpha}{dt}$，结合[[连续方程]]：

$$
c_v \frac{dT}{dt} = \dot{Q} - p\alpha \nabla \cdot \vec{V}
$$

##### 焓方程

$$
\frac{dh}{dt} = \frac{d}{dt}(c_p T) = \dot{Q} + \alpha \omega
$$

这些形式有助于与动能方程联合导出总能量方程。

---

#### 6. 湿空气与假相当位温（简要）

对于湿空气但未饱和时，可近似使用干空气方程。一旦饱和，发生凝结，需考虑潜热释放。

- **假相当位温 $\theta_{se}$**：气块假绝热地上升，所有水汽凝结并脱离，再干绝热地返回1000 hPa时的温度。在湿绝热过程中，$\theta_{se}$ 近似守恒。
- 相应的热力学方程变为：

$$
\frac{d\theta_{se}}{dt} \approx 0 \quad (\text{湿绝热、假绝热过程})
$$

常用于暴雨和强对流分析。

#### 7. 总能量方程（与动能方程联合）

将动能方程与热力学方程相加，可得**总能量方程**。在无摩擦、绝热下，**干静力能** $E_d = c_p T + gz$ 守恒。加入潜热后，**湿静力能** $E_m = c_p T + gz + L_v q$ 在湿绝热过程中守恒，这是热带扰动发展诊断的关键。

---

#### 8. 小结：不同形式的选用

| 形式 | 表达式 | 适用场景 |
|------|--------|----------|
| 温度方程 | $\frac{dT}{dt} = \frac{\dot{Q}}{c_p} + \frac{RT}{c_p p}\omega$ | 诊断温度变化，p坐标常用 |
| 位温方程 | $\frac{d\theta}{dt} = \frac{\theta}{c_p T}\dot{Q}$ | 追踪气团、稳定度分析 |
| 热流量方程（p坐标） | $\frac{\partial T}{\partial t} + \vec{V}\cdot\nabla T - S_p \omega = \frac{\dot{Q}}{c_p}$ | 数值预报、诊断垂直运动 |
| 内能方程 | $c_v\frac{dT}{dt} = \dot{Q} - p\alpha\nabla\cdot\vec{V}$ | 研究压缩做功与动能转换 |

#### 思考题与解答

##### 思考题1：为什么在干绝热过程中位温守恒（$\frac{d\theta}{dt}=0$），而温度却不守恒？两者的物理含义有何不同？

> **解答**：温度方程 $\frac{dT}{dt} = \frac{\dot{Q}}{c_p} + \frac{RT}{c_p p}\omega$ 显示，即使在绝热条件（$\dot{Q}=0$）下，温度仍会因 $\omega$ 项（压缩/膨胀做功）而发生变化——上升运动（$\omega<0$）导致膨胀冷却，下沉运动（$\omega>0$）导致压缩增温。而位温 $\theta = T(p_0/p)^{R/c_p}$ 通过数学变换将气压的影响"扣除"了——表示气块干绝热地移到标准参考气压（1000 hPa）时的温度。**温度$T$是含"气压坐标"的状态量，位温$\theta$是扣除了气压影响后的"本质温度"**。

##### 思考题2：静力稳定度参数 $S_p = -\frac{T}{\theta}\frac{\partial\theta}{\partial p}$ 的物理含义是什么？

> **解答**：$S_p$ 本质上衡量的是**环境大气的位温垂直梯度**。$S_p > 0$ 表示层结稳定（位温随高度增加，气块受恢复力），$S_p < 0$ 表示层结不稳定。$S_p$ 绝对值大小反映给定垂直运动下温度变化的幅度——层结越稳定，同样上升运动导致的绝热冷却越强。

#### 9. 详细推导：从熵表示到温度方程（选自MOOC常见问题）

##### Q1：外源加热都包含哪些方式？

> **解答**：外源加热包括了**辐射**、**热传导**和**潜热释放**等方式。

##### Q2：从用熵表示的热力学能量方程推导出用温度和气压表示的热力学能量方程。

> **解答**（完整推导链）：

> 热力学第二定律：$T\frac{ds}{dt} = \dot{Q}$

> 熵的表达式：$s = c_p \ln\theta$（其中 $\theta = T(1000/P)^{R/c_p}$，$c_p = c_v + R$）

> **推导步骤**：
> 1. 从 $ds = c_p d\ln\theta$，得 $\frac{ds}{dt} = \frac{c_p}{\theta}\frac{d\theta}{dt}$
> 2. 热力学能量方程：$T\frac{ds}{dt} = \dot{Q}$ → $\frac{c_p T}{\theta}\frac{d\theta}{dt} = \dot{Q}$
> 3. 取 $\ln\theta = \ln T + \frac{R}{c_p}(\ln 1000 - \ln P)$，对时间求导：
>    $$\frac{1}{\theta}\frac{d\theta}{dt} = \frac{1}{T}\frac{dT}{dt} - \frac{R}{c_p P}\frac{dP}{dt}$$
> 4. 代入：
>    $$\frac{c_p T}{\theta}\frac{d\theta}{dt} = c_p\frac{dT}{dt} - \frac{RT}{P}\frac{dP}{dt} = \dot{Q}$$
> 5. 整理得：$c_p\frac{dT}{dt} - \frac{RT}{P}\omega = \dot{Q}$
> 
> 或等价形式：
> $$\boxed{\frac{dT}{dt} = \frac{\dot{Q}}{c_p} + \frac{RT}{c_p P}\omega}$$

> **本质**：这个推导将"熵增加"（热力学第二定律）与"温度变化"（可观测的量）联系起来。中间的桥梁是**位温**——它在绝热过程中保守（$\dot{Q}=0$ 时 $d\theta/dt=0$），这使得它成为分析大气过程的理想工具。

##### 思考题3：为什么假相当位温 $\theta_{se}$ 在暴雨分析中比普通位温 $\theta$ 更有用？

> **解答**：普通位温 $\theta$ 仅在干绝热过程中守恒，一旦发生水汽凝结（潜热释放），$\theta$ 就不再守恒。假相当位温 $\theta_{se}$ 在湿绝热/假绝热过程中近似守恒——它已将水汽凝结释放的全部潜热"计入"气块的温度之中。因此在对流性降水（暴雨）诊断中，$\theta_{se}$ 是比 $\theta$ 更好的示踪物和稳定度指标：$\frac{\partial\theta_{se}}{\partial z} < 0$ 表示对流性不稳定，有利于暴雨发生。

##### 思考题4：请列举热力学能量方程的四种常用形式并说明各自适用场景。

> **解答**：

| 形式 | 表达式 | 适用场景 |
|------|--------|----------|
| ① 温度方程 | $\frac{dT}{dt} = \frac{\dot{Q}}{c_p} + \frac{RT}{c_p p}\omega$ | p坐标诊断温度变化 |
| ② 位温方程 | $\frac{d\theta}{dt} = \frac{\theta}{c_p T}\dot{Q}$ | 追踪气团、判断稳定度 |
| ③ 热流量方程(p坐标) | $\frac{\partial T}{\partial t} + \vec{V}\cdot\nabla T - S_p\omega = \frac{\dot{Q}}{c_p}$ | 数值预报、诊断垂直运动 |
| ④ 熵方程 | $T\frac{ds}{dt} = \dot{Q}$ | 理论推导、大气能量学 |
