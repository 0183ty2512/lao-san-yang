## 核心公式速查

| 公式 | 名称 | 含义 |
|------|------|------|
| $\frac{d\mathbf{V}}{dt} = -\frac{1}{\rho}\nabla p - 2\boldsymbol{\Omega}\times\mathbf{V} + \mathbf{g} + \mathbf{F}$ | 运动方程 | 动量守恒 |
| $\frac{\partial\rho}{\partial t} + \nabla\cdot(\rho\mathbf{V}) = 0$ | 连续方程 | 质量守恒 |
| $p = \rho R_d T$ | 状态方程 | 理想气体 |
| $\mathbf{V}_g = \frac{1}{f\rho}\mathbf{k}\times\nabla_h p$ | 地转风 | PGF = Cor |
| $Ro = \frac{U}{f_0 L}$ | 罗斯贝数 | 惯性力/科氏力 |
| $\frac{d(\zeta+f)}{dt} = -f\nabla_h\cdot\mathbf{V}_h$ | 简化涡度方程 | 大尺度 |
| $\frac{d}{dt}(\frac{\boldsymbol{\omega}_a\cdot\nabla\theta}{\rho}) = 0$ | 位涡守恒 | 绝热无摩擦 |
| $\omega = \overline{u}k - \frac{\beta k}{k^2+l^2}$ | 罗斯贝波频散 | $\beta$效应 |
| $w_E = \frac{1}{2}H_E\zeta_g$ | 埃克曼抽吸 | 边界层-自由大气耦合 |
| $A^* = \frac{1}{2}\int\frac{\overline{T}}{\gamma_d-\gamma}(\frac{T'}{\overline{T}})^2\frac{dp}{g}$ | 有效位能 | 可转换能量 |
