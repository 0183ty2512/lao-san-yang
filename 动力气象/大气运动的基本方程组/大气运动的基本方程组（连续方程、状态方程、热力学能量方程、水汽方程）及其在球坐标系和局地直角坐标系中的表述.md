## 大气运动的基本方程组

> **重点**
> - 五个方程构成闭合方程组：运动方程（动量守恒）、连续方程（质量守恒）、热力学能量方程（能量守恒）、水汽方程（水汽守恒）、状态方程（物性关系），可求解 $u,v,w,\rho,T,q$ 六个未知量
> - **球坐标系**保留完整的曲率项和科氏力分量（含 $\tan\phi$ 项），适用于全球环流和低纬动力学；**局地直角坐标系**是 $L \ll a$ 近似，忽略曲率，$f$ 取常数或 $\beta y$
> - 全导数 $\frac{d}{dt} = \frac{\partial}{\partial t} + \mathbf{V}\cdot\nabla$ 在两种坐标系中展开方式不同，球坐标系中平流项含 $\frac{1}{r\cos\phi}$ 等几何因子
> - 连续方程在 $p$ 坐标系中形式最简：$\nabla_h\cdot\mathbf{V}_h + \partial\omega/\partial p = 0$，是诊断垂直运动的核心工具
> - 状态方程是标量方程，在所有坐标系中形式一致，引入虚温 $T_v = (1+0.608q)T$ 处理湿空气效应
> - 热力学能量方程中 $\frac{dp}{dt}$ 项在静力平衡下可简化为 $-\rho g w$，大尺度运动中温度变化由温度平流和垂直运动主导
> - 水汽方程 $\frac{dq}{dt} = S/\rho$ 中源汇项 $S$ 在干过程中为零（$q$ 守恒），在湿过程中与热力学方程通过凝结潜热耦合

### （1） 概述

大气运动的基本方程组由以下五个方程组成，它们分别描述了动量守恒、质量守恒、热力学能量守恒、水汽质量守恒以及气体的状态关系。在适当边界条件和初始条件下，可求解大气的运动状态。

| 方程名称 | 物理本质 | 未知量 |
| :--- | :--- | :--- |
| 运动方程 | 牛顿第二定律（动量守恒） | $\mathbf{V} = (u,v,w)$ |
| 连续方程 | 质量守恒 | $\rho$ |
| 热力学能量方程 | 热力学第一定律（能量守恒） | $T$（或位温 $\theta$） |
| 水汽方程 | 水汽质量守恒 | $q$（比湿） |
| 状态方程 | 理想气体状态方程 | 联系 $p, \rho, T$ |

方程组是闭合的：5 个方程，5 个未知量（$u,v,w,\rho,T$，若考虑水汽则增加 $q$ 和状态方程中的虚温修正）。

### （2） 连续方程（质量守恒）

#### 向量形式（适用于任何坐标系）
$$\frac{\partial \rho}{\partial t} + \nabla \cdot (\rho \mathbf{V}) = 0$$
或等价地
$$\frac{d\rho}{dt} + \rho \nabla \cdot \mathbf{V} = 0$$

#### ① 球坐标系 $(\lambda, \phi, r)$
速度分量：$u = r\cos\phi \frac{d\lambda}{dt}$（东向），$v = r\frac{d\phi}{dt}$（北向），$w = \frac{dr}{dt}$（径向，向上为正）。

$$\frac{\partial \rho}{\partial t} + \frac{1}{r\cos\phi} \frac{\partial (\rho u)}{\partial \lambda} + \frac{1}{r\cos\phi} \frac{\partial (\rho v \cos\phi)}{\partial \phi} + \frac{1}{r^2} \frac{\partial (\rho w r^2)}{\partial r} = 0$$

#### ② 局地直角坐标系 $(x, y, z)$
（$x$ 向东，$y$ 向北，$z$ 向上，不考虑曲率）
$$\frac{\partial \rho}{\partial t} + \frac{\partial (\rho u)}{\partial x} + \frac{\partial (\rho v)}{\partial y} + \frac{\partial (\rho w)}{\partial z} = 0$$

### （3） 状态方程（理想气体假设）

#### 向量形式
$$p = \rho R_d T_v$$
其中 $T_v = (1+0.608q)T$ 为虚温，$R_d = 287\,\text{J}\cdot\text{kg}^{-1}\cdot\text{K}^{-1}$。

#### ① 球坐标系
$$p(\lambda,\phi,r,t) = \rho(\lambda,\phi,r,t)\, R_d\, T_v(\lambda,\phi,r,t)$$

#### ② 局地直角坐标系
$$p(x,y,z,t) = \rho(x,y,z,t)\, R_d\, T_v(x,y,z,t)$$

> **说明**：状态方程是标量方程，在不同坐标系下形式完全一致，仅自变量不同。

---

### （4） 热力学能量方程（热力学第一定律）

#### 向量形式（常用形式）
$$c_p \frac{dT}{dt} - \alpha \frac{dp}{dt} = \dot{Q}$$
其中 $\alpha = 1/\rho$ 为比容，$\dot{Q}$ 为单位质量非绝热加热率。

#### ① 球坐标系
全导数为：
$$\frac{dT}{dt} = \frac{\partial T}{\partial t} + \frac{u}{r\cos\phi}\frac{\partial T}{\partial \lambda} + \frac{v}{r}\frac{\partial T}{\partial \phi} + w\frac{\partial T}{\partial r}$$
代入即可。静力平衡下 $\frac{dp}{dt}$ 可按需展开。

#### ② 局地直角坐标系
$$\frac{\partial T}{\partial t} + u\frac{\partial T}{\partial x} + v\frac{\partial T}{\partial y} + w\frac{\partial T}{\partial z} - \frac{\alpha}{c_p}\frac{dp}{dt} = \frac{\dot{Q}}{c_p}$$
在尺度分析中，常略去 $\frac{dp}{dt}$ 项中的非静力部分，得到简化形式。

---

### （5） 水汽方程（水汽质量守恒）

#### 向量形式（比湿 $q$）
$$\frac{dq}{dt} = \frac{S}{\rho}$$
其中 $S$ 为水汽源汇项（单位体积、单位时间的水汽质量变化，如蒸发、凝结）。

#### ① 球坐标系
$$\frac{\partial q}{\partial t} + \frac{u}{r\cos\phi}\frac{\partial q}{\partial \lambda} + \frac{v}{r}\frac{\partial q}{\partial \phi} + w\frac{\partial q}{\partial r} = \frac{S}{\rho}$$

#### ② 局地直角坐标系
$$\frac{\partial q}{\partial t} + u\frac{\partial q}{\partial x} + v\frac{\partial q}{\partial y} + w\frac{\partial q}{\partial z} = \frac{S}{\rho}$$

---

### （6） 球坐标系与局地直角坐标系的对比

| 特性 | 球坐标系 $(\lambda,\phi,r)$ | 局地直角坐标系 $(x,y,z)$ |
| :--- | :--- | :--- |
| 适用范围 | 全球、大尺度、任意纬度 | 中纬度、有限区域（$L \ll a$） |
| 曲率项 | 完整保留 | 忽略 |
| 科氏力项 | 包含 $u,v,w$ 引起的分量 | 简化为 $-fv$ 和 $fu$（$f$ 常数或 $\beta y$） |
| 方程形式 | 复杂，含 $\tan\phi$ 等项 | 简单，与笛卡尔坐标系相同 |
| 重力 | 径向引力+离心力合成 $g(r,\phi)$ | 常数 $g$，仅在 $z$ 方向 |

> **小结**：局地直角坐标系是球坐标系在 $L \ll a$ 条件下的近似，是研究中纬度天气尺度运动的基准框架。球坐标系则用于全球环流和低纬动力学的精确描述。

### 思考题

> **思考题 1**：五个方程构成的闭合方程组中，哪两个方程之间存在最紧密的双向耦合关系？为什么？请以热带气旋中的凝结潜热反馈为例，说明水汽方程和热力学方程的耦合机制。

> **思考题 2**：在球坐标运动方程中，$\frac{uv\tan\phi}{r}$ 项被称为"曲率项"或"几何项"。它在赤道（$\phi = 0$）处消失，在极地（$\phi \to 90^\circ$）发散——这一奇点对全球模式设计带来了什么困难？数值模式如何处理这一奇点？

> **思考题 3**：若将局地直角坐标系直接用于赤道地区（$f \approx 0$），地转平衡近似不再成立。那么赤道地区大气的动力约束是什么？为什么需要保留球坐标系中的完整科氏力项？

> **思考题 4**：水汽方程 $\frac{dq}{dt} = S/\rho$ 形式上极其简洁，但在实际数值天气预报中是误差最大的方程之一。其根本困难不在于方程本身，而在于源汇项 $S$ 的参数化——请讨论对流参数化方案的"灰区"问题。
