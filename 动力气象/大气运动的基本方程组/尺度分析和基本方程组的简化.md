## 尺度分析和基本方程组的简化

> **重点**
> - 尺度分析通过估计方程各项量级（利用特征尺度 $L, D, U, W, \tau$），忽略小量级项，保留主导项，从而将复杂非线性方程组简化为可处理的近似方程
> - **罗斯贝数** $Ro = \frac{U}{f_0 L}$ 是判断地转平衡成立与否的核心参数：大尺度 $Ro \sim 0.1$ 表明科氏力主导惯性力，地转平衡成立
> - **零级近似**给出地转平衡（水平运动）和静力平衡（铅直运动）；**一级近似**保留加速度项得到准地转近似，地转偏差虽小但控制系统演变
> - 大尺度运动水平散度量级远小于水平速度梯度各项，零级近似为水平无辐散；$p$ 坐标系连续方程 $\nabla_h\cdot\mathbf{V}_h + \partial\omega/\partial p = 0$ 是诊断垂直运动的核心
> - $f$ 平面近似（$f = f_0$ 常数）和 $\beta$ 平面近似（$f = f_0 + \beta y$）是中纬度动力学最常用的简化——系数位取 $f_0$，涡度方程中 $\partial f/\partial y = \beta$ 必须保留
> - **理查森数** $Ri = \frac{N^2}{(\partial V/\partial z)^2}$ 综合评估层结稳定度与风切变效应：$Ri < 0.25$ 时湍流易发展，$Ri > 1$ 时湍流被抑制
> - 大尺度运动的五个"准"特征：准地转、准静力、准水平、准定常、准水平无辐散，构成经典天气尺度动力学的基本框架
> - 尺度分析的结果依赖于尺度的选择——不同运动类别（大、中、小尺度）主导项不同，简化结果各异

### 1. 尺度分析的基本思想

大气运动包含多种时空尺度（从几米到上万公里，从几秒到几周）。基本方程组非常复杂且高度非线性，难以精确求解。**尺度分析** 是通过估计方程中各项的量级，忽略次要项，保留主导项，从而简化方程，突出核心物理过程的方法。

### 2. 尺度的定义与分类

- **空间尺度**：运动系统在水平方向的特征尺度 $L$（单位：m），例如气旋半径、波长等。根据水平尺度 $L$ 的大小，可将大气运动分类：

| 运动类别 | 水平尺度 $L$ | 举例 |
| :--- | :--- | :--- |
| 大尺度运动 | $\ge 10^6$ m | 大气长波、气旋、反气旋、副高 |
| 中尺度运动 | $\sim 10^5$ m | 台风、飑线、海陆风、锋面 |
| 小尺度运动 | $\le 10^4$ m | 龙卷、雷暴单体、积云 |

- **铅直尺度** $D$：系统的厚度（单位：m）。大尺度运动中 $D \sim 10^4$ m（相当于对流层厚度）。
- **速度尺度**：水平速度尺度 $U$（通常为 $10$ m/s），垂直速度尺度 $W$（大尺度为 $10^{-2}$ m/s，中尺度为 $10^{-1}$ m/s，小尺度为 $1$ m/s）。
- **时间尺度** $\tau$：系统演变的特征时间。对平流为主的过程，$\tau = L/U$；对波动传播，$\tau = L/c$。

### 3. 大尺度运动各物理量的典型尺度

以下为大尺度（天气尺度）运动的典型数量级（中纬度）：

| 物理量 | 符号 | 尺度值 | 数量级 |
| :--- | :--- | :--- | :--- |
| 水平尺度 | $L$ | $10^6$ m | $10^6$ |
| 铅直尺度 | $D$ | $10^4$ m | $10^4$ |
| 水平速度 | $U$ | $10$ m/s | $10^1$ |
| 垂直速度 | $W$ | $10^{-2}$ m/s | $10^{-2}$ |
| 时间尺度（平流） | $\tau = L/U$ | $10^5$ s | $10^5$ |
| 气压水平变化 | $\Delta_h P$ | $10^3$ Pa | $10^3$ |
| 气压铅直变化 | $\Delta_z P$ | $10^5$ Pa | $10^5$ |
| 密度水平变化 | $\Delta_h \rho$ | $10^{-2}$ kg/m³ | $10^{-2}$ |
| 密度铅直变化 | $\Delta_z \rho$ | $10^{-1}$ kg/m³ | $10^{-1}$ |
| 科氏参数 | $f_0$ | $10^{-4}$ s⁻¹ | $10^{-4}$ |
| $\beta = \frac{df}{dy}$ | $\beta$ | $1.6 \times 10^{-11}$ m⁻¹s⁻¹ | $10^{-11}$ |
| 重力加速度 | $g$ | $9.8$ m/s² | $10^1$ |

### 4. 无量纲参数

尺度分析引入几个关键无量纲参数，它们决定了运动的性质。

- **罗斯贝数** $Ro = \frac{U}{f_0 L}$
  - 物理意义：惯性力与科氏力之比。
  - 大尺度运动：$Ro \sim 0.1$，表明科氏力占主导 → **准地转**。

- **基别尔数** $\epsilon = \frac{1}{f_0 \tau}$
  - 物理意义：局地惯性力与科氏力之比。
  - 大尺度运动取平流时间尺度 $\tau = L/U$，则 $\epsilon = Ro$。

- **理查森数** $Ri = \frac{N^2}{(\partial V/\partial z)^2}$
  - 物理意义：层结稳定度与垂直风切变之比。
  - $Ri < 0.25$ 时湍流易发展；$Ri > 1$ 时湍流被抑制。

- **厚度参数** $\lambda = D/H$，$H = \frac{RT}{g}$ 为大气标高（$\sim 10^4$ m）。
  - $\lambda \ll 1$：浅薄系统；$\lambda \sim 1$：深厚系统。

### 5. 大尺度运动方程组的简化结果

#### （1） 水平运动方程 → 地转平衡与准地转近似

零级近似（最大项平衡）：
$$-\frac{1}{\rho}\nabla_h p - f \mathbf{k} \times \mathbf{V}_h = 0$$
即**地转平衡**：
$$\mathbf{V}_g = \frac{1}{f\rho} \mathbf{k} \times \nabla_h p$$
地转风沿等压线吹，北半球背风而立，高压在右。

一级近似（保留时间导数和平流项）：
$$\frac{d\mathbf{V}_h}{dt} = -\frac{1}{\rho}\nabla_h p - f \mathbf{k} \times \mathbf{V}_h$$
称为**准地转近似**：实际风 $=$ 地转风 $+$ 小偏差（地转偏差），地转偏差虽小，但控制系统的演变。

#### （2） 铅直运动方程 → 准静力平衡

零级至几级近似均给出：
$$0 = -\frac{1}{\rho}\frac{\partial p}{\partial z} - g$$
即**准静力平衡**：
$$\frac{\partial p}{\partial z} = -\rho g$$
静力平衡滤掉了铅直方向的声波，是天气尺度运动的基本特征。

#### （3） 连续方程 → 准水平无辐散与达因补偿

零级近似：
$$\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} = 0$$
水平无辐散。

一级近似（考虑垂直运动）：
$$\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial w}{\partial z} = 0$$
或等价地（$p$ 坐标系）：
$$\nabla_h \cdot \mathbf{V}_h + \frac{\partial \omega}{\partial p} = 0$$
**达因补偿原理**：对整层大气积分，上下层的水平辐散辐合相互补偿，使得整层大气水平无辐散。

#### （4） 热力学方程 → 温度平流与垂直运动主导

简化后：
$$\frac{\partial T}{\partial t} = -\mathbf{V}_h \cdot \nabla_h T - w(\gamma_d - \gamma) + \frac{\dot{Q}}{c_p}$$
- 第一项：温度平流
- 第二项：垂直运动的绝热冷却/加热
- 第三项：非绝热加热（辐射、凝结等）

#### （5） 科氏参数的简化（$f$ 平面与 $\beta$ 平面）

- **$f$ 平面近似**：当运动经向尺度 $L$ 远小于地球半径 $a$ 时，可令 $f = f_0$ 常数。
- **$\beta$ 平面近似**：考虑 $f$ 随纬度的变化，取 $f = f_0 + \beta y$，其中 $\beta = \frac{2\Omega \cos \phi_0}{a}$。在涡度方程中 $\partial f/\partial y = \beta$ 保留，系数位置 $f$ 取 $f_0$。

### 6. 大尺度运动方程组的零级与一级近似对比

| 方程 | 零级近似（诊断） | 一级近似（预报） |
| :--- | :--- | :--- |
| 水平运动 | 地转平衡 | 准地转（含加速度） |
| 铅直运动 | 静力平衡 | 静力平衡 |
| 连续方程 | 水平无辐散 | 水平散度+垂直伸缩 |
| 热力学 | — | 平流+垂直运动+非绝热 |

**五个“准”**：准地转、准静力、准水平、准定常、准水平无辐散。

---

> **小结**：尺度分析是动力气象学的核心方法之一。通过它，我们得到了适用于大尺度运动的简化方程组，突出了地转平衡、静力平衡、水平无辐散等关键特征，为后续研究天气系统的演变（准地转理论）和波动（Rossby 波等）奠定了基础。
