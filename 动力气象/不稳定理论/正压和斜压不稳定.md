## 正压和斜压不稳定

**重点**

- **正压不稳定**的能量来源于基本气流的水平动能（水平切变 $\partial \overline{u}/\partial y \neq 0$），发生在无水平温度梯度的正压大气中。
- **斜压不稳定**的能量来源于基本气流的有效位能（水平温度梯度），发生在等压面与等密度面相交的斜压大气中。
- 正压不稳定的必要条件（Rayleigh 定理）：基本位涡梯度 $\frac{d\overline{q}}{dy} = \beta - \overline{u}''$ 必须在流场内变号；Fjørtoft 定理给出了更强的约束条件。
- 斜压不稳定的必要条件（Charney–Stern 定理）：准地转位涡梯度 $\frac{\partial \overline{q}}{\partial y}$ 在内部变号，或地面位温梯度满足适当符号条件。
- 经典斜压不稳定模型：**Eady 模型**（刚盖顶、$f$ 常数）给出最不稳定波长约 4700 km；**Charney 模型**（辐射顶、含 $\beta$）更符合实际大气。
- 能量转换机制：正压不稳定通过雷诺应力 $\overline{u'v'}$ 与基本流切变相互作用；斜压不稳定通过热量输送 $\overline{v'T'}$ 使暖空气上升、冷空气下沉，释放有效位能。
- 实际大气中正压和斜压不稳定常共存：中纬度气旋以斜压不稳定为主导，高层急流区和热带扰动中正压不稳定更为重要。
- 扰动槽线的倾斜方向决定能量转换方向：槽线随高度向西倾斜（斜压）利于有效位能释放，曳式槽（正压）利于从水平切变获取动能。

### 1. 不稳定理论概述

大气中的不稳定是指：基本气流（通常是纬向流）上叠加的小扰动能够从基本气流中获得能量，随时间增长的现象。根据能量来源的不同，主要分为：

- **正压不稳定**：扰动能量来源于基本气流的水平动能（主要是水平切变）。
- **斜压不稳定**：扰动能量来源于基本气流的有效位能（即水平温度梯度所储存的能量）。

这两种不稳定是解释中纬度天气系统（如气旋、锋面波动）生成和发展的重要机制。

### 2. 正压不稳定

#### （1） 定义与物理机制

**正压不稳定**发生在正压大气（密度仅为气压的函数，等压面与等密度面平行）中，此时大气没有水平温度梯度，不存在有效位能。扰动发展的唯一能量来源是基本气流的水平动能，具体地，来自基本气流的水平切变（即 $d\overline{u}/dy \neq 0$）。

基本气流可能具有“拐点”（即绝对涡度极值），当扰动结构合适时，可以通过雷诺应力将基本气流的动能转换为扰动动能，使扰动增长。

#### （2） 必要条件（Rayleigh 定理、Fjørtoft 定理）

对于无摩擦、正压、无辐散的纬向基本气流 $\overline{u}(y)$，线性化涡度方程为：
$$\left(\frac{\partial}{\partial t} + \overline{u}\frac{\partial}{\partial x}\right)\nabla^2\psi' + \frac{d\overline{q}}{dy}\frac{\partial\psi'}{\partial x} = 0$$
其中 $\overline{q} = f_0 + \beta y - \frac{d^2\overline{u}}{dy^2}$ 为基本气流的位势涡度（正压近似下）。设扰动具有波形解 $\psi' = \Psi(y)e^{ik(x-ct)}$，代入可得雷利方程。正压不稳定的**必要条件**为：

- **Rayleigh 定理**：$\frac{d\overline{q}}{dy}$ 必须在某个纬度变号（即基本位涡梯度在区域内改变符号）。在正压无辐散条件下，$\frac{d\overline{q}}{dy} = \beta - \frac{d^2\overline{u}}{dy^2}$，因此不稳定要求 $\beta - \overline{u}''$ 在流场内变号。
- **Fjørtoft 定理**（更强的条件）：存在某个纬度 $y_s$，使得 $\frac{d\overline{q}}{dy}(\overline{u} - \overline{u}_s) < 0$，其中 $\overline{u}_s$ 为 $\frac{d\overline{q}}{dy}=0$ 处的纬向风速。

在实际大气中，正压不稳定通常与急流轴附近强的水平切变有关。例如，副热带急流和极锋急流的某些配置可能满足条件，产生正压不稳定，导致高空槽脊的发展或变形。

#### （3） 能量转换

正压不稳定扰动从基本气流获得能量的机制是：扰动产生的经向动量通量 $\overline{u'v'}$ 与基本风场的水平切变 $\partial\overline{u}/\partial y$ 同号，即：
$$\frac{\partial K'}{\partial t} \propto \overline{u'v'} \frac{\partial\overline{u}}{\partial y} > 0$$
（这里 $K'$ 为扰动动能，$\overline{u'v'}$ 是雷诺应力，通常 $\overline{u'v'} = -\overline{u'v'}$ 符号约定不同，但本质是扰动动量输送向下游方向）。

当槽线呈东北-西南走向（曳式槽）时，$\overline{u'v'} > 0$（北半球），若 $\partial\overline{u}/\partial y > 0$（西风随纬度增加），则扰动从基本流获得能量，不稳定；反之若槽线呈西北-东南走向（导式槽），扰动能量转换方向相反，稳定。实际上，正压不稳定的详细能量学比这复杂，但基本思想是扰动通过倾斜的槽脊线从基本气流的水平切变中吸取动能。

#### （4） 实例

- 中纬度急流轴南侧（西风随纬度减小，$\overline{u}'<0$），可能出现正压不稳定。
- 热带东风急流中也观测到正压不稳定，可产生热带气旋的初始扰动。
- 数值模拟中，正压不稳定可解释某些高空切断低压的形成。

### 3. 斜压不稳定

#### （1） 定义与物理机制

**斜压不稳定**发生在斜压大气（等压面与等密度面相交，存在水平温度梯度）中。扰动的能量来源是基本气流的有效位能（即水平温度梯度所储存的能量）。当扰动发展时，暖空气上升、冷空气下沉，使有效位能转换为扰动动能，同时扰动也通过热量输送进一步释放有效位能。

斜压不稳定是中纬度气旋生成（锋面波动）的主要机制，也是大气长波（罗斯贝波）不稳定的核心。

#### （2） 必要条件（Charney–Stern 定理）

对于斜压、准地转、无摩擦的纬向基本气流 $\overline{u}(y,p)$，其准地转位涡梯度 $\frac{\partial \overline{q}}{\partial y}$ 和地面位温梯度 $\frac{\partial \overline{\theta}}{\partial y}$ 需要满足一定的符号条件。**Charney–Stern 定理**指出，斜压不稳定的必要条件是：
- $\frac{\partial \overline{q}}{\partial y}$ 在内部变号，或
- $\frac{\partial \overline{\theta}}{\partial y}$ 在边界（地面或顶）为适当的符号。

通常，在中纬度，$\frac{\partial \overline{\theta}}{\partial y} < 0$（北冷南暖），满足条件，因此斜压不稳定广泛存在。

#### （3） 经典模型：Eady 模型和 Charney 模型

**Eady 模型**（1949）：
- 假设：基本气流 $\overline{u} = \Lambda z$（线性切变），$f$ 常数，$N^2$ 常数，刚盖顶（$z=H$），地面无摩擦。
- 特点：扰动结构相当正压，垂直速度最大在中间，位相随高度变化。
- 不稳定条件：对于任意波数，只要波长足够长（$k$ 小），都会不稳定。最不稳定波长约为 $L \approx 3.9H N / f$，对于中纬度典型值 $H=10^4$ m，$N=1.2\times10^{-2}\,\text{s}^{-1}$，$f=10^{-4}\,\text{s}^{-1}$，$L \approx 4700$ km，与实际气旋尺度相近。
- 增长率：$\sigma \approx 0.31 \Lambda f / N$，典型 e 折时间约 2–3 天。

**Charney 模型**（1947）：
- 假设：基本气流 $\overline{u} = \Lambda z$，但考虑 $\beta$ 效应，且顶为辐射边界条件（允许波能向上传播）。
- 特点：短波被稳定，长波不稳定；存在最不稳定波长，且与 Eady 模型类似。
- 意义：更符合实际大气，解释了长波的不稳定。

#### （4） 能量转换

斜压不稳定发展过程中，扰动通过热量输送（$\overline{v'T'}$ 或 $\overline{v'\theta'}$）使暖空气上升、冷空气下沉，从而将有效位能转换为动能。能量转换项为：
$$\{A',K'\} = -\frac{R}{p} \int \overline{T'\omega'} dM \quad \text{或} \quad \propto \overline{v'T'} \frac{\partial \overline{T}}{\partial y}$$
当扰动槽线随高度向西倾斜（即冷槽落后于高度槽）时，暖平流在槽前上升、冷平流在槽后下沉，有效位能释放，扰动增长。

#### （5） 斜压不稳定与锋生、气旋生成

- 斜压不稳定是锋面波动（极锋气旋）的触发机制。
- 最不稳定波长与斜压区的宽度和静力稳定度有关，决定了气旋的典型尺度（~1000–2000 km）。
- 在数值天气预报中，斜压不稳定是中期预报（3-7天）的关键过程，模式需合理描述其发展。

### 4. 正压与斜压不稳定的比较

| 特征 | 正压不稳定 | 斜压不稳定 |
| :--- | :--- | :--- |
| **能量来源** | 基本气流的水平动能（水平切变） | 基本气流的有效位能（水平温度梯度） |
| **大气状态** | 正压大气 | 斜压大气 |
| **必要条件** | $\beta - \overline{u}''$ 变号 | $\partial \overline{q}/\partial y$ 变号或边界温度梯度 |
| **典型波长** | 与急流宽度有关，几百至几千公里 | 几千公里（气旋尺度） |
| **增长率** | 较快（几天） | 较慢（2-3天） |
| **能量转换项** | $\overline{u'v'} \partial\overline{u}/\partial y$ | $\overline{v'T'} \partial\overline{T}/\partial y$ |
| **典型现象** | 高空急流附近的扰动发展 | 温带气旋生成、锋面波动 |

### 5. 实际大气的综合情况

实际大气中，正压和斜压不稳定常常共存。例如，一个发展中的气旋可能同时从水平切变（正压）和温度梯度（斜压）获取能量。但在中纬度，斜压不稳定通常是气旋发展的主导机制，而正压不稳定在高层急流区（如副热带急流）和热带扰动中更为重要。

此外，**对称不稳定**是斜压不稳定和惯性不稳定的混合，发生在锋面附近具有强垂直风切变的区域，是产生中尺度雨带的重要机制。
