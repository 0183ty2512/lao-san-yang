## 涡度及其在不同坐标系下的方程

### 重点

- 涡度 $\zeta = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}$ 是速度场旋度的垂直分量，正涡度对应气旋式旋转；其宏观积分即为环流（斯托克斯定理 $\oint \mathbf{V}\cdot d\mathbf{r} = \int \zeta dA$）。
- 绝对涡度 $\zeta_a = \zeta + f$ 是相对涡度与地转涡度之和——大尺度运动中 $|\zeta| \ll |f|$，$\zeta_a \approx f$，绝对涡度的变化主要由 $f$ 的平流（$\beta v$ 项）和散度效应决定。
- 散度项 $-(f+\zeta)\nabla_h\cdot\mathbf{V}_h$ 是涡度方程中最重要的源汇项：水平辐合拉伸气柱使涡度增大（角动量守恒类比），辐散则使涡度减小，这是天气系统发展的核心机制。
- 自然坐标系中涡度分解为曲率涡度 $\frac{V}{R_s}$ 与切变涡度 $-\frac{\partial V}{\partial n}$，锋面和急流区的涡度异常可由此直观诊断——急流轴南侧的气旋式切变贡献正涡度。
- $p$ 坐标系涡度方程无显式力管项，斜压性通过扭曲项 $\frac{\partial\omega}{\partial y}\frac{\partial u}{\partial p} - \frac{\partial\omega}{\partial x}\frac{\partial v}{\partial p}$（$\omega$ 不均匀性与风垂直切变的耦合）间接影响涡度。
- 大尺度简化方程 $\frac{d_h(\zeta+f)}{dt} = -f\nabla_h\cdot\mathbf{V}_h$ 是准地转理论的核心；进一步取无辐散近似得到正压涡度方程，它是罗斯贝波的理论基础。

### 1. 涡度的定义

**涡度**（Vorticity）是描述流体微团旋转运动的微观物理量，定义为速度场的旋度。

$$\boldsymbol{\omega} = \nabla \times \mathbf{V}$$

在直角坐标系中，涡度的三个分量为：
$$\omega_x = \frac{\partial w}{\partial y} - \frac{\partial v}{\partial z}, \quad
\omega_y = \frac{\partial u}{\partial z} - \frac{\partial w}{\partial x}, \quad
\omega_z = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}$$

对于大尺度大气运动，水平运动远强于垂直运动，通常主要关注**垂直方向上的涡度分量**，并简称为涡度（相对涡度）：
$$\zeta = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}$$

- **正涡度**（$\zeta > 0$）：对应气旋式旋转（北半球逆时针）
- **负涡度**（$\zeta < 0$）：对应反气旋式旋转（北半球顺时针）

#### 涡度与环流的关系（斯托克斯定理）
$$\oint_L \mathbf{V} \cdot d\mathbf{r} = \int_A \boldsymbol{\omega} \cdot d\mathbf{A}$$
即沿闭合环线的环流等于通过该环线所围面积的涡通量。涡度是微观的旋转强度，环流是宏观的积分量。

---

### 2. 绝对涡度与相对涡度

在旋转地球上，空气微团相对于惯性空间的旋转称为**绝对涡度** $\boldsymbol{\omega}_a$，它等于相对涡度 $\boldsymbol{\omega}$ 与地球自转涡度 $2\boldsymbol{\Omega}$ 之和：
$$\boldsymbol{\omega}_a = \boldsymbol{\omega} + 2\boldsymbol{\Omega}$$

其垂直分量为：
$$\zeta_a = \zeta + f$$
其中 $f = 2\Omega \sin \phi$ 为科氏参数（也称为地转涡度或牵连涡度）。

- **相对涡度** $\zeta$：相对于地球的旋转
- **牵连涡度** $f$：地球自转的垂直分量

---

### 3. 涡度方程的一般形式

涡度方程是涡度随时间变化的控制方程，可从水平运动方程推导得到。

#### （1） 直角坐标系中的涡度方程（$z$ 坐标）

不计摩擦的水平动量方程为：
$$\begin{cases}
\displaystyle \frac{\partial u}{\partial t} + u\frac{\partial u}{\partial x} + v\frac{\partial u}{\partial y} + w\frac{\partial u}{\partial z} = -\frac{1}{\rho}\frac{\partial p}{\partial x} + fv \\[1em]
\displaystyle \frac{\partial v}{\partial t} + u\frac{\partial v}{\partial x} + v\frac{\partial v}{\partial y} + w\frac{\partial v}{\partial z} = -\frac{1}{\rho}\frac{\partial p}{\partial y} - fu
\end{cases}$$

将第二式对 $x$ 求偏导，第一式对 $y$ 求偏导，然后相减，并利用 $\zeta = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}$，得到：

$$\begin{aligned}
\frac{\partial \zeta}{\partial t} + u\frac{\partial \zeta}{\partial x} + v\frac{\partial \zeta}{\partial y} + w\frac{\partial \zeta}{\partial z} = & -\beta v - (f+\zeta)\left(\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}\right) \\
& - \left(\frac{\partial w}{\partial x}\frac{\partial v}{\partial z} - \frac{\partial w}{\partial y}\frac{\partial u}{\partial z}\right) \\
& + \frac{1}{\rho^2}\left(\frac{\partial \rho}{\partial x}\frac{\partial p}{\partial y} - \frac{\partial \rho}{\partial y}\frac{\partial p}{\partial x}\right)
\end{aligned}$$

其中 $\beta = \frac{df}{dy}$。

左端为**绝对涡度的个别变化** $\frac{d(\zeta + f)}{dt}$（因为 $\frac{df}{dt} = v\frac{df}{dy} = \beta v$）。于是可写为：

$$\frac{d(\zeta + f)}{dt} = - (f+\zeta)\left(\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}\right) - \underbrace{\left(\frac{\partial w}{\partial x}\frac{\partial v}{\partial z} - \frac{\partial w}{\partial y}\frac{\partial u}{\partial z}\right)}_{\text{扭曲项}} + \underbrace{\frac{1}{\rho^2}\left(\frac{\partial \rho}{\partial x}\frac{\partial p}{\partial y} - \frac{\partial \rho}{\partial y}\frac{\partial p}{\partial x}\right)}_{\text{力管项}}$$

#### （2） 各项物理意义

| 项 | 表达式 | 物理意义 |
| :--- | :--- | :--- |
| 局地变化 | $\frac{\partial \zeta}{\partial t}$ | 固定点涡度随时间变化 |
| 平流项 | $-\mathbf{V}_h\cdot\nabla_h\zeta - w\frac{\partial \zeta}{\partial z}$ | 涡度被气流输送 |
| 散度项 | $-(f+\zeta)\nabla_h\cdot\mathbf{V}_h$ | 水平辐合辐散通过拉伸或压缩改变涡度（最重要项） |
| $\beta$ 项 | $-\beta v$ | 南北运动引起的地转涡度变化 |
| 扭曲项 | $-\left(\frac{\partial w}{\partial x}\frac{\partial v}{\partial z} - \frac{\partial w}{\partial y}\frac{\partial u}{\partial z}\right)$ | 垂直风切变与水平涡管倾斜的相互作用 |
| 力管项 | $\frac{1}{\rho^2}(\nabla\rho\times\nabla p)_z$ | 斜压性产生的涡度，仅当等压面与等密度面相交时存在 |

### 4. 自然坐标系中的涡度表达式

在自然坐标系（$s$ 沿流线，$n$ 垂直流线指向左侧）中，涡度 $\zeta$ 可分解为**曲率涡度**和**切变涡度**两部分：

$$\zeta = \frac{V}{R_s} - \frac{\partial V}{\partial n}$$

- **曲率涡度** $\frac{V}{R_s}$：由流线弯曲引起。气旋式弯曲（$R_s > 0$）产生正涡度；反气旋式弯曲（$R_s < 0$）产生负涡度。
- **切变涡度** $-\frac{\partial V}{\partial n}$：由风速的水平切变引起。当风速随 $n$ 向左递减（$\partial V/\partial n < 0$）时为正涡度（气旋式切变）。

这一分解在锋面、急流和槽脊系统的涡度分析中非常直观。

---

### 5. $p$ 坐标系中的涡度方程

在 $p$ 坐标系中，水平运动方程为：
$$\begin{cases}
\displaystyle \frac{\partial u}{\partial t} + u\frac{\partial u}{\partial x} + v\frac{\partial u}{\partial y} + \omega\frac{\partial u}{\partial p} = -\frac{\partial \Phi}{\partial x} + fv \\[1em]
\displaystyle \frac{\partial v}{\partial t} + u\frac{\partial v}{\partial x} + v\frac{\partial v}{\partial y} + \omega\frac{\partial v}{\partial p} = -\frac{\partial \Phi}{\partial y} - fu
\end{cases}$$

采用与直角坐标系相同的推导方法（$\frac{\partial}{\partial x}(2) - \frac{\partial}{\partial y}(1)$），得到 $p$ 坐标系中的涡度方程：

$$\frac{\partial \zeta_p}{\partial t} + u\frac{\partial \zeta_p}{\partial x} + v\frac{\partial \zeta_p}{\partial y} + \omega\frac{\partial \zeta_p}{\partial p} = -\beta v - (f+\zeta_p)\left(\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}\right) + \left(\frac{\partial \omega}{\partial y}\frac{\partial u}{\partial p} - \frac{\partial \omega}{\partial x}\frac{\partial v}{\partial p}\right)$$

其中 $\zeta_p = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}$ 是 $p$ 面上的相对涡度。

#### $p$ 坐标系涡度方程的特点：
- **没有显式的力管项**：斜压性通过 $\omega$ 与风垂直切变的耦合项（即扭曲项）间接影响涡度。
- **散度项** $-(f+\zeta_p)\left(\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}\right)$ 与 $z$ 坐标系类似。
- **扭曲项** $\frac{\partial \omega}{\partial y}\frac{\partial u}{\partial p} - \frac{\partial \omega}{\partial x}\frac{\partial v}{\partial p}$ 反映了 $\omega$ 场不均匀与风垂直切变的相互作用，可视为 $p$ 坐标系下的“倾斜项”。

---

### 6. 大尺度运动的简化涡度方程

对于中纬度天气尺度运动（$L \sim 10^6\,\text{m}$，$Ro \sim 0.1$），对涡度方程进行尺度分析，可忽略扭曲项和力管项（比主要项小1-2个量级），且 $|\zeta| \ll |f|$，得到：

$$\frac{d_h(\zeta + f)}{dt} = -f\,\nabla_h\cdot\mathbf{V}_h$$

或展开为：
$$\frac{\partial \zeta}{\partial t} + u\frac{\partial \zeta}{\partial x} + v\frac{\partial \zeta}{\partial y} + \beta v = -f\left(\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}\right)$$

- 左端：绝对涡度的水平个别变化
- 右端：散度项（地转涡度 $f$ 与水平散度的乘积）

如果进一步假设水平无辐散（$\nabla_h\cdot\mathbf{V}_h = 0$），则得到**正压无辐散涡度方程**：
$$\frac{d_h(\zeta + f)}{dt} = 0 \quad \text{或} \quad \frac{\partial \zeta}{\partial t} + u\frac{\partial \zeta}{\partial x} + v\frac{\partial \zeta}{\partial y} + \beta v = 0$$
这是罗斯贝波理论的基础。

---

### 7. 涡度方程与散度方程的耦合

在 $p$ 坐标系中，同时存在**散度方程**（由水平运动方程取散度得到）和涡度方程。对于大尺度运动，两者通过散度项耦合。将连续方程 $\nabla_h\cdot\mathbf{V}_h + \frac{\partial \omega}{\partial p}=0$ 代入简化涡度方程，可得：
$$\frac{d_h(\zeta + f)}{dt} = f\frac{\partial \omega}{\partial p}$$
这一关系将涡度变化与垂直速度的垂直切变联系起来，是准地转理论中诊断垂直运动的重要工具。

---

## 小结

| 坐标系 | 涡度定义 | 涡度方程特点 |
| :--- | :--- | :--- |
| 直角坐标系 $(x,y,z)$ | $\zeta = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}$ | 包含完整的平流、散度、扭曲、力管项 |
| 自然坐标系 $(s,n)$ | $\zeta = \frac{V}{R_s} - \frac{\partial V}{\partial n}$ | 清晰分离曲率涡度和切变涡度 |
| $p$ 坐标系 $(x,y,p)$ | $\zeta_p = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}$ | 无显式力管项，斜压性通过扭曲项体现 |
| 大尺度简化 | $\frac{d_h(\zeta+f)}{dt} = -f\nabla_h\cdot\mathbf{V}_h$ | 散度项主导，是准地转理论核心 |

涡度方程是动力气象学中最重要的诊断和预报方程之一，它连接了风场、温度场和垂直运动，是理解天气系统发生发展的关键工具。

### 思考题

> **思考题 1**：水平辐合为什么能使涡度增大？请用角动量守恒（花样滑冰运动员收臂加速旋转）类比，解释散度项 $-(f+\zeta)\nabla_h\cdot\mathbf{V}_h$ 的物理本质——气柱被水平辐合”挤压”时为何转得更快？
>
> **思考题 2**：$p$ 坐标系涡度方程中没有显式的力管项，这是否意味着斜压性不再影响 $p$ 坐标系下的涡度变化？如果不是，斜压性通过方程中的哪个项发挥作用？与 $z$ 坐标系的力管项有何对应关系？
>
> **思考题 3**：正压无辐散涡度方程 $\frac{d_h(\zeta+f)}{dt}=0$ 表明绝对涡度沿水平轨迹守恒。一气块从 $20^\circ N$ 向 $50^\circ N$ 移动时（$f$ 增大），其相对涡度 $\zeta$ 应为负值——这是否与中纬度西风带中自西向东移动的气旋/反气旋的涡度特征一致？
