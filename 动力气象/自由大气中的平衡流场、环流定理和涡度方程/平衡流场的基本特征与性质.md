## 平衡流场的基本特征与性质

### 重点

- 地转风是水平气压梯度力与科里奥利力的精确平衡，满足白贝罗定律（北半球背风而立，高压在右、低压在左），且 $p$ 坐标系下地转风为水平无辐散。
- 梯度风方程 $V_G^2/R_T + fV_G + \frac{1}{\rho}\frac{\partial p}{\partial n}=0$ 是三力平衡的完整形式——气旋中地转风偏大，反气旋中地转风偏小且风速存在物理上限。
- 热成风是地转风随高度的垂直切变，$\mathbf{V}_T = \frac{R}{f}\mathbf{k}\times\nabla_p\overline{T}$，由温度水平梯度驱动，仅在斜压大气中存在。
- 地转偏差 $\mathbf{V}' = \mathbf{V} - \mathbf{V}_g$ 虽量级小（$|\mathbf{V}'| \ll |\mathbf{V}_g|$），但它直接联系水平辐合辐散与垂直运动——高空槽前辐散上升、槽后辐合下沉，是驱动天气系统演变的关键。
- 不同平衡流类型由罗斯贝数 $Ro = V/(fL)$ 区分：$Ro \ll 1$ 为地转流，$Ro \sim 1$ 为梯度流，$Ro \gg 1$ 为旋衡流（龙卷、尘卷风等）。
- 自然坐标系是分析弯曲流场的核心工具——法向方程统一了所有平衡流模型，曲率半径 $R_T$ 的符号区分气旋式与反气旋式环流。
- 从地转风到热成风再到地转偏差，构成了"零级平衡—垂直结构—偏差驱动的天气"的完整认知链条。

### 1. 平衡流场概述

**平衡流场** 是指在自由大气（忽略摩擦）中，水平气压梯度力、科里奥利力和惯性离心力三者达到平衡时所对应的风场。根据不同的平衡组合，可得到多种平衡流模型，它们是实际大气运动状态的一级近似，对理解大尺度环流和天气系统演变具有重要意义。

平衡流场的基本特征：
- **无摩擦**（自由大气，忽略湍流粘性）
- **水平运动为主**（垂直运动次要或忽略）
- **等压面与流线近似重合**（梯度风平衡时，风沿等压线吹）
- **适用于大尺度、中尺度等不同运动**（不同平衡类型主导）

常用的平衡流模型包括：**地转风**、**惯性运动**、**旋衡运动**、**梯度风**、**热成风** 以及 **地转偏差**。

### 2. 地转风（Geostrophic Wind）

#### （1） 定义
地转风是水平气压梯度力与科里奥利力平衡时的水平风场。这是大气运动零级近似的平衡状态。

$$\frac{1}{\rho}\nabla_h p + f \mathbf{k} \times \mathbf{V}_g = 0$$

#### （2） 公式
- 矢量形式：
  $$\mathbf{V}_g = \frac{1}{f\rho} \mathbf{k} \times \nabla_h p$$
- 分量形式（局地直角坐标系）：
  $$u_g = -\frac{1}{f\rho}\frac{\partial p}{\partial y},\quad v_g = \frac{1}{f\rho}\frac{\partial p}{\partial x}$$
- $p$ 坐标系（$\Phi = gz$ 为位势）：
  $$u_g = -\frac{1}{f}\frac{\partial \Phi}{\partial y},\quad v_g = \frac{1}{f}\frac{\partial \Phi}{\partial x}$$

#### （3） 基本特征与性质
- **平衡条件**：等压线平直（曲率半径无穷大），无加速度，无摩擦。
- **适用范围**：中高纬度自由大气的大尺度运动（$Ro \ll 1$），赤道附近 $f \to 0$ 不适用。
- **白贝罗定律**（北半球）：背风而立，高压在右，低压在左；南半球相反。
- **地转风散度**：$p$ 坐标系下 $\nabla_p \cdot \mathbf{V}_g = 0$，即地转风是水平无辐散的。
- **地转风大小**：$V_g = \frac{1}{f\rho}|\nabla_h p|$，与气压梯度成正比，与纬度和密度成反比。
- **定常特性**：地转平衡下风场与气压场配置固定，无加速度。

### 3. 惯性运动（Inertial Motion）

#### （1） 定义
当水平气压梯度力为零时，科里奥利力单独提供向心加速度，气块做惯性圆周运动。

#### （2） 公式
自然坐标系中，法向方程：
$$\frac{V_i^2}{R_T} + f V_i = 0 \quad \Rightarrow \quad R_T = -\frac{V_i}{f}$$
- $V_i$：惯性运动速度（常数）
- $R_T$：轨迹曲率半径

#### （3） 基本特征
- $R_T < 0$ 表明在北半球是反气旋式弯曲（顺时针）。
- 惯性圆半径 $|R_T| = V_i / f$，周期 $T = 2\pi/f$（惯性周期）。
- 实际大气中纯惯性运动罕见，通常与气压梯度共同作用形成梯度风或惯性重力波。
- **特点**：水平气压均匀时，运动轨迹为圆；能量来自初始扰动，无外力维持。

---

### 4. 旋衡运动（Cyclostrophic Motion）

#### （1） 定义
当水平运动尺度很小或风速极大时，惯性离心力远大于科里奥利力，气压梯度力与离心力平衡的运动。常用于龙卷、尘卷风等强涡旋系统。

#### （2） 公式
$$\frac{V_c^2}{R_T} = -\frac{1}{\rho}\frac{\partial p}{\partial n}$$
$$\Rightarrow V_c = \sqrt{-\frac{R_T}{\rho}\frac{\partial p}{\partial n}}$$
要求右端为正，故有两种情形：
- $R_T > 0$（气旋式）且 $\frac{\partial p}{\partial n} < 0$（指向低压）
- $R_T < 0$（反气旋式）且 $\frac{\partial p}{\partial n} > 0$（指向高压）

#### （3） 基本特征
- **适用范围**：小尺度强涡旋（如龙卷、尘卷风），$Ro = V/(fR_T) \gg 1$，科氏力可忽略。
- 龙卷多为气旋式，因初始科氏力使气流右偏，建立绕低压的气旋环流。
- 旋衡风与气压梯度平方根成正比，风速可极大（龙卷可达数十至百米每秒）。

### 5. 梯度风（Gradient Wind）

#### （1） 定义
水平气压梯度力、科里奥利力和惯性离心力三者平衡时的水平风场。它是地转风的曲率修正，适用于有显著弯曲的等压线情形。

#### （2） 公式（自然坐标系）
法向方程：
$$\frac{V_G^2}{R_T} + f V_G + \frac{1}{\rho}\frac{\partial p}{\partial n} = 0$$
解出：
$$V_G = -\frac{f R_T}{2} + \sqrt{\left(\frac{f R_T}{2}\right)^2 - \frac{R_T}{\rho}\frac{\partial p}{\partial n}}$$
其中 $R_T$ 为轨迹曲率半径（气旋式 $R_T>0$，反气旋式 $R_T<0$），$\frac{\partial p}{\partial n}$ 为指向法线（左侧）的气压梯度。

#### （3） 解的选择与特征
- 北半球自然坐标系中，风速 $V_G > 0$，风压定律要求 $\frac{\partial p}{\partial n} < 0$（梯度指向高压）。
- **气旋式环流**（$R_T > 0$）：取“$+$”号，$V_G$ 随 $|\frac{\partial p}{\partial n}|$ 增大而增大，无上限。
- **反气旋式环流**（$R_T < 0$）：取“$+$”号，且存在最大梯度风 $V_{G,\max} = -\frac{f R_T}{2}$，对应最大气压梯度 $|\frac{\partial p}{\partial n}|_{\max} = \frac{\rho f^2 R_T}{4}$。即反气旋内部气压梯度小，风速有上限。

#### （4） 梯度风与地转风比较
$$V_g = -\frac{1}{f\rho}\frac{\partial p}{\partial n},\quad V_G = -\frac{1}{f\rho}\frac{\partial p}{\partial n} \cdot \frac{2}{1 + \sqrt{1 + 4V_g/(f R_T)}}$$
- 气旋中（$R_T>0$）：$V_g > V_G$，地转风偏大。
- 反气旋中（$R_T<0$）：$V_g < V_G$，地转风偏小，且 $V_G \le 2V_g$。

#### （5） 梯度风高度
指风场达到梯度风平衡所需的高度（通常距地面300–500米以上），此高度以上摩擦影响可忽略。

### 6. 热成风（Thermal Wind）

#### （1） 概念
地转风随高度的变化量称为**热成风**，反映了大气斜压性（温度水平梯度）对风场垂直结构的影响。

#### （2） 表达式
- $p$ 坐标系中，地转风 $u_g = -\frac{1}{f}\frac{\partial \Phi}{\partial y}$，$v_g = \frac{1}{f}\frac{\partial \Phi}{\partial x}$。
  对 $p$ 求偏导并利用静力关系 $\frac{\partial \Phi}{\partial p} = -\frac{RT}{p}$ 得：
  $$\frac{\partial u_g}{\partial p} = \frac{R}{f p}\frac{\partial T}{\partial y},\quad \frac{\partial v_g}{\partial p} = -\frac{R}{f p}\frac{\partial T}{\partial x}$$
- 矢量形式：
  $$\mathbf{V}_T = \mathbf{V}_{g}(p_1) - \mathbf{V}_{g}(p_0) = \frac{R}{f} \mathbf{k} \times \nabla_p \overline{T}$$
  其中 $\overline{T}$ 为 $p_0$ 与 $p_1$ 之间的平均温度。

#### （3） 基本特征
- **热成风与等平均温度线平行**：北半球背热成风而立，低温在左，高温在右。
- **风速大小**：$V_T = \frac{R}{f} |\nabla_p \overline{T}|$，与温度梯度成正比，与纬度成反比。锋区温度梯度大，热成风强。
- **仅在斜压大气中存在**：若大气正压（无水平温度梯度），则热成风为零，地转风不随高度变化。

#### （4） 应用：冷暖平流与深厚/浅薄系统
- **冷平流**：风随高度逆转（$u_g$ 随高度减小），低层风由冷区吹向暖区，气层中冷平流。
- **暖平流**：风随高度顺转（$u_g$ 随高度增大），低层风由暖区吹向冷区，气层中暖平流。
- **深厚系统**：如冷低压、暖高压，低空形势在高空加强或维持，热成风方向与实际风一致。
- **浅薄系统**：如冷高压、暖低压，低空形势在高空削弱甚至反转，热成风方向与实际风相反。

### 7. 地转偏差（Ageostrophic Wind）

#### （1） 定义
实际风 $\mathbf{V}$ 与地转风 $\mathbf{V}_g$ 之差：
$$\mathbf{V}' = \mathbf{V} - \mathbf{V}_g$$

#### （2） 边界层中的地转偏差（有摩擦）
平衡方程：$-\frac{1}{\rho}\nabla_h p - f\mathbf{k}\times\mathbf{V} + \mathbf{F} = 0$  
代入地转关系得：
$$\mathbf{V}' = \frac{1}{f} \mathbf{k} \times \mathbf{F}$$
**特征**：地转偏差指向摩擦力的右侧（北半球），与摩擦力垂直。它使实际风穿越等压线，导致水平辐合辐散，驱动垂直运动。

#### （3） 自由大气中的地转偏差（无摩擦）
由水平运动方程：
$$\frac{d\mathbf{V}}{dt} = -f\mathbf{k}\times(\mathbf{V} - \mathbf{V}_g) \quad \Rightarrow \quad \mathbf{V}' = \frac{1}{f} \mathbf{k} \times \frac{d\mathbf{V}}{dt}$$
**特征**：地转偏差指向加速度的左侧（北半球），与加速度垂直。将加速度分解为局地变化、平流等，可得：
- **变压风**：$\frac{1}{f}\mathbf{k}\times\frac{\partial\mathbf{V}}{\partial t}$，与变压梯度有关。
- **水平平流项**：$\frac{1}{f}\mathbf{k}\times(\mathbf{V}\cdot\nabla)\mathbf{V}$，可分解为法向偏差（等压线辐合辐散）和切向偏差（曲率效应）。

#### （4） 地转偏差的天气意义
- 地转偏差虽小（$|\mathbf{V}'| \ll |\mathbf{V}_g|$），但它是造成天气系统演变和垂直运动的关键。
- **高空槽前**：偏差风辐散 → 上升运动 → 降水。
- **高空槽后**：偏差风辐合 → 下沉运动 → 晴好天气。

## 小结

| 平衡流类型 | 平衡力 | 适用条件 | 关键性质 |
| :--- | :--- | :--- | :--- |
| 地转风 | PGF = Cor | 大尺度，平直等压线，无摩擦 | 水平无辐散，白贝罗定律 |
| 惯性运动 | Cor = 离心力 | 无 PGF | 反气旋式圆，周期 $2\pi/f$ |
| 旋衡运动 | PGF = 离心力 | 小尺度强涡旋，$Ro\gg 1$ | 气旋式为主，风速可极大 |
| 梯度风 | PGF + Cor = 离心力 | 弯曲等压线 | 气旋风速无上限，反气旋有上限 |
| 热成风 | 地转风随高度变化 | 斜压大气 | 反映温度平流，判断系统深浅 |
| 地转偏差 | 非平衡剩余 | 任何有加速度的情形 | 驱动辐合辐散，联系垂直运动 |

这些平衡流场模型构成了动力气象学中分析大气运动和天气系统的基础。

### 思考题

> **思考题 1**：为什么反气旋式梯度风存在风速上限，而气旋式梯度风不存在？这一差异如何解释副热带高压（反气旋）内部气压梯度总是很小，而台风（气旋）中心附近气压梯度可以极大？
>
> **思考题 2**：地转风是水平无辐散的，但实际大气中地转偏差却能产生显著的辐合辐散和垂直运动——请从连续方程 $\nabla_h\cdot\mathbf{V} = -\frac{\partial\omega}{\partial p}$ 出发，解释这两者之间如何通过偏差风耦合。
>
> **思考题 3**：冷平流时”风随高度逆转”，暖平流时”风随高度顺转”——用热成风关系 $\mathbf{V}_T = \frac{R}{f}\mathbf{k}\times\nabla_p\overline{T}$ 说明，为什么冷平流区低层风从冷区吹向暖区，且风随高度向低温方向逆转？
>
> **思考题 4**：如果大气完全是正压的（$\nabla_p T = 0$），地转风随高度不变。在此情形下，仅靠地转风场能否维持天气系统的发生和发展？地转偏差在其中起什么作用？
