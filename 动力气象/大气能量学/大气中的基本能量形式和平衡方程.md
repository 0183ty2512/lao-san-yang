## 大气中的基本能量形式和平衡方程

### 重点

- 大气中存在五种基本能量形式——位能（$gz$）、内能（$c_v T$）、动能（$\frac{1}{2}V^2$）、潜热能（$Lq$）、压力能（$RT$），它们通过状态方程和静力平衡相互关联。
- 内能与位能之间存在固定比例关系：$$\Phi^* = \frac{R}{c_v} I^* \approx 0.4 I^*$$，这一关系源于静力平衡与理想气体状态方程的联合约束，意味着加热大气时位能的增加必然伴随内能的增加。
- 实际应用中常将基本能量组合为全位能（$c_v T + gz$）、显热能/焓（$c_p T$）、湿静力能（$c_p T + gz + Lq$）等形式——组合的核心目的是将相互耦合的能量统一描述，简化能量收支分析。
- 压力能与位能在静力平衡下数值相等（$$\Phi^* = J^* = \int_0^{p_0} \frac{RT}{g} dp$$），这解释了为何显热能 $c_p T$ 能同时代表内能与压力能之和，而非静力平衡条件下此关系不成立。
- 动能与全位能之间的转换通过 $$\int_M \alpha \omega \, dM$$ 实现：暖空气上升（$T>0, \omega<0$）、冷空气下沉时该项为负，全位能转换为动能；反之动能转换为全位能。**垂直运动与温度的协方差**是能量转换的物理核心。
- 在绝热无摩擦的封闭系统中，总能量守恒：$$\frac{\partial}{\partial t}\int_M (K+E)\,dM = 0$$，全位能与动能此消彼长，摩擦耗散和非绝热加热是仅有的外部源汇。
- 穿越等压线的水平运动（地转偏差）是动能源——气压梯度力在水平方向上做功 $$-\mathbf{V}_h\cdot\nabla_h\Phi$$，只有穿越等压线的风分量（即非地转风）才能参与能量转换，纯地转风不做功。
- 各种能量组合形式（干静力能、湿静力能、总能量）在特定大气过程中分别守恒，为诊断分析提供了有力工具：例如湿静力能在湿绝热过程中近似守恒，可用于追踪气块来源。

### 1. 大气中的基本能量形式

大气中的能量存在多种形式，它们之间可以相互转换。以下以单位质量空气或单位截面积铅直气柱的形式给出。

#### （1） 重力位能（位能）

单位质量空气的重力位能为：
$$\Phi = gz$$

对于高度为 $h$ 的单位截面积铅直气柱，总位能为：
$$\Phi^* = \int_0^h \rho gz \, dz = -\int_{p_0}^{p_h} z \, dp$$

当 $h \to \infty$（$p_h \to 0$）且地面 $z=0$ 时：
$$\Phi^* = \int_0^{p_0} \frac{RT}{g} \, dp$$

#### （2） 内能

单位质量空气的内能为：
$$I = c_v T$$

其中 $c_v = 717\,\text{J}\cdot\text{kg}^{-1}\cdot\text{K}^{-1}$ 为干空气定容比热。

单位截面积铅直气柱的总内能为：
$$I^* = \int_0^h \rho c_v T \, dz = \int_0^{p_0} \frac{c_v T}{g} \, dp$$

**内能与位能的关系**：利用状态方程和静力平衡，可得：
$$\Phi^* = \frac{R}{c_v} I^* \approx 0.4 I^*$$
即大气的位能约为内能的40%。

#### （3） 动能

单位质量空气的动能为：
$$K = \frac{1}{2}(u^2 + v^2 + w^2)$$

对于大尺度运动，$w \ll u,v$，通常只考虑水平动能：
$$K_h = \frac{1}{2}(u^2 + v^2)$$

单位截面积铅直气柱的总动能为：
$$K^* = \int_0^h \rho K \, dz = \int_0^{p_0} \frac{K}{g} \, dp$$

#### （4） 潜热能

单位质量空气的潜热能（水汽全部凝结释放的热量）为：
$$H = L q$$

其中 $L$ 为相变潜热（$L_v \approx 2.5\times10^6\,\text{J}\cdot\text{kg}^{-1}$ 为汽化潜热），$q$ 为比湿。

单位截面积气柱的总潜热能为：
$$H^* = \int_0^h \rho L q \, dz = \int_0^{p_0} \frac{L q}{g} \, dp$$

#### （5） 压力能

单位质量空气的压力能为：
$$J = \alpha p = RT$$

单位截面积气柱的压力能为：
$$J^* = \int_0^h \rho RT \, dz = \int_0^{p_0} \frac{RT}{g} \, dp = \Phi^*$$
即压力能与位能数值相等（在静力平衡下）。

### 2. 基本能量形式的组合

实际应用中常将上述基本能量组合成新的物理量，以简化能量转换分析。

| 组合名称 | 表达式 | 说明 |
| :--- | :--- | :--- |
| **显热能（焓）** | $h = c_p T$ | 内能 + 压力能，仅与温度有关 |
| **全位能** | $P = c_v T + gz$ | 内能 + 位能，两者变化一致 |
| **温湿能（湿焓）** | $h_m = c_p T + L q$ | 显热能 + 潜热能 |
| **干静力能** | $\Phi_d = c_p T + gz$ | 显热能 + 位能（蒙哥马利位势） |
| **湿静力能** | $\Phi_m = c_p T + gz + L q$ | 干静力能 + 潜热能 |
| **总能量** | $E_{\text{total}} = c_v T + gz + \frac{V^2}{2} + L q$ | 内能 + 位能 + 动能 + 潜热能 |

### 3. 大气能量方程

#### （1） 动能方程

从 $p$ 坐标系水平运动方程出发：
$$\frac{\partial \mathbf{V}_h}{\partial t} + (\mathbf{V}_h\cdot\nabla)\mathbf{V}_h + \omega\frac{\partial \mathbf{V}_h}{\partial p} = -\nabla_h\Phi - f\mathbf{k}\times\mathbf{V}_h + \mathbf{F}_r$$

两边点乘 $\mathbf{V}_h$，并利用 $\mathbf{V}_h\cdot(f\mathbf{k}\times\mathbf{V}_h)=0$：
$$\frac{\partial K}{\partial t} + \mathbf{V}_h\cdot\nabla K + \omega\frac{\partial K}{\partial p} = -\mathbf{V}_h\cdot\nabla_h\Phi + \mathbf{V}_h\cdot\mathbf{F}_r$$
其中 $K = \frac{1}{2}(u^2+v^2)$ 为单位质量动能。

**物理意义**：
- 左端：动能的局地变化 + 平流 + 垂直输送
- 右端第一项：气压梯度力做功（穿越等压线时转换能量）
- 右端第二项：摩擦力做功（耗散，$\mathbf{V}_h\cdot\mathbf{F}_r < 0$）

**封闭系统**（边界无质量交换）的动能积分形式：
$$\frac{\partial}{\partial t}\int_M K\,dM = -\int_M \mathbf{V}_h\cdot\nabla_h\Phi\,dM - \int_M D\,dM$$
其中 $D = -\mathbf{V}_h\cdot\mathbf{F}_r > 0$ 为摩擦耗散率。

利用连续方程，可将 $-\mathbf{V}_h\cdot\nabla_h\Phi$ 改写为：
$$-\mathbf{V}_h\cdot\nabla_h\Phi = -\nabla_h\cdot(\Phi\mathbf{V}_h) - \alpha \omega$$
代入体积分，散度项积分后由边界条件（刚壁）为零，得：
$$\frac{\partial}{\partial t}\int_M K\,dM = -\int_M \alpha \omega \, dM - \int_M D\,dM$$

#### （2） 全位能方程

全位能 $E = c_v T + gz = c_p T - RT + gz$，在 $p$ 坐标系下常用形式为 $E = c_p T$（因为 $c_p T$ 已包含内能和压力能）。热力学第一定律：
$$c_p\frac{dT}{dt} - \alpha \omega = \dot{Q}$$

写成全位能形式：
$$\frac{dE}{dt} - \alpha \omega = \dot{Q}$$
利用连续方程，可导出全位能的积分方程为：
$$\frac{\partial}{\partial t}\int_M E\,dM = \int_M \alpha \omega \, dM + \int_M \dot{Q}\,dM$$

#### （3） 闭合系统中的能量转换

动能方程与全位能方程中均出现 $\int_M \alpha \omega \, dM$，但符号相反。因此该项是**动能与全位能之间的转换项**：
- $\int_M \alpha \omega \, dM < 0$：全位能减少，动能增加（$\text{全位能} \to \text{动能}$）
- $\int_M \alpha \omega \, dM > 0$：动能减少，全位能增加（$\text{动能} \to \text{全位能}$）

**转换的物理条件**：
$$\int_M \alpha \omega \, dM = \int_M \frac{RT}{p} \omega \, dM \propto \int_M T \omega \, dM$$
- 暖空气上升（$T>0,\omega<0$）、冷空气下沉（$T>0,\omega>0$） → $T\omega < 0$ → 全位能转换为动能
- 相反配置则动能转换为全位能

**绝热无摩擦闭合系统的总能量守恒**：
$$\frac{\partial}{\partial t}\int_M (K+E)\,dM = 0$$

### 4. 能量方程在纬向平均和涡动分解中的应用（简介）

将大气运动分解为纬向平均部分（$\overline{A}$，沿纬圈的平均）和涡动部分（$A'$，扰动），可得到平均动能、涡动动能、平均有效位能、涡动有效位能的收支方程，以及它们之间的转换项（如 $\{\overline{A},\overline{K}\}$、$\{A',K'\}$ 等）。这些转换关系构成了大气环流能量循环的基础，详见教材第七章。

## 小结

| 能量形式 | 表达式 | 组合 |
| :--- | :--- | :--- |
| 位能 | $gz$ | 全位能 $= c_vT + gz$ |
| 内能 | $c_vT$ | 显热能 $= c_pT$ |
| 动能 | $\frac12(u^2+v^2)$ | 总能量 $= c_vT + gz + K + Lq$ |
| 潜热能 | $Lq$ | 湿静力能 $= c_pT + gz + Lq$ |
| 压力能 | $RT$ | — |

能量转换的关键是**垂直运动**（$\omega$）与**温度**的相关系数，以及**穿越等压线的水平运动**（地转偏差）。全位能与动能之间的转换通过 $\int \alpha \omega \, dM$ 实现，而摩擦和非绝热加热则为外部源汇。

## 思考题

> **思考题 1**：为什么全位能不能全部转化为动能？从能量转换项 $\int_M \alpha \omega \, dM$ 的物理意义出发，结合参考状态和正压大气的性质，说明实际大气中限制全位能释放的主要因素。

> **思考题 2**：压力能与位能数值相等（$\Phi^* = J^*$），但它们是不同类型的能量。请推导这一等式的物理根源，并讨论：在非静力平衡条件下（如强对流云内），这一关系是否仍然成立？为什么？

> **思考题 3**：在绝热无摩擦条件下，动能方程和全位能方程中 $\int_M \alpha \omega \, dM$ 项符号相反。请从热力学第一定律和运动方程出发，推导这一结果，并解释为什么符号相反恰恰体现了全位能与动能之间的双向转换关系。

> **思考题 4**：温湿能（湿焓）$h_m = c_p T + L q$ 将显热能和潜热能组合在一起。在哪些大气过程中，这种组合比分别考虑 $c_p T$ 和 $L q$ 更为方便？请结合湿绝热过程或对流参数化中的实际应用举例说明。

> **思考题 5**：动能方程中，水平气压梯度力做功项 $-\mathbf{V}_h\cdot\nabla_h\Phi$ 可分解为散度项和 $-\alpha\omega$ 项。为什么纯地转风不做功？请从地转风与等压线的关系出发给出物理解释。
