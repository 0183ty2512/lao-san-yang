## 有效位能

### 重点

- 有效位能（APE）的本质是**实际大气全位能与绝热调整后最小全位能状态之差**——等价于大气中真正有可能转换为动能的那部分全位能。Lorenz（1955）提出这一概念，解决了"全位能巨大但极少能释放"的悖论。
- 参考状态（最小全位能状态）需满足三个条件：等压面与等温面重合（正压性）、层结稳定、全位能达到极小值。这意味着所有等熵面趋于水平，温度场水平均匀，无水平温度梯度则无力管驱动运动。
- 有效位能的近似表达式 $$A' = \frac{1}{2} \frac{\bar{T}}{\gamma_d - \gamma} \left( \frac{T'}{\bar{T}} \right)^2$$ 表明 APE 正比于**温度扰动方差**——水平温度梯度（斜压性）越强，APE 越大，因此 APE 也被称为**斜压能**。
- 有效位能也可通过浮力频率 $N^2$ 和位温扰动表达：$$A' = \frac{1}{2} \frac{g}{N^2} \left( \frac{\theta'}{\bar{\theta}} \right)^2$$，层结越稳定（$N^2$ 越大），单位位温扰动储存的 APE 越小——强稳定层结抑制了 APE 的积累。
- 表达式中 $\gamma_d - \gamma$ 出现在分母：当层结趋于中性（$\gamma \to \gamma_d$）时，有效位能趋于无穷大，这反映了中性层结下微小的温度扰动即可驱动强对流——APE 更易释放而非积累。
- 在全球能量循环中，有效位能只占全位能的约 **1/200**，而真正转换为动能的仅约有效位能的 **1/10**——可见大气是一台效率极低的"热机"，绝大部分能量以辐射形式耗散回太空。
- 有效位能可分解为纬向平均有效位能 $\overline{A}$ 和涡动有效位能 $A'$，二者分别通过经圈环流（平均经圈翻转）和斜压涡动（天气尺度波动）向动能转换，构成了 Lorenz 能量循环的核心框架。
- 锋区、急流区、风暴轴等**强斜压区**是有效位能的主要储存库——这些区域的水平温度梯度大，APE 密度高，是气旋生成和发展的能量来源。

### 1. 为什么需要有效位能？

大气运动的最终能源是太阳辐射，但辐射能不能直接转换为动能。在静力平衡大气中，太阳辐射能首先以全位能（内能+位能）的形式储存，只有通过穿越等压线的水平运动（即地转偏差），全位能才可能转换为动能。

然而，大气中的全位能绝大部分不能转换为动能。例如，一个正压、水平温度均匀、层结稳定的大气，虽然具有巨大的全位能，但无法释放为动能，因为没有力管驱动运动。因此，我们需要一个概念来描述 **"实际大气中真正有可能转换为动能的那部分全位能"**。

### 2. 有效位能的定义（Lorenz, 1955）

**有效位能**（Available Potential Energy, APE）是指：**大气现有状态下的全位能与经过绝热调整后达到某一参考状态时具有的全位能之差**。参考状态的选择原则是：在绝热调整过程中，大气满足静力平衡，且调整终态具有正压性（等压面与等温面重合）和稳定的层结，并且该终态的全位能是可能的最小值。

$$A^* = P^* - P_{\min}^* = \int_M c_p (T - T_e) \, dM$$

- $P^*$：实际大气的全位能
- $P_{\min}^*$：经绝热调整后参考状态的全位能
- $T$：实际温度
- $T_e$：参考状态的温度

**物理意义**：有效位能是大气中全位能向动能转换的最大可能值。它代表在绝热无摩擦条件下，大气能够释放出来转变为动能的那部分位能。

### 3. 有效位能的表达式（近似）

#### （1） 参考状态的选择

参考状态（通常称为"最小全位能状态"）需满足：
- 等压面与等温面重合，温度场水平均匀（无水平温度梯度）
- 层结稳定（位温随高度增加）
- 质量分布使得总位能最小
实际调整过程是：空气微团在等熵面上绝热移动，重新排列，使等熵面趋于水平（即所有等位温面变成水平面），此时风场为零，全位能达到最小。

#### （2） 单位质量气块的有效位能（气块法）

考虑一个静止、正压、层结稳定的参考大气。将单位质量气块从高度 $z_0$ 绝热抬升到 $z_1$，由于层结稳定，气块受到回复力（浮力）。反抗净浮力所做的功即为该气块的有效位能。

由浮力振荡理论，回复力为 $B = -N^2 z$，其中 $N^2 = g \frac{\partial \ln \bar{\theta}}{\partial z}$ 为浮力频率。从 $z=0$ 抬升到 $z_1$ 反抗浮力做功：
$$W = \int_0^{z_1} N^2 z \, dz = \frac{1}{2} N^2 z_1^2$$

利用位温差 $\theta' = \bar{\theta}(0) - \bar{\theta}(z_1) = -\frac{\partial \bar{\theta}}{\partial z} z_1$，得：
$$W = \frac{1}{2} N^2 \left( \frac{\theta'}{\partial \bar{\theta}/\partial z} \right)^2$$

因此，单位质量空气的有效位能可近似为：
$$A' = \frac{1}{2} \frac{g}{\gamma_d - \gamma} \left( \frac{\theta'}{\bar{\theta}} \right)^2 \approx \frac{1}{2} \frac{\bar{T}}{\gamma_d - \gamma} \left( \frac{T'}{\bar{T}} \right)^2$$

其中 $\gamma_d = g/c_p$ 为干绝热递减率，$\gamma = -\partial T/\partial z$ 为环境递减率。

#### （3） 单位截面积气柱的有效位能

对铅直气柱积分：
$$\overline{A'} = \int_0^{p_0} \frac{1}{2} \frac{\bar{T}}{\gamma_d - \gamma} \left( \frac{T'}{\bar{T}} \right)^2 \frac{dp}{g}$$

或写成：
$$\overline{A'} = \int_0^{p_0} \frac{g}{2N^2} \left( \frac{\theta'}{\bar{\theta}} \right)^2 \frac{dp}{g} = \frac{1}{2} \int_0^{p_0} \frac{1}{N^2} \left( \frac{\theta'}{\bar{\theta}} \right)^2 dp$$

### 4. 有效位能的性质

| 性质 | 说明 |
| :--- | :--- |
| **正值性** | 实际大气总是偏离正压状态，故 $A^* > 0$，仅当大气完全正压且层结稳定时 $A^*=0$ |
| **可转换性** | 只有部分有效位能可转换为动能，实际转换效率有限 |
| **与斜压性对应** | 有效位能反映了大气水平温度梯度造成的斜压能量，因此也称为**斜压能** |
| **守恒性** | 在绝热无摩擦条件下，全球有效位能与动能之和守恒 |
| **计算方法** | 可由温度（或位温）扰动场估算，无需显式计算参考状态 |

---

### 5. 有效位能在大气能量循环中的角色

在全球大气能量循环中（见第七章第8节），有效位能进一步分解为**纬向平均有效位能 $\overline{A}$** 和**涡动有效位能 $A'$**。

能量转换路径：
- **非绝热加热**（太阳辐射、凝结潜热等）产生有效位能（$\{\overline{Q},\overline{A}\} > 0$，$\{Q',A'\} > 0$）
- 平均有效位能通过经圈环流向平均动能转换（$\{\overline{A},\overline{K}\}$）
- 涡动有效位能通过斜压波流向涡动动能转换（$\{A',K'\}$）
- 平均动能与涡动动能之间通过正压过程转换（$\{K',\overline{K}\}$）

典型数值（北半球年平均）：
- 有效位能约占全位能的 $1/200$
- 只有约 $1/10$ 的有效位能真正转换为动能
- 动能只占全位能的 $1/2000$

---

### 6. 应用举例

- **锋生与气旋生成**：斜压区（锋区）水平温度梯度大，有效位能高。当高空槽前暖平流叠加在低层锋区上时，有效位能释放，转换为气旋的旋转动能，导致气旋发展。
- **风暴轴**：冬季中纬度海洋上空的强斜压区是有效位能的最大储存库，驱动风暴轴上的气旋频繁生成。
- **正压化过程**：随着斜压不稳定波的发展，有效位能逐渐消耗，大气趋于正压，能量循环减弱。

## 小结

| 概念 | 定义 | 意义 |
| :--- | :--- | :--- |
| 有效位能（APE） | 实际全位能与最小全位能之差 | 可转换为动能的最大可能能量 |
| 参考状态 | 绝热调整后水平均质、稳定层结的正压大气 | 全位能最小 |
| 表达式 | $A^* = \frac12 \int \frac{\bar{T}}{\gamma_d-\gamma}\left(\frac{T'}{\bar{T}}\right)^2 \frac{dp}{g}$ | 由温度扰动估算 |
| 与斜压性的关系 | 斜压性越强，$A^*$ 越大 | 又称斜压能 |
| 全球能量循环 | 非绝热加热 → 有效位能 → 动能 | 能量循环的关键环节 |

## 思考题

> **思考题 1**：为什么在正压大气中有效位能为零？请从有效位能的定义出发，结合参考状态（等压面与等温面重合、层结稳定、全位能最小）的三个条件给出严格论证。

> **思考题 2**：有效位能的近似表达式 $$A' = \frac{1}{2} \frac{\bar{T}}{\gamma_d - \gamma} \left( \frac{T'}{\bar{T}} \right)^2$$ 的分母中含有 $\gamma_d - \gamma$（干绝热递减率与环境递减率之差）。请分析：当大气层结趋于中性（$\gamma \to \gamma_d$）时，有效位能的表达式会出现什么行为？这一数学行为的物理含义是什么——是意味着 APE 无穷大，还是该近似公式在此条件下失效？

> **思考题 3**：有效位能被称为"斜压能"。请阐述水平温度梯度、力管（单位压容管，$\oint -\alpha\,dp$）和有效位能三者之间的物理联系，并说明为什么正压大气即使具有巨大的全位能也无法驱动运动。

> **思考题 4**：在 Lorenz 能量循环框架中，非绝热加热产生有效位能，有效位能再转换为动能。请思考：局地的非绝热加热（如热带对流降水释放凝结潜热）是通过什么机制在全球尺度上维持有效位能的？低纬度的潜热释放与中纬度的斜压区之间存在怎样的能量输送关系？

> **思考题 5**：为什么有效位能只占全位能的极小一部分（约 1/200）？请从大气静力平衡的约束（$\Phi^* \approx 0.4 I^*$）、全位能的量级估算和水平温度扰动的统计特征出发，给出定量或半定量的物理解释。
