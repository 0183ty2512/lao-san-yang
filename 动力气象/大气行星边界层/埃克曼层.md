## 埃克曼层（Ekman Layer）

### 重点

1. 埃克曼层是湍流粘性力、科里奥利力和水平气压梯度力三力平衡下的物理模型，三者共同决定边界层风场的垂直结构。
2. 埃克曼螺线描述了风矢端迹随高度增加螺旋趋近地转风的特征——北半球风向随高度顺时针旋转（向右转）。
3. 地面风速为零（无滑移条件），风向与地转风夹角为 $45^\circ$（常数 $K_m$ 假设下），实际观测中该偏角通常仅 $10^\circ\text{–}30^\circ$。
4. 参数 $\gamma = \sqrt{f_0/(2K_m)}$ 是决定螺线旋转速率和边界层厚度的核心尺度因子，$\gamma^{-1} = H_E$ 即为埃克曼标高。
5. 埃克曼抽吸是边界层与自由大气动力耦合的关键机制——边界层顶的垂直速度 $w_E = \frac{1}{2} H_E \zeta_g$ 与地转涡度成正比。
6. 旋转减弱时间尺度 $\tau_E \sim 5$ 天，与中纬度气旋的典型衰亡时间一致，表明埃克曼抽吸是天气系统衰减的主要机械耗散机制。
7. 常数 $K_m$ 假设是该理论最主要局限——实际大气中 $K_m$ 随高度、层结稳定度剧烈变化，使实际风廓线偏离理想埃克曼螺线。

### 1. 埃克曼层的定义与基本假设

**埃克曼层**是行星边界层中从近地面层顶（约几十米）到梯度风高度（约500–1500米）之间的气层。在这一层中，湍流粘性力、科里奥利力和水平气压梯度力三者共同作用，风向随高度显著旋转，风速逐渐增大并趋近于地转风。

为了得到埃克曼层的解析解，通常作以下简化假设：

1. **水平均匀**：$\frac{\partial}{\partial x} = \frac{\partial}{\partial y} = 0$（忽略水平平流）
2. **定常**：$\frac{\partial}{\partial t} = 0$
3. **正压边界层**：水平气压梯度力不随高度变化，即地转风 $\mathbf{V}_g$ 为常数
4. **密度常数**：$\rho = \rho_0$（Boussinesq 近似）
5. **湍流粘性系数 $K_m$ 为常数**（不随高度变化）
6. **$f$ 平面近似**：$f = f_0$ 常数
7. **忽略分子粘性**（湍流粘性主导）

### 2. 埃克曼层控制方程

在上述假设下，平均动量方程简化为：

$$0 = f_0(v - v_g) + K_m \frac{d^2 u}{dz^2}$$

$$0 = -f_0(u - u_g) + K_m \frac{d^2 v}{dz^2}$$

其中 $(u_g, v_g)$ 为地转风分量（常数），$(u, v)$ 为边界层内实际平均风。

引入复数变量：
$$W = (u - u_g) + i(v - v_g)$$

将两个方程合并为一个复数方程：
$$K_m \frac{d^2 W}{dz^2} - i f_0 W = 0$$

### 3. 方程求解

特征方程：$K_m r^2 - i f_0 = 0 \quad \Rightarrow \quad r^2 = \frac{i f_0}{K_m}$

利用 $\sqrt{i} = \frac{1+i}{\sqrt{2}}$，得：
$$r = \pm (1+i)\gamma,\quad \gamma = \sqrt{\frac{f_0}{2K_m}}$$

因此通解为：
$$W = A e^{(1+i)\gamma z} + B e^{-(1+i)\gamma z}$$

为使解在 $z \to \infty$ 时有界（$W$ 有限），必须 $A = 0$。故：
$$W = W_0 e^{-(1+i)\gamma z}$$
其中 $W_0 = W(0) = (u_0 - u_g) + i(v_0 - v_g)$ 为下边界（$z=0$）处的偏差。

### 4. 下边界条件

通常假设在 $z=0$ 处风速为零（无滑移条件）：
$$u(0) = 0,\quad v(0) = 0$$
因此：
$$W_0 = -u_g - i v_g$$

代入得：
$$W = -(u_g + i v_g) e^{-(1+i)\gamma z}$$

### 5. 埃克曼螺线解

将实部与虚部分离，利用欧拉公式 $e^{-i\gamma z} = \cos(\gamma z) - i\sin(\gamma z)$：

$$u = u_g \left[ 1 - e^{-\gamma z} \cos(\gamma z) \right] - v_g e^{-\gamma z} \sin(\gamma z)$$
$$v = v_g \left[ 1 - e^{-\gamma z} \cos(\gamma z) \right] + u_g e^{-\gamma z} \sin(\gamma z)$$

若选择坐标系使得地转风沿 $x$ 轴（$v_g = 0$），则：
$$u = u_g \left[ 1 - e^{-\gamma z} \cos(\gamma z) \right]$$
$$v = u_g e^{-\gamma z} \sin(\gamma z)$$

**埃克曼螺线**：以 $(u, v)$ 为坐标绘制的风矢端迹，随高度增加呈螺旋形趋向于 $(u_g, 0)$。

### 6. 重要特征参数

- **埃克曼标高** $H_E$：
  $$H_E = \sqrt{\frac{2K_m}{f_0}} = \frac{1}{\gamma}$$
  物理意义：湍流粘性力与科氏力量级相当的特征高度。

- **埃克曼厚度** $D_E$：
  $$D_E = \frac{\pi}{\gamma} = \pi H_E$$
  通常认为在 $z = D_E$ 处，风向与地转风首次重合（$v=0$），此后风向围绕地转风微弱摆动。

- **梯度风高度** $H_B$：
  $$H_B = \pi H_E = D_E$$
  在此高度以上，湍流摩擦力可忽略，大气近似为自由大气。

### 7. 埃克曼层的风场特征

| 高度 $z$ | 风速 $V$ | 风向与地转风夹角 $\theta$ |
| :--- | :--- | :--- |
| $z=0$ | $0$ | $45^\circ$（北半球，风向偏左于地转风） |
| $z = H_E$ | $\approx 0.80 u_g$ | $\approx 22.5^\circ$ |
| $z = D_E = \pi H_E$ | $\approx u_g (1+e^{-\pi}) \approx 1.043 u_g$（稍有超调） | $0^\circ$（首次重合） |
| $z \to \infty$ | $\to u_g$ | $\to 0^\circ$ |

- **风的旋转方向**：北半球，随高度增加，风向顺时针旋转（向右转），从地面与等压线交角 $45^\circ$ 逐渐变为与等压线平行。
- **速度超调**：在 $z \approx \pi H_E/2$ 附近，风速可略大于地转风（最大约 $1.043 u_g$）。

### 8. 埃克曼抽吸（Ekman Pumping）

由于埃克曼层中风向偏向低压一侧（北半球），产生水平质量辐合或辐散，进而驱动垂直运动。

对连续方程积分（从 $z=0$ 到 $z=\infty$，假设 $w(0)=0$）：
$$w(\infty) = -\int_0^\infty \left( \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} \right) dz$$

利用地转关系 $\frac{\partial u_g}{\partial x}=0$（假设地转风沿 $x$ 方向），可导出埃克曼层顶的垂直速度：
$$w_E = \left( \frac{K_m}{2f_0} \right)^{1/2} \zeta_g = \frac{1}{2} H_E \zeta_g$$
其中 $\zeta_g = \frac{\partial v_g}{\partial x} - \frac{\partial u_g}{\partial y}$ 为地转涡度。

- **气旋区**（$\zeta_g > 0$）：$w_E > 0$，边界层顶上升，自由大气中产生水平辐散，削弱气旋。
- **反气旋区**（$\zeta_g < 0$）：$w_E < 0$，边界层顶下沉，自由大气中产生水平辐合，削弱反气旋。

这种由边界层摩擦强迫产生的垂直运动称为 **埃克曼抽吸** 或 **埃克曼泵**。

### 9. 旋转减弱（Spin-down）

埃克曼抽吸将边界层内的辐合/辐散效应传递到自由大气中，导致自由大气涡度随时间衰减。在正压近似下，自由大气涡度满足：
$$\frac{\partial \zeta_g}{\partial t} = \frac{f_0 w_E}{H} = -\frac{f_0}{H} \sqrt{\frac{K_m}{2f_0}} \zeta_g$$

解得：
$$\zeta_g(t) = \zeta_g(0) e^{-t/\tau_E}$$
其中旋转减弱时间尺度：
$$\tau_E = \frac{H}{\sqrt{f_0 K_m / 2}} \approx \frac{H}{f_0 H_E}$$

取 $H \sim 10^4\,\text{m}$，$K_m \sim 10\,\text{m}^2/\text{s}$，$f_0 \sim 10^{-4}\,\text{s}^{-1}$，则 $\tau_E \sim 4.5\times10^5\,\text{s} \approx 5$ 天。这一时间尺度与中纬度气旋的自然消亡时间一致，表明**埃克曼抽吸是天气系统衰减的主要机制**，远比分子粘性耗散（约115天）重要。

### 10. 埃克曼层解的局限性

- **$K_m$ 常数假设**：实际中 $K_m$ 随高度、层结稳定度变化，非中性层结下需用更复杂的参数化（如 Monin-Obukhov 相似理论）。
- **水平均匀假设**：对于锋区、急流等强水平梯度区域，平流项不可忽略。
- **忽略非静力过程**：强对流、山地波等情形下不适用。
- **观测与理论偏差**：实际边界层中，地面风向与地转风夹角通常小于 $45^\circ$（约 $10^\circ\text{–}30^\circ$），风速廓线也偏离理想埃克曼螺线。

## 小结

| 参数 | 符号 | 表达式 | 典型值 |
| :--- | :--- | :--- | :--- |
| 埃克曼标高 | $H_E$ | $\sqrt{2K_m/f_0}$ | 200–1000 m |
| 埃克曼厚度 | $D_E$ | $\pi H_E$ | 600–3000 m |
| 地面风向偏角 | $\alpha$ | $45^\circ$（常数 $K_m$ 假设） | 实际 $10^\circ\text{–}30^\circ$ |
| 埃克曼抽吸速度 | $w_E$ | $\frac{1}{2} H_E \zeta_g$ | $10^{-3}\,\text{m/s}$ |
| 旋转减弱时间 | $\tau_E$ | $\frac{H}{\sqrt{f_0 K_m/2}}$ | 约5天 |

埃克曼层理论是行星边界层动力学的基础，它定量描述了湍流摩擦对风场垂直结构的影响，并揭示了边界层与自由大气之间的动力耦合——埃克曼抽吸和旋转减弱，是天气系统消亡的重要机制。

## 思考题

> **思考题 1**：埃克曼层控制方程中忽略了水平平流项 $\partial/\partial x$ 和 $\partial/\partial y$。如果存在强的水平温度梯度（如锋区），这一简化是否仍然合理？试从尺度分析角度讨论平流项与摩擦项、科氏力项的量级对比。

> **思考题 2**：埃克曼抽吸的物理本质是什么？试从水平质量辐合/辐散出发，推导埃克曼层顶垂直速度 $w_E$ 与地转涡度 $\zeta_g$ 的正比关系，并解释为何气旋区边界层顶上升、反气旋区下沉。

> **思考题 3**：理论预测地面风向与地转风的夹角为 $45^\circ$，但实际观测通常为 $10^\circ\text{–}30^\circ$。试从混合长理论（$K_m$ 非均匀）和热力层结稳定度两个角度分析造成这一偏差的可能原因。

> **思考题 4**：旋转减弱过程如何将自由大气的涡度”传递”给地面摩擦？比较埃克曼抽吸耗散（$\tau_E \sim 5$ 天）与分子粘性耗散（$\sim 115$ 天）的巨大差异，说明湍流在天气系统衰减中的决定性作用。

> **思考题 5**：若 $K_m$ 随高度线性增大（$K_m(z) = K_0 + \alpha z$），埃克曼螺线会发生怎样的定性变化（如地面风偏角、边界层厚度、超调量等）？是否仍存在解析解？
