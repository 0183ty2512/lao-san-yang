## 平均动量方程

### 重点

1. 雷诺分解 $\phi = \overline{\phi} + \phi'$ 是处理湍流的数学基石，将瞬时场分离为缓变的平均场和快速脉动的湍流场两个截然不同的物理成分。
2. 非线性平流项的雷诺平均产生额外的脉动相关项 $-\partial\overline{u_i'u_j'}/\partial x_j$，即雷诺应力散度——这是平均动量方程与原始N-S方程形式上的核心区别。
3. 雷诺应力 $\tau_{ij} = -\rho\overline{u_i'u_j'}$ 在物理上代表湍流脉动对平均动量的净输送，是方程组不封闭的根本原因，必须参数化。
4. 湍流交换系数 $K_m$ 的引入（$\overline{u'w'} = -K_m\,\partial\overline{u}/\partial z$）是闭合假设的核心——将二阶脉动相关量用一阶平均量的梯度表达，使方程组可解。
5. 在行星边界层中，垂直方向（$z$）的湍流输送量级远大于水平方向，故可忽略水平雷诺应力项，使方程大幅简化。
6. 在定常、水平均匀、正压边界层近似下，平均动量方程简化为埃克曼层经典控制方程——地转偏差与湍流摩擦力之间的平衡关系。

### 1. 湍流与雷诺分解

大气行星边界层中，运动通常为湍流状态。湍流是叠加在平均运动之上的随机脉动。为了处理湍流对平均运动的影响，引入**雷诺分解**：将任一物理量 $\phi$ 分解为平均量 $\overline{\phi}$ 和脉动量 $\phi'$：
$$\phi = \overline{\phi} + \phi'$$
其中平均量通常取时间平均（或系综平均），满足 $\overline{\phi'} = 0$。

对于速度分量：
$$u = \overline{u} + u',\quad v = \overline{v} + v',\quad w = \overline{w} + w'$$

### 2. 平均动量方程的推导

#### （1） 原始动量方程（直角坐标系，忽略科氏力变化，考虑分子粘性）

$$\frac{\partial u}{\partial t} + u\frac{\partial u}{\partial x} + v\frac{\partial u}{\partial y} + w\frac{\partial u}{\partial z} = -\frac{1}{\rho}\frac{\partial p}{\partial x} + fv + \nu\nabla^2 u$$
$$\frac{\partial v}{\partial t} + u\frac{\partial v}{\partial x} + v\frac{\partial v}{\partial y} + w\frac{\partial v}{\partial z} = -\frac{1}{\rho}\frac{\partial p}{\partial y} - fu + \nu\nabla^2 v$$
其中 $\nu$ 为分子运动粘性系数（大气中很小，除了最贴近地面的薄层外可忽略）。

#### （2） 代入雷诺分解并取平均

将 $u = \overline{u}+u'$，$p = \overline{p}+p'$ 等代入，并对方程取时间平均。利用平均运算规则：
- $\overline{\overline{\phi}} = \overline{\phi}$
- $\overline{\phi'} = 0$
- $\overline{\phi \psi} = \overline{\phi}\,\overline{\psi} + \overline{\phi'\psi'}$
- $\overline{\frac{\partial \phi}{\partial t}} = \frac{\partial \overline{\phi}}{\partial t}$（平均与微分可交换）

以 $x$ 方向为例，平流项 $\overline{u\frac{\partial u}{\partial x}}$ 的平均为：
$$\overline{u\frac{\partial u}{\partial x}} = \overline{(\overline{u}+u')\frac{\partial (\overline{u}+u')}{\partial x}} = \overline{u}\frac{\partial \overline{u}}{\partial x} + \overline{u' \frac{\partial u'}{\partial x}}$$
同样地，其他项也产生类似的湍流脉动相关项。

#### （3） 平均动量方程（雷诺方程）

最终得到**平均动量方程**（常称为雷诺方程）：

$$\frac{\partial \overline{u}}{\partial t} + \overline{u}\frac{\partial \overline{u}}{\partial x} + \overline{v}\frac{\partial \overline{u}}{\partial y} + \overline{w}\frac{\partial \overline{u}}{\partial z} = -\frac{1}{\rho}\frac{\partial \overline{p}}{\partial x} + f\overline{v} - \left( \frac{\partial \overline{u'^2}}{\partial x} + \frac{\partial \overline{u'v'}}{\partial y} + \frac{\partial \overline{u'w'}}{\partial z} \right) + \nu\nabla^2 \overline{u}$$

$$\frac{\partial \overline{v}}{\partial t} + \overline{u}\frac{\partial \overline{v}}{\partial x} + \overline{v}\frac{\partial \overline{v}}{\partial y} + \overline{w}\frac{\partial \overline{v}}{\partial z} = -\frac{1}{\rho}\frac{\partial \overline{p}}{\partial y} - f\overline{u} - \left( \frac{\partial \overline{u'v'}}{\partial x} + \frac{\partial \overline{v'^2}}{\partial y} + \frac{\partial \overline{v'w'}}{\partial z} \right) + \nu\nabla^2 \overline{v}$$

其中 $\overline{u'^2}$、$\overline{v'^2}$、$\overline{w'^2}$ 为速度脉动的方差，$\overline{u'v'}$、$\overline{u'w'}$、$\overline{v'w'}$ 为雷诺应力（湍流切应力）。

### 3. 湍流应力（雷诺应力）

湍流对平均运动的净效应类似于应力，称为**雷诺应力**（湍流应力）。对于单位质量空气，雷诺应力的分量为：
$$\tau_{ij} = -\rho \overline{u_i' u_j'}$$
例如：
- $\tau_{xz} = -\rho \overline{u' w'}$：垂直方向输送水平动量的湍流应力
- $\tau_{yz} = -\rho \overline{v' w'}$

在边界层中，垂直方向（$z$ 方向）的湍流输送通常比水平方向更重要，且分子粘性项相对于湍流应力项可忽略。因此平均动量方程可简化为：

$$\frac{\partial \overline{u}}{\partial t} + \overline{u}\frac{\partial \overline{u}}{\partial x} + \overline{v}\frac{\partial \overline{u}}{\partial y} + \overline{w}\frac{\partial \overline{u}}{\partial z} = -\frac{1}{\rho}\frac{\partial \overline{p}}{\partial x} + f\overline{v} + \frac{\partial}{\partial z}\left( K_m \frac{\partial \overline{u}}{\partial z} \right)$$

$$\frac{\partial \overline{v}}{\partial t} + \overline{u}\frac{\partial \overline{v}}{\partial x} + \overline{v}\frac{\partial \overline{v}}{\partial y} + \overline{w}\frac{\partial \overline{v}}{\partial z} = -\frac{1}{\rho}\frac{\partial \overline{p}}{\partial y} - f\overline{u} + \frac{\partial}{\partial z}\left( K_m \frac{\partial \overline{v}}{\partial z} \right)$$

这里引入了**湍流交换系数**（涡动粘性系数）$K_m$，将雷诺应力参数化为：
$$\overline{u'w'} = -K_m \frac{\partial \overline{u}}{\partial z},\quad \overline{v'w'} = -K_m \frac{\partial \overline{v}}{\partial z}$$

### 4. 湍流交换系数的性质

- $K_m$ 不是流体属性，而是湍流的属性，依赖于流动状态（如风切变、层结稳定度、距地高度等）。
- 量级：近地面层 $K_m \sim 0.1\,\text{m}^2/\text{s}$，埃克曼层 $K_m \sim 1\text{–}10\,\text{m}^2/\text{s}$。
- 对于热量和水汽，可类似定义湍流热通量系数 $K_h$ 和水汽通量系数 $K_q$。在近中性条件下，常假设 $K_m = K_h = K_q$。

### 5. 平均动量方程的简化（边界层近似）

在行星边界层中，通常采用以下简化假设：

- **定常**：$\frac{\partial}{\partial t} = 0$
- **水平均匀**：$\frac{\partial}{\partial x} = \frac{\partial}{\partial y} = 0$（或忽略水平平流项）
- **垂直输送主导**：忽略水平湍流应力项
- **$f$ 平面近似**：$f = f_0$ 常数
- **正压边界层**：$\frac{\partial \overline{p}}{\partial x}, \frac{\partial \overline{p}}{\partial y}$ 不随高度变化，地转风 $\overline{u}_g, \overline{v}_g$ 为常数

此时平均动量方程简化为：
$$0 = f_0(\overline{v} - \overline{v}_g) + \frac{\partial}{\partial z}\left( K_m \frac{\partial \overline{u}}{\partial z} \right)$$
$$0 = -f_0(\overline{u} - \overline{u}_g) + \frac{\partial}{\partial z}\left( K_m \frac{\partial \overline{v}}{\partial z} \right)$$
其中 $\overline{u}_g = -\frac{1}{f_0\rho}\frac{\partial \overline{p}}{\partial y}$，$\overline{v}_g = \frac{1}{f_0\rho}\frac{\partial \overline{p}}{\partial x}$。

这就是**埃克曼层（Ekman 层）的经典控制方程**。当 $K_m$ 为常数时，可解析求解，得到著名的埃克曼螺线分布。

## 小结

| 项目 | 内容 |
| :--- | :--- |
| 雷诺分解 | $\phi = \overline{\phi} + \phi'$，$\overline{\phi'}=0$ |
| 平均动量方程 | 与原始方程形式类似，但多出雷诺应力项 $-\frac{\partial \overline{u_i'u_j'}}{\partial x_j}$ |
| 湍流应力（雷诺应力） | $\tau_{ij} = -\rho \overline{u_i'u_j'}$，表示湍流对平均运动的摩擦作用 |
| 湍流交换系数 $K_m$ | $\overline{u'w'} = -K_m\frac{\partial \overline{u}}{\partial z}$，闭合假设 |
| 边界层简化方程 | 地转风、科氏力、湍流摩擦力平衡，导出埃克曼层解 |

平均动量方程是行星边界层动力学的基础，它通过雷诺应力描述了湍流对平均流的拖曳效应，并通过参数化 $K_m$ 闭合方程组。

## 思考题

> **思考题 1**：雷诺平均操作中，非线性平流项 $\overline{u_j \partial u_i / \partial x_j}$ 为何会产生脉动相关项 $\overline{u_j' \partial u_i' / \partial x_j}$？试以不可压缩条件 $\partial u_j'/\partial x_j = 0$ 为辅助，推导该结果并说明其物理本质。

> **思考题 2**：湍流交换系数 $K_m$ 的参数化形式 $\overline{u'w'} = -K_m \partial\overline{u}/\partial z$ 隐含了”梯度输送”假设（即湍流通量沿平均梯度方向）。该假设在什么条件下失效？在强对流边界层中应如何修正？

> **思考题 3**：如果保留非定常项 $\partial\overline{u}/\partial t$，并考虑日变化热力强迫（如午后地表加热增强），平均动量方程中的各项平衡关系如何随时间演变？这对边界层风场的日变化有何影响？

> **思考题 4**：比较分子粘性系数 $\nu$（约 $1.5\times10^{-5}\,\text{m}^2/\text{s}$）与湍流交换系数 $K_m$（近地层约 $0.1\,\text{m}^2/\text{s}$，埃克曼层约 $1\text{–}10\,\text{m}^2/\text{s}$）的量级差异，说明为什么除粘性底层（约毫米级）外，分子粘性项在边界层中总是可忽略的。
