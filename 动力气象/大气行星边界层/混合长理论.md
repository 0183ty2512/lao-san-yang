## 混合长理论

### 重点

1. 混合长理论类比气体分子运动论，假设湍涡在运动过程中保持自身属性不变、移动一段特征距离（混合长 $l$）后才与周围环境完全混合。
2. 湍流交换系数的核心表达式 $K_m = l^2 |\partial\overline{u}/\partial z|$ 将雷诺应力与平均风切变直接联系起来，物理图像清晰、计算简便。
3. 近地面层中混合长与离地高度成正比：$l = \kappa z$（$\kappa \approx 0.41$ 为冯·卡门常数），导出了经典的对数风廓线 $\overline{u}(z) = \frac{u_*}{\kappa}\ln(z/z_0)$。
4. 对数风廓线在中性层结下被广泛观测验证——在 $\ln z$ 与 $\overline{u}$ 坐标系中呈直线，斜率即为 $u_*/\kappa$。
5. 非中性层结需引入稳定度修正函数 $\phi_m(\zeta)$（$\zeta = z/L$），这构成了莫宁-奥布霍夫相似理论的闭合基础。
6. 混合长理论本质上是一阶闭合方案（仅使用一阶平均量及其梯度），其最大局限在于无法描述湍流的非局部输送（如大涡对流输送）。

### 1. 混合长理论的基本思想

在行星边界层中，湍流运动对平均动量、热量和水汽的输送起着决定性作用。雷诺平均后的方程组引入了新的未知量——雷诺应力（如 $\overline{u'w'}$），导致方程组不闭合。为了求解，必须将湍流项用平均量表示，这称为**湍流参数化**或**闭合问题**。

**混合长理论**（Mixing Length Theory）由普朗特（Prandtl）和冯·卡门（Von Kármán）提出，是历史上最早也是最经典的湍流参数化方案之一。其核心思想是：湍涡在运动过程中类似于气体分子，在经历一段特征距离（混合长）后，才与周围环境混合，在此过程中保持其原有的物理属性不变。

### 2. 混合长理论的基本假设

1. **守恒性假设**：湍涡在运动起始高度 $z - l'$ 上具有该高度的平均物理属性（如平均速度 $\overline{u}(z-l')$），并在移动一个**混合长** $l'$ 到达新高度 $z$ 的过程中，其属性保持不变。
2. **不连续混合假设**：湍涡的运动是不连续的，即它独立地移动一段距离后才与周围空气完全混合，失去原有的属性。
3. **各向同性假设**（简化）：湍流脉动速度在各方向上的量级相同，即 $|u'| \sim |v'| \sim |w'|$。

### 3. 湍流应力的混合长表达

考虑垂直方向上的动量输送。在高度 $z$ 处，平均风速为 $\overline{u}(z)$。来自下方 $z-l'$ 的湍涡携带较低的平均速度 $\overline{u}(z-l')$ 向上运动（$w'>0$），到达 $z$ 高度时，它相对于周围空气的脉动速度为：
$$u' \approx \overline{u}(z-l') - \overline{u}(z) \approx -l' \frac{\partial \overline{u}}{\partial z}$$
其中用了泰勒展开，并假设 $l'$ 很小。

类似地，来自上方 $z+l'$ 的湍涡向下运动（$w'<0$），携带较高的平均速度，产生的脉动速度 $u' \approx +l' \frac{\partial \overline{u}}{\partial z}$。因此，无论湍涡来自上方还是下方，总有：
$$u' \sim -l' \frac{\partial \overline{u}}{\partial z}$$
且 $l'$ 与 $w'$ 符号相同（向上运动的涡 $w'>0$，$l'>0$；向下运动的涡 $w'<0$，$l'<0$）。

由此，垂直湍流动量通量（雷诺应力）可写为：
$$\overline{u'w'} = \overline{w' \cdot \left( -l' \frac{\partial \overline{u}}{\partial z} \right)} = - \overline{w' l'} \frac{\partial \overline{u}}{\partial z}$$

令 $K_m = \overline{w' l'}$，称为**湍流交换系数**（或涡动粘性系数），则：
$$\overline{u'w'} = -K_m \frac{\partial \overline{u}}{\partial z}$$

进一步假设湍流脉动速度 $w'$ 与 $l'$ 成正比，且 $|w'| \sim l' \left|\frac{\partial \overline{u}}{\partial z}\right|$，则：
$$K_m = \overline{c\, l'^2} \left|\frac{\partial \overline{u}}{\partial z}\right| = l^2 \left|\frac{\partial \overline{u}}{\partial z}\right|$$
其中 $l$ 称为**平均混合长**，包含了比例常数和脉动的统计特性。

### 4. 混合长的尺度估算

- **近地面层**：湍涡尺度受地面限制，混合长与离地高度成正比：$l = \kappa z$，其中 $\kappa \approx 0.41$ 为**冯·卡门常数**。
- **自由对流层**：混合长可能受限于边界层厚度或热力层结。
- **稳定层结**：混合长减小，因为浮力抑制垂直运动。

### 5. 混合长理论的应用——中性近地面层风廓线

在近地面层（常通量层），湍流应力近似为常数，记为 $u_*^2 = -\overline{u'w'}$（$u_*$ 为摩擦速度）。代入混合长公式：
$$u_*^2 = K_m \frac{d\overline{u}}{dz} = l^2 \left|\frac{d\overline{u}}{dz}\right| \frac{d\overline{u}}{dz} = l^2 \left(\frac{d\overline{u}}{dz}\right)^2$$
由于 $\frac{d\overline{u}}{dz} > 0$，取正根得：
$$\frac{d\overline{u}}{dz} = \frac{u_*}{l} = \frac{u_*}{\kappa z}$$

积分，并设 $z = z_0$ 处 $\overline{u}=0$（$z_0$ 为地面粗糙度），得到**对数风廓线公式**：
$$\overline{u}(z) = \frac{u_*}{\kappa} \ln \frac{z}{z_0}$$

在 $\ln z$ 与 $\overline{u}$ 的坐标系中，中性层结下的风廓线呈直线，斜率 $u_*/\kappa$，截距由 $z_0$ 决定。

### 6. 混合长理论的优缺点

| 优点 | 缺点 |
| :--- | :--- |
| 物理图像清晰，简单易用 | 假设湍涡混合是不连续的过程，与实际不符 |
| 成功解释了中性层结下的对数风廓线 | 假设湍涡在运动中保持属性不变，忽略了压力梯度、粘性等作用 |
| 为高阶湍流闭合方案奠定了基础 | 混合长 $l$ 需经验确定，随层结、高度变化 |
| 在数值模式中仍有应用（如$K$理论） | 动量、热量、水汽的混合长可能不同，但常假定相等 |

### 7. 与非中性层结的拓展

在非中性层结（不稳定或稳定）下，混合长理论需引入**稳定度修正函数** $\phi_m(\zeta)$：
$$\frac{d\overline{u}}{dz} = \frac{u_*}{\kappa z} \phi_m(\zeta)$$
其中 $\zeta = z/L$，$L$ 为莫宁-奥布霍夫长度。这就是**莫宁-奥布霍夫相似理论**的基础，是混合长理论的重要发展。

### 8. 在埃克曼层中的局限性

在埃克曼层中，$K_m$ 通常假设为常数以得到解析解。但实际 $K_m$ 随高度变化，混合长理论在这里不直接适用。更精确的埃克曼层解需考虑 $K_m$ 的垂直变化，通常借助高阶闭合或大涡模拟（LES）获得。

## 小结

| 概念 | 内容 |
| :--- | :--- |
| 混合长 $l$ | 湍涡在混合前移动的特征距离，$l = \kappa z$（近地面） |
| 湍流交换系数 | $K_m = l^2 \left|\frac{\partial \overline{u}}{\partial z}\right|$ |
| 对数风廓线 | $\overline{u}(z) = \frac{u_*}{\kappa} \ln \frac{z}{z_0}$（中性层结） |
| 主要应用 | 近地面层风、温度、水汽廓线的参数化 |
| 局限性 | 假设过强，不适用于非中性层结和强对流 |

混合长理论是最简单的湍流闭合模型，尽管存在诸多局限，但其物理直观性和对近地面层的成功描述使其在边界层气象学中仍占有重要地位。现代数值模式中常用的 $K$ 理论即源于混合长思想。

## 思考题

> **思考题 1**：混合长 $l$ 与湍涡的实际物理尺度有何区别与联系？为什么近地面层中 $l$ 必须正比于 $z$（即 $l = \kappa z$），而不能取为常数？

> **思考题 2**：”湍涡在运动中保持属性不变”这一假设在哪种大气条件下最为合理？在强不稳定对流边界层或强稳定层结中，该假设为何会严重失效？

> **思考题 3**：混合长理论给出的 $K_m = l^2|\partial\overline{u}/\partial z|$ 中使用了切变的绝对值而非切变本身。如果直接使用切变而非绝对值，会出现什么物理上的不合理？

> **思考题 4**：如果同时考虑动量和热量的湍流输送，动量的混合长 $l_m$ 和热量的混合长 $l_h$ 在物理上是否应该相等？造成二者差异的根本物理原因是什么？这对通量理查森数 $Rf = (K_h/K_m)Ri$ 有何影响？
