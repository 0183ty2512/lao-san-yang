## 台风发展的第二类条件不稳定（CISK）理论

**重点**

- **CISK**（第二类条件不稳定）是描述大尺度环流与积云对流之间正反馈相互作用的机制，由 Charney–Eliassen（1964）和 Ooyama（1964）分别独立提出。
- **四步正反馈循环**：大尺度低压扰动→边界层摩擦辐合（水汽集中+上升）→积云对流触发（释放凝结潜热）→中层增暖、地面气压降低→气旋性环流增强→回到辐合增强。
- CISK 与第一类条件不稳定的本质区别：第一类针对单个气块的浮力不稳定，CISK 强调**大尺度环流通过对流组织化**释放潜热来维持和增强自身。
- **暖心结构**是台风区别于温带气旋的典型特征：对流加热在中高层最为显著（5–10 km），使等压面向上凸起，地面气压下降，增强气旋性环流。
- 台风生成的五个必要条件：海表温度 $\ge 26.5$°C、低层辐合源、垂直风切变 $< 10$ m/s、中层高湿（防止干空气卷入）、纬度 $\ge 5°$（足够的 $f$）。
- 能量来源是海洋水汽的凝结潜热——西太平洋暖池（海温 >28°C）是全球 CISK 最易发生、台风最活跃的区域。
- **WISHE**（风致海面热交换）机制是现代对 CISK 的重要补充：海面蒸发随风速增大而增强，形成另一个正反馈，在强台风阶段可能比 CISK 更为关键。
- CISK 理论的局限：实际对流并非均匀加热（仅眼墙等组织化对流有效）、WISHE 的作用可能超过 CISK、高分辨率模拟显示两者共同作用。

### 1. CISK 的基本概念

**CISK**（Conditional Instability of the Second Kind，第二类条件不稳定）是一种描述大尺度环流与积云对流之间正反馈相互作用的机制。其核心思想是：

- **大尺度** 扰动（如热带低压）通过边界层摩擦辐合，为**小尺度** 积云对流提供水汽和抬升条件；
- **积云对流** 释放的凝结潜热，反过来加热大气、降低地面气压，增强大尺度环流。

这种正反馈循环使得初始的弱扰动能够自我加强，发展成为台风（热带气旋）等强烈天气系统。

CISK 是由 Charney 和 Eliassen（1964）以及 Ooyama（1964）分别提出的，用以解释热带气旋的生成与维持。它与第一类条件不稳定（单个气块的浮力不稳定）不同，强调**对流组织化**和**大尺度强迫**的协同作用。

### 2. CISK 的物理机制

#### （1） 正反馈过程（四步循环）

1. **初始大尺度低压扰动**：例如东风波、季风槽中的低压区，产生低空气压梯度。
2. **边界层摩擦辐合**：空气向低压中心流动（在热带，科氏力弱，径向入流明显），将水汽集中在低压区，并产生上升运动。
3. **积云对流触发**：上升运动使湿空气达到饱和，释放凝结潜热，加热对流层中高层。
4. **暖心结构与低压增强**：高层增暖使等压面向上凸起（重力位势增加），根据静力平衡和热成风关系，地面气压下降，气旋性环流增强 → 回到步骤 2，循环加强。

只要海洋持续供应水汽（海表温度 > 26.5°C）且垂直风切变较弱，这一正反馈可自持，直至发展为成熟台风。

#### （2） CISK 的数学本质（简化模型）

在热带 $\beta$ 平面上，考虑边界层顶的垂直速度 $w_B$ 由 Ekman 抽吸引起：$w_B = \frac{1}{2} \sqrt{\frac{K_m}{f}} \zeta$（$f$ 很小，但仍有意义）。对流加热率 $Q_c$ 正比于上升质量通量（或 $w_B$），且加热集中在对流层中层。大尺度涡度方程和热力学方程耦合，形成增长率方程。CISK 的不稳定增长率可表示为：
$$\sigma \sim \sqrt{\frac{K_m}{f_0}} \cdot \text{（加热率）} - \text{（耗散）}$$
当海温足够高、摩擦耗散足够小时，$\sigma > 0$，扰动呈指数增长。

#### （3） CISK 与暖心结构的形成

- 对流加热在大气中高层最为显著（因为深层对流释放的潜热主要在 5–10 km 高度）。
- 加热导致高层温度升高，等压面向上凸起，位势高度增加。
- 根据静力平衡，地面气压必须降低以补偿高层位势的升高，从而增强地面气旋性环流。
- 这种暖心结构是台风区别于温带气旋的典型特征。

### 3. CISK 在台风生成中的应用

#### （1） 台风生成的环境条件（CISK 成立的必要条件）

| 条件 | 作用 |
| :--- | :--- |
| 海表温度 ≥ 26.5°C | 确保充足的水汽通量和潜热释放 |
| 低层辐合（季风槽、东风波） | 提供初始大尺度上升区和气旋性涡度 |
| 弱垂直风切变（< 10 m/s） | 防止对流加热被切离低压中心 |
| 高湿的中层（避免干空气卷入） | 维持对流效率，防止蒸发冷却 |
| 足够大的科氏参数（纬度 ≥ 5°） | 提供气旋性涡度组织和地转调整 |

#### （2） CISK 与“暖池”区域

西太平洋暖池（海温 > 28°C，深层暖水）是 CISK 最易发生的区域，也是全球台风最活跃的海域。暖池提供持续的潜热通量，维持高 CAPE，使 CISK 正反馈能够克服摩擦耗散。

#### （3） 从热带扰动到台风的发展阶段

- **扰动阶段**：弱低压环流，无组织对流。
- **CISK 启动**：边界层辐合增强，出现持续的对流云团，中层开始增暖。
- **发展阶段**：暖心建立，气压快速下降，风速增强，环流组织成螺旋雨带。
- **成熟台风**：CISK 继续维持，但眼区下沉和眼墙对流形成更强的动力结构。

### 4. CISK 理论的局限与改进

- **海气相互作用**：CISK 最初强调大气内部反馈，但实际海面蒸发随风速增大而增强（风速越大，潜热通量越大），这称为 **WISHE**（Wind-Induced Surface Heat Exchange）机制。现代观点认为，WISHE 在台风发展中可能比 CISK 更重要，特别是对于强台风。
- **实际对流不是均匀加热**：CISK 假设大尺度上升与对流加热成正比，但实际中只有一部分组织化的对流（如眼墙）才有效加热核心区。
- **高分辨率模拟**：云分辨模式可直接模拟对流与环流的耦合，显示 CISK 和 WISHE 共同作用。

### 5. CISK 的观测证据

- **热带云团（Tropical Cloud Cluster）**：卫星观测表明，许多台风最初来源于中尺度对流系统（MCS）或热带云团，云团中的深对流释放潜热，导致地面气压下降，环流逐渐组织化。
- **台风生成前的增暖信号**：在对流层中高层（200–300 hPa）可观测到温度正异常，先于地面气压下降。
- **边界层水汽辐合**：飞机观测和再分析资料显示，台风生成区低空有持续的强辐合和水汽通量辐合。

### 6. CISK 与热带气旋强度理论

- CISK 提供了一种正反馈机制，可以解释为什么台风能在暖水上发展成很强的气旋。
- 最大潜在强度（PI）理论（Emanuel, 1986）结合了 CISK 和 WISHE，通过热力平衡估算台风可能达到的最大风速。
- 实际强度受限于海洋热含量、垂直风切变、环境湿度等因素，CISK 的正反馈可能被这些因素削弱或阻断。

## 小结

| 项目 | 内容 |
| :--- | :--- |
| **CISK 全称** | Conditional Instability of the Second Kind |
| **核心机制** | 大尺度环流与积云对流的正反馈：辐合 → 对流 → 加热 → 增强辐合 |
| **应用对象** | 热带气旋（台风、飓风）的生成与发展 |
| **必要环境** | 暖海温（≥26.5°C）、低层辐合、弱风切变、高湿 |
| **能量来源** | 海洋水汽的凝结潜热 |
| **局限** | 实际海气耦合（WISHE）可能更重要，CISK 在高分辨率模拟中需与对流组织化结合 |
| **理论贡献** | 解释了为什么热带扰动能在无斜压环境下发展为强烈气旋 |

CISK 理论是热带气旋动力学的里程碑，尽管后来有所修正，但其”对流与大尺度运动耦合”的核心思想至今仍是理解台风生成的基础。

> **思考题 2**：为什么 CISK 机制要求海表温度 $\ge 26.5$°C？如果海温低于这一阈值，CISK 正反馈循环中的哪个环节首先受到影响？
> **思考题 3**：在赤道上（$f=0$），CISK 机制还能使扰动发展为台风吗？为什么实际观测中台风通常生成在纬度 $\ge 5°$ 的区域？
> **思考题 4**：WISHE（风致海面热交换）机制如何补充和修正经典 CISK 理论？在强台风阶段（例如超强台风），为什么 WISHE 的作用可能超过 CISK？
> **思考题 5**：如果一个热带扰动位于强垂直风切变（>15 m/s）的环境中，CISK 正反馈循环会在哪个具体环节被破坏？从暖心结构的空间偏移和潜热加热效率的角度解释。
