# 动力气象学 综合试卷一 参考答案与解析

## 一、选择题

**1. C**
- 解析：三个基本假设为连续性假设、理想气体假设、薄层近似。不可压缩假设不是基本假设（仅在特定条件下使用）。

**2. B**
- 解析：$Ro = U/(f_0 L) = 0.1 \ll 1$ → 科氏力远大于惯性力 → 准地转运动。

**3. C**
- 解析：常数 $K_m$ 假设下，埃克曼螺线给出地面风与地转风夹角为 $45^\circ$。实际观测约 $10^\circ\text{–}30^\circ$。

**4. B**
- 解析：$c_{px} - \overline{u} = -\beta/(k^2+l^2) < 0$，相对于基本气流总是向西传播。

**5. C**
- 解析：静力平衡下 $\omega = \sqrt{gH_0}k$，$c = \sqrt{gH_0}$ 与波数无关 → 非频散波。

**6. B**
- 解析：有效位能约占全位能的 $1/200$（约0.5%），其中仅约10%能真正转换为动能。

**7. B**
- 解析：斜压不稳定能量来源于基本气流的有效位能（水平温度梯度），通过 $\overline{v'T'}$ 释放。

**8. B**
- 解析：CISK = 第二类条件不稳定，核心是大尺度辐合 → 积云对流 → 凝结潜热释放 → 暖心建立 → 低压增强的正反馈。

**9. B**
- 解析：位势涡度 $q = \frac{\boldsymbol{\omega}_a \cdot \nabla \theta}{\rho}$ 在绝热（$\dot{Q}=0$）且无摩擦条件下守恒。

**10. B**
- 解析：$p$ 坐标系连续方程不含时间导数，是诊断方程，用于诊断垂直速度 $\omega$。

## 三、简答题

**21. 尺度分析的基本思想和五个"准"：**

尺度分析通过估计方程各项的量级，忽略次要项，保留主导项，简化方程组。对大尺度运动：
- 零级近似给出诊断关系（地转平衡、静力平衡）
- 一级近似给出预报方程（准地转涡度方程等）

五个"准"：准地转、准静力、准水平、准定常、准水平无辐散。

---

**22. 地转风、梯度风、热成风的关系：**

- **地转风**：水平气压梯度力与科氏力平衡，适用于平直等压线、$Ro \ll 1$。是零级近似。
- **梯度风**：加入了惯性离心力，适用于弯曲等压线。气旋中 $V_g > V_G$（地转风高估），反气旋中 $V_g < V_G$ 且有上限。
- **热成风**：地转风随高度的变化量 $\mathbf{V}_T = \mathbf{V}_g(p_1) - \mathbf{V}_g(p_0)$，由水平温度梯度引起，反映大气斜压性。

三者关系：热成风是地转风在垂直方向的切变，梯度风是地转风的曲率修正。

---

**23. 位势涡度守恒与南北运动：**

位涡 $q \approx \frac{\zeta + f}{\Delta p}$（等熵气柱厚度为 $\Delta p$）。

气块向北运动：$f$ 增大 → 为使 $q$ 守恒，若厚度不变，则 $\zeta$ 必须减小（产生反气旋式涡度）→ 气流向南偏转。

气块向南运动：$f$ 减小 → $\zeta$ 必须增大（产生气旋式涡度）→ 气流向北偏转。

这是罗斯贝波恢复机制的位涡解释，也是涡度方程中 $\beta v$ 项的物理来源。

---

**24. 重力内波与罗斯贝波的比较：**

| 特征 | 重力内波 | 罗斯贝波 |
|:---|:---|:---|
| 恢复力 | 浮力（稳定层结 $N^2>0$） | $\beta$ 效应 |
| 频散性 | 频散波 | 频散波 |
| $\mathbf{c}$ 与 $\mathbf{c}_g$ | $\mathbf{c} \perp \mathbf{c}_g$（垂直） | 可同向或反向 |
| 频率范围 | $\omega \le N$（高频） | $\omega \ll f_0$（低频） |
| 传播特征 | 三维传播，能量可向上 | 准水平，垂直方向相当正压 |
| 滤波条件 | 中性层结（$N^2=0$） | 无$\beta$效应（$f$常数） |

**25. 埃克曼抽吸与旋转减弱：**

边界层中摩擦使风偏向低压一侧，产生水平辐合（气旋区）或辐散（反气旋区）。由连续方程，边界层顶产生垂直运动：
$$w_E = \frac{1}{2}H_E\zeta_g$$

气旋区 $w_E > 0$（上升），将边界层涡度输送到自由大气，自由大气为补偿质量需水平辐散，涡度随之减弱：
$$\frac{\partial \zeta_g}{\partial t} = -\frac{f_0 w_E}{H} = -\frac{\zeta_g}{\tau_E}$$

旋转减弱时间 $\tau_E \approx 5$ 天，与气旋自然消亡时间一致，是天气系统衰减的主要机制。

## 四、推导题

**26. 罗斯贝波频散关系推导：**

正压无辐散涡度方程：
$$\frac{d(\zeta + f)}{dt} = 0$$

设 $u = \overline{u} + u', v = v'$，线性化：
$$\frac{\partial \zeta'}{\partial t} + \overline{u}\frac{\partial \zeta'}{\partial x} + \beta v' = 0$$

引入流函数 $\psi'$：$u' = -\partial\psi'/\partial y, v' = \partial\psi'/\partial x, \zeta' = \nabla^2\psi'$：
$$\left(\frac{\partial}{\partial t} + \overline{u}\frac{\partial}{\partial x}\right)\nabla^2\psi' + \beta\frac{\partial\psi'}{\partial x} = 0$$

设 $\psi' = \Psi e^{i(kx+ly-\omega t)}$：
$$(-i\omega + i\overline{u}k)(-k^2-l^2)\Psi + i\beta k \Psi = 0$$
$$(-\omega + \overline{u}k)(k^2+l^2) + \beta k = 0$$

$$\omega = \overline{u}k - \frac{\beta k}{k^2+l^2}$$

---

**27. 位温守恒推导：**

热力学第一定律常用形式（$\dot{Q}=0$ 绝热）：
$$c_p \frac{dT}{dt} - \alpha \frac{dp}{dt} = 0$$

代入 $\alpha = R_d T/p$：
$$c_p \frac{dT}{dt} - \frac{R_d T}{p} \frac{dp}{dt} = 0$$
$$c_p \frac{dT}{T} = R_d \frac{dp}{p}$$

积分：$c_p \ln T - R_d \ln p = \text{常数}$

定义位温 $\theta = T \left(\frac{p_{00}}{p}\right)^{R_d/c_p}$，其中 $p_{00}=1000\,\text{hPa}$。

在干绝热过程中 $\frac{d\theta}{dt} = 0$（位温守恒）。

## 五、计算题

**28. 解：**

**(1) 地转风：**

南北方向位势梯度（南高北低，$\partial\Phi/\partial y < 0$）：
$$\frac{\partial \Phi}{\partial y} = -\frac{80 \times 9.8}{4 \times 10^{5}} = -1.96 \times 10^{-3}\,\text{m}\cdot\text{s}^{-2}$$

$$u_g = -\frac{1}{f_0}\frac{\partial \Phi}{\partial y} = -\frac{1}{10^{-4}} \times (-1.96 \times 10^{-3}) = 19.6\,\text{m/s}$$

地转风大小为 $19.6\,\text{m/s}$，方向为西风（南高北低 → 地转风自西向东）。

**(2) 梯度风：**

气压梯度力项：
$$-\frac{1}{\rho}\frac{\partial p}{\partial n} = f_0 V_g = 10^{-4} \times 19.6 = 1.96 \times 10^{-3}$$

$$\frac{f_0 R_T}{2} = \frac{10^{-4} \times 6 \times 10^{5}}{2} = 30$$

气旋式（$R_T > 0$），取"+"号：
$$V_G = -30 + \sqrt{30^2 + 6 \times 10^{5} \times 1.96 \times 10^{-3}}$$
$$= -30 + \sqrt{900 + 1176} = -30 + \sqrt{2076}$$
$$= -30 + 45.56 \approx 15.6\,\text{m/s}$$

$V_g(19.6) > V_G(15.6)$，气旋中地转风高估实际风速，这与理论一致。
