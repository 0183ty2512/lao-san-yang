# 动力气象学 综合试卷二 参考答案与解析

## 一、选择题

**1. B** — $\Phi = gz$ 为位势，$p$ 坐标系中用位势梯度替代气压梯度。

**2. B** — 惯性不稳定条件为绝对涡度 $\zeta_a < 0$（北半球）。

**3. B** — 重力内波频率 $\omega^2 = \frac{N^2 k^2}{k^2+m^2} \le N^2$，最大值为 $N$。

**4. B** — 对数风廓线是在中性层结、混合长 $l = \kappa z$ 假设下导出的。

**5. C** — Eady模型 $L_{\max} \approx 3.9HN/f \approx 4700\,\text{km}$（中纬度典型值）。

**6. B** — 两者频散关系均为 $\omega = k\sqrt{gH_0}$（非频散）。开尔文波仅东传且需 $\beta \neq 0$。

**7. C** — 湿静力能 $= c_p T + gz + Lq$（显热 + 位能 + 潜热）。

**8. B** — 台风发展需要**弱**垂直风切变（$<10\,\text{m/s}$），强切变会破坏暖心结构。

**9. B** — $\frac{V}{R_s}$ 为曲率涡度（流线弯曲），$-\frac{\partial V}{\partial n}$ 为切变涡度。

**10. B** — $\tau_E = H / \sqrt{f_0 K_m/2} \approx 5$ 天。

## 三、简答题

**21. $f$ 平面与 $\beta$ 平面的区别：**

| 特征 | $f$ 平面近似 | $\beta$ 平面近似 |
|:---|:---|:---|
| $f$ 取值 | $f = f_0$ 常数 | $f = f_0 + \beta y$ |
| 适用条件 | 经向尺度 $\ll a$ | 需考虑 $f$ 变化对涡度的影响 |
| 应用 | 中尺度系统、地转适应 | 罗斯贝波、大尺度环流 |
| 涡度方程 | $\partial f/\partial y = 0$ | $\partial f/\partial y = \beta$ 保留 |

---

**22. 全位能不能全转换为动能的原因及有效位能：**

原因：
1. 正压大气中（无温度梯度）无驱动环流的力管
2. 大气热机效率受限于卡诺效率 $\eta \approx (T_h-T_c)/T_h \approx 10\%$
3. 经绝热质量重排后达到的正压参考状态具有最小全位能

**有效位能（APE）**：实际全位能与经绝热调整后的最小全位能之差。其物理意义是大气中真正能转换为动能的那部分位能。APE $\approx$ 全位能的 $1/200$，与温度扰动的平方成正比：
$$A^* = \frac{1}{2}\int \frac{\overline{T}}{\gamma_d-\gamma}\left(\frac{T'}{\overline{T}}\right)^2\frac{dp}{g}$$

---

**23. 小扰动法的步骤和局限性：**

**基本步骤**：
1. 将物理量分解为基本量 $+$ 扰动量：$f = \overline{f} + f'$
2. 基本量满足原方程和边界条件
3. 代入原方程，减去基本量方程
4. 略去扰动量二次及以上乘积项（线性化）
5. 设简正波解 $f' \propto e^{i(kx+ly-\omega t)}$，导出频散关系

**局限性**：
- 仅适用于小振幅阶段（初始发展阶段）
- 不能描述有限振幅的非线性过程（波-波相互作用、能量串级）
- 不能预测波动饱和、破碎等最终状态

---

**24. 正压与斜压不稳定比较：**

| 特征 | 正压不稳定 | 斜压不稳定 |
|:---|:---|:---|
| 能量来源 | 基本气流水平动能（水平切变） | 基本气流有效位能（温度梯度） |
| 必要条件 | $\beta - \overline{u}''$ 变号 | $\partial\overline{q}/\partial y$ 变号 |
| 能量转换项 | $\overline{u'v'}\partial\overline{u}/\partial y$ | $\overline{v'T'}\partial\overline{T}/\partial y$ |
| 典型现象 | 急流扰动 | 温带气旋生成、锋面波动 |

---

**25. CISK正反馈循环：**

1. **初始低压扰动** → 气压梯度力驱动低空辐合
2. **边界层摩擦辐合（Ekman抽吸）** → 水汽集中 + 上升运动
3. **积云对流触发** → 凝结潜热释放 → 加热中高层大气
4. **暖心建立** → 等压面抬高 → 地面气压降低 → 气旋环流增强
5. **反馈** → 更强的辐合 → 更多对流 → ...（循环加强）

需要条件：暖海温（$\ge 26.5^\circ\text{C}$）、弱风切变、高湿中层。

## 四、推导题

**26. $p$ 坐标系涡度方程推导：**

$p$ 坐标系水平运动方程：
$$\frac{\partial u}{\partial t} + u\frac{\partial u}{\partial x} + v\frac{\partial u}{\partial y} + \omega\frac{\partial u}{\partial p} = -\frac{\partial \Phi}{\partial x} + fv$$
$$\frac{\partial v}{\partial t} + u\frac{\partial v}{\partial x} + v\frac{\partial v}{\partial y} + \omega\frac{\partial v}{\partial p} = -\frac{\partial \Phi}{\partial y} - fu$$

取 $\frac{\partial}{\partial x}$(第二式) $-$ $\frac{\partial}{\partial y}$(第一式)，令 $\zeta_p = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}$：

$$\frac{\partial \zeta_p}{\partial t} + u\frac{\partial \zeta_p}{\partial x} + v\frac{\partial \zeta_p}{\partial y} + \omega\frac{\partial \zeta_p}{\partial p} = -\beta v - (f+\zeta_p)\left(\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}\right) + \left(\frac{\partial \omega}{\partial y}\frac{\partial u}{\partial p} - \frac{\partial \omega}{\partial x}\frac{\partial v}{\partial p}\right)$$

**与 $z$ 坐标系的主要区别**：
- $p$ 坐标系中**没有显式的力管项**（因 $\Phi$ 为单值函数，$\nabla \times \nabla\Phi = 0$）
- 斜压性通过扭曲项 $\frac{\partial \omega}{\partial y}\frac{\partial u}{\partial p} - \frac{\partial \omega}{\partial x}\frac{\partial v}{\partial p}$ 间接体现
- $p$ 坐标系形式更简洁，更适合大尺度分析

---

**27. $p$ 坐标系连续方程推导：**

$z$ 坐标系连续方程：
$$\frac{\partial \rho}{\partial t} + \frac{\partial(\rho u)}{\partial x} + \frac{\partial(\rho v)}{\partial y} + \frac{\partial(\rho w)}{\partial z} = 0$$

在 $p$ 坐标系中，利用静力平衡 $\partial p/\partial z = -\rho g$，进行坐标变换。最终得到：

$$\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial \omega}{\partial p} = 0$$

其中 $\omega = dp/dt$ 为 $p$ 坐标垂直速度。

**为何称为诊断方程**：该方程不含时间导数，不能用于预报，但可用于根据水平风场诊断垂直速度：
$$\omega(p) = \omega(p_0) - \int_{p_0}^{p} \left(\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}\right)_p dp$$

## 五、分析计算题

**28. 解：**

**(1) 热成风大小：**

$$\frac{\partial T}{\partial y} = \frac{-8}{5 \times 10^{5}} = -1.6 \times 10^{-5}\,\text{K/m}$$

$$V_T = \frac{R}{f} \left|\frac{\partial T}{\partial y}\right| \ln\frac{p_0}{p_1} = \frac{287}{10^{-4}} \times 1.6 \times 10^{-5} \times \ln\frac{850}{300}$$

$$= 2.87 \times 10^{6} \times 1.6 \times 10^{-5} \times 1.041 = 47.8\,\text{m/s}$$

**(2) $300\,\text{hPa}$ 地转风：**

$850\,\text{hPa}$：$u_g = 10\,\text{m/s}$（西风），$v_g = 0$

热成风公式 $\frac{\partial u_g}{\partial p} = \frac{R}{fp}\frac{\partial T}{\partial y}$：
$$\frac{\partial T}{\partial y} = -1.6 \times 10^{-5} < 0$$

$$\frac{\partial u_g}{\partial p} = \frac{287}{10^{-4} \times p} \times (-1.6 \times 10^{-5}) = -\frac{45.92}{p}$$

从 $850\,\text{hPa}$ 到 $300\,\text{hPa}$，$p$ 减小，$\frac{\partial u_g}{\partial p}$ 为负且绝对值增大 → $u_g$ 随高度增加。

热成风 $V_T = 47.8\,\text{m/s}$，方向：$\partial T/\partial y < 0$（北冷南暖），热成风为西风（与温度梯度方向满足热成风关系）。

$300\,\text{hPa}$ 地转风 $\approx 10 + 47.8 = 57.8\,\text{m/s}$ 的西风。

**(3) 冷暖平流分析：**

$850\,\text{hPa}$ 为纯西风（$v_g = 0$），无南北分量 → 无温度平流。

但热成风为西风说明 $u_g$ 随高度增加（风随高度顺转不显著，因 $v_g$ 始终为零）。

若实际风有微小的南北分量：
- 低层南风分量 + 北冷南暖 → 暖平流
- 低层北风分量 + 北冷南暖 → 冷平流

纯西风情况下无温度平流，温度场近似定常。
