# 动力气象学 综合试卷四 参考答案与解析

## 一、选择题

**1. D**

- 解析：$c_{gx} = \overline{u} - \frac{\beta(l^2-k^2)}{(k^2+l^2)^2}$。当 $k > l$ 时，$l^2-k^2 < 0$，故 $-\frac{\beta(l^2-k^2)}{(k^2+l^2)^2} > 0$，$c_{gx} > \overline{u}$。而相速度 $c_{px} = \overline{u} - \frac{\beta}{k^2+l^2} < \overline{u}$。因此 $c_{gx} > \overline{u} > c_{px}$，群速度向东且大于相速度，与相速度同向（均向东），但群速度超过基本气流。注意：群速度与相速度同向（均向东传播），不存在"反向"。

**2. B**

- 解析：重力内波频散关系中 $\omega$ 仅取决于波数矢量方向而非大小（$\omega = Nk/\sqrt{k^2+m^2} = N\cos\alpha$，其中 $\alpha$ 为波数矢量与水平面的夹角）。由此 $\mathbf{c}_g = \nabla_{\mathbf{K}}\omega$，且检验可知 $\mathbf{c}_g \cdot \mathbf{K} \neq 0$ 但在Boussinesq内波中有 $\mathbf{c}_g \perp \mathbf{c}$（群速度与相速度垂直），而非 $\mathbf{c}_g$ 与 $\mathbf{K}$ 垂直。需注意：群速度指向等频率面 $\omega(k,m)=$ 常数的梯度方向，在 $(k,m)$ 平面上与等频线垂直。

**3. C**

- 解析：Eady模型中最不稳定波长 $L \sim 3.9 H_\rho N/f$，该式不显含 $\partial\overline{u}/\partial z$（垂直切变仅影响增长率而不影响最不稳定波长）。但需要注意：实际上 Eady 最不稳定波长约为 $4.0 H_\rho N/f$，与切变无关。

**4. A**

- 解析：$\partial\overline{q}/\partial y = \beta - \partial^2\overline{u}/\partial y^2$（正压情况），Kuo定理要求 $\beta - \overline{u}''$ 在区域内改变符号，即绝对涡度梯度 $\beta - \overline{u}'' = \partial(\zeta_a)/\partial y$ 必须变号。这是正压不稳定必要条件的标准表述。

**5. B**

- 解析：$\omega^2 = f_0^2 + gH_0 K^2 \ge f_0^2$，故 $\omega \ge f_0$（取正频率分支）。$0 < \omega < f_0$ 的频率范围是惯性重力波不能传播的"间隙带"。

**6. B**

- 解析：斜压不稳定短波截断的物理原因是：短波的垂直穿透深度（与波长成正比）太小，无法使上下边界（如Eady模型中的两个刚壁边界，或Charney模型中的地面和无限高处）的位涡异常相互耦合产生正反馈。数学上表现为短波对应的垂直结构衰减太快。

**7. B**

- 解析：对称不稳定的必要条件为 $Ri < f/\zeta_a$。当 $\zeta_a \approx f$ 时简化为 $Ri < 1$。这比Kelvin-Helmholtz不稳定判据 $Ri < 0.25$ 更为宽松。对称不稳定是惯性不稳定（$\zeta_a < 0$）和静力不稳定（$N^2 < 0$）之间的"中间态"不稳定。

**8. C**

- 解析：罗斯贝波中 $c_{gx} = \overline{u} + \frac{\beta(k^2-l^2)}{(k^2+l^2)^2}$。当 $l > k$（经向尺度小于纬向尺度）时，$\frac{\beta(k^2-l^2)}{(k^2+l^2)^2} < 0$，可能使 $c_{gx} < \overline{u}$，甚至在 $\overline{u}$ 较小时使 $c_{gx} < 0$——能量逆基本气流向上游传播，激发上游新扰动。这就是"上游发展"的波能频散解释。

**9. A**

- 解析：Charney-Drazin定理给出罗斯贝波垂直传播的条件为 $0 < \overline{u} < \overline{u}_c$，其中 $\overline{u}_c = \beta/(k^2 + f_0^2/(4H_0^2 N^2))$。即需要西风但不大于临界值。东风（$\overline{u} < 0$）和强西风（$\overline{u} > \overline{u}_c$）均阻止垂直传播。这解释了平流层冬季（西风）可接收到上传行星波而夏季（东风）则不能。

**10. A**

- 解析：Charney-Stern定理是准地转斜压/正压不稳定的统一必要条件：经向位涡梯度 $\partial\overline{q}/\partial y$（含边界贡献）必须在区域内改变符号。这包含并推广了Kuo定理（正压情况）和Charney的斜压不稳定性判据。

## 三、简答题

**21. 罗斯贝波的"上游发展"与"下游发展"：**

**波能密度与波能通量**：
- 波能密度 $E \propto |\psi'|^2$（扰动振幅的平方）
- 波能通量 $\mathbf{F} = E\mathbf{c}_g$（能量以群速度传播）

**罗斯贝波群速度的特征**：
$$c_{gx} = \overline{u} + \frac{\beta(k^2-l^2)}{(k^2+l^2)^2}$$

- 当 $k \gg l$（纬向伸长型扰动）：$c_{gx} > \overline{u}$，群速度大于基本气流，能量**向下游**快速传播 → **下游发展**（downstream development）——在初始扰动东侧先后生成新的槽脊系统
- 当 $k \ll l$（经向伸长型扰动）：$c_{gx}$ 可能小于 $\overline{u}$ 甚至变为负值 → 能量逆基本气流**向上游**传播 → **上游发展**（upstream development）——初始扰动的西侧先出现加强

**天气尺度的典型特征**：天气尺度扰动通常 $k \approx l$（准各向同性），群速度向东但慢于基本气流。此时能量向下游传播，导致"下游频散增强"——扰动能量向下游频散，在下游激发出新的槽脊系统。这正是实际天气图上经常观测到的"下游效应"：一个强槽的下游常可见到新生且加强的扰动。

**22. Eady模型与Charney模型的比较：**

| 特征 | Eady模型 | Charney模型 |
|:---|:---|:---|
| **基本气流** | $\partial\overline{u}/\partial z = \Lambda$ 常数（线性切变） | $\partial\overline{u}/\partial z = \Lambda$ 常数（线性切变） |
| **$\beta$ 效应** | $\beta = 0$（$f$ 平面） | $\beta \neq 0$（$\beta$ 平面） |
| **上边界** | 刚壁（$z=H$） | 辐射边界（$z \to \infty$） |
| **下边界** | 刚壁（$z=0$） | 地面（$z=0$） |
| **不稳定机制** | 上下边界Rossby边缘波的位相锁定 | 地面Rossby边缘波与内部Rossby波的相互作用 |
| **短波截断** | 有（波长 $\sim 2.4 H_\rho N/f$） | 有（$\beta$ 效应提供额外截断） |
| **长波截断** | 无（任意长波均可不稳定） | 有（$\beta$ 效应导致长波稳定） |
| **最不稳定波长** | $\sim 3.9 H_\rho N/f$ | $\sim 4.0 H_\rho N/f$（与Eady相近） |

**物理机制的共同点**：均通过Rossby边缘波（由边界上的经向位涡梯度"代理"）之间的相互作用产生不稳定。不同之处在于Charney模型中$\beta$效应提供内部位涡梯度，使之更接近真实大气。

**23. 波-流相互作用及Eliassen-Palm通量：**

**波-流相互作用（wave-mean flow interaction）** 指大气波动通过输送动量、热量等物理量与基本气流（平均流）之间发生的双向反馈过程。

**Rossby波上传的物理图像**：
1. 对流层（如地形或斜压扰动）激发Rossby波
2. Rossby波沿西风气流向上传播（满足Charney-Drazin条件 $0 < \overline{u} < \overline{u}_c$）
3. 波动携带的Eliassen-Palm（EP）通量向上传输

**EP通量散度的作用**：
$$\frac{\partial\overline{u}}{\partial t} = \frac{1}{\rho_0}\nabla\cdot\mathbf{F} + \text{（其他强迫项）}$$

- 当 $\nabla\cdot\mathbf{F} > 0$（EP通量辐散）→ $\partial\overline{u}/\partial t > 0$ → **西风加速**
- 当 $\nabla\cdot\mathbf{F} < 0$（EP通量辐合）→ $\partial\overline{u}/\partial t < 0$ → **西风减速/东风加速**

典型例子：平流层爆发性增温（SSW）——对流层上传的行星波在平流层发生EP通量辐合，导致极夜急流减速甚至反转，伴随极区剧烈增温（下沉运动）。

**物理本质**：波动消耗自身的波能（或波作用量）来改变基本气流的动量分布，实现"波-流"间的能量和动量交换。

**24. 对称不稳定与惯性/静力不稳定的关系：**

**三者关系的统一框架**：
在 $(y,z)$ 平面或 $(x,z)$ 平面内，大气的浮力（静力恢复力）和惯性（旋转恢复力）共同决定气块位移后的稳定性。

考虑气块沿等熵面倾斜位移时：
- **静力不稳定**：纯垂直位移，$N^2 < 0$，恢复力为浮力
- **惯性不稳定**：纯水平位移，$\zeta_a = f - \partial\overline{u}/\partial y < 0$，恢复力为惯性力（科氏力+离心力）
- **对称不稳定**：倾斜位移，当 $Ri < f/\zeta_a$ 时发生，即 $f^2/N^2 < (\partial\overline{u}/\partial z)^2$

**对称不稳定的条件**：
$$Ri = \frac{N^2}{(\partial\overline{u}/\partial z)^2} < \frac{f}{\zeta_a} \approx 1 \quad(\text{当 }\zeta_a \approx f\text{ 时})$$

**在锋面降水带状结构中的作用**：
1. 锋面区域通常有强水平温度梯度（斜压性强），满足 $\partial\overline{u}/\partial z$ 大（热成风强）
2. 锋面附近 $N^2$ 可能因湿过程而减小，$Ri$ 可以降至临界值以下
3. 对称不稳定引发倾斜对流——沿等熵面的倾斜上升运动
4. 倾斜对流在水平方向呈带状排列（与热成风方向平行），产生**带状降水结构**
5. 这是许多中纬度锋面降水呈现"雨带交替"特征的重要机制之一

**25. 正压能量转换项的物理意义：**

$$\langle -\overline{u'v'}\frac{\partial\overline{u}}{\partial y}\rangle$$

- **动量通量**：$\overline{u'v'}$ 为扰动动量经向输送（协方差）
- **切变**：$\partial\overline{u}/\partial y$ 为基本气流的水平切变

**物理图像**：
- $\overline{u'v'} < 0$ 且 $\partial\overline{u}/\partial y > 0$ → 转换项为正 → 扰动从基本气流获取动能（正压不稳定）
- $\overline{u'v'} > 0$ 且 $\partial\overline{u}/\partial y > 0$ → 转换项为负 → 扰动向基本气流输送动能（正压稳定）

**急流两侧方向相反的原因**：
急流南侧 $\partial\overline{u}/\partial y > 0$（风速向北减小），急流北侧 $\partial\overline{u}/\partial y < 0$（风速向北增大减至零）。扰动动量通量 $\overline{u'v'}$ 的符号也随纬向变化（与波动倾斜方向有关）。因此在急流两侧，$\overline{u'v'}$ 与 $\partial\overline{u}/\partial y$ 的乘积符号可能不同，导致一侧能量从基本流转入扰动，另一侧反向——正压衰减与正压增长共同存在。

## 四、推导题

**26. Charney-Stern不稳定必要条件的推导：**

**步骤1：写出线性化准地转位涡方程**

$$\left(\frac{\partial}{\partial t} + \overline{u}\frac{\partial}{\partial x}\right)q' + \frac{\partial\overline{q}}{\partial y}\frac{\partial\psi'}{\partial x} = 0$$

其中：
$$q' = \nabla^2\psi' + \frac{f_0^2}{N^2}\frac{\partial^2\psi'}{\partial z^2},\quad \frac{\partial\overline{q}}{\partial y} = \beta - \frac{\partial^2\overline{u}}{\partial y^2} - \frac{f_0^2}{N^2}\frac{\partial^2\overline{u}}{\partial z^2}$$

**步骤2：设简正波解**

$\psi' = \Psi(y,z)e^{ik(x-ct)}$，代入方程：

$$(\overline{u} - c)\underbrace{\left(\frac{\partial^2\Psi}{\partial y^2} - k^2\Psi + \frac{f_0^2}{N^2}\frac{\partial^2\Psi}{\partial z^2}\right)}_{q_\Psi} + \frac{\partial\overline{q}}{\partial y}\Psi = 0$$

**步骤3：用 $\Psi^*/(\overline{u}-c)$ 乘以方程，并对 $(y,z)$ 全域积分**

积分域：经向从 $y_1$ 到 $y_2$（刚壁或无穷远，$\Psi=0$），垂直从 $z=0$ 到 $z=H$。

$$\int\int \frac{|\Psi|^2}{\overline{u}-c}\frac{\partial\overline{q}}{\partial y} + \Psi^*\left(\frac{\partial^2\Psi}{\partial y^2} - k^2\Psi + \frac{f_0^2}{N^2}\frac{\partial^2\Psi}{\partial z^2}\right) + \text{c.c.} = 0$$

**步骤4：分部积分**

对 $\frac{\partial^2\Psi}{\partial y^2}$ 项：
$$\int_{y_1}^{y_2} \Psi^*\frac{\partial^2\Psi}{\partial y^2}dy = \left.\Psi^*\frac{\partial\Psi}{\partial y}\right|_{y_1}^{y_2} - \int_{y_1}^{y_2} \left|\frac{\partial\Psi}{\partial y}\right|^2 dy$$

边界条件 $\Psi=0$ 使边界项为零。垂直方向类似处理。

**步骤5：取虚部**

$c = c_r + ic_i$，其中 $c_i > 0$ 为不稳定。

$$\text{Im}\left(\frac{1}{\overline{u}-c}\right) = \frac{c_i}{(\overline{u}-c_r)^2 + c_i^2} > 0$$

积分式取虚部：
$$\int\int \frac{|\Psi|^2 c_i}{|\overline{u}-c|^2} \frac{\partial\overline{q}}{\partial y}\,dy\,dz + \text{（边界贡献）} = 0$$

**步骤6：Charney-Stern定理的结论**

由于 $c_i > 0$ 且 $|\Psi|^2/|\overline{u}-c|^2 > 0$，要使积分为零，**$\partial\overline{q}/\partial y$ 必须在区域内改变符号**（或边界上有等效的"代理"梯度使其变号）。这就是Charney-Stern不稳定必要条件。

**特殊情形**：
- 正压情况（无垂直切变）：退化为Kuo定理 $(\beta - \overline{u}'')$ 必须变号
- Eady情况（$\beta=0$, $\partial\overline{q}/\partial y=0$ 内部，不稳定来自上下边界 $\partial\overline{u}/\partial z \neq 0$ 的边界贡献）
- Charney情况（$\beta \neq 0$）：内部 $\partial\overline{q}/\partial y = \beta > 0$，但地面边界提供反向贡献

**27. 对称不稳定判据的推导：**

**步骤1：二维 $(x,z)$ Boussinesq方程组**

设基本量为 $\overline{u}(y,z)$ 满足热成风平衡：
$$f\frac{\partial\overline{u}}{\partial z} = -\frac{g}{\theta_0}\frac{\partial\overline{\theta}}{\partial y}$$

考虑沿 $(x,z)$ 平面的二维扰动（$\partial/\partial y = 0$ 且 $v$ 方程用于约束 $\partial\overline{u}/\partial y$ 的惯性效应）。

**步骤2：气块倾斜位移法**

考虑一气块从其平衡位置做一倾斜位移，位移矢量与水平面的夹角为 $\alpha$，即位移方向取决于 $M$（绝对动量）和 $\theta$ 的等值面。

定义绝对动量 $M = \overline{u} - fy$（$y$ 方向），满足 $\partial M/\partial z = \partial\overline{u}/\partial z$，$\partial M/\partial y = \partial\overline{u}/\partial y - f = -\zeta_a$。

**步骤3：气块位移后的恢复力**

气块沿倾斜路径 $dz/dy = \tan\alpha$ 位移后，所受的有效恢复力（单位质量）取决于：

- 沿 $(y,z)$ 的浮力梯度（$\partial\overline{\theta}/\partial y, \partial\overline{\theta}/\partial z$）
- 沿 $(y,z)$ 的惯性力梯度（$\partial M/\partial y, \partial M/\partial z$）

有效浮力频率的平方（沿倾斜路径）为：
$$N_{\text{eff}}^2 = N^2\cos^2\alpha + f\zeta_a\sin^2\alpha - 2f\frac{\partial\overline{u}}{\partial z}\sin\alpha\cos\alpha$$

其中第三项来自热成风关系。

**步骤4：对称不稳定的临界条件**

当 $N_{\text{eff}}^2 < 0$ 时，倾斜位移在 $\alpha$ 方向失去恢复力，发生对称不稳定。

求 $N_{\text{eff}}^2$ 关于 $\alpha$ 的最小值，可得最不稳定倾斜角满足：
$$\tan(2\alpha_{\max}) = \frac{2f\partial\overline{u}/\partial z}{N^2 - f\zeta_a}$$

代入后，$N_{\text{eff}}^2 < 0$ 的条件为：
$$\left(f\frac{\partial\overline{u}}{\partial z}\right)^2 > N^2 f\zeta_a$$

即：
$$Ri = \frac{N^2}{(\partial\overline{u}/\partial z)^2} < \frac{f}{\zeta_a}$$

**步骤5：当 $\zeta_a \approx f$ 时**

在大尺度地转平衡下，$\partial\overline{u}/\partial y \ll f$，故 $\zeta_a = f - \partial\overline{u}/\partial y \approx f$，此时：
$$Ri < 1$$

这就是对称不稳定的常用近似判据。注意它与 Kelvin-Helmholtz 不稳定（$Ri < 1/4$）的区别：对称不稳定是准二维的、沿等熵面倾斜的不稳定，K-H 不稳定是纯垂直切变引起的小尺度不稳定。

## 五、综合分析题

**28. 解：**

**(1) 正压不稳定判断：**

$\overline{u}(y) = U_0\,\text{sech}^2(y/L)$，$U_0 = 50\,\text{m/s}$，$L = 800\,\text{km} = 8 \times 10^5\,\text{m}$

计算二阶导数。设 $\xi = y/L$：
$$\overline{u}(\xi) = U_0\,\text{sech}^2\xi$$

一阶导数：
$$\frac{\partial\overline{u}}{\partial y} = U_0 \cdot (-2)\,\text{sech}^2\xi \cdot \tanh\xi \cdot \frac{1}{L} = -\frac{2U_0}{L}\text{sech}^2\xi\tanh\xi$$

二阶导数（使用 $\frac{d}{d\xi}(\text{sech}^2\xi\tanh\xi) = \text{sech}^4\xi - 2\text{sech}^2\xi\tanh^2\xi$）：
$$\frac{\partial^2\overline{u}}{\partial y^2} = \frac{2U_0}{L^2}\text{sech}^2\xi(3\tanh^2\xi - 1)$$

在急流轴上 $\xi = 0$：$\text{sech}^2(0) = 1$，$\tanh(0) = 0$
$$\left.\frac{\partial^2\overline{u}}{\partial y^2}\right|_{y=0} = \frac{2U_0}{L^2} \times 1 \times (0 - 1) = -\frac{2U_0}{L^2}$$

$$= -\frac{2 \times 50}{(8 \times 10^5)^2} = -\frac{100}{6.4 \times 10^{11}} = -1.5625 \times 10^{-10}\,\text{m}^{-1}\text{s}^{-1}$$

$$\beta - \frac{\partial^2\overline{u}}{\partial y^2} = 1.6 \times 10^{-11} - (-1.5625 \times 10^{-10}) = 1.7225 \times 10^{-10} > 0$$

在急流轴上，$\partial(\zeta_a)/\partial y > 0$（不变号）。但由于急流两侧 $\partial^2\overline{u}/\partial y^2$ 符号改变（$\xi=0$ 处为负，远离急流轴处 $3\tanh^2\xi > 1$ 时变为正），在 $y = \pm y_c$ 处（$3\tanh^2(y_c/L) = 1$ 即 $\tanh(y_c/L) = 1/\sqrt{3}$，$y_c \approx \pm 0.66L \approx \pm 527\,\text{km}$）$\partial^2\overline{u}/\partial y^2 = 0$，满足Kuo定理的变号条件 → **存在正压不稳定的可能**。

**(2) 最不稳定斜压波波长（Eady模型）：**

$$L_c \approx 4.0\, H_\rho \frac{N}{f} = 4.0 \times 8 \times 10^3 \times \frac{\sqrt{1.0 \times 10^{-4}}}{10^{-4}}$$

$$= 4.0 \times 8 \times 10^3 \times \frac{10^{-2}}{10^{-4}} = 4.0 \times 8 \times 10^3 \times 100 = 3.2 \times 10^6\,\text{m} = 3200\,\text{km}$$

该值接近中纬度典型天气尺度斜压波的观测波长（$\sim 3000\text{–}4000\,\text{km}$）。

**(3) 罗斯贝波列群速度与能量传播：**

波数 $k = 2\pi/(4 \times 10^6) = 1.57 \times 10^{-6}\,\text{m}^{-1}$

忽略 $l$（$l=0$）时：
$$c_{px} = \overline{u} - \frac{\beta}{k^2} = 50 - \frac{1.6 \times 10^{-11}}{(1.57 \times 10^{-6})^2} = 50 - \frac{1.6 \times 10^{-11}}{2.46 \times 10^{-12}}$$
$$= 50 - 6.50 = 43.5\,\text{m/s}$$

$$c_{gx} = \overline{u} + \frac{\beta}{k^2} = 50 + 6.50 = 56.5\,\text{m/s}$$

这里 $c_{gx} > c_{px}$ 且 $c_{gx} > \overline{u}$，群速度超过基本气流，能量向下游传播。

**分析**：
- 该罗斯贝波的相速度为 $43.5\,\text{m/s}$（向东），群速度为 $56.5\,\text{m/s}$（向东更快）
- $c_{gx} > \overline{u}$ 意味着波能从急流出口区**向下游快速频散**
- 下游急流入口区将先于位相"感受"到能量输入 → 激发新的槽脊系统
- 这是典型的**下游发展**（downstream development）场景
- 能量传播时间：下游 $2000\,\text{km}$ 处约需 $2000\times 10^3 / (56.5 - 50) \approx 3.6 \times 10^5\,\text{s} \approx 4$ 天即可接收到能量

**结论**：该波列可以有效地将能量从急流出口区向下游急流入口区传播，支持温带气旋家族的下游发展序列。
