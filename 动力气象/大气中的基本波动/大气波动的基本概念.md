## 大气波动的基本概念

**重点**

1. 波动是振动状态在空间中的传播，传播的是相位和能量，而非介质质点——介质质点仅在平衡位置附近做同频率振动
2. 相速度 $c = \omega/k$ 描述等位相面的传播速度，群速度 $c_g = d\omega/dk$ 描述波包（能量）的传播速度，二者仅在非频散波中相等
3. 频散波中 $c_g \neq c$，相速度依赖于波数（波长），导致不同频率的分量传播速度不同，波形在传播中扩散
4. 小扰动法将物理量分解为基本量与扰动量（$f = \overline{f} + f'$），线性化后略去扰动量的二次及以上乘积项，是研究波动频散关系和稳定性的基本方法
5. 标准波形法（简正波法）将扰动设为 $A e^{i(kx+ly+mz-\omega t)}$ 形式代入线性化方程组，导出频散关系 $\omega = \omega(k,l,m)$，将波动问题转化为本征值问题
6. 复数表示利用欧拉公式使求导运算简化为代数运算：$\partial/\partial t \to -i\omega$，$\partial/\partial x \to ik$，$\nabla \to i\mathbf{K}$，极大简化频散关系的推导
7. 频散关系中 $\operatorname{Im}(\omega)$ 的符号决定波动稳定性：$\operatorname{Im}(\omega) > 0$ 为不稳定增长波，$= 0$ 为中性稳定波，$< 0$ 为衰减波
8. 大气中的波动按恢复机制分类：声波（可压缩性）、重力外波（重力+自由面）、重力内波（浮力+稳定层结）、惯性波（科氏力）、罗斯贝波（$\beta$效应），不同波动有不同的滤波条件

### 1. 波动的定义与基本特征

**波动**是振动状态（或扰动）在空间中的传播过程。大气中存在着各种不同频率和振幅的波动，如声波、重力波、惯性波、罗斯贝波等，它们是大尺度环流演变和天气系统发生发展的重要形式。

波动的基本特征：
- **相位传播**：振动状态（即相位）在介质中传播。
- **能量传播**：波动携带能量，振源不断输入能量以维持波动。
- **质点不随波逐流**：介质质点仅在自身平衡位置附近做同频率、同方向的振动，各质点的振动相位沿传播方向依次落后。

### 2. 描述波动的基本物理参量

以一维简谐波为例：$f(x,t) = A \cos(kx - \omega t + \alpha)$

| 参数 | 符号 | 定义 | 关系 |
| :--- | :--- | :--- | :--- |
| 振幅 | $A$ | 质点离开平衡位置的最大位移 | — |
| 波长 | $L$（或 $\lambda$） | 相邻两个同相位点之间的距离 | $L = \frac{2\pi}{k}$ |
| 波数 | $k$ | $2\pi$ 距离内所含波长的数目 | $k = \frac{2\pi}{L}$ |
| 周期 | $T$ | 质点完成一次全振动所需的时间 | $T = \frac{2\pi}{\omega}$ |
| 频率 | $f$ | 单位时间内完成全振动的次数 | $f = \frac{1}{T}$ |
| 圆频率（角频率） | $\omega$ | 单位时间内位相的变化（弧度） | $\omega = 2\pi f = \frac{2\pi}{T}$ |
| 相速度 | $c$ | 等位相面的传播速度 | $c = \frac{\omega}{k} = \frac{L}{T}$ |
| 初位相 | $\alpha$ | $t=0$ 时的位相 | — |

**几点说明**：
- 波数也可定义为 $k = 1/L$（光谱学常用），但在动力气象学中通常采用 $k = 2\pi/L$。
- 圆频率 $\omega > 0$ 表示波动随时间周期性变化，波数 $k > 0$ 表示波动沿 $x$ 方向传播。

### 3. 简谐波动方程

- **一维**：$f(x,t) = A \cos(kx - \omega t + \alpha)$
- **二维**：$f(x,y,t) = A \cos(kx + ly - \omega t + \alpha)$
- **三维**：$f(x,y,z,t) = A \cos(kx + ly + mz - \omega t + \alpha)$

其中 $k, l, m$ 分别为 $x, y, z$ 方向的波数。引入**波数矢量**：
$$\mathbf{K} = k\mathbf{i} + l\mathbf{j} + m\mathbf{k} = \nabla \theta$$
其中 $\theta = \mathbf{K}\cdot\mathbf{r} - \omega t$ 为位相。等位相面由 $\mathbf{K}\cdot\mathbf{r} - \omega t = \text{常数}$ 给出，是平面波。波数矢量的模为：
$$K = |\mathbf{K}| = \sqrt{k^2 + l^2 + m^2}$$

### 4. 相速度与群速度

#### （1） 相速度

等位相面移动的速度，方向沿波数矢量方向：
$$\mathbf{c} = \frac{\omega}{K^2} \mathbf{K}$$
大小 $c = \frac{\omega}{K}$。对于一维情形，$c = \frac{\omega}{k}$。

#### （2） 群速度与频散

实际大气中的波动通常不是单一频率的单色波，而是许多不同频率、不同波数的波叠加而成的**波群**（群波）。波群中**包络线（波包）**的移动速度称为**群速度** $c_g$，它代表波动能量的传播速度。

对于一维波群，由两个频率相近的波叠加：
$$f_1 + f_2 = 2A \cos\left(\frac{\Delta k}{2}x - \frac{\Delta \omega}{2}t\right) \cos(kx - \omega t)$$
包络线传播速度为：
$$c_g = \frac{\Delta \omega}{\Delta k} \xrightarrow{\Delta k \to 0} \frac{d\omega}{dk}$$

群速度与相速度的关系：
$$c_g = \frac{d\omega}{dk} = \frac{d(kc)}{dk} = c + k\frac{dc}{dk}$$

- **非频散波**：$dc/dk = 0$，即相速度与波数无关，则 $c_g = c$。波动能量与相位一起传播，波形不扩散。
- **频散波**：$dc/dk \neq 0$，即相速度依赖于波数（或波长），则 $c_g \neq c$。波包与载波分离，波形随传播而扩散。$c_g > c$ 时能量先于相位到达下游，$c_g < c$ 时能量滞后。

### 5. 波动方程的复数表示

利用欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$，简谐波可表示为复数形式：
$$f(x,t) = \operatorname{Re}\left\{ A e^{i(kx - \omega t + \alpha)} \right\} = \operatorname{Re}\left\{ F e^{i(kx - \omega t)} \right\}$$
其中 $F = A e^{i\alpha}$ 称为**复振幅**（包含振幅和初位相信息）。实际应用中常省略“Re”，直接用复数表示，最后取实部得到物理量。复数表示的优点是求导运算简便：
$$\frac{\partial}{\partial t} \to -i\omega,\quad \frac{\partial}{\partial x} \to ik,\quad \nabla \to i\mathbf{K}$$

### 6. 小扰动法与线性化

大气运动的基本方程组是非线性的，难以直接解析求解。**小扰动法**（微扰法）是研究波动问题的基本方法。

#### 基本思想
1. 将任一物理量分解为**基本量**（代表大气的平衡状态）和**扰动量**（代表波动）：
   $$f(x,y,z,t) = \overline{f}(y,z) + f'(x,y,z,t)$$
   基本量可以是静止状态（$\overline{u}=0$）或均匀西风基流（$\overline{u}=\text{const}$）等。
2. 基本量满足基本方程和边界条件。
3. 假设扰动量的振幅远小于基本量（$|f'| \ll |\overline{f}|$），或其空间导数很小。
4. 将分解后的表达式代入原始方程，减去基本量满足的方程，并略去扰动量的二次及以上乘积项（非线性项），得到**线性化扰动方程组**。

#### 适用范围
- 仅适用于波动的**初始发展阶段**（小振幅阶段）。
- 对于有限振幅波动（如发展旺盛的气旋、台风），非线性项重要，小扰动法失效。
- 是研究波动频散关系、稳定性等基本性质的常用工具。

#### 基本量的常见取法
- 静止大气：$\overline{u} = \overline{v} = \overline{w} = 0$，$\overline{\rho}=\overline{\rho}(z)$，$\overline{\theta}=\overline{\theta}(z)$
- 均匀西风基流：$\overline{u} = \text{const}$，$\overline{v} = \overline{w} = 0$
- 切变基流：$\overline{u}(y,z)$（用于斜压或正压不稳定分析）

### 7. 标准波形法（简正波法）

在得到线性化扰动方程组后，通常假设波动解具有简正波形式：
$$(u', v', w', p', \rho', \theta') = (\hat{u}(z), \hat{v}(z), \hat{w}(z), \hat{p}(z), \hat{\rho}(z), \hat{\theta}(z)) e^{i(kx + ly - \omega t)}$$
其中 $k, l$ 为水平波数（实数），$\omega$ 为圆频率（一般为复数）。将其代入线性化方程组，得到关于振幅的常微分方程（**本征值问题**）。本征值 $\omega$ 与波数的关系 $\omega = \omega(k,l)$ 称为**频散关系**（或频率方程）。

- 若 $\operatorname{Im}(\omega) > 0$，则波动随时间指数增长，称为**不稳定波**。
- 若 $\operatorname{Im}(\omega) < 0$，波动衰减（通常由耗散引起）。
- 若 $\operatorname{Im}(\omega) = 0$，波动是**中性稳定**的，以恒定振幅传播。

通过频散关系可计算相速度和群速度，判断波动的性质（快波/慢波，频散/非频散，稳定/不稳定等）。

### 8. 大气中常见波动的分类

| 波动类型 | 恢复机制 | 主要特征 | 典型频率 | 滤波条件 |
| :--- | :--- | :--- | :--- | :--- |
| 声波 | 可压缩性 | 快波，纵波，非频散 | $\omega \sim c_s k$ | 不可压、静力平衡 |
| 重力外波 | 重力 + 自由面 | 快波，横波，浅水波非频散 | $\omega = \sqrt{gH_0}k$ | 固定上下边界 |
| 重力内波 | 浮力（稳定层结） | 慢波，频散，$c \perp c_g$ | $\omega \le N$ | 中性层结 |
| 惯性波 | 科氏力 | 慢波，频散 | $\omega = f$ | 无科氏力 |
| 惯性重力波 | 科氏力 + 浮力 | 混和波，频散 | $\omega > \max(N,f)$ | 无层结/无旋转 |
| 罗斯贝波 | $\beta$ 效应 | 慢波，准水平，频散 | $\omega = -\frac{\beta k}{k^2+l^2}$ | 无 $\beta$ 效应、无涡度 |

## 小结

| 概念 | 核心要点 |
| :--- | :--- |
| 波动 | 振动状态在空间中的传播，能量传递，质点不随波迁移 |
| 描述参数 | $A, L, k, T, \omega, f, c$ |
| 相速度 $c$ | 等位相面移动速度，$c = \omega/k$ |
| 群速度 $c_g$ | 波包（能量）移动速度，$c_g = d\omega/dk$ |
| 频散波 | $c_g \neq c$，相速度依赖于波长 |
| 小扰动法 | 将变量分解为基本量+扰动量，线性化，略去高阶项 |
| 标准波形法 | 设解为 $e^{i(kx+ly-\omega t)}$，导出频散关系 |
| 复数表示 | $e^{i(kx-\omega t)}$，求导简化为乘 $i$ 因子 |

大气波动的基本概念是理解各类波动特性（传播、频散、能量输送、稳定性）的基础，也是后续分析罗斯贝波、重力波、惯性波的前提。
