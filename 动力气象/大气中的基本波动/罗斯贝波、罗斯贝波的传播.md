## 罗斯贝波、罗斯贝波的传播

**重点**

1. 罗斯贝波（大气长波/行星波）的恢复力是 $\beta$ 效应（$df/dy = \beta$），物理机制为绝对涡度守恒 $\frac{d}{dt}(\zeta+f)=0$：质点南北运动引起 $f$ 变化，为保持绝对涡度守恒而改变相对涡度 $\zeta$，从而使槽脊向西发展
2. 正压无辐散罗斯贝波的频散关系为 $\omega = \overline{u}k - \frac{\beta k}{k^2+l^2}$，相对于基本气流总是向西传播（$c_{px} - \overline{u} = -\beta/(k^2+l^2) < 0$），是典型的频散慢波
3. 静止波长 $L_s = 2\pi\sqrt{\overline{u}/\beta}$ 是判别波动地面传播方向的关键参数：$L < L_s$ 时波动东进，$L > L_s$ 时波动西退，$L = L_s$ 时准静止
4. 群速度 $c_{gx} = \overline{u} + \beta\frac{k^2-l^2}{(k^2+l^2)^2}$，当 $k^2 > l^2$（纬向波数大于经向波数）时 $c_{gx} > c_{px}$，能量先于位相到达下游，产生"上游效应"，是中长期天气预报上下游效应理论的基础
5. 斜压大气中罗斯贝波可沿垂直方向传播，传播条件由 $m^2 = \frac{N^2}{f_0^2}\left(\frac{\beta}{c-\overline{u}} - k^2 - l^2\right) > 0$ 决定，对流层中罗斯贝波通常呈现相当正压结构
6. 冬季中高纬度对流层中上层 500hPa 位势高度图上常可看到 3-5 个长波绕纬圈分布，超长波（波数 1-2）通常准静止或缓慢西退
7. 阻塞高压和切断低压是罗斯贝波强烈非线性发展的产物，可维持数天至数周，造成持续性异常天气，是中长期预报的重点难题
8. 忽略 $\beta$ 效应（取 $f$ 为常数 $f_0$）即可滤除罗斯贝波；准地转近似则保留罗斯贝波而滤除重力惯性波，是大尺度动力学标准分析框架

### 1. 罗斯贝波的基本概念

**罗斯贝波**（Rossby Wave）又称**大气长波**或**行星波**，是大尺度大气运动中最重要的一类波动。它是由地球旋转效应（主要是科氏参数 $f$ 随纬度的变化，即 $\beta$ 效应）作为恢复力而产生的涡旋性慢波。在北半球中纬度对流层中上层，等压面图上常可看到 3–6 个波绕纬圈分布，这些正是罗斯贝波。

罗斯贝波具有以下基本特征：
- **准水平、准无辐散**，以涡旋运动为主。
- **传播速度较慢**（与西风风速同量级），相对于基本气流向西传播（但若基本西风足够强，可表现为向东传播）。
- **频散波**，能量传播速度（群速度）可与相速度不同，具有重要的上游效应。
- **水平尺度大**（数千公里），可与地球半径相比拟，因此也称行星波。

### 2. 罗斯贝波的物理机制——$\beta$ 效应

考虑正压、水平无辐散的大气。绝对涡度 $\zeta_a = \zeta + f$ 守恒：
$$\frac{d}{dt}(\zeta + f) = 0$$

初始时刻，假设在某一纬带上有一列正弦形流线（或等高线）扰动。在扰动波中，质点南北运动引起 $f$ 的变化，为保持绝对涡度守恒，相对涡度 $\zeta$ 必须相应变化，从而改变流场，使波形移动。

具体过程（北半球）：
- 在 **A–C 段**：质点向南运动（$v<0$），$f$ 减小 → $\zeta$ 增大（气旋性涡度增加）→ 产生正的 $\zeta$ 倾向，使槽加深并向西扩展。
- 在 **C–E 段**：质点向北运动（$v>0$），$f$ 增大 → $\zeta$ 减小（反气旋性涡度增加）→ 产生负的 $\zeta$ 倾向，使脊加深并向西扩展。

结果：整个波动**向西传播**（相对于基本气流）。这就是罗斯贝波的基本形成机制。若基本气流为西风 $\overline{u}$，则波动相对于地面的传播速度为 $\overline{u} + c_r$（$c_r$ 为相对基本气流的西传速度），当西风足够强时，波动可表现为向东移动。

### 3. 正压无辐散罗斯贝波理论

#### （1） 基本方程

正压、水平无辐散、无摩擦的涡度方程为：
$$\frac{d(\zeta + f)}{dt} = 0$$

在局地直角坐标系中，$\zeta = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}$，$f = f_0 + \beta y$。设基本气流为均匀西风：$u = \overline{u} + u'$，$v = v'$，线性化得：
$$\frac{\partial \zeta'}{\partial t} + \overline{u} \frac{\partial \zeta'}{\partial x} + \beta v' = 0$$

引入流函数 $\psi$：$u' = -\frac{\partial \psi'}{\partial y}$，$v' = \frac{\partial \psi'}{\partial x}$，$\zeta' = \nabla^2 \psi'$，代入得：
$$\left(\frac{\partial}{\partial t} + \overline{u} \frac{\partial}{\partial x}\right) \nabla^2 \psi' + \beta \frac{\partial \psi'}{\partial x} = 0$$

#### （2） 频散关系

设波动解 $\psi' = \Psi e^{i(kx+ly-\omega t)}$，代入得频率方程：
$$\omega = \overline{u} k - \frac{\beta k}{k^2 + l^2}$$

- 纬向相速度：
  $$c_{px} = \frac{\omega}{k} = \overline{u} - \frac{\beta}{k^2 + l^2}$$
- 纬向群速度：
  $$c_{gx} = \frac{\partial \omega}{\partial k} = \overline{u} + \beta \frac{k^2 - l^2}{(k^2 + l^2)^2}$$

**重要结论**：
- 相对于基本气流，罗斯贝波总是**向西传播**（$c_{px} - \overline{u} = -\beta/(k^2+l^2) < 0$）。
- 相速度与波数有关 → **频散波**。
- 长波（$k$ 小）向西传播更快（$|c_{px} - \overline{u}|$ 大），短波传播较慢。
- 存在**静止波波长** $L_s = 2\pi \sqrt{\overline{u}/\beta}$：当实际波长 $L = L_s$ 时，$c_{px}=0$，波动相对于地面静止；$L > L_s$ 时，$c_{px} < 0$（西退）；$L < L_s$ 时，$c_{px} > 0$（东进，但相对于基本气流仍是西传）。
- 对于中纬度典型值：$L_x = 6000\,\text{km}$，$L_y = 3000\,\text{km}$，$c_{px} - \overline{u} \approx -3\,\text{m/s}$，波动缓慢西退；若 $\overline{u} \approx 10\,\text{m/s}$，则 $c_{px} \approx 7\,\text{m/s}$ 向东移动。

### 4. 罗斯贝波的传播与能量频散

#### （1） 能量频散与上游效应

由于罗斯贝波是频散波，群速度 $c_{gx}$ 与相速度 $c_{px}$ 不同。对于正压无辐散情况：
- 当 $k^2 > l^2$（纬向波数大于经向波数，即纬向尺度较小）时，$c_{gx} > \overline{u}$，且 $c_{gx} > c_{px}$（短波条件下能量向东传播更快）。
- 当 $k^2 < l^2$ 时，$c_{gx} < \overline{u}$（长波条件下能量传播慢于基本气流）。

**上游效应**：当上游出现新的扰动时，其能量以群速度向下游传播。由于群速度可能大于相速度，下游地区可提前感受到扰动的影响，从而在新的地区激发出波动或使已有波动加强。这是中长期天气预报中“上下游效应”的理论基础。

#### （2） 经向传播与波导

若基本气流 $\overline{u}$ 随纬度变化（例如存在急流轴），则波动可在经向方向传播。采用 WKB 方法，可导出经向波数满足：
$$l^2 = \frac{\beta - \overline{u}''}{\overline{u} - c} - k^2$$
其中 $\overline{u}'' = d^2\overline{u}/dy^2$。波动在 $l^2 > 0$ 的区域传播（波导），在 $l^2 < 0$ 的区域指数衰减（波阻）。通常，罗斯贝波被限制在中高纬度，赤道和极地附近为波阻区。

#### （3） 垂直传播（斜压罗斯贝波）

在斜压大气中，罗斯贝波可沿垂直方向传播。采用准地转位涡方程，设 $\psi' = \Psi(z) e^{i(kx+ly-\omega t)}$，可得垂直结构方程：
$$\frac{d^2 \Psi}{dz^2} + m^2 \Psi = 0$$
其中 $m^2 = \frac{N^2}{f_0^2} \left( \frac{\beta}{c - \overline{u}} - k^2 - l^2 \right)$。当 $m^2 > 0$ 时波动可垂直传播，$m^2 < 0$ 时波动被陷（垂直方向指数衰减）。对流层中，罗斯贝波通常呈现相当正压结构（位相随高度变化小），但在平流层可向上传播。

### 5. 罗斯贝波的观测特征

- 冬季中高纬度对流层中上层，500 hPa 位势高度图上，常有 3–5 个长波槽脊绕纬圈分布，自西向东缓慢移动（或准静止）。
- 超长波（波数 1–2）通常准静止或缓慢西退，与地形和热力强迫有关。
- 长波槽前对应暖平流和上升运动，槽后对应冷平流和下沉运动；槽脊的发展与温度平流的垂直变化密切相关（斜压发展）。
- 阻塞高压和切断低压是罗斯贝波强烈非线性发展的产物，可维持数天至数周，造成异常天气。

### 6. 滤波条件（如何滤除罗斯贝波）

- 忽略 $\beta$ 效应（$f$ 取常数 $f_0$）→ 无罗斯贝波。
- 不考虑涡旋运动（无涡度方程）→ 无罗斯贝波。
- 正压无辐散条件下，罗斯贝波是唯一的慢波；引入水平辐散后，会同时产生重力惯性波和罗斯贝波，但准地转近似可滤掉快波而保留罗斯贝波。

## 小结

| 项目 | 内容 |
| :--- | :--- |
| 恢复力 | $\beta$ 效应（$f$ 随纬度变化） |
| 控制方程 | $\frac{d}{dt}(\zeta+f)=0$（正压无辐散） |
| 频散关系 | $\omega = \overline{u}k - \frac{\beta k}{k^2+l^2}$ |
| 相速度（相对基本气流） | $c_{px} - \overline{u} = -\frac{\beta}{k^2+l^2} < 0$（西传） |
| 群速度 | $c_{gx} = \overline{u} + \beta\frac{k^2-l^2}{(k^2+l^2)^2}$，可正可负 |
| 静止波长 | $L_s = 2\pi\sqrt{\overline{u}/\beta}$ |
| 典型尺度 | 数千公里，慢波（几米/秒） |
| 重要天气意义 | 控制中纬度大尺度环流演变，上游效应，阻塞形势 |

罗斯贝波是动力气象学的核心内容之一，它解释了中纬度天气尺度系统（如槽脊）的形成和移动规律，也是数值天气预报中需要准确模拟的关键波动。
