# 动力气象学习题4参考答案

**一、名词解释（每题5分，共50分）**

1、设在 $z$ 处的某一物理属性 $s$ 的平均值为 $\bar{s}(z)$，在 $z+l$ 处为 $\bar{s}(z+l)$，

$$s'=s(z+l)-\bar{s}(z+l)=\bar{s}(z)-\bar{s}(z+l)=-l\dfrac{\partial \bar{s}}{\partial z}$$

则湍流粘性力项如

$$-\rho\overline{u'w'}=\rho w'l\dfrac{\partial \bar{u}}{\partial z},\quad\Rightarrow-\rho\overline{u'w'}=\rho c l^2\left|\dfrac{\partial \bar{u}}{\partial z}\right|\dfrac{\partial \bar{u}}{\partial z}$$

如果定义涡动粘性系数

$$k_m=\bar{l}^2\left|\dfrac{\partial \bar{u}}{\partial z}\right|,\ \text{则有：}\ -\rho\overline{u'w'}=\rho k_m\dfrac{\partial \bar{u}}{\partial z},\ -\rho\overline{v'w'}=\rho k_m\dfrac{\partial \bar{v}}{\partial z}$$

2、水平气压梯度力，水平科氏力和离心力三力平衡。

3、在低纬或赤道地区，取 $f=\beta y=\dfrac{2\Omega}{a}y$。

4、力管是等压面和等容面的相交构成的管子，可以产生新环流或使原有环流加强或减弱的动力作用。

5、罗斯贝数 $R_o=\dfrac{U}{fL}$ 是水平惯性力与水平科里奥利力之比。

6、包辛内斯克近似是针对大气密度所做的近似，在水平运动方程中的气压梯度力项，其密度扰动可以忽略，用其平均值代替；在垂直运动方程中，与浮力相关的密度扰动要加以考虑，不能忽略；在连续性方程中，大气密度扰动的个别变化项可以忽略；但热力学能量方程中，由密度扰动引起的能量变化与由于温度扰动变化引起的能量变化或者由于气压扰动变化引起的能量变化具有相同量级，不能忽略。

7、重力内波是指大气内部的不连续界面上（例如：密度不连续的锋面附近），在重力作用下产生的波动。

8、实际风与地转风的矢量差为地转偏差，即：$\vec{V}'=\vec{V}_h-\vec{V}_g$。地转偏差的方向与水平加速度的方向垂直，背对地转偏差的方向而立，在北半球，加速度方向指向右；（或面朝加速度的方向而立，地转偏差的方向在其左）。（2）地转偏差的存在使气流有穿越等压线的运动，则气压梯度力对空气微团做功，使其动能发生变化。（3）大气的垂直运动主要是由地转偏差散度造成的。

9、在正压大气中，由于平均纬向气流的水平切变引起的大气长波扰动发展的动力机制，称为正压不稳定。正压不稳定必要条件是平均气流的绝对涡度梯度在区域中的某些地方必须为零。

10、自然坐标系：以流点的轨迹为坐标轴 $S$，在轨迹上任意取一点为坐标原点。两个坐标轴 $(\vec{s},\vec{n})$ 在水平面内，标架方向 $\vec{s}$ 与流点的运动方向一致。另一标架方向 $\vec{n}$，它与 $\vec{s}$ 垂直并指向运动方向的左方。

2、参考答案：

大气的可压缩性是产生声波的内在条件，辐合辐散交替变化是声波传播的机制；惯性重力波是在重力和旋转共同作用下产生的，水平辐合辐散交替变化是惯性重力波传播的机制；惯性重力外波需要自由表面，惯性重力内波需要层结。
