# 动力气象学习题7参考答案

**一、名词解释（每题5分，共50分）**

1. 湿静能是湿空气的内能，压力能，位能加潜热能。

2. 一个气层内上下两层地转风的矢量差称其为该气层内的热成风。

3. 小参数展开法：利用摄动法求方程的渐进解，通常要将物理方程和定解的条件无量纲化，在无量纲方程中选择一个描述物理特征的无量纲小参数做摄动量，然后假设其解析解可按小参数展开为幂级数，并将其代入无量纲方程后，可得到各级近似方程，求得有效的解析解。

4. 斜压大气：空气的密度不仅是气压的函数，而且还是其它物理量的函数，这样的大气称为斜压大气。

5. 罗斯贝参数：$\beta = \dfrac{df}{dy} = \dfrac{2\Omega\cos\varphi_0}{a}$。当不被微分处于系数地位时，$f = f_0$；当处于微分地位时，$f = f_0 + \beta y$。

6. 自然坐标系：以流点的轨迹为坐标轴，在轨迹上任意取一点为坐标原点。两个坐标轴 $(s, n)$ 在水平面内，$s$ 方向与流点的运动方向一致，$n$ 方向与轨迹垂直并指向运动方向的左方。

7. 惯性重力波是在重力和旋转共同作用下产生的，水平辐合辐散交替变化是惯性重力波传播的机制；惯性重力外波需要自由表面，惯性重力内波需要层结。

8. 惯性平衡：科氏力与惯性离心力平衡。

9. 在具有垂直切变基流中产生的长波不稳定称为斜压不稳定。由斜压不稳定产生的斜压长波发展的能源主要来自基本气流的有效位能，也可部分来自基本气流的动能。斜压不稳定的充分和必要条件是：$|\overline{U}| > U_c$ 和 $k^2 < \lambda^2$（或 $L > L_c$），其中 $L_c$ 是临界波长，$U_c$ 为临界垂直切变，$\lambda^2 = \dfrac{f_0^2}{c_e^2}$。

10. 依据描述其运动状态的动力学变量和热力学物理量的特征值，来估计大气运动方程中各项量级大小，并对方程进行分析和简化的有效方法。

**二、回答问题（每题10分，共40分）**

1. 包辛尼斯克近似是针对大气密度所做的近似。在水平运动方程中的气压梯度力项，其密度扰动可以忽略，用其平均值代替；在垂直运动方程中，与浮力相关的密度扰动要加以考虑，不能忽略；在连续性方程中，大气密度扰动的个别变化项可以忽略；但热力学能量方程中，由密度扰动引起的能量变化与由于温度扰动变化引起的能量变化或者由于气压扰动变化引起的能量变化具有相同量级，不能忽略。

包辛尼斯克近似可以滤掉声波；因在此近似下流体是不可压的，从而将声波的产生机制去掉了。

2. 绝热、无摩擦、位涡度守恒。$\dfrac{d}{dt}\left(\dfrac{\partial \theta}{\partial p}\right) = 0$，或 $\dfrac{d}{dt}\left(\dfrac{\partial \theta}{\partial \varphi}\right) = 0$。

假定山脉为南北走向，初始为均匀西风，设地面附近的等位温面与地面平行。而高空大气，受地形影响较小，等位温面几乎是水平。因为绝热，两等位温面之间的位温差不改变。

(a) 涡度：$\zeta + \beta y = f_0\left(\dfrac{\delta p}{\delta p_0} - 1\right) < 0$，初始：$y = y_0, \zeta = 0, f = f_0, \delta p = \delta p_0$。

(b) 迎风坡和背风坡：$\delta p < \delta p_0$，$f_0\left(\dfrac{\delta p}{\delta p_0} - 1\right) < 0$ 总为负涡度。若 $y < y_0$，则 $-\beta(y - y_0) > 0$，正涡度。若 $y > y_0$，则 $-\beta(y - y_0) < 0$，负涡度。

(c) 过山后：$\delta p = \delta p_0, \zeta = -\beta(y - y_0)$。如果 $y < y_0$，则有 $-\beta(y - y_0) > 0$ 正涡度。如果 $y > y_0$，则有负涡度。

3. 正压大气中的罗斯贝波是由绝对涡度守恒控制的一种大尺度涡旋性慢波，具有准地转效应。罗斯贝波相对于基本气流向西传播，$\beta$ 效应是其得以传播的主要机制。

4. 任何一个物理量可以看成由已知的基本量和迭加在其上的微扰动量组成。即物理量 $q$ 可以写成：$q = \bar{q} + q'$，其中 $\bar{q}$ 表示物理量 $q$ 的基本物理量，$q'$ 表示 $q$ 的小扰动量。基本量满足原来的基本方程和边界条件。小扰动量相对于基本量是一个小量（$q' \ll \bar{q}$），因此小扰动量及其导数的二次乘积在方程和边界条件中，可以作为高阶小量而略去。

**六、参考答案：**

（1）如果以科氏力的尺度为标准，将水平运动方程无量纲化，有

$$
\begin{cases}
Ro\left(\dfrac{\partial u_g}{\partial t} + u_g\dfrac{\partial u_g}{\partial x} + v_g\dfrac{\partial u_g}{\partial y}\right) = -\dfrac{\partial \phi}{\partial x} - \dfrac{1}{f_0} v_g\\[6pt]
Ro\left(\dfrac{\partial v_g}{\partial t} + u_g\dfrac{\partial v_g}{\partial x} + v_g\dfrac{\partial v_g}{\partial y}\right) = -\dfrac{\partial \phi}{\partial y} + \dfrac{1}{f_0} u_g
\end{cases}
$$

如果上式中 $Ro \ll 1$，即科氏力和气压梯度力是大项，而加速度和摩擦力是小项，这种力的平衡就称为准地转平衡。（5分）

（2）相应的准地转方程组为

$$
\begin{cases}
\dfrac{\partial u_g}{\partial t} + u_g\dfrac{\partial u_g}{\partial x} + v_g\dfrac{\partial u_g}{\partial y} = -\dfrac{\partial \phi}{\partial x}\\[6pt]
\dfrac{\partial v_g}{\partial t} + u_g\dfrac{\partial v_g}{\partial x} + v_g\dfrac{\partial v_g}{\partial y} = -\dfrac{\partial \phi}{\partial y}\\[6pt]
\dfrac{\partial \phi}{\partial p} = \dfrac{RT}{p}\\[6pt]
\dfrac{\partial u_g}{\partial x} + \dfrac{\partial v_g}{\partial y} + \dfrac{\partial \omega}{\partial p} = 0\\[6pt]
\left(\dfrac{\partial}{\partial t} + u_g\dfrac{\partial}{\partial x} + v_g\dfrac{\partial}{\partial y}\right)\left(\dfrac{1}{f_0}\nabla^2 \phi\right) + \beta v_g = f_0\dfrac{\partial \omega}{\partial p}
\end{cases}
$$

其中 $u_g = -\dfrac{1}{f_0}\dfrac{\partial \phi}{\partial y}$，$v_g = \dfrac{1}{f_0}\dfrac{\partial \phi}{\partial x}$。（10分）
